#+TITLE: Ergonomics
#+DESCRIPTION: How Jotain reduces modifier chords with repeat maps and a few global rebindings.

* Ergonomics
:PROPERTIES:
:CUSTOM_ID: ergonomics
:END:

Long sessions strain the fingers that hold modifiers. Protesilaos Stavrou's [[https://protesilaos.com/keeb/][keyboard writing]] argues for one-shot modifiers, where a modifier is tapped and not held. Most of that lives in keyboard firmware. The Emacs side is =repeat-mode=, described in [[info:emacs#Repeating]].

=repeat-mode= is enabled by the =newcomers-presets= theme, and =init-core.el= sets =repeat-exit-timeout= to 2 seconds. After a command with a repeat map, the bare trailing keys keep running related commands until another key is pressed or the timeout passes. For example =M-o o o O= cycles windows, =C-/ u u= undoes repeatedly, and =M-g n n p= steps through errors. =M-x describe-repeat-maps= lists every map.

Jotain adds =jotain-window-layout-repeat-map= under =C-x W=, which repeats the =window-layout-*= commands, so =C-x W r r r= keeps rotating the window tree. To add a map, define it with =defvar-keymap= and =:repeat t= in =lisp/init-keys.el= or in the module that owns the commands.

Other choices: =M-o= is =other-window=, =C-z= and =C-x C-z= are unbound, and Shift with the arrow keys moves between windows. Emacs also ships =modifier-bar-mode=, a tool-bar widget for one-shot modifiers. It is off because Jotain hides the tool bar; enable both modes to try it.
