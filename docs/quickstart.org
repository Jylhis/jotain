** Launch from a checkout
:PROPERTIES:
:CUSTOM_ID: quickstart-launch
:END:

Use an =x86_64-linux= machine with Nix (with the =nix-command= and =flakes= features), Git and a graphical session:

#+begin_src bash
git clone https://github.com/Jylhis/jotain.git
cd jotain
nix develop
just run-built
#+end_src

The recipe builds Emacs and starts it with the checkout as the init directory, so your =~/.emacs.d= is bypassed. The first build downloads the Nix closure and may compile Emacs when the binary cache cannot supply it. Trial state such as the native compilation cache and the review queues goes under =var/= in the checkout, and packages that Nix does not provide are installed under =elpa/=. =nix run github:Jylhis/jotain= starts the same configuration without a checkout, with its init directory in =${XDG_STATE_HOME:-~/.local/state}/jotain=. [[file:installation.org][Installation]] and [[file:launching.org][Launching Emacs]] cover an installed daemon.

** Review your first file
:PROPERTIES:
:CUSTOM_ID: quickstart-review
:END:

Use an existing Git checkout, or make a small one in a shell:

#+begin_src bash
trial_repo="$(mktemp -d)"
git -C "$trial_repo" init
printf '# Sample project\n' > "$trial_repo/example.md"
git -C "$trial_repo" add example.md
printf '%s/example.md\n' "$trial_repo"
#+end_src

1. In Emacs, press =C-x C-f= and open the printed path to =example.md=.
2. Press =C-x g= to open Magit and see the staged file. =C-x b= returns to the =example.md= buffer.
3. Press =C-x p R= to open the review queue of the project. Put point on the file's headline and press =RET= to open the file read-only. Back in the queue, press =t= and select =DONE= to record your progress.

The review state is saved in the queue. [[file:review.org][Whole-repo review queue]] covers notes and pull requests.

** Find help or diagnose a launch
:PROPERTIES:
:CUSTOM_ID: quickstart-help
:END:

- =C-h i d m Jotain RET= opens this manual inside Emacs.
- [[file:keybindings.org][Keybindings]] lists the other project and editing commands.
- If startup reports an init error, run =just run-built-debug=, or =just run-built --debug-init=, which passes its arguments on to Emacs.
- To try a daemon next to an existing one, start a named daemon as described in [[file:launching.org][Launching Emacs]].
