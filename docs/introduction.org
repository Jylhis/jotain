* Introduction
:PROPERTIES:
:CUSTOM_ID: introduction
:END:

Jotain is Finnish for "something". It is a GNU Emacs 31 configuration (the floor is Emacs 31.1) with a Nix build layer. No framework such as Doom or Spacemacs lies underneath. Nix builds the editor and its packages, and modular Emacs Lisp configures it, one file per concern.

The repository holds:

- The Emacs Lisp configuration: =early-init.el=, =init.el= and =lisp/init-*.el=.
- A Nix flake that builds Emacs with its packages, every tree-sitter grammar from nixpkgs and this manual.
- A development shell with linters, language servers and documentation tools. It has no Emacs; =just run-built= builds and launches it.
- A Home Manager module that runs Jotain as a user daemon, and a NixOS module that installs it.

The configuration follows a few rules that show up throughout the manual:

- A package that only enhances a built-in lives in the same file as that built-in (=dirvish= with =dired=, =magit= with =vc=).
- User options are set with =setopt=, so =:set= callbacks and type checks run. See [[info:elisp#Setting Variables]].
- The configuration uses Emacs 31 features directly, with native compilation, tree-sitter modes and the built-in =use-package=.

[[file:installation.org][Installation]] explains how to run it. The source is at [[https://github.com/Jylhis/jotain][github.com/Jylhis/jotain]].
