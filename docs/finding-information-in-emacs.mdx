## The self-documenting editor

The starting point is always the Help prefix, `C-h`. If you remember nothing else, remember
`C-h C-h`: it lists every help command.


## 1. The Help system (`C-h`)

Press `C-h` and pause, and `which-key` shows the available subcommands. `C-h C-h` (or `C-h ?`) runs
`help-for-help`, the meta-help menu; `C-h C-q` (`help-quick-toggle`) toggles a cheat sheet of
common commands.

<Note>
Jotain rebinds several help keys to [`helpful`](https://github.com/Wilfred/helpful), which shows
richer buffers (source, callers, references): `C-h f` → `helpful-callable`, `C-h v` →
`helpful-variable`, `C-h k` → `helpful-key`, `C-h F` → `helpful-function`, `C-h C` →
`helpful-command`, and `C-h o` / `C-h .` → `helpful-symbol` / `helpful-at-point`. The stock
commands below are still available via `M-x`.
</Note>

### The essential eight

`C-h f` (`describe-function`) documents a function, with completion. `C-h v`
(`describe-variable`) shows a variable's documentation and current value. `C-h k` (`describe-key`)
tells you what command a key sequence runs. `C-h o` (`describe-symbol`) combines function,
variable, and face docs for a symbol. `C-h m` (`describe-mode`) describes the major mode and all
active minor modes. `C-h b` (`describe-bindings`) lists every active binding in the buffer. `C-h x`
(`describe-command`) is `C-h f` restricted to interactive commands. `C-h w` (`where-is`) tells you
which keys run a command.

### More help commands

`C-h c` (`describe-key-briefly`) shows a key's command in the echo area. `C-h a`
(`apropos-command`) finds commands matching a pattern; `C-h d` (`apropos-documentation`) searches
docstrings. `C-h i` (`info`) opens the Info browser, `C-h r` the Emacs manual, `C-h R` any manual
by name, and `C-h S` (`info-lookup-symbol`) the symbol at point in the language's manual. `C-h K`
(`Info-goto-emacs-key-command-node`) finds a key in the Emacs manual; stock Emacs has
`Info-goto-emacs-command-node` on `C-h F`, which Jotain gives to helpful.

For orientation: `C-h t` (`help-with-tutorial`), `C-h p` (`finder-by-keyword`) to browse packages by
category, `C-h P` (`describe-package`), `C-h l` (`view-lossage`) for your recent keystrokes, and
`C-h e` (`view-echo-area-messages`) for the message history. `C-h n` (`view-emacs-news`) shows
release notes. The internationalization helpers are `C-h I` (`describe-input-method`), `C-h L`
(`describe-language-environment`), and `M-x describe-coding-system` (stock `C-h C`).

### Built-in documents

`C-h t` is the tutorial (20+ languages), `C-h n` (or `C-h C-n`) the release notes, `C-h C-f` the
FAQ, `C-h C-p` known problems, `C-h C-d` how to debug Emacs, `C-h C-a` version, license, and
credits, and `C-h h` the HELLO file of script samples. Printable reference cards live in
`etc/refcards/`.

### Navigating Help buffers

In a `*Help*` buffer, `TAB` / `S-TAB` move between links and `RET` follows one. `s` jumps to the
source of the described item, `i` looks it up in the Info manual, `I` in the Elisp Reference
Manual, and `c` customizes a variable or face. `l` / `r` go back and forward, `n` / `p` move
between help pages, and `q` quits. (`helpful` buffers use their own keys; the source is shown
inline.)

`s` is the fastest path from "what does it do?" to "how does it work?"


## 2. The describe family

The essential eight are above. The rest, grouped by what they inspect:

### Code

`describe-function` shows the docstring, arglist, type, keybindings, source file, and
obsolescence. `describe-variable` shows the value, docstring, buffer-local and
safe-local-variable status, and custom type. `describe-symbol` combines both plus face docs;
`describe-command` limits `describe-function` to interactive commands.

### Keys and bindings

`describe-key` documents the command bound to a key; `describe-key-briefly` just names it.
`describe-bindings` lists all active bindings (minor mode, major mode, global). `describe-keymap`
shows one named keymap. `describe-prefix-bindings` shows what follows a prefix: `C-x C-h` lists
everything after `C-x`, and the same works for `C-c C-h`, `M-g C-h`, and so on.
`describe-personal-keybindings` shows the `bind-key` / `use-package :bind` overrides. Jotain also
binds `C-h B` to `embark-bindings`, a searchable list of the current bindings.

### Modes

`describe-mode` shows the major mode plus active minor modes. `describe-minor-mode` documents one
minor mode; `describe-minor-mode-from-indicator` identifies one from its mode-line lighter.

### Text and display

`describe-char` tells you everything about the character at point: code point, properties,
overlays, face, and font. `describe-text-properties` shows the text properties at point.
`describe-face` gives a face's attributes, `describe-font` font metrics, and `describe-fontset`
which fonts cover which character ranges. `describe-syntax` shows the syntax table,
`describe-categories` the category table, `describe-char-fold-equivalences` a character's fold
equivalents, `describe-buffer-case-table` the case conversion rules, and
`describe-current-display-table` how characters render.

### International

`describe-coding-system` (encodings such as UTF-8 or latin-1), `describe-current-coding-system`
(the buffer's or process's active encoding), `describe-input-method`,
`describe-language-environment` (charsets, encodings, input methods, samples), and
`describe-character-set`.

### Packages, themes, widgets

`describe-package` (metadata, dependencies, status), `describe-theme`, `describe-widget` (widget
and button properties at point), and `describe-icon`.


## 3. Apropos, finding what you don't know the name of

When you don't know the exact name, apropos searches by pattern.

`apropos-command` (`C-h a`) searches interactive command names. `apropos-documentation` (`C-h d`)
searches docstrings. `apropos-user-option` searches `defcustom` names. Via `M-x`: `apropos`
(functions, variables, and faces), `apropos-function` (including non-interactive functions),
`apropos-variable`, `apropos-value` (values of variables and function definitions),
`apropos-library` (symbols defined in one library), and `apropos-local-variable` /
`apropos-local-value` (buffer-local variables and values).

### Pattern syntax

A single word like `"buffer"` matches any name containing it. Several words like
`"buffer read only"` match symbols containing at least two of them. A pattern containing any of
`^$*+?.\[` is a regular expression. Synonyms also match, so "find" matches "open" and "edit"
(`apropos-synonyms`).

### Examples

`C-h a font` finds commands with "font" in the name. `C-h d overlay` finds symbols whose docstring
mentions "overlay". `M-x apropos-library RET python` lists everything defined in python.el.
`M-x apropos-value RET "utf-8"` finds variables whose value contains "utf-8".

### Reading apropos output

Each result shows the clickable symbol name, type indicators (`c` command, `f` function, `m` macro,
`v` variable, `u` user option, `a` face), key bindings, and the first docstring line.


## 4. The Info reader, structured manuals

Info is the primary documentation format for GNU software. Emacs ships the Emacs Manual, the Emacs
Lisp Reference Manual, and dozens of subsystem manuals.

### Opening Info

`C-h i` opens the directory of all manuals, `C-h r` the Emacs Manual, and `C-h R` a manual by name.
`C-h K` finds a key's section in the Emacs manual, and `C-h S` looks up a symbol in the
language's manual.

### Navigation

`n` / `p` move to the next and previous node at the same level, `u` to the parent. `]` / `[` move
in reading order, into children. `m` picks a menu item and `f` follows a cross-reference, both with
completion. `l` / `r` go back and forward, `SPC` / `DEL` scroll, `d` goes to the Info directory, and
`q` quits.

### Searching

`i` searches the manual's index, the best way to find a specific item; `,` jumps to the next index
match. `I` builds a virtual index of all matching index entries. `s` searches the full text (in
Jotain, `consult-info`, which searches across manuals). `M-x info-apropos` searches the indices of
every installed manual.

Prefer index search (`i`) over text search: the index is curated and points to the most relevant
section, while text search finds every mention.

### `info-lookup-symbol` (`C-h S`)

Underused and language-aware: in an Elisp buffer it searches the Elisp Reference Manual index, in a
C buffer the C library manual, and in a Python buffer the Python manual (if installed). With point
on `mapcar` in Elisp, `C-h S RET` opens the Elisp manual at its definition.

### Available manuals

`C-h R TAB` lists the installed manuals. A typical Emacs 30 install includes Emacs, Elisp, Org,
Gnus, Tramp, CC Mode, Eglot, Flymake, use-package, ERT, Calc, Ediff, Info, ERC, Eshell, and more.

### The Jotain manual

Jotain ships its own Info manual, `(jotain)`. `C-h i d m Jotain RET` opens it: installation, the
module layout, the Nix build layer, and the Nix module option reference. `M-x consult-info`
(`C-c i`) includes it in cross-manual search. Nix-installed distributions put it on `INFOPATH`; in
a source checkout, `just info` builds `result-info/` and `init-docs.el` picks it up.


## 5. Automatic and contextual help

### ElDoc

ElDoc shows function signatures and variable docs in the echo area as you type; it is on by default
(`global-eldoc-mode`). While typing `(mapcar |)`, the echo area shows `mapcar: (FUNCTION SEQUENCE)`.
`eldoc-idle-delay` sets the delay (default 0.5 s), `eldoc-echo-area-use-multiline-p` controls
multi-line display, and `M-x eldoc-doc-buffer` shows full docs in a buffer.

### which-key

Pause after a prefix key like `C-x` and a popup lists the continuations with descriptions; it is
built into Emacs 30. `which-key-idle-delay` sets the delay (default 1.0 s) and
`which-key-popup-type` the display (minibuffer, side window, or frame).
`M-x which-key-show-major-mode` shows the major mode's bindings, and
`M-x which-key-show-minor-mode-keymap` a minor mode's.

### Completion annotations

With completion (`M-x`, `C-h f`, `C-h v`), each candidate shows a type indicator and the first line
of its docstring, so typing a partial name doubles as browsing what exists.

Jotain filters `M-x` candidates with `read-extended-command-predicate` set to
`command-completion-default-include-p` (in `init-core`). A command tagged with modes after its
`interactive` spec, e.g. `(interactive nil foo-mode)` or `(interactive "p" foo-mode bar-mode)`,
only appears when one of those modes is active. Untagged commands always appear, and typing a full
command name runs it regardless. Two stricter predicates ship with Emacs:
`command-completion-using-modes-and-keymaps-p` (only commands tied to active modes or keymaps) and
`command-completion-using-modes-p` (only commands tagged for an active mode).

### Help at point

`C-h .` (`display-local-help`) shows the `help-echo` text at point, which buttons, links, and
mode-line indicators carry. In Jotain it runs `helpful-at-point` instead, which describes the
symbol at point.


## 6. Source code navigation

### find-function family

`find-function` and `find-variable` (each with an `-other-window` variant) open a definition.
`find-face-definition` finds a face's, `find-library` opens a library by name,
`find-function-on-key` finds the command on a key, and `find-function-at-point` /
`find-variable-at-point` use the symbol at point. In a `*Help*` buffer, `s` jumps to source.

### xref (cross-reference framework)

`M-.` (`xref-find-definitions`) jumps to a definition, `M-?` (`xref-find-references`) finds
references, `M-,` (`xref-go-back`) returns, and `C-M-,` (`xref-go-forward`) goes forward again.
`M-x xref-find-apropos` finds definitions matching a regexp. Backends include etags, Eglot/LSP, and
grep.


## 7. Shortdoc, function groups by topic

`M-x shortdoc` shows common functions grouped by topic, each with its signature, a description,
and live examples. Emacs 30 groups include `string`, `list`, `alist`, `sequence` (`seq-map`,
`seq-filter`, `seq-reduce`, …), `number`, `vector`, `regexp`, `buffer`, `process`, `file-name`,
`file`, `hash-table`, `keymaps`, `text-properties`, `overlay`, `symbol`, `comparison`, and `map`.


## 8. Customization browser

`M-x customize` doubles as a documentation browser: every `defcustom` shows its type, valid values,
default, and description.

`customize` shows the top-level groups, `customize-browse` a tree of all groups, `customize-group`
one group, `customize-variable` one option, and `customize-face` a face with preview.
`customize-apropos` finds options by pattern (`customize-apropos-faces` and
`customize-apropos-groups` for faces and groups). Browsing groups like `programming`, `editing`,
and `convenience` in `customize-browse` reveals features you didn't know existed.


## 9. Search-based discovery

### In the current buffer

`C-s` / `C-r` (`isearch-forward` / `isearch-backward`) search incrementally, `C-M-s`
(`isearch-forward-regexp`) by regexp, and `M-x occur` lists matching lines in a clickable buffer.
Jotain adds `M-s l` (`consult-line`).

### Across files

`M-x grep`, `M-x rgrep` (recursive, with directory and file filters), and `M-x lgrep` (one
directory) produce clickable result buffers. `C-x p g` (`project-find-regexp`) searches the current
project and `C-x p f` (`project-find-file`) finds files in it. Jotain adds `M-s r`
(`consult-ripgrep`).

### Across buffers

`multi-occur` runs `occur` across several buffers; `multi-occur-in-matching-buffers` across buffers
whose names match a regexp.


## 10. External documentation inside Emacs

### Unix manual pages

`M-x man` shows a man page (needs the external `man`); `M-x woman` ("WithOut Man") needs nothing
external. Both render hyperlinked output. Jotain binds `C-c m` to `consult-man`.

### Web browsing

`M-x eww` opens a URL or searches the web; `M-x eww-open-file` opens a local HTML file.

### Package discovery

`C-h p` (`finder-by-keyword`) browses packages by keyword, `M-x list-packages` lists all available
packages, and `C-h P` (`describe-package`) documents one.


## 11. Runtime introspection

### Evaluate any expression

`M-:` (`eval-expression`) evaluates any Elisp expression, so you can query anything:

```elisp
;; What mode is this buffer in?
M-: major-mode RET

;; What's the value of a variable?
M-: tab-width RET

;; What key runs a command?
M-: (where-is-internal 'save-buffer) RET

;; What command is on a key?
M-: (key-binding (kbd "C-x C-s")) RET
```

### Debugging as discovery

`debug-on-entry` steps through a function. `debug-on-variable-change` breaks when a variable
changes, to find who mutates it. `trace-function` logs every call with arguments and return
values. `edebug-defun` instruments a function for stepping with breakpoints. `profiler-start` /
`profiler-report` profile CPU and memory.

### Observing recent activity

`C-h l` (`view-lossage`) shows recent keystrokes and commands; `C-h e`
(`view-echo-area-messages`) shows recent `message` output.


## 12. Elisp introspection functions

The building blocks, for `M-:`, `*scratch*`, or batch mode.

### Documentation

```elisp
;; Get a function's docstring
(documentation 'mapcar t)

;; Get a variable's docstring
(documentation-property 'tab-width 'variable-documentation)

;; Get the arglist of a function
(help-function-arglist 'mapcar)
;; → (FUNCTION SEQUENCE)
```

### Finding where things come from

```elisp
;; Which file defines a function?
(symbol-file 'python-mode 'defun)
;; → "python"

;; Which file defines a variable?
(symbol-file 'tab-width 'defvar)

;; Is this a C primitive or Elisp?
(subr-primitive-p (symbol-function 'forward-char))  ;; → t (C)
(subr-primitive-p (symbol-function 'forward-sexp))  ;; → nil (Elisp)

;; Is it native-compiled? (Emacs 30; `subr-native-elisp-p' before that)
(native-comp-function-p (symbol-function 'forward-sexp))

;; Where is a library file?
(locate-library "org")
;; → "/path/to/org.elc"
```

### Discovering API surfaces

```elisp
;; Find all functions with a prefix
(apropos-internal "^font-lock-" #'functionp)

;; Find all commands with a prefix
(apropos-internal "^describe-" #'commandp)

;; Find all user options in a prefix
(apropos-internal "^org-" #'custom-variable-p)
```

### Key binding introspection

```elisp
;; What command is on a key?
(key-binding (kbd "C-x C-f"))
;; → find-file

;; What keys run a command?
(where-is-internal 'find-file)
;; → ([24 6] [open] ...)

;; Human-readable:
(mapconcat #'key-description (where-is-internal 'find-file) ", ")
;; → "C-x C-f, <open>, ..."
```

### Symbol properties

```elisp
;; The property list reveals metadata the docs don't mention:
(symbol-plist 'font-lock-mode)
;; Properties like: safe-local-variable, permanent-local, risky-local-variable,
;; side-effect-free, byte-compile, compiler-macro

;; Check if a variable is safe as a file-local variable
(get 'tab-width 'safe-local-variable)

;; Get the customize type (shows all valid values)
(require 'cus-edit)
(custom-variable-type 'font-lock-maximum-decoration)
```

### Feature and capability testing

```elisp
;; Does this Emacs have native compilation?
(featurep 'native-compile)

;; Does it have tree-sitter?
(featurep 'treesit)

;; What features are loaded?
features  ;; → (rmc iso-transl tooltip ...)

;; Build configuration
system-configuration-options
emacs-version
system-type
```

### Simulating a file open

```elisp
;; What mode + minor modes activate for a .py file?
(with-temp-buffer
  (setq buffer-file-name "/tmp/test.py")
  (set-auto-mode)
  (cons major-mode
        (seq-filter (lambda (m) (and (boundp m) (symbol-value m)))
                    minor-mode-list)))
```


## 13. Accessing documentation from outside Emacs

For scripts, CI, and AI agents: batch mode (standalone) or emacsclient (persistent).

### `emacs --batch --eval`

Starts a fresh Emacs without a GUI, user config, or persistent state, evaluates the code, and
exits.

```bash
# Get a function's documentation
emacs --batch --eval '(princ (documentation '\''mapcar t))' 2>/dev/null

# Find what command a key runs
emacs --batch --eval '(princ (key-binding (kbd "C-x C-f")))' 2>/dev/null

# Find what keys run a command
emacs --batch --eval '(princ (mapconcat #'\''key-description (where-is-internal '\''find-file) ", "))' 2>/dev/null

# List all functions matching a prefix
emacs --batch --eval '(princ (mapconcat #'\''symbol-name (apropos-internal "^font-lock-" #'\''functionp) "\n"))' 2>/dev/null

# Get a function's arglist
emacs --batch --eval '(princ (help-function-arglist '\''make-overlay))' 2>/dev/null

# Find where a function is defined
emacs --batch --eval '(princ (symbol-file '\''python-mode '\''defun))' 2>/dev/null

# Check if a feature exists
emacs --batch --eval '(princ (featurep '\''native-compile))' 2>/dev/null

# Get build configuration
emacs --batch --eval '(princ system-configuration-options)' 2>/dev/null

# Simulate opening a file and list active modes
emacs --batch --eval '(progn
  (with-temp-buffer
    (setq buffer-file-name "/tmp/test.py")
    (set-auto-mode)
    (let ((modes (list major-mode)))
      (dolist (m minor-mode-list)
        (when (and (boundp m) (symbol-value m))
          (push m modes)))
      (princ (mapconcat #'\''symbol-name modes "\n")))))' 2>/dev/null

# Load a library first, then query
emacs --batch --eval '(progn
  (require '\''auth-source)
  (princ (documentation '\''auth-source-search t)))' 2>/dev/null
```

### Temp file pattern for large output

When the output is too large for stdout, write it to a file:

```bash
emacs --batch --eval '(with-temp-file "/tmp/emacs-result.txt"
  (dolist (fn (apropos-internal "^overlay-" #'\''functionp))
    (insert (format "%s: %s\n\n" fn (documentation fn)))))' 2>/dev/null

# Then read it
cat /tmp/emacs-result.txt
```

### `emacsclient --eval`

Connects to a running Emacs server: no cold start, and the user config and loaded state are
available.

```bash
# Requires: M-x server-start or emacs --daemon first
emacsclient --eval '(documentation '\''mapcar t)'
emacsclient --eval '(buffer-list)'
```

### Comparison

`emacs --batch --eval` needs no server but pays a cold start (about 0.5-1.0 s), keeps no state
between calls, and loads no user config: best for scripts, CI, and standalone queries.
`emacsclient --eval` starts in about 0.1 s and shares the running Emacs's state and config: best
for interactive workflows.

### Limitations of batch mode

Each invocation is a fresh process, so chain operations in one `(progn ...)`, and batch many
queries into one call to avoid repeated cold starts. Functions that need interactive input fail.
Use `princ` for stdout and `2>/dev/null` to suppress startup messages. Non-default libraries must
be loaded with `(require 'library)` or `--load file.el`.


## 14. What ships with Emacs

### The source code as documentation

Emacs Lisp source documents itself in three ways.

Commentary sections at the top of each file explain the module's purpose and design:

```elisp
;;; Commentary:
;; A grab-bag of basic Emacs commands not specifically related to some
;; major mode or to file-handling.
```

Find them with `M-x find-library`, then search for `;;; Commentary:`.

Docstrings on every function and variable, via `C-h f` / `C-h v` or `(documentation 'symbol t)`.

Defcustom declarations, which show the type, valid values, and group of every user option:

```elisp
(defcustom make-backup-files t
  "Non-nil means make a backup of a file the first time it is saved.
This can be done by renaming the file or by copying. ..."
  :type 'boolean
  :group 'backup)
```

### Key source directories

`lisp/` holds the Elisp standard library: `lisp/progmodes/` the programming modes (`python.el`,
`js.el`), `lisp/emacs-lisp/` the language infrastructure (byte-compiler, cl-lib, seq, map),
`lisp/net/` networking (Tramp, EWW, URL), and `lisp/org/` Org mode. `src/` is the C core: the Lisp
interpreter, display engine, and buffer management. `doc/emacs/`, `doc/lispref/`, and `doc/misc/`
hold the texinfo sources of the Emacs Manual, the Elisp Reference, and the subsystem manuals.
`etc/NEWS*` is the version-by-version changelog.


## Quick reference: "How do I find out about...?"

What a function does: `C-h f function-name`. What a variable controls: `C-h v variable-name`. What a
key does: `C-h k` then the key. What key runs a command: `C-h w command-name`. What this mode
provides: `C-h m`. All current bindings: `C-h b`. Everything about a symbol: `C-h o symbol-name`.

Functions you can't name: `C-h a partial-name` or `C-h d keyword`. A topic in the manual: `C-h i`
then `i topic`. How a function is implemented: `C-h f function-name`, then the source. What
functions exist for X: `M-x shortdoc` or `M-: (apropos-internal "^prefix-" #'functionp)`. What
options exist for X: `M-x customize-group` or `M-x customize-apropos`. What packages do X: `C-h p`
or `M-x list-packages`. What changed in this version: `C-h n`. A Unix command's manual: `M-x man` or
`M-x woman`. What just happened: `C-h l` for keystrokes, `C-h e` for messages. From a script or AI
agent: `emacs --batch --eval '(princ (documentation '\''fn t))' 2>/dev/null`.
