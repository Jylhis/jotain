#+TITLE: Keybindings
#+DESCRIPTION: The global keybindings Jotain adds, organised by prefix, and the mode-local bindings it defines.

* Keybindings
:PROPERTIES:
:CUSTOM_ID: keybindings
:END:

Only global rebindings live in =lisp/init-keys.el=. Per-package bindings sit in the package's =use-package= block. =which-key= is on, so a menu of continuations appears after any prefix key, and =init-keys.el= registers labels for the shared =C-c= and =C-x= prefixes so the menu shows names instead of command names.

** Mode-local bindings
:PROPERTIES:
:CUSTOM_ID: mode-local
:END:

- =dired-mode=: =C-c C-e= enters writable Dired (=wdired-change-to-wdired-mode=).
- Minibuffer: =C-c C-o= runs =embark-export=.
- =dired=, =calc=, =Info= and =ibuffer=: =C-o= opens the =casual= menu of the mode, and =<f2>= does the same during isearch.
- =org-mode=: =C-c b= is the Babel notebook prefix, see [[file:notebooks.org][Notebooks with Org Babel]]. =C-c C-r= is the =verb= HTTP client map.
- =smerge-mode=: =C-c ^ S= re-resolves the file with =mergiraf= (=jotain-vc-mergiraf-solve=) next to the stock =C-c ^= bindings.
- =sops-mode=: =C-c C-c= saves, =C-c C-k= cancels and =C-c C-d= edits the file.
- =kotlin-ts-mode=: =C-c C-t t=, =f= and =p= run the test at point, the test class and the project, =C-c C-t g= goes to the test file, =C-c C-z= opens a REPL, and =C-c C-r= and =C-c C-b= send the region and the buffer to it.

** Embark
:PROPERTIES:
:CUSTOM_ID: embark
:END:

=C-.= opens a menu of actions for the thing at point or the current minibuffer candidate, and =C-;= runs the default action. Press =C-h= after =C-.= for a searchable list of every applicable action. The [[info:embark#Top][Embark manual]] covers actions, export, collect and the rest.

Jotain relies on one combination: from =consult-ripgrep=, =C-. E= (or =C-c C-o=) exports the matches to a grep buffer, and =C-x C-q= (wgrep) makes it editable, so one edit rewrites every match across the files. See [[file:compilation.org][Compilation and grep]].

** Why no leader-key framework
:PROPERTIES:
:CUSTOM_ID: no-leader
:END:

[[https://bicycleforyourmind.com/generaldotel-to-conquer-emacs-keybindings]["general.el to conquer Emacs keybindings"]] argues for [[https://github.com/noctuid/general.el][general.el]] as a leader-key layer. Jotain does not adopt it. Its main feature is =:states= for evil-mode, which Jotain does not use, and =keymap-set=, =which-key= and the =:bind= keyword of =use-package= already cover discoverability. The self-documenting prefixes live in the =which-key= label table in =init-keys.el=.
