# Quickstart

## Clone the repository

```bash
git clone https://github.com/Jylhis/jotain.git
cd jotain
```

## Enter the development shell

The development shell provides the tooling: `just`, `nil`, `nixfmt`, `treefmt` and the other Nix linters, the language servers the config shells out to, the docs tools and the fonts the UI config looks up. Emacs is **not** in the shell; it is built via Nix on demand (see [Launching Emacs](/usage/launching)). Enter the shell with `nix develop` (or `nix-shell`):

```bash
nix develop
```

## Build and run Emacs with the Jotain configuration

```bash
just run-built            # build for the current platform, then launch result/bin/emacs
just run-built-debug      # same, with --debug-init and debug-on-error
```

`just run-built` builds the full distribution (Emacs 31 + packages + tree-sitter grammars, usually a binary-cache pull rather than a compile) and launches `./result/bin/emacs` with `--init-directory=<repo>`, so it never touches `~/.emacs.d`. The first launch installs any package Nix doesn't provide from MELPA; later launches load from the package cache.

[Launching Emacs](/usage/launching) covers the daemon + client pattern and the `emd` / `em` / `emg` shell aliases (`services.jotain.shellAliases`).

## Sanity-check the configuration

```bash
just check          # nix flake check: package builds, Nix linting, docs checks,
                    # elisp paren check, byte-compile (warnings as errors), ERT tests
just test           # build only the elisp-test flake check (ERT tests under test/)
just fmt            # nix fmt: treefmt with nixfmt-rfc-style, deadnix, statix
```

## Clean build artifacts

```bash
just clean          # .elc files, autosaves, var/eln-cache, result*
just clean-all      # also elpa/ and var/ (forces a full re-fetch)
```

## Update pinned sources

`flake.lock` is the single source of truth for input revs.

```bash
just update             # nix flake update
just update-pins        # bump the hand-pinned upstreams (extra packages, ECA, design pin)
```
