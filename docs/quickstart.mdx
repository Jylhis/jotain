# Quickstart

## Go to the configuration

The configuration lives in the jylhis tree. From a checkout:

```bash
cd etc/emacs
```

## Enter the development shell

This configuration ships a [devenv](https://devenv.sh) shell with the tooling: `nil`, `nixfmt`, `treefmt` and the other Nix linters, the language servers the config shells out to, and the fonts the UI config looks up. Emacs is **not** in the shell; it is built via Nix on demand (see [Launching Emacs](/usage/launching)). `just` itself is not in the shell either, so install it separately. No `.envrc` is tracked, so enter the shell manually (or write your own `.envrc`):

```bash
devenv shell
```

## Build and run Emacs with the configuration

```bash
just run-built               # build, then launch result/bin/emacs
just run-built --debug-init  # arguments are passed on to Emacs
```

`just run-built` builds the full distribution (Emacs 31 + packages + tree-sitter grammars, usually a binary-cache pull rather than a compile) and launches `./result/bin/emacs` with `--init-directory=<etc/emacs>`, so it never touches `~/.emacs.d`. The first launch installs any package Nix doesn't provide from MELPA; later launches load from the package cache.

[Launching Emacs](/usage/launching) covers the daemon + client pattern and the `emd` / `em` / `emg` shell aliases (`services.emacsConfig.shellAliases`).

## Sanity-check the configuration

```bash
just test           # every emacs-* check of the tree: Nix linting, docs checks,
                    # elisp paren check, byte-compile (warnings as errors), ERT tests
just fmt            # treefmt with nixfmt-rfc-style, deadnix, statix
```

## Clean build artifacts

```bash
just clean          # .elc files, var/eln-cache, result
```

## Update pinned sources

The tree's nixtamal pins (`nix/tamal/` at the repo root) are the source of truth for nixpkgs and emacs-overlay.

```bash
just update             # at the repo root: bump the tree's pins
just cache-parity       # here: assert the bare builds still match their prebuilt siblings
```
