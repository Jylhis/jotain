# Ergonomics

Long Emacs sessions punish the modifier-holding fingers. Protesilaos
Stavrou's [keyboard ergonomics writing](https://protesilaos.com/keeb/)
argues for replacing **held** modifier chords with **one-shot
modifiers** (tap, then press), so only the fingers typing characters
are under load. Most of Prot's solution lives in keyboard firmware; the
Emacs side of the same idea is **`repeat-mode`** plus a few
`repeat-map`s.

## Repeat-mode: the Emacs-native one-shot

`repeat-mode` (built in since Emacs 28) is enabled in `init-core.el`.
After a command that has a `repeat-map`, the map stays active: the
*bare* trailing keys keep running related commands until you press
anything else or 2 seconds pass (`repeat-exit-timeout`, also set in
`init-core.el`), so no `C-g` is needed.

The everyday wins are built in:

| Type once    | Then keep typing | What happens                  |
| ------------ | ---------------- | ----------------------------- |
| `M-o`        | `o o O`          | Cycle through windows, then back |
| `C-/`        | `u u u`          | Undo, undo, undo              |
| `C-x →`      | `→ →`            | Cycle through buffers         |
| `M-g n`      | `n n p`          | Step through compilation errors |
| `C-x ^`      | `^ ^ v`          | Resize the window, then correct |
| `C-x }`      | `} } {`          | Widen the window, then narrow |

`M-x describe-repeat-maps` lists every map. `shrink-window` (`v`) has
no global key, so it only works once a resize command has started the
map.

## Jotain-specific maps

On Emacs 31+, `lisp/init-keys.el` adds `jotain-window-layout-repeat-map`
under `C-x W`. It repeats the `window-layout-*` commands, so
`C-x W r r r` keeps rotating the whole window tree.

## Extending repeat-maps

Add a `defvar-keymap` with `:repeat t` to `lisp/init-keys.el` (or the
module owning the commands); every command in the map gets its
`repeat-map` property set. For example, paragraph navigation:

```elisp
(defvar-keymap my-paragraph-repeat-map
  :repeat t
  "{" #'backward-paragraph
  "}" #'forward-paragraph)
```

Now `M-{ { {` walks backward through paragraphs without holding Meta.

## Pinky-stretch escape hatches Jotain already takes

- **`M-o` → `other-window`** instead of `C-x o`: one chord, no prefix.
- **`C-z` and `C-x C-z` disabled**: removes a foot-gun and frees `C-z`.
- **`windmove-default-keybindings`**: `Shift-<arrow>` moves between
  windows.
- **macOS `Cmd` → Meta** (`init-core.el`): Meta under the thumb, not the
  pinky.

## Beyond Emacs: the rest of Prot's advice

Most of Prot's recommendations are outside Emacs:

- **Caps Lock → Ctrl** is fine, but reinforces left-pinky overuse.
  Prefer a keyboard with thumb-reachable Ctrl (or remap *both* sides).
- **Split keyboards** (Prot uses an Iris) keep each hand in its natural
  posture and put modifiers under the thumbs.
- **Firmware one-shot mods** (QMK, ZMK) let any key act as a modifier
  for the next press: the hardware analogue of `repeat-mode`.

## Optional: `modifier-bar-mode`

Emacs 30 ships `modifier-bar-mode`, a tool-bar widget: tap
`Ctrl`/`Meta`/`Super`/`Hyper` and it applies to the next keypress, a
clickable one-shot modifier. Jotain hides the tool bar in
`early-init.el`, so it is **off by default**. To try it:

```elisp
(tool-bar-mode 1)
(modifier-bar-mode 1)
```
