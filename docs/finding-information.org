#+TITLE: Finding information
#+DESCRIPTION: How to find documentation inside Jotain: the help commands it rebinds, the bundled manual and the upstream manuals.

* Finding information
:PROPERTIES:
:CUSTOM_ID: finding-information
:END:

Emacs documents itself, and Jotain changes little about that. =init-help.el= binds =C-h f=, =C-h v=, =C-h k=, =C-h F=, =C-h C=, =C-h o= and =C-h .= to the =helpful= variants (see [[file:keybindings.org::#other-global][Keybindings]]), which show source, callers and references in the help buffer. =consult-info= on =C-c i= and =consult-man= on =C-c m= search the Info manuals and man pages with completion.

This manual is installed as Info. Open it with =C-h i d m Jotain RET=. Nix installs put it on =INFOPATH=, and in a source checkout =init-docs.el= adds =JOTAIN_INFO_DIR=, =result-info/share/info= or =result/share/info= (the first that exists) to =Info-additional-directory-list=.

The upstream manuals are the reference for everything else:

- [[info:emacs#Help]] and [[info:emacs#Apropos]] for the help system and searching it.
- [[info:info#Top]] for reading Info.
- [[info:emacs#Xref]] for jumping to definitions and references.
- [[info:elisp#Documentation]] for how documentation strings work.
