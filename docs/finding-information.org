#+TITLE: Finding information
#+DESCRIPTION: How to find documentation inside Jotain: the help commands it rebinds, the bundled manual and the upstream manuals.

* Finding information
:PROPERTIES:
:CUSTOM_ID: finding-information
:END:

Emacs documents itself, and Jotain changes little about that. =init-help.el= binds =C-h f=, =C-h v=, =C-h k=, =C-h F=, =C-h C=, =C-h o= and =C-h .= to the =helpful= variants (see [[file:keybindings.org::#other-global][Keybindings]]), which show source, callers and references in the help buffer. =consult-info= on =C-c i= and =consult-man= on =C-c m= search the Info manuals and man pages with completion.

This manual is installed as Info. Open it with =C-h i d m Jotain RET=. Nix installs put it on =INFOPATH=, and in a source checkout =init-docs.el= adds =JOTAIN_INFO_DIR=, =result-info/share/info= or =result/share/info= (the first that exists) to =Info-additional-directory-list=.

** Commands worth knowing
:PROPERTIES:
:CUSTOM_ID: finding-commands
:END:

- Help prefix: =C-h C-h= lists every help command, and pausing after =C-h= shows the continuations through =which-key=. =C-h m= describes the active modes, =C-h b= lists every active binding, =C-h w= finds the keys of a command and =C-h c= names a key briefly. =C-x C-h= lists everything after =C-x=, and the same works after any other prefix. =C-h B= searches the bindings with =embark-bindings=.
- Apropos: =C-h a= (=apropos-command=) finds commands by pattern, =C-h d= searches docstrings, and =M-x apropos-user-option=, =apropos-value= and =apropos-library= search options, values and the symbols of one library. Several words match symbols that contain at least two of them, and a pattern with any of =^$*+?.\[= is a regular expression.
- Info: =C-h i= opens the directory of manuals, =C-h r= the Emacs manual and =C-h R= a manual by name. =C-h S= (=info-lookup-symbol=) opens the manual entry of the symbol at point, in the manual of the language of the buffer. Inside Info, =i= searches the index of a manual, which beats a text search because the index is curated, and =M-x info-apropos= searches the indices of every installed manual. Jotain remaps text search to =consult-info=, which searches across manuals.
- Help buffers: in a =*Help*= buffer, =s= jumps to the source, =i= and =I= look the item up in the Emacs and Elisp manuals, and =c= customizes a variable or face. =helpful= buffers show the source inline.
- Source: =M-.= (=xref-find-definitions=), =M-?= (=xref-find-references=) and =M-,= (=xref-go-back=). =find-function=, =find-variable= and =find-library= open a definition by name.
- Search: =M-s l= runs =consult-line= and =M-s r= runs =consult-ripgrep=. =C-x p g= (=project-find-regexp=) searches the project.
- Elisp: =M-x shortdoc= shows functions grouped by topic with live examples, =M-:= evaluates an expression, and =M-x customize-browse= browses every option by group.

ElDoc shows signatures and variable documentation in the echo area as you type, and =M-x eldoc-doc-buffer= shows the full text in a buffer. =M-x= hides commands that are tagged for modes that are not active (=read-extended-command-predicate= is =command-completion-default-include-p=). Untagged commands always appear, and typing a full command name runs it regardless.
