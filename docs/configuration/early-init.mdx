# early-init.el

`early-init.el` is loaded before `package.el` runs, before the first frame is drawn, and before `init.el`. Only what *must* happen that early lives here; everything else is in `init.el` or a `lisp/init-*.el` module.

## Garbage collection

GC is effectively off during startup; `init-core` restores a 16 MiB runtime value.

```elisp
(setq gc-cons-threshold most-positive-fixnum
      gc-cons-percentage 0.6)
```

## Bidirectional text

Jotain targets LTR-only text, so bidi reordering and the bidi parenthesis algorithm are disabled; they otherwise run on every redisplay and cost time in large files.

```elisp
(setq-default bidi-display-reordering nil
              bidi-paragraph-direction 'left-to-right)
(setopt bidi-inhibit-bpa t)
```

## Load preference

Prefer newer source files over stale `.elc` only in batch mode. Interactive sessions skip the mtime check.

```elisp
(setq load-prefer-newer noninteractive)
```

## package.el and use-package

`package.el` stays on with `package-quickstart` enabled; Nix already puts most packages on `load-path`. Before `init.el` loads, only imenu support and `use-package-always-ensure` are configured.

```elisp
(setq package-quickstart-file
      (expand-file-name "var/package-quickstart.el" user-emacs-directory)
      package-quickstart t)
(setq use-package-enable-imenu-support t
      use-package-always-ensure t)
```

`package-quickstart-file` **must** be pinned here, not in `init.el`: `startup.el` runs `package-activate-all` between `early-init.el` and `init.el`, using whatever path the variable holds at that moment. The default path is outside `var/`, so without the pin quickstart is never loaded but still pays its refresh cost on every `package-install`.

The quickstart file caches absolute `/nix/store` load-path entries, so `early-init.el` deletes it whenever a hash of `EMACSLOADPATH` (stored in `var/package-quickstart.gen`) changes. Otherwise a redeploy could activate stale package versions.

With `use-package-always-ensure` set to `t`, every `use-package` block installs its package if missing. Built-ins must opt out with `:ensure nil`.

Setting `JOTAIN_PROFILE_STARTUP` turns on `use-package-compute-statistics`, so `M-x use-package-report` shows per-block timings.

### Silencing a quickstart false-positive

`package-quickstart-refresh` (run after every `package-install`) re-calls `package-initialize`, which trips the "Unnecessary call to `package-initialize` in init file" warning. That internal call can't be told apart from a user one, so the warning type is suppressed:

```elisp
(with-eval-after-load 'warnings
  (add-to-list 'warning-suppress-log-types '(package reinitialization)))
```

## Frame chrome

The tool bar and scroll bars are disabled in `default-frame-alist` *before* the first frame is drawn, which is cheaper than toggling the modes off afterwards. The menu bar stays on. `frame-inhibit-implied-resize` stops startup font and fringe changes from resizing the frame, since each resize is a round-trip to the window system.

```elisp
(push '(tool-bar-lines . 0) default-frame-alist)
(push '(vertical-scroll-bars) default-frame-alist)
(when (featurep 'ns)
  (push '(ns-transparent-titlebar . t) default-frame-alist)
  (push '(ns-appearance . dark) default-frame-alist))

(setq frame-inhibit-implied-resize t)

(setq inhibit-startup-screen t
      inhibit-startup-message t
      inhibit-startup-echo-area-message user-login-name
      initial-scratch-message nil)
```

## Byte-compiler noise

Silence obsolete-symbol warnings from third-party packages. Other warnings still surface.

```elisp
(setq byte-compile-warnings '(not obsolete))
```

## Font caches

Trade a little RAM for smoother redisplay.

```elisp
(setq inhibit-compacting-font-caches t)
(when (eq system-type 'darwin)
  (setq ns-use-thin-smoothing t))
```

## Native compilation

When native compilation is available: move the eln-cache to `var/eln-cache/` and run at most half the logical cores (1 to 3) as async jobs so a background recompile can't starve redisplay. On Emacs 31+, background compilation also pauses on battery power. Async warnings keep their default: since Emacs 30, `native-comp-async-warnings-errors-kind` limits them to errors and important warnings.

```elisp
(when (and (fboundp 'native-comp-available-p)
           (native-comp-available-p))
  (setq native-comp-speed 2
        native-comp-async-jobs-number (max 1 (min 3 (/ (num-processors) 2)))
        native-comp-async-on-battery-power nil)
  (when (fboundp 'startup-redirect-eln-cache)
    (startup-redirect-eln-cache
     (convert-standard-filename
      (expand-file-name "var/eln-cache/" user-emacs-directory)))))
```

If `JOTAIN_ELN_PATH` names a directory (set by the Home Manager wrapper when `services.jotain.nativeCompile.enable` is on, and by `just run-built-fast`), it is *appended* to `native-comp-eln-load-path`, so the config's ahead-of-time compiled `.eln` files load from the store. It must not be prepended: Emacs writes JIT output to the first writable entry, which has to stay the `var/` cache.

## Tree-sitter grammars

No setup is needed here: nixpkgs' `site-start.el` sets `treesit-extra-load-path` to the bundled grammars, and `init-prog.el` forwards it to native-comp workers.

## Terminal aliases

Ghostty advertises `TERM=xterm-ghostty`, but Emacs ships no `term/xterm-ghostty.el`. Aliasing it to `xterm-256color` loads `term/xterm.el` instead, restoring `modifyOtherKeys` and 24-bit colour. It must be set in `early-init.el` because `tty-run-terminal-initialization` runs before `init.el`. Ghostel buffers use the same `TERM`, so this also covers a nested `emacs -nw`.

```elisp
(add-to-list 'term-file-aliases '("xterm-ghostty" . "xterm-256color"))
```
