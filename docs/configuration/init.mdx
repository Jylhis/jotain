# init.el

`init.el` is deliberately tiny. It:

1. Registers MELPA and NonGNU ELPA as fallback archives for anything Nix does not ship.
2. Puts `lisp/` on the load-path.
3. Points `custom-file` at `var/custom.el`.
4. `require`s each module in order.

Everything else (GC, encoding, theme, keybindings, package configuration) lives in `early-init.el` or a `lisp/init-*.el` module.

## Package archives

```elisp
(require 'package)
(add-to-list 'package-archives '("melpa"  . "https://melpa.org/packages/")     t)
(add-to-list 'package-archives '("nongnu" . "https://elpa.nongnu.org/nongnu/") t)
```

Nix provides most packages via `load-path`, so the archives only matter for packages it doesn't ship. Registering an archive does no I/O, and nothing refreshes the archive index at launch. A download happens only when needed:

- `package-install` (including the `:ensure t` path) reads the on-disk cache under `elpa/archives/` and downloads only when that cache is empty.
- `M-x package-refresh-contents` and `M-x list-packages` refresh when you ask.

A fresh Nix deployment, where every `:ensure`d package is already on `load-path`, starts without contacting MELPA. Keeping downloads off the startup path also means a flaky network can't take a daemon down at launch.

## Load path

```elisp
(add-to-list 'load-path (expand-file-name "lisp" user-emacs-directory))
```

## Custom file

```elisp
(setq custom-file (locate-user-emacs-file "var/custom.el"))
```

`custom.el` is write-only: Jotain never loads it back, so the declarative config in git stays the single source of truth. It only gives `M-x customize` somewhere to write without touching `init.el`.

## Module loading

`init.el` then `require`s each module in order. See [Modules](/architecture/modules) for what each file owns.

```elisp
(require 'init-core)         ; GC, encoding, var/ paths, sane defaults
(require 'init-keys)         ; Global keymap and leader-key setup
(require 'init-ui)           ; Theme, modeline, fonts, frame tweaks
(require 'init-tabs)         ; Workspace tabs via tab-bar-mode
(require 'init-help)         ; helpful + built-in help tweaks
(require 'init-docs)         ; Surface jotain.info under C-h i
(require 'init-editing)      ; Electric pairs, delsel, whitespace, region tools
(require 'init-completion)   ; Vertico, marginalia, orderless, consult, corfu
(require 'init-navigation)   ; Dired + dirvish, project, windmove, winner
(require 'init-casual)       ; Transient menus for dired/calc/isearch/ibuffer/Info
(require 'init-vc)           ; vc + magit + diff-hl + forge
(require 'init-prog)         ; prog-mode, treesit, eglot, flymake, eldoc, compile
(require 'init-snippets)     ; tempel snippets + eglot-tempel LSP expansion
(require 'init-project)      ; project + projection + compile-multi
(require 'init-devenv)       ; devenv.sh: tasks, processes, env, LSP, MCP
(require 'init-ai)           ; eca, claude-code-ide, gptel, mcp
(require 'init-shell)        ; eshell, comint, ielm
(require 'init-terminal)     ; ghostel terminal + tty integration (kkp, clipetty)
(require 'init-systems)      ; sops, logview, auth-source-1password
(require 'init-writing)      ; jinx, markdown-mode, denote, pdf-tools
(require 'init-org)          ; org, org-modern, capture templates
(require 'init-http)         ; verb HTTP/REST client (org-based)

(require 'init-lang-nix)
(require 'init-lang-rust)
(require 'init-lang-python)
(require 'init-lang-go)
(require 'init-lang-web)       ; TS/TSX/CSS/HTML/JSON/web-mode
(require 'init-lang-devops)    ; Dockerfile, terraform, just, ansible
(require 'init-lang-data)      ; yaml, csv, sql, jinja2, gnuplot
(require 'init-lang-systems)   ; C/C++, CMake, Meson, Haskell, Zig
(require 'init-lang-qml)        ; QML (Quickshell / Qt Quick)
```
