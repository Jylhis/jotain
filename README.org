#+TITLE: Jotain

Jotain (Finnish for "something") is a GNU Emacs 31 configuration with a Nix build layer and no framework underneath. Nix builds the editor and its packages, and modular Emacs Lisp (=lisp/init-*.el=, one file per concern) configures it.

* Quick start

#+begin_src sh
git clone https://github.com/Jylhis/jotain.git
cd jotain
nix develop
just run-built
#+end_src

=just run-built= builds Emacs through Nix and launches it with this configuration, isolated from =~/.emacs.d=. The development shell has tooling only and no Emacs.

The flake targets =x86_64-linux= and provides a Home Manager module (=services.jotain=, a user daemon) and a NixOS module. See [[https://page.jylhis.com/jotain/docs/installation/][Installation]].

* Documentation

The manual, the module options and the Emacs reference manuals are at https://page.jylhis.com/jotain. Inside Emacs, open the manual with =C-h i d m Jotain RET=.
