Keybindings — considered and not adopted

  • general.el to conquer Emacs keybindings — argues for a leader-key system built on general.el. Researched against the built-in alternatives and rejected for Jotain: general.el's primary differentiator is :states for evil-mode integration, which Jotain does not use. Emacs 30's keymap-set, built-in which-key, and use-package :bind already cover the article's discoverability and leader-key goals without a new dependency. The article's spirit — memorable, categorised, self-documenting prefixes — is instead realised through which-key-add-key-based-replacements registered in init-keys.el, with the per-package bindings staying colocated with their use-package blocks. See Keybindings for the resulting namespace map.
