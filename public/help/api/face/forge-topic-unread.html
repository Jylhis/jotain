Face: forge-topic-unread

Face Sample:

The quick brown fox jumps over the lazy dog.

Documentation:

Face used for summaries of entities with unread notifications. This face is always used together with, and takes preference over, a `forge-{issue,pullreq}-STATE' face and should not specify any attribute that is specified by any of those faces. Likewise those faces should not set `:weight' or `:slant'.

Defined in `forge-topic.el'.
