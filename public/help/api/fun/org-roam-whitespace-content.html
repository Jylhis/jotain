Function: org-roam-whitespace-content

org-roam-whitespace-content is a natively compiled function defined in org-roam-utils.el.

Signature

(org-roam-whitespace-content S)

Documentation

Return the whitespace content at the end of S.

Source Code

;; Defined in /nix/store/qfyfp7k8wj4czdja2mlsqxrhlx7mvj76-emacs-packages-deps/share/emacs/site-lisp/elpa/org-roam-20260425.1623/org-roam-utils.el
(defun org-roam-whitespace-content (s)
  "Return the whitespace content at the end of S."
  (with-temp-buffer
    (insert s)
    (skip-chars-backward " \t\n")
    (buffer-substring-no-properties
     (point) (point-max))))
