Function: doom-modeline-face

doom-modeline-face is a natively compiled function defined in doom-modeline-core.el.

Signature

(doom-modeline-face &optional FACE INACTIVE-FACE)

Documentation

Display FACE in active window, and INACTIVE-FACE in inactive window.

IF FACE is nil, mode-line face will be used. If INACTIVE-FACE is nil, mode-line-inactive face will be added.

(defun doom-modeline-face (&optional face inactive-face)
  "Display FACE in active window, and INACTIVE-FACE in inactive window.
IF FACE is nil, `mode-line' face will be used.
If INACTIVE-FACE is nil, `mode-line-inactive' face will be added."
  (if (doom-modeline--active)
      `(:inherit (doom-modeline
                  ,(cond ((facep face) face)
                         ((facep 'mode-line-active) 'mode-line-active)
                         (t 'mode-line))))
    `(:inherit (doom-modeline
                ,(if (facep inactive-face) inactive-face
                   `(:inherit (mode-line-inactive ,face)))))))
