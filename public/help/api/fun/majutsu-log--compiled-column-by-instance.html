Function: majutsu-log--compiled-column-by-instance

majutsu-log--compiled-column-by-instance is a natively compiled function defined in majutsu-log.el.

Signature

(majutsu-log--compiled-column-by-instance COMPILED INSTANCE)

Documentation

Return column spec from COMPILED identified by INSTANCE.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-log.el
(defun majutsu-log--compiled-column-by-instance (compiled instance)
  "Return column spec from COMPILED identified by INSTANCE."
  (seq-find (lambda (column)
              (eql (plist-get column :instance) instance))
            (plist-get compiled :columns)))
