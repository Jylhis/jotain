Function: majutsu-tag-delete

majutsu-tag-delete is an interactive and natively compiled function defined in majutsu-tag.el.

Signature

(majutsu-tag-delete NAMES)

Documentation

Delete tag NAMES.

NAMES are passed as jj string patterns.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-tag.el
;;;###autoload
(defun majutsu-tag-delete (names)
  "Delete tag NAMES.
NAMES are passed as jj string patterns."
  (interactive
   (list (majutsu-tag--read-patterns "Delete tag(s)/pattern(s)")))
  (when names
    (when (zerop (majutsu-run-jj "tag" "delete" names))
      (message "Deleted tag(s): %s" (string-join names ", ")))))
