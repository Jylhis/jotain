Function: verb-send-request-on-point-other-window-stay

verb-send-request-on-point-other-window-stay is a function alias and interactive for verb-send-request-on-point-display, defined in verb.el.

This command is obsolete since 2025-07-26; Use verb-send-request-on-point-display instead.

Signature

(verb-send-request-on-point-other-window-stay &optional ARG)

Documentation

Send the request specified by the selected heading's text contents.

Show the results on another window but don't switch to it, using verb-send-request-on-point. See that function's documentation for a description of prefix argument ARG.

Key Bindings

verb-command-map C-r

Aliases

verb-send-request-on-point-display
