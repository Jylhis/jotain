Function: claude-code-ide-file-path-to-uri

claude-code-ide-file-path-to-uri is a natively compiled function defined in claude-code-ide-diagnostics.el.

(claude-code-ide-file-path-to-uri FILE-PATH)

Source Code

;; Defined in /nix/store/ca4a4maamih3h4ksbbhy6racb61djy6q-emacs-packages-deps/share/emacs/site-lisp/claude-code-ide-diagnostics.el
(defun claude-code-ide-file-path-to-uri (file-path)
  "Convert a FILE-PATH to a file URI."
  (concat "file://" (url-hexify-string file-path)))
