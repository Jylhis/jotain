Function: majutsu-conflict--disable

majutsu-conflict--disable is a natively compiled function defined in majutsu-conflict.el.

Signature

(majutsu-conflict--disable)

Documentation

Disable conflict highlighting.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-conflict.el
(defun majutsu-conflict--disable ()
  "Disable conflict highlighting."
  (font-lock-remove-keywords nil majutsu-conflict-font-lock-keywords)
  (remove-hook 'font-lock-extend-region-functions
               #'majutsu-conflict--extend-font-lock-region t)
  (remove-hook 'after-change-functions #'majutsu-conflict--after-change t)
  (when font-lock-mode
    (font-lock-flush))
  (majutsu-conflict--clear-overlays))
