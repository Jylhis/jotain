Function: dockerfile-build-arg-string

dockerfile-build-arg-string is a natively compiled function defined in dockerfile-mode.el.

Signature

(dockerfile-build-arg-string)

Documentation

Create a --build-arg string for each element in dockerfile-build-args.

Source Code

;; Defined in /nix/store/r1ar6k5jqxvw9mv0g6rq6h6hk8j9zhli-emacs-packages-deps/share/emacs/site-lisp/elpa/dockerfile-mode-20251221.1644/dockerfile-mode.el
(defun dockerfile-build-arg-string ()
  "Create a --build-arg string for each element in `dockerfile-build-args'."
  (mapconcat (lambda (arg) (concat "--build-arg="  (replace-regexp-in-string "\\\\=" "=" (shell-quote-argument arg))))
             dockerfile-build-args " "))
