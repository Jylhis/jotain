Function: ghostel--apply-initial-input-mode

ghostel--apply-initial-input-mode is a natively compiled function defined in ghostel.el.

Signature

(ghostel--apply-initial-input-mode)

Documentation

Switch a new ghostel terminal to ghostel-initial-input-mode.

char applies now; line is deferred to the first prompt; semi-char needs nothing.

Source Code

;; Defined in /nix/store/1jkgkg7y6y6hp0xia3dsmcl5zaj0bnhq-emacs-packages-deps/share/emacs/site-lisp/ghostel.el
(defun ghostel--apply-initial-input-mode ()
  "Switch a new `ghostel' terminal to `ghostel-initial-input-mode'.
`char' applies now; `line' is deferred to the first prompt;
`semi-char' needs nothing."
  (pcase ghostel-initial-input-mode
    ('char (ghostel-char-mode))
    ('line (setq ghostel--pending-initial-line-mode t))))
