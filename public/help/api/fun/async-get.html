Function: async-get

async-get is a natively compiled function defined in async.el.

Signature

(async-get FUTURE)

Documentation

Get the value from process FUTURE when it is ready.

FUTURE is returned by async-start or async-start-process when its FINISH-FUNC is nil.

(defun async-get (future)
  "Get the value from process FUTURE when it is ready.
FUTURE is returned by `async-start' or `async-start-process' when
its FINISH-FUNC is nil."
  (and future (async-wait future))
  (let ((buf (process-buffer future)))
    (when (buffer-live-p buf)
      (with-current-buffer buf
        (async-handle-result
         #'identity async-callback-value (current-buffer))))))
