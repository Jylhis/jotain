Function: ghostel-cursor-point

ghostel-cursor-point is a natively compiled function defined in ghostel.el.

Signature

(ghostel-cursor-point)

Documentation

Return the buffer position of the terminal cursor.

This is the live editing position — wherever readline / zle / prompt_toolkit currently has the cursor — which can sit *inside* the typed input when the user moved it back with arrow keys, not necessarily at the end of typed content.

Returns nil when no terminal cursor is available.
