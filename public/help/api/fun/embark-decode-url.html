Function: embark-decode-url

embark-decode-url is an interactive and natively compiled function defined in embark.el.

Signature

(embark-decode-url START END)

Documentation

Decode the URI-encoded region between START and END in current buffer.

It assumes the URL was encoded in UTF-8.

Key Bindings

embark-encode-map U embark-region-map > U

;; Defined in /nix/store/fs4fhphi5ajjmvzx1rm550ibr8slmvxd-emacs-packages-deps/share/emacs/site-lisp/elpa/embark-20260610.302/embark.el
(defun embark-decode-url (start end)
  "Decode the URI-encoded region between START and END in current buffer.
It assumes the URL was encoded in UTF-8."
  (interactive "r")
  (let ((decoded (decode-coding-string
                  (url-unhex-string
                   (buffer-substring-no-properties start end))
                  'utf-8)))
    (delete-region start end)
    (insert decoded)))
