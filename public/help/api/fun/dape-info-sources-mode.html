Function: dape-info-sources-mode

dape-info-sources-mode is a natively compiled function defined in dape.el.

Signature

(dape-info-sources-mode)

Documentation

Major mode for viewing loaded sources.

In addition to any hooks its parent mode dape-info-parent-mode might have run, this mode runs the hook dape-info-sources-mode-hook, as the final or penultimate step during initialization.
