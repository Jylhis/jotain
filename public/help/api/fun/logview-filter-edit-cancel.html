Function: logview-filter-edit-cancel

logview-filter-edit-cancel is an interactive and natively compiled function defined in logview.el.

Signature

(logview-filter-edit-cancel)

Documentation

Quit the buffer and its window, discarding all edits.

If \<logview-filter-edit-mode-map>M-x logview-filter-edit-apply (logview-filter-edit-apply) has been used from this buffer, its effects remain: only edits after it get discarded.

Key Bindings

logview-filter-edit-mode-map C-c C-k
