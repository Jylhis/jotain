Function: eca-chat-inline--viewport-mode

eca-chat-inline--viewport-mode is an interactive and natively compiled function defined in eca-chat-inline.el.

Signature

(eca-chat-inline--viewport-mode &optional ARG)

Documentation

Buffer-wide keys while an ECA inline overlay is displayed.

Internal; enabled and disabled by the inline overlay lifecycle. The scroll keys fall back to their regular bindings when there is nothing to scroll.

This is a minor mode. If called interactively, toggle the Eca-Chat-Inline--Viewport mode mode. If the prefix argument is positive, enable the mode, and if it is zero or negative, disable the mode.

If called from Lisp, toggle the mode if ARG is toggle. Enable the mode if ARG is nil, omitted, or is a positive number. Disable the mode if ARG is a negative number.

To check whether the minor mode is enabled in the current buffer, evaluate the variable eca-chat-inline--viewport-mode(var)/eca-chat-inline--viewport-mode(fun).

The mode's hook is called both when the mode is enabled and when it is disabled.

Key Bindings

This command is not in any keymaps.
