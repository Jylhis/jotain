Function: projection--join-shell-commands

projection--join-shell-commands is a natively compiled function defined in projection-utils.el.

(projection--join-shell-commands ARGVS)

Documentation

Join multiple shell commands ARGVS conditionally chaining them.

(defun projection--join-shell-commands (argvs)
  "Join multiple shell commands ARGVS conditionally chaining them."
  (string-join
   (thread-last
     argvs
     (mapcar #'ensure-list)
     (mapcar #'projection--join-shell-command))
   " && "))
