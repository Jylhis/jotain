Function: verb-re-send-request

verb-re-send-request is an interactive and natively compiled function defined in verb.el.

Signature

(verb-re-send-request)

Documentation

Re-send request for the response shown on current buffer.

If the user chose to show the current response buffer on another window, show the new one on another window as well. Return the buffer where the response will be loaded in.

If you use this command frequently, consider setting verb-auto-kill-response-buffers to t. This will help avoiding having many response buffers open.

Key Bindings

verb-response-body-mode-map C-c C-r C-f

(defun verb-re-send-request ()
  "Re-send request for the response shown on current buffer.
If the user chose to show the current response buffer on another
window, show the new one on another window as well.  Return the buffer
where the response will be loaded in.

If you use this command frequently, consider setting
`verb-auto-kill-response-buffers' to t.  This will help avoiding
having many response buffers open."
  (interactive)
  (verb--check-response-buffer)
  (verb--request-spec-send (oref verb-http-response request)
