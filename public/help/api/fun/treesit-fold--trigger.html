Function: treesit-fold--trigger

treesit-fold--trigger is a natively compiled function defined in treesit-fold.el.

(treesit-fold--trigger)

Documentation

Enable treesit-fold-mode(var)/treesit-fold-mode(fun) when the current mode is treesit-fold compatible.

(defun treesit-fold--trigger ()
  "Enable `treesit-fold-mode' when the current mode is treesit-fold compatible."
  (when (and (treesit-fold-ready-p)
             (treesit-fold-usable-mode-p))
    (treesit-fold-mode 1)))
