Function: magit-set-header-line-format

magit-set-header-line-format is a natively compiled function defined in magit-base.el.

Signature

(magit-set-header-line-format STRING)

Documentation

Set header-line-format in the current buffer based on STRING.

Pad the left side of STRING so that it aligns with the text area.

;; Defined in /nix/store/k1kwf51rwhxc2r08pvslpgkhbnr4nxnr-emacs-packages-deps/share/emacs/site-lisp/elpa/magit-20260822.1158/magit-base.el
(defun magit-set-header-line-format (string)
  "Set `header-line-format' in the current buffer based on STRING.
Pad the left side of STRING so that it aligns with the text area."
  (setq header-line-format
        (concat (propertize " " 'display '(space :align-to 0))
                string)))
