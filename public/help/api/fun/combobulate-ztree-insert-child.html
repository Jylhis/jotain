Function: combobulate-ztree-insert-child

combobulate-ztree-insert-child is a natively compiled function defined in combobulate-ztree.el.

Signature

(combobulate-ztree-insert-child LOC ITEM)

Documentation

Insert as the leftmost child of this LOC's node the ITEM.

Return same loc with children updated.

Source Code

;; Defined in /nix/store/9y0jasyzsqjcbfkwqsgdyxcnskjnsypg-emacs-packages-deps/share/emacs/site-lisp/combobulate-ztree.el
(defun combobulate-ztree-insert-child (loc item)
  "Insert as the leftmost child of this LOC's node the ITEM.
Return same loc with children updated."
  (combobulate-ztree-replace loc (combobulate-ztree-make-node loc (combobulate-ztree-node loc) (cons item (combobulate-ztree-children loc)))))
