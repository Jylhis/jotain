Function: web-mode-prog-mode

web-mode-prog-mode is a function alias and interactive for prog-mode, defined in prog-mode.el.gz.

Signature

(web-mode-prog-mode)

Documentation

Major mode for editing programming language source code.

This mode runs the hook prog-mode-hook, as the final or penultimate step during initialization.

C-M-q prog-indent-sexp
M-q prog-fill-reindent-defun

Key Bindings

This command is not in any keymaps.

Aliases

prog-mode
