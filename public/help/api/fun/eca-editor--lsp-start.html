Function: eca-editor--lsp-start

eca-editor--lsp-start is a natively compiled function defined in eca-editor.el.

Signature

(eca-editor--lsp-start)

Documentation

Start lsp-mode in the current buffer when an installed client matches.

Return non-nil when a start was attempted, nil when no installed lsp-mode client supports this buffer. Checking the clients first avoids lsp-mode's interactive server-install prompt, which must never fire from the process filter.

(defun eca-editor--lsp-start ()
  "Start lsp-mode in the current buffer when an installed client matches.
Return non-nil when a start was attempted, nil when no installed
lsp-mode client supports this buffer.  Checking the clients first
avoids lsp-mode's interactive server-install prompt, which must
never fire from the process filter."
  (when (or (not (fboundp 'lsp--find-clients))
            (lsp--find-clients))
    (lsp)
    t))
