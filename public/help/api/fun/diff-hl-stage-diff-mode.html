Function: diff-hl-stage-diff-mode

diff-hl-stage-diff-mode is an interactive and natively compiled function defined in diff-hl.el.

Signature

(diff-hl-stage-diff-mode)

Documentation

Major mode for editing a diff buffer before staging.

M-x diff-hl-stage-commit (diff-hl-stage-commit)

In addition to any hooks its parent mode diff-mode might have run, this mode runs the hook diff-hl-stage-diff-mode-hook, as the final or penultimate step during initialization.

Key Bindings

This command is not in any keymaps.
