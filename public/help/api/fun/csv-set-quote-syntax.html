Function: csv-set-quote-syntax

csv-set-quote-syntax is a natively compiled function defined in csv-mode.el.

Signature

(csv-set-quote-syntax FIELD-QUOTES)

Documentation

Set syntax for field quote characters FIELD-QUOTES to be "string".

FIELD-QUOTES should be a list of single-character strings.

Source Code

;; Defined in /nix/store/mrygxsladaca2yfyr2cy0am5zm9lzddg-emacs-packages-deps/share/emacs/site-lisp/elpa/csv-mode-1.27/csv-mode.el
(defun csv-set-quote-syntax (field-quotes)
  "Set syntax for field quote characters FIELD-QUOTES to be \"string\".
FIELD-QUOTES should be a list of single-character strings."
  (mapc (lambda (x)
	  (modify-syntax-entry
	   (string-to-char x) "\""
	   ;; symbol-value to avoid compiler warning:
	   (symbol-value 'csv-mode-syntax-table)))
	field-quotes))
