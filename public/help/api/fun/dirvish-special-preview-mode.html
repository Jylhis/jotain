Function: dirvish-special-preview-mode

dirvish-special-preview-mode is an interactive and natively compiled function defined in dirvish.el.

Signature

(dirvish-special-preview-mode)

Documentation

Major mode for info, shell command output and non-text file preview buffer.

In addition to any hooks its parent mode special-mode might have run, this mode runs the hook dirvish-special-preview-mode-hook, as the final or penultimate step during initialization.

q dirvish-quit

Key Bindings

This command is not in any keymaps.
