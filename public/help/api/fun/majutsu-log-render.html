Function: majutsu-log-render

majutsu-log-render is a natively compiled function defined in majutsu-log.el.

Signature

(majutsu-log-render)

Documentation

Render the log buffer using cached data.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-log.el
(defun majutsu-log-render ()
  "Render the log buffer using cached data."
  (magit-insert-section (logbuf)
    (run-hooks 'majutsu-log-sections-hook)
    (majutsu-selection-render)))
