Function: ghostel--tty-esc-window-change

ghostel--tty-esc-window-change is a natively compiled function defined in ghostel.el.

Signature

(ghostel--tty-esc-window-change WINDOW)

Documentation

Install the lone-ESC filter on WINDOW's frame terminal.

Covers ghostel buffers displayed on frames created after the buffer, e.g. a later "emacsclient -t" session.

Source Code

;; Defined in /nix/store/1jkgkg7y6y6hp0xia3dsmcl5zaj0bnhq-emacs-packages-deps/share/emacs/site-lisp/ghostel.el
(defun ghostel--tty-esc-window-change (window)
  "Install the lone-ESC filter on WINDOW's frame terminal.
Covers ghostel buffers displayed on frames created after the buffer,
e.g. a later \"emacsclient -t\" session."
  (when (windowp window)
    (ghostel--tty-esc-init (window-frame window))))
