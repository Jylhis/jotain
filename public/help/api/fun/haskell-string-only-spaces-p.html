Function: haskell-string-only-spaces-p

haskell-string-only-spaces-p is a natively compiled function defined in haskell-string.el.

Signature

(haskell-string-only-spaces-p STRING)

Documentation

Return t if STRING contains only whitespace (or is empty).

(defun haskell-string-only-spaces-p (string)
  "Return t if STRING contains only whitespace (or is empty)."
  (string= "" (haskell-string-trim string)))
