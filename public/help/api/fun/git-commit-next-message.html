Function: git-commit-next-message

git-commit-next-message is an interactive and natively compiled function defined in git-commit.el.

Signature

(git-commit-next-message ARG)

Documentation

Cycle forward through message history, after saving current message.

With a numeric prefix ARG, go forward ARG messages.

Key Bindings

git-commit-mode-map M-n

Source Code

;; Defined in /nix/store/k1kwf51rwhxc2r08pvslpgkhbnr4nxnr-emacs-packages-deps/share/emacs/site-lisp/elpa/magit-20260822.1158/git-commit.el
(defun git-commit-next-message (arg)
  "Cycle forward through message history, after saving current message.
With a numeric prefix ARG, go forward ARG messages."
  (interactive "*p")
  (git-commit-prev-message (- arg)))
