Function: super-save-include-p

super-save-include-p is a natively compiled function defined in super-save.el.

Signature

(super-save-include-p FILENAME)

Documentation

Return non-nil if FILENAME doesn't match any of the super-save-exclude.

Source Code

;; Defined in /nix/store/wqk38r7f0ly8xacdb8fb4xzdq0iqx7lz-emacs-packages-deps/share/emacs/site-lisp/elpa/super-save-20260318.1214/super-save.el
(defun super-save-include-p (filename)
  "Return non-nil if FILENAME doesn't match any of the `super-save-exclude'."
  (not (seq-some (lambda (regexp) (string-match-p regexp filename)) super-save-exclude)))
