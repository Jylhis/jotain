Function: majutsu-shell-command-topdir

majutsu-shell-command-topdir is an interactive and natively compiled function defined in majutsu-command.el.

Signature

(majutsu-shell-command-topdir COMMAND)

Documentation

Execute COMMAND asynchronously in the workspace root; display output.

Interactively, prompt for COMMAND in the minibuffer.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-command.el
;;;###autoload
(defun majutsu-shell-command-topdir (command)
  "Execute COMMAND asynchronously in the workspace root; display output.

Interactively, prompt for COMMAND in the minibuffer."
  (interactive (list (majutsu-read-shell-command t)))
  (majutsu--shell-command command (majutsu--shell-command-directory t)))
