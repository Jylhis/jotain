Function: pdf-cache--clear-data-of-annotations

pdf-cache--clear-data-of-annotations is a natively compiled function defined in pdf-cache.el.

Signature

(pdf-cache--clear-data-of-annotations FN)

Documentation

Clear the data cache when annotations are modified.

FN is a closure as described in pdf-annot-modified-functions.

Note: This is an internal function and not meant to be directly used.

(defun pdf-cache--clear-data-of-annotations (fn)
  "Clear the data cache when annotations are modified.

FN is a closure as described in `pdf-annot-modified-functions'.

Note: This is an internal function and not meant to be directly used."

         (mapcar (lambda (a)
                   (cdr (assq 'page a)))
                 (funcall fn t))))
