Function: haskell-mode-generate-tags

haskell-mode-generate-tags is an interactive and natively compiled function defined in haskell-mode.el.

Signature

(haskell-mode-generate-tags &optional AND-THEN-FIND-THIS-TAG)

Documentation

Generate tags using Hasktags. This is synchronous function.

If optional AND-THEN-FIND-THIS-TAG argument is present it is used with function xref-find-definitions after new table was generated.

Key Bindings

This command is not in any keymaps.

(defun haskell-mode-generate-tags (&optional and-then-find-this-tag)
  "Generate tags using Hasktags.  This is synchronous function.

If optional AND-THEN-FIND-THIS-TAG argument is present it is used
with function `xref-find-definitions' after new table was
generated."
  (interactive)
  (let* ((dir (haskell-cabal--find-tags-dir))
         (command (haskell-cabal--compose-hasktags-command dir)))
    (if (not command)
        (error "Unable to compose hasktags command")
      (when (zerop (shell-command command))
        (haskell-mode-message-line "Tags generated."))
      (when and-then-find-this-tag
        (let ((tags-file-name dir))
          (xref-find-definitions and-then-find-this-tag))))))
