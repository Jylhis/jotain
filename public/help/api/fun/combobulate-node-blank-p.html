Function: combobulate-node-blank-p

combobulate-node-blank-p is a natively compiled function defined in combobulate-navigation.el.

Signature

(combobulate-node-blank-p NODE)

Documentation

Returns t if NODE consists of blank characters.

The function string-blank-p is used to determine this.

Source Code

(defun combobulate-node-blank-p (node)
  "Returns t if NODE consists of blank characters.

The function `string-blank-p' is used to determine this."
  (string-blank-p (combobulate-node-text node)))
