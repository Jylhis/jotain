Function: git-commit-self-ident

git-commit-self-ident is a function alias for git-commit-get-ident, defined in git-commit.el.

Signature

(git-commit-self-ident &optional PROMPT)

Documentation

Return name and email of the user or read another name and email.

If PROMPT and current-prefix-arg are both non-nil, read name and email using git-commit-read-ident (which see), otherwise return name and email of the current user (you).

Aliases

git-commit-get-ident
