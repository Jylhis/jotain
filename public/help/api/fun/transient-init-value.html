Function: transient-init-value

transient-init-value is a byte-compiled function defined in transient.el.

Signature

(transient-init-value OBJ)

Documentation

Set the initial value of the prefix or suffix object OBJ.

This function is called for all prefix and suffix commands.

Third-party subclasses of transient-infix(var)/transient-infix(fun) must implement a primary method.

Non-infix suffixes usually don't have a value. Call `transient-default-value' but because that is a noop for `transient-suffix', this function is effectively also a noop.

(transient-init-value (OBJ transient-prefix)) in `transient.el'.

Set OBJ's initial value to the set, saved or default value. Use `transient-default-value' to determine the default value.

:around (transient-init-value (OBJ transient-infix)) in `transient.el'.

If bound, use the value returned by OBJ's `init-value' function. If the value of OBJ's `init-value' is non-nil, call that function to determine the value. Otherwise call the primary method according to OBJ's class.
