Function: eca-editor--lsp-obj-get

eca-editor--lsp-obj-get is a natively compiled function defined in eca-editor.el.

Signature

(eca-editor--lsp-obj-get OBJ KEY)

Documentation

Get keyword KEY from lsp result OBJ.

Supports both lsp-mode result representations: hash-tables with string keys and plists with keyword keys.

(defun eca-editor--lsp-obj-get (obj key)
  "Get keyword KEY from lsp result OBJ.
Supports both lsp-mode result representations: hash-tables with
string keys and plists with keyword keys."
  (cond
   ((hash-table-p obj) (gethash (substring (symbol-name key) 1) obj))
   ((listp obj) (plist-get obj key))))
