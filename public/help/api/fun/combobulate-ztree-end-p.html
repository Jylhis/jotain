Function: combobulate-ztree-end-p

combobulate-ztree-end-p is a natively compiled function defined in combobulate-ztree.el.

Signature

(combobulate-ztree-end-p LOC)

Documentation

Return t if LOC represents the end of a depth-first walk.

Source Code

;; Defined in /nix/store/9y0jasyzsqjcbfkwqsgdyxcnskjnsypg-emacs-packages-deps/share/emacs/site-lisp/combobulate-ztree.el
(defun combobulate-ztree-end-p (loc)
  "Return t if LOC represents the end of a depth-first walk."
  (equal :end (combobulate-ztree--context loc)))
