Function: pdf-view-active-region

pdf-view-active-region is a natively compiled function defined in pdf-view.el.

Signature

(pdf-view-active-region &optional DEACTIVATE-P)

Documentation

Return the active region, as a cons cell of page number and list of edges.

Deactivate the region if DEACTIVATE-P is non-nil.

Source Code

;; Defined in /nix/store/wm0vc3dfi6c7pwjhcfpsnhyg4hd0b5yc-emacs-packages-deps/share/emacs/site-lisp/elpa/pdf-tools-20260102.1101/pdf-view.el
(defun pdf-view-active-region (&optional deactivate-p)
  "Return the active region, as a cons cell of page number and list of edges.

Deactivate the region if DEACTIVATE-P is non-nil."
  (pdf-view-assert-active-region)
  (prog1
      pdf-view-active-region
    (when deactivate-p
      (pdf-view-deactivate-region))))
