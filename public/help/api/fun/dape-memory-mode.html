Function: dape-memory-mode

dape-memory-mode is a natively compiled function defined in dape.el.

Signature

(dape-memory-mode)

Documentation

Major mode for interacting with debuggee's memory.

In addition to any hooks its parent mode hexl-mode might have run, this mode runs the hook dape-memory-mode-hook, as the final or penultimate step during initialization.
