Function: pdf-tools-disable-minor-modes

pdf-tools-disable-minor-modes is an interactive and natively compiled function defined in pdf-tools.el.

Signature

(pdf-tools-disable-minor-modes &optional MODES)

Documentation

Disable MODES in the current buffer.

MODES defaults to pdf-tools-enabled-modes.

Key Bindings

This command is not in any keymaps.

(defun pdf-tools-disable-minor-modes (&optional modes)
  "Disable MODES in the current buffer.

MODES defaults to `pdf-tools-enabled-modes'."
  (interactive)
  (pdf-tools-set-modes-enabled nil modes))
