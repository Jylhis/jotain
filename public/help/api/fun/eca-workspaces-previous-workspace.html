Function: eca-workspaces-previous-workspace

eca-workspaces-previous-workspace is an interactive and natively compiled function defined in eca-workspaces.el.

Signature

(eca-workspaces-previous-workspace &optional COUNT)

Documentation

Move point to the previous workspace (session) entry.

With prefix COUNT, repeat that many times.

Key Bindings

eca-workspaces-mode-map P

Source Code

;; Defined in /nix/store/53rcj4vx02sm8hj89vj9g7rhbbilbzvy-emacs-packages-deps/share/emacs/site-lisp/elpa/eca-20260828.1422/eca-workspaces.el
(defun eca-workspaces-previous-workspace (&optional count)
  "Move point to the previous workspace (session) entry.
With prefix COUNT, repeat that many times."
  (interactive "p")
  (dotimes (_ (or count 1))
    (eca-workspaces--previous-line-matching
     #'eca-workspaces--session-line-p)))
