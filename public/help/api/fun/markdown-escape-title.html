Function: markdown-escape-title

markdown-escape-title is a natively compiled function defined in markdown-mode.el.

Signature

(markdown-escape-title TITLE)

Documentation

Escape a minimum set of characters in TITLE so they don't clash with html.

Source Code

;; Defined in /nix/store/s4bvm9kdxw2hixpjqbqj3gi5xi7kr8wh-emacs-packages-deps/share/emacs/site-lisp/elpa/markdown-mode-20260827.909/markdown-mode.el
(defun markdown-escape-title (title)
  "Escape a minimum set of characters in TITLE so they don't clash with html."
  (replace-regexp-in-string ">" "&gt;"
    (replace-regexp-in-string "<" "&lt;"
      (replace-regexp-in-string "&" "&amp;" title))))
