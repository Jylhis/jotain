Function: haskell-cabal--find-tags-dir

haskell-cabal--find-tags-dir is a natively compiled function defined in haskell-cabal.el.

Signature

(haskell-cabal--find-tags-dir)

Documentation

Return a directory where TAGS file will be generated.

Tries to find cabal file first and if succeeds uses its location. If cabal file not found uses current file directory. If current buffer not visiting a file returns nil.

(defun haskell-cabal--find-tags-dir ()
  "Return a directory where TAGS file will be generated.
Tries to find cabal file first and if succeeds uses its location.
If cabal file not found uses current file directory.  If current
buffer not visiting a file returns nil."
  (or (haskell-cabal-find-dir)
      (when buffer-file-name
        (file-name-directory buffer-file-name))))
