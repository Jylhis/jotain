Function: majutsu-buffer-value

majutsu-buffer-value is a byte-compiled function defined in majutsu-mode.el.

Signature

(majutsu-buffer-value)

Documentation

Return the value of the current buffer.

The "value" identifies what is being displayed in the buffer. Buffers that are locked use this value to avoid being reused for another value.
