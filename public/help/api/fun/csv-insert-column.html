Function: csv-insert-column

csv-insert-column is an interactive and natively compiled function defined in csv-mode.el.

(csv-insert-column FIELD)

Documentation

Insert an empty column at point.

;; Defined in /nix/store/mrygxsladaca2yfyr2cy0am5zm9lzddg-emacs-packages-deps/share/emacs/site-lisp/elpa/csv-mode-1.27/csv-mode.el
(defun csv-insert-column (field)
  "Insert an empty column at point."
  (interactive
   (let ((cur (csv--field-index)))
     (list (if (and (csv--eof-p) (not (csv--bof-p))) (1+ cur) cur))))
  (save-excursion
    (goto-char (point-min))
    (while (not (eobp))
      (or (csv-not-looking-at-record)
	  (progn
	    (csv-sort-skip-fields field t)
	    (insert (car csv-separators))))
      (forward-line 1))
    (csv--jit-flush-columns)))
