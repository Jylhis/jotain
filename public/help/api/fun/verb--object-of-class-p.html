Function: verb--object-of-class-p

verb--object-of-class-p is a natively compiled function defined in verb.el.

Signature

(verb--object-of-class-p OBJ CLASS)

Documentation

Return non-nil if OBJ is an instance of CLASS.

CLASS must be an EIEIO class.

Source Code

(defun verb--object-of-class-p (obj class)
  "Return non-nil if OBJ is an instance of CLASS.
CLASS must be an EIEIO class."
  (ignore-errors
    (object-of-class-p obj class)))
