Function: ediff

ediff is a function alias and interactive for ediff-files, defined in ediff.el.gz.

Signature

(ediff FILE-A FILE-B &optional STARTUP-HOOKS)

Documentation

Run Ediff on a pair of files, FILE-A and FILE-B.

STARTUP-HOOKS is a list of functions that Emacs calls without arguments after setting up the Ediff buffers.

Probably introduced at or before Emacs version 22.1.

Key Bindings

This command is not in any keymaps.

Aliases

ediff-files
