Function: denote--add-prompts

denote--add-prompts is a function alias for denote-add-prompts, defined in denote.el.

This function is obsolete since 3.0.0; use denote-add-prompts instead.

Signature

(denote--add-prompts ADDITIONAL-PROMPTS)

Documentation

Add list of ADDITIONAL-PROMPTS to denote-prompts.

This is best done inside of a let to create a wrapper function around denote, denote-rename-file, and generally any command that consults the value of denote-prompts.

Aliases

denote-add-prompts
