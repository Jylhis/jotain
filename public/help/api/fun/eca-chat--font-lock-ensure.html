Function: eca-chat--font-lock-ensure

eca-chat--font-lock-ensure is a natively compiled function defined in eca-chat.el.

Signature

(eca-chat--font-lock-ensure BEG END)

Documentation

Fontify BEG to END without shifting visible chat windows.

Hidden markdown markup can change display geometry after streaming. Preserve window starts and force a cheap redisplay update so fenced block layout settles before later point motion.

(defun eca-chat--font-lock-ensure (beg end)
  "Fontify BEG to END without shifting visible chat windows.
Hidden markdown markup can change display geometry after streaming.
Preserve window starts and force a cheap redisplay update so fenced
block layout settles before later point motion."
  (prog1
      (eca-chat--with-preserved-scroll
        (font-lock-ensure beg end))
    (force-window-update (current-buffer))))
