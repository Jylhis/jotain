Function: majutsu--append-unique

majutsu--append-unique is a natively compiled function defined in majutsu-base.el.

(majutsu--append-unique ITEMS ITEM &optional TESTFN)

Documentation

Return ITEMS with ITEM appended unless already present.

TESTFN defaults to equal.

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-base.el
(defun majutsu--append-unique (items item &optional testfn)
  "Return ITEMS with ITEM appended unless already present.
TESTFN defaults to `equal'."
  (if (cl-member item items :test (or testfn #'equal))
      items
    (append items (list item))))
