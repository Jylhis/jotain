Function: majutsu--shell-command-directory

majutsu--shell-command-directory is a natively compiled function defined in majutsu-command.el.

Signature

(majutsu--shell-command-directory &optional TOPDIR)

Documentation

Return directory used for ad-hoc command runners.

When TOPDIR or current-prefix-arg is non-nil, use the current workspace root. Otherwise use default-directory.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-command.el
(defun majutsu--shell-command-directory (&optional topdir)
  "Return directory used for ad-hoc command runners.
When TOPDIR or `current-prefix-arg' is non-nil, use the current
workspace root.  Otherwise use `default-directory'."
  (if (or topdir current-prefix-arg)
      (majutsu--toplevel-safe)
    default-directory))
