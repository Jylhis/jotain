Function: embark-insert-relative-path

embark-insert-relative-path is an interactive and natively compiled function defined in embark.el.

Signature

(embark-insert-relative-path FILE)

Documentation

Insert relative path to FILE.

The insert path is relative to default-directory.

Key Bindings

embark-file-map I

Source Code

;; Defined in /nix/store/fs4fhphi5ajjmvzx1rm550ibr8slmvxd-emacs-packages-deps/share/emacs/site-lisp/elpa/embark-20260610.302/embark.el
(defun embark-insert-relative-path (file)
  "Insert relative path to FILE.
The insert path is relative to `default-directory'."
  (interactive "FFile: ")
  (embark-insert (list (file-relative-name (substitute-in-file-name file)))))
