Function: majutsu-diff-save-arguments

majutsu-diff-save-arguments is an interactive and natively compiled function defined in majutsu-diff.el.

Signature

(majutsu-diff-save-arguments)

Documentation

Save current transient arguments as global defaults.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-diff.el
(defun majutsu-diff-save-arguments ()
  "Save current transient arguments as global defaults."
  (interactive)
  (unless (and transient--prefix
               (object-of-class-p transient--prefix 'majutsu-diff-prefix))
    (user-error "Not in a Majutsu diff transient"))
  (transient-save-value transient--prefix)
  (message "Saved diff arguments as global defaults"))
