Function: magit-delete-match

magit-delete-match is a natively compiled function defined in magit-base.el.

Signature

(magit-delete-match &optional NUM)

Documentation

Delete text matched by last search.

If optional NUM is specified, only delete that subexpression.

Source Code

;; Defined in /nix/store/k1kwf51rwhxc2r08pvslpgkhbnr4nxnr-emacs-packages-deps/share/emacs/site-lisp/elpa/magit-20260822.1158/magit-base.el
(defun magit-delete-match (&optional num)
  "Delete text matched by last search.
If optional NUM is specified, only delete that subexpression."
  (delete-region (match-beginning (or num 0))
                 (match-end (or num 0))))
