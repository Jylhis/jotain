Function: ghostel--anchored-windows

ghostel--anchored-windows is a natively compiled function defined in ghostel.el.

Signature

(ghostel--anchored-windows &optional BUFFER ALL-FRAMES)

Documentation

Return anchored Ghostel windows.

BUFFER and ALL-FRAMES have the same meaning as in ghostel--windows.

Source Code

;; Defined in /nix/store/1jkgkg7y6y6hp0xia3dsmcl5zaj0bnhq-emacs-packages-deps/share/emacs/site-lisp/ghostel.el
(defun ghostel--anchored-windows (&optional buffer all-frames)
  "Return anchored Ghostel windows.
BUFFER and ALL-FRAMES have the same meaning as in `ghostel--windows'."
  (cl-remove-if-not #'ghostel--window-anchored-p
                    (ghostel--windows buffer all-frames)))
