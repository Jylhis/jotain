Function: gptel-highlight--fringe-prefix

gptel-highlight--fringe-prefix is a natively compiled function defined in gptel.el.

Signature

(gptel-highlight--fringe-prefix TYPE)

Documentation

Create fringe prefix string for TYPE.

Supported TYPEs are response, ignore and tool calls.

(defun gptel-highlight--fringe-prefix (type)
  "Create fringe prefix string for TYPE.

Supported TYPEs are response, ignore and tool calls."
  (propertize ">" 'display
              `( left-fringe gptel-highlight-fringe
                 ,(pcase type
                    ('response 'gptel-response-fringe-highlight)
                    ('ignore 'shadow)
                    (`(tool . ,_) 'shadow)))))
