Function: pdf-view-previous-page

pdf-view-previous-page is an interactive and natively compiled function defined in pdf-view.el.

Signature

(pdf-view-previous-page &optional N)

Documentation

View the previous page in the PDF.

Optional parameter N moves N pages backward.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/wm0vc3dfi6c7pwjhcfpsnhyg4hd0b5yc-emacs-packages-deps/share/emacs/site-lisp/elpa/pdf-tools-20260102.1101/pdf-view.el
(defun pdf-view-previous-page (&optional n)
  "View the previous page in the PDF.

Optional parameter N moves N pages backward."
  (interactive "p")
  (pdf-view-next-page (- (or n 1))))
