Function: project-ignores

project-ignores is a byte-compiled function defined in project.el.gz.

Signature

(project-ignores PROJECT DIR)

Documentation

Return the list of glob patterns to ignore inside DIR.

Patterns can match both regular files and directories. To root an entry, start it with ./. To match directories only, end it with /. DIR must be either project-root or one of project-external-roots.

Implementations

(project-ignores (PROJECT bazel-workspace) DIR) in `bazel.el'.

Return glob patterns for files to be ignored in a Bazel repository PROJECT. Ignore the convenience symbolic links and directories listed in .bazelignore. PROJECT refers to a Bazel repository, and DIR is the Bazel repository directory to consider. See URL ‘https://bazel.build/run/bazelrc#bazelignore’.

(cl-defgeneric project-ignores (_project dir)
  "Return the list of glob patterns to ignore inside DIR.
Patterns can match both regular files and directories.
To root an entry, start it with `./'.  To match directories only,
end it with `/'.  DIR must be either `project-root' or one of
`project-external-roots'."
  ;; TODO: Document and support regexp ignores as used by Hg.
  ;; TODO: Support whitelist entries.
  (require 'grep)
  (defvar grep-find-ignored-files)
  (declare-function grep-find-ignored-files "grep" (dir))
  (nconc
   (mapcar
    (lambda (dir)
      (concat dir "/"))
    vc-directory-exclusion-list)
   (if (fboundp 'grep-find-ignored-files)
       (grep-find-ignored-files dir)
     grep-find-ignored-files)))
