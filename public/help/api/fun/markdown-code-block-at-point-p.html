Function: markdown-code-block-at-point-p

markdown-code-block-at-point-p is a natively compiled function defined in markdown-mode.el.

Signature

(markdown-code-block-at-point-p &optional POS)

Documentation

Return non-nil if there is a code block at the POS.

This includes pre blocks, tilde-fenced code blocks, and GFM quoted code blocks. This function does not modify the match data. See markdown-inline-code-at-point-p for inline code.

Aliases

markdown-code-block-at-point
