Function: eca-chat-expandable--reset-id-table

eca-chat-expandable--reset-id-table is a natively compiled function defined in eca-chat-expandable.el.

Signature

(eca-chat-expandable--reset-id-table)

Documentation

Clear the expandable id→overlay map for the current buffer.

Should be called whenever overlays are wholesale removed (e.g. erase-buffer + remove-overlays in eca-chat--clear).
