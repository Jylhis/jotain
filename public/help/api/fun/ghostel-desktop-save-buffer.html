Function: ghostel-desktop-save-buffer

ghostel-desktop-save-buffer is an autoloaded and natively compiled function defined in ghostel-desktop.el.

Signature

(ghostel-desktop-save-buffer DESKTOP-DIRNAME)

Documentation

Return this ghostel buffer's desktop data: (DIRECTORY IDENTITY).

An identity command key (the argv of an exec'd program) is written to the desktop file in plaintext.
