Function: sqlind-in-comment-or-string

sqlind-in-comment-or-string is a byte-compiled function defined in sql-indent.el.

Signature

(sqlind-in-comment-or-string POS)

Documentation

Return non nil if POS is inside a comment or a string.

We actually return 'string if POS is inside a string,
'comment if POS is inside a comment, nil otherwise.

\\='comment if POS is inside a comment, nil otherwise."
