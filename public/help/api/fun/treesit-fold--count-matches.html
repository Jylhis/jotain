Function: treesit-fold--count-matches

treesit-fold--count-matches is a natively compiled function defined in treesit-fold-util.el.

Signature

(treesit-fold--count-matches PATTERN STR)

Documentation

Count occurrences of PATTERN in STR.

Like function s-count-matches but faster.

Source Code

;; Defined in /nix/store/8bsxam5z769p2v85807qya1p1fb50bqx-emacs-packages-deps/share/emacs/site-lisp/elpa/treesit-fold-0.2.1/treesit-fold-util.el
(defun treesit-fold--count-matches (pattern str)
  "Count occurrences of PATTERN in STR.

Like function `s-count-matches' but faster."
  (max 0 (1- (length (split-string str pattern)))))
