Function: logview-next-timestamp-gap

logview-next-timestamp-gap is an interactive and natively compiled function defined in logview.el.

Signature

(logview-next-timestamp-gap &optional N)

Documentation

Move to the next large gap in entry timestamps.

If N is specified, use that as a gap count. Filtered out entries are ignored.

Point is positioned at the beginning of the message of the first entry after the gap. If there is a large enough gap just after the current entry and N is one, this command just moves one entry down.

Key Bindings

logview-mode-map z n
