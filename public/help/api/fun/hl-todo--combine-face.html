Function: hl-todo--combine-face

hl-todo--combine-face is a natively compiled function defined in hl-todo.el.

Signature

(hl-todo--combine-face COLOR)

Documentation

Combine COLOR string with hl-todo default face.

If COLOR is a face symbol, do not combine, return COLOR instead.

Source Code

;; Defined in /nix/store/qpi14jchz4rd13fyys79w0acswf9phnl-emacs-packages-deps/share/emacs/site-lisp/elpa/hl-todo-20260601.1508/hl-todo.el
(defun hl-todo--combine-face (color)
  "Combine COLOR string with `hl-todo' default face.
If COLOR is a face symbol, do not combine, return COLOR instead."
  (if (stringp color)
      `((,(if hl-todo-color-background :background :foreground)
         ,color)
        hl-todo)
    color))
