Function: vundo-mode

vundo-mode is an interactive and natively compiled function defined in vundo.el.

Signature

(vundo-mode)

Documentation

Mode for displaying the undo tree.

In addition to any hooks its parent mode special-mode might have run, this mode runs the hook vundo-mode-hook, as the final or penultimate step during initialization.

;; Defined in /nix/store/7c2696v2qdrdv2vf2im8alazibi7qq0z-emacs-packages-deps/share/emacs/site-lisp/elpa/vundo-2.4.0/vundo.el
(define-derived-mode vundo-mode special-mode
  "Vundo" "Mode for displaying the undo tree."
  (setq mode-line-format nil
        truncate-lines t
        cursor-type nil)
  (jit-lock-mode nil)
  (face-remap-add-relative 'default 'vundo-default)

  ;; Disable evil-mode, as normal-mode
  ;; key bindings override the ones set by vundo.
  (when (and (boundp 'evil-emacs-state-modes)
             (not (memq 'vundo-mode evil-emacs-state-modes)))
    (push 'vundo-mode evil-emacs-state-modes)))
