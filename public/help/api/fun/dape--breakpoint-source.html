Function: dape--breakpoint-source

dape--breakpoint-source is a natively compiled function defined in dape.el.

(dape--breakpoint-source BREAKPOINT)

Return the source of BREAKPOINT.

Source is either a buffer or file name.

;; Defined in /nix/store/l2knzmz5nqc323cf0hwsi3pa45p8w61v-emacs-packages-deps/share/emacs/site-lisp/elpa/dape-0.27.1/dape.el
(defun dape--breakpoint-source (breakpoint)
  "Return the source of BREAKPOINT.
Source is either a buffer or file name."
  (if-let* ((buffer (dape--breakpoint-buffer breakpoint)))
      buffer
    (dape--breakpoint-file-name breakpoint)))
