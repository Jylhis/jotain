Function: neocaml-interface-mode

neocaml-interface-mode is an interactive and natively compiled function defined in neocaml.el.

Signature

(neocaml-interface-mode)

Documentation

Major mode for editing OCaml interface (mli) code.

C-M-u neocaml-backward-up-list
C-c 4 C-a ff-find-other-file-other-window
C-c C-a ff-find-other-file
C-c C-c compile
C-c C-f neocaml-format-buffer

In addition to any hooks its parent mode neocaml-base-mode might have run, this mode runs the hook neocaml-interface-mode-hook, as the final or penultimate step during initialization.

Key Bindings

This command is not in any keymaps.
