Function: dirvish-preview-dispatch

dirvish-preview-dispatch is a byte-compiled function defined in dirvish.el.

Signature

(dirvish-preview-dispatch RECIPE DV)

Documentation

Return preview buffer generated according to RECIPE in session DV.

Implementations

(dirvish-preview-dispatch (RECIPE (head dired)) DV) in `dirvish.el'.

Fill DV's preview buffer with output of sh command from RECIPE.

(dirvish-preview-dispatch (RECIPE (head shell)) DV) in `dirvish.el'.

Fill DV's preview buffer with output of sh command from RECIPE.

(dirvish-preview-dispatch (RECIPE (head buffer)) DV) in `dirvish.el'.

Use payload of RECIPE as preview buffer of DV directly.

(dirvish-preview-dispatch (RECIPE (head info)) DV) in `dirvish.el'.

Insert info string from RECIPE into DV's preview buffer.
