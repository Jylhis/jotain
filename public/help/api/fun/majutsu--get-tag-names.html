Function: majutsu--get-tag-names

majutsu--get-tag-names is a natively compiled function defined in majutsu-tag.el.

Signature

(majutsu--get-tag-names &optional SCOPE)

Documentation

Return tag names for completion.

SCOPE controls what to return:

- nil or local: local tag names (e.g. "v1.0")
- t or remote: remote tag refs (e.g. "v1.0@git")
