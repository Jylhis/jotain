Function: forge-notification-child-p

forge-notification-child-p is a function alias for forge-notification--eieio-childp, defined in forge-notify.el.

This function is obsolete since 25.1; use (cl-typep ... 'forge-notification) instead

Signature

(forge-notification-child-p OBJ)

Documentation

Return non-nil if OBJ is an object of type forge-notification(var)/forge-notification(fun) or a subclass.
