Function: gnuplot-insert-filename

gnuplot-insert-filename is an interactive and natively compiled function defined in gnuplot.el.

Signature

(gnuplot-insert-filename)

Documentation

Insert a filename at point, prompting for name in the minibuffer.

This inserts a filename relative to the buffer's default directory. Uses completion and the value of gnuplot-quote-character. Bound to M-x gnuplot-insert-filename (gnuplot-insert-filename)

;;; --- miscellaneous functions: insert file name, indentation, negation

(defun gnuplot-insert-filename ()
  "Insert a filename at point, prompting for name in the minibuffer.
This inserts a filename relative to the buffer's default directory.
Uses completion and the value of `gnuplot-quote-character'.
Bound to \\[gnuplot-insert-filename]"
  (interactive nil gnuplot-mode gnuplot-comint-mode)
  (insert gnuplot-quote-character
          (file-relative-name (read-file-name "Filename > " "")
                              default-directory)
          gnuplot-quote-character))
