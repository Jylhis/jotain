Function: vundo-previous

vundo-previous is an interactive and natively compiled function defined in vundo.el.

Signature

(vundo-previous ARG)

Documentation

Move to node above the current one. Move ARG steps.

Key Bindings

vundo-mode-map <up> vundo-mode-map p

Source Code

;; Defined in /nix/store/7c2696v2qdrdv2vf2im8alazibi7qq0z-emacs-packages-deps/share/emacs/site-lisp/elpa/vundo-2.4.0/vundo.el
(defun vundo-previous (arg)
  "Move to node above the current one. Move ARG steps."
  (interactive "p")
  (vundo-next (- arg)))
