Function: sqlind-match-string

sqlind-match-string is a byte-compiled function defined in sql-indent.el.

Signature

(sqlind-match-string POS)

Documentation

Return the match data at POS in the current buffer.

This is similar to match-data, but the text is fetched without text properties and it is conveted to lower case.

(defsubst sqlind-match-string (pos)
  "Return the match data at POS in the current buffer.
This is similar to `match-data', but the text is fetched without
text properties and it is conveted to lower case."
  (let ((start (match-beginning pos))
	(end (match-end pos)))
    (when (and start end)
      (downcase (buffer-substring-no-properties start end)))))
