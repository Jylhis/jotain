Function: majutsu-goto-commit

majutsu-goto-commit is an interactive and natively compiled function defined in majutsu-log.el.

Signature

(majutsu-goto-commit COMMIT-ID)

Documentation

Jump to a specific COMMIT-ID in the log.

Key Bindings

This command is not in any keymaps.

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-log.el
(defun majutsu-goto-commit (commit-id)
  "Jump to a specific COMMIT-ID in the log."
  (interactive "sCommit ID: ")
  (let ((start-pos (point)))
    (goto-char (point-min))
    (if (re-search-forward (regexp-quote commit-id) nil t)
        (goto-char (line-beginning-position))
      (goto-char start-pos)
      (message "Commit %s not found" commit-id))))
