Function: pdf-view-set-slice-common-bounding-box

pdf-view-set-slice-common-bounding-box is an interactive and natively compiled function defined in pdf-view.el.

Signature

(pdf-view-set-slice-common-bounding-box &optional WINDOW)

Documentation

Set the slice from the common bounding box of all pages.

WINDOW specifies which document to use; defaults to selected-window. A margin is added from pdf-view-bounding-box-margin.

Key Bindings

pdf-view-mode-map s c

(defun pdf-view-set-slice-common-bounding-box (&optional window)
  "Set the slice from the common bounding box of all pages.

WINDOW specifies which document to use; defaults to `selected-window'.
A margin is added from `pdf-view-bounding-box-margin'."
  (interactive)
  (let* ((bb (pdf-document-common-bounding-box))
         (slice (pdf-view--bounding-box-to-slice bb)))
    (when window
      (push slice window))
    (message (prin1-to-string slice))
    (apply 'pdf-view-set-slice slice)))
