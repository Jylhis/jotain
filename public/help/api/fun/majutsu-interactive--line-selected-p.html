Function: majutsu-interactive--line-selected-p

majutsu-interactive--line-selected-p is a natively compiled function defined in majutsu-interactive.el.

(majutsu-interactive--line-selected-p BOL EOL RANGES)

Documentation

Return non-nil if [BOL,EOL] overlaps any RANGES.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-interactive.el
(defun majutsu-interactive--line-selected-p (bol eol ranges)
  "Return non-nil if [BOL,EOL] overlaps any RANGES."
  (seq-some (lambda (range)
              (and (< (car range) eol)
                   (> (cdr range) bol)))
            ranges))
