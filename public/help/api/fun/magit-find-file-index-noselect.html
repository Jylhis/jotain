Function: magit-find-file-index-noselect

magit-find-file-index-noselect is a natively compiled function defined in magit-files.el.

This function is obsolete since Magit 4.6.0; use magit-find-file-noselect instead.

Signature

(magit-find-file-index-noselect FILE)

Documentation

Read FILE from the index into a buffer and return the buffer.
