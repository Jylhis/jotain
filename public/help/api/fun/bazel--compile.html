Function: bazel--compile

bazel--compile is a natively compiled function defined in bazel.el.

Signature

(bazel--compile COMMAND &rest ARGS)

Documentation

Run Bazel in a Compilation buffer with the given COMMAND and ARGS.

Insert command options from ‘bazel-command-options’ between COMMAND and ARGS.

;; Defined in /nix/store/r10y5b6qa35avdgxmn3dzmd6b9ibs9zi-emacs-packages-deps/share/emacs/site-lisp/elpa/bazel-20260826.1211/bazel.el
(defun bazel--compile (command &rest args)
  "Run Bazel in a Compilation buffer with the given COMMAND and ARGS.
Insert command options from ‘bazel-command-options’ between
COMMAND and ARGS."
  (compile (mapconcat #'shell-quote-argument
                      (append bazel-command (list command)
                              bazel-command-options args)
                      " "))
  nil)
