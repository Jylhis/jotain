Function: pulsar-recenter-top

pulsar-recenter-top is an interactive and natively compiled function defined in pulsar.el.

(defun pulsar-recenter-top ()
  "Reposition point at the top of the window and pulse line."
  (interactive)
  (recenter 0)
  (call-interactively 'pulsar-highlight-pulse))
