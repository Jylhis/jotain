Function: tuareg-interface-mode

tuareg-interface-mode is an interactive and natively compiled function defined in tuareg.el.

Signature

(tuareg-interface-mode)

Documentation

Major mode for editing OCaml interface (.mli) files.

In addition to any hooks its parent mode tuareg-mode might have run, this mode runs the hook tuareg-interface-mode-hook, as the final or penultimate step during initialization.

Key Bindings

This command is not in any keymaps.
