Function: majutsu-get-mode-buffer

majutsu-get-mode-buffer is a natively compiled function defined in majutsu-mode.el.

Signature

(majutsu-get-mode-buffer MODE &optional VALUE DIRECTORY)

Documentation

Return a buffer for DIRECTORY whose major-mode is MODE.

If VALUE is nil, return the first unlocked buffer. If VALUE is non-nil, return the buffer locked to that value.

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-mode.el
(defun majutsu-get-mode-buffer (mode &optional value directory)
  "Return a buffer for DIRECTORY whose `major-mode' is MODE.

If VALUE is nil, return the first unlocked buffer.
If VALUE is non-nil, return the buffer locked to that value."
  (let ((topdir (or directory (majutsu--toplevel-safe))))
    (seq-find
     (lambda (buffer)
       (with-current-buffer buffer
         (and (eq major-mode mode)
              (equal majutsu--default-directory topdir)
              (if value
                  (and majutsu-buffer-locked-p
                       (equal (majutsu-buffer-value) value))
                (not majutsu-buffer-locked-p))
              buffer)))
     (buffer-list))))
