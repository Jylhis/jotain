Function: magit-buffer-file-name

magit-buffer-file-name is a natively compiled function defined in magit-mode.el.

Signature

(magit-buffer-file-name)

Documentation

Return magit-buffer-file-name(var)/magit-buffer-file-name(fun) or if that is nil buffer-file-name(var)/buffer-file-name(fun).

In an indirect buffer get the value for its base buffer.
