Function: pdf-tools-locate-build-directory

pdf-tools-locate-build-directory is a natively compiled function defined in pdf-tools.el.

Signature

(pdf-tools-locate-build-directory)

Documentation

Attempt to locate a source directory.

Returns a appropriate directory or nil. See also pdf-tools-identify-build-directory.

;; Defined in /nix/store/wm0vc3dfi6c7pwjhcfpsnhyg4hd0b5yc-emacs-packages-deps/share/emacs/site-lisp/elpa/pdf-tools-20260102.1101/pdf-tools.el
(defun pdf-tools-locate-build-directory ()
  "Attempt to locate a source directory.

Returns a appropriate directory or nil.  See also
`pdf-tools-identify-build-directory'."
  (cl-some #'pdf-tools-identify-build-directory
           (list default-directory
                 (expand-file-name "build/server" pdf-tools-directory)
                 (expand-file-name "server")
                 (expand-file-name "server" pdf-tools-directory)
                 (expand-file-name "../server" pdf-tools-directory))))
