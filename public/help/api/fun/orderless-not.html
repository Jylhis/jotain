Function: orderless-not

orderless-not is a natively compiled function defined in orderless.el.

Signature

(orderless-not PRED REGEXP)

Documentation

Match strings that do *not* match PRED and REGEXP.

;; Defined in /nix/store/w4nd3vqafwr5yv9m3q76kmi7a9pr8jas-emacs-packages-deps/share/emacs/site-lisp/elpa/orderless-20260830.1156/orderless.el
(defun orderless-not (pred regexp)
  "Match strings that do *not* match PRED and REGEXP."
  (lambda (str)
    (not (orderless--match-p pred regexp str))))
