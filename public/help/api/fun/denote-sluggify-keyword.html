Function: denote-sluggify-keyword

denote-sluggify-keyword is a natively compiled function defined in denote.el.

Signature

(denote-sluggify-keyword STR)

Documentation

Sluggify STR while joining separate words.

Source Code

;; Defined in /nix/store/5x9606vmybcj80x6qrajp43rma9pa1i7-emacs-packages-deps/share/emacs/site-lisp/elpa/denote-4.2.3/denote.el
(defun denote-sluggify-keyword (str)
  "Sluggify STR while joining separate words."
  (downcase
   (replace-regexp-in-string "[][{}!@#$%^&*()+'\"?,.\|;:~`‘’“”/_ =-]*" "" str)))
