Function: majutsu-diff--default-revset

majutsu-diff--default-revset is a natively compiled function defined in majutsu-diff.el.

Signature

(majutsu-diff--default-revset)

Documentation

Return the revset implied by the current diff buffer.

If on a removed line, return the from-rev; otherwise return the to-rev.

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-diff.el
(defun majutsu-diff--default-revset ()
  "Return the revset implied by the current diff buffer.
If on a removed line, return the from-rev; otherwise return the to-rev."
  (let* ((revs (majutsu-diff--revisions))
         (removed (majutsu-diff--on-removed-line-p)))
    (if removed (car revs) (cdr revs))))
