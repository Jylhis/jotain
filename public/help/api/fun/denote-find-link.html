Function: denote-find-link

denote-find-link is an interactive and natively compiled function defined in denote.el.

Signature

(denote-find-link)

Documentation

Use minibuffer completion to visit linked file.

Also see denote-find-backlink.

Key Bindings

This command is not in any keymaps.

;;;###autoload
(defun denote-find-link ()
  "Use minibuffer completion to visit linked file.
Also see `denote-find-backlink'."
  (declare (interactive-only t))
  (interactive)
  (when-let* ((links (or (denote-get-links)
                         (user-error "No links found")))
              (selected (denote-select-from-files-prompt links "Select among LINKS")))
    (find-file selected)))
