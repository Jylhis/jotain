Function: global-pretty-sha-path-mode

global-pretty-sha-path-mode is an interactive and natively compiled function defined in pretty-sha-path.el.

Signature

(global-pretty-sha-path-mode &optional ARG)

Documentation

Toggle Pretty-Sha-Path mode in many buffers.

Specifically, Pretty-Sha-Path mode is enabled in all buffers where pretty-sha-path-turn-on would do it.

With prefix ARG, enable Global Pretty-Sha-Path mode if ARG is positive; otherwise, disable it.

If called from Lisp, toggle the mode if ARG is toggle. Enable the mode if ARG is nil, omitted, or is a positive number. Disable the mode if ARG is a negative number.

See pretty-sha-path-mode(var)/pretty-sha-path-mode(fun) for more information on Pretty-Sha-Path mode.

Key Bindings

This command is not in any keymaps.

Aliases
