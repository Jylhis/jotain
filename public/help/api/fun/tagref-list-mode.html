Function: tagref-list-mode

tagref-list-mode is an interactive and natively compiled function defined in tagref.el.

Signature

(tagref-list-mode)

Documentation

Major mode for displaying tagref tags.

Supports next-error navigation with C-x ` (next-error) and M-g p (previous-error).

In addition to any hooks its parent mode tabulated-list-mode might have run, this mode runs the hook tagref-list-mode-hook, as the final or penultimate step during initialization.

Key Bindings

This command is not in any keymaps.

;; Defined in /nix/store/569pb56gyz7bfhc7d47q808dqp08qfsi-emacs-packages-deps/share/emacs/site-lisp/tagref.el
(define-derived-mode tagref-list-mode tabulated-list-mode "Tagref-List"
  "Major mode for displaying tagref tags.
Supports `next-error' navigation with \\[next-error] and \\[previous-error]."
  (setq tabulated-list-format [("Tag" 40 t)
                               ("File" 50 t)
                               ("Line" 6 t)])
  (setq tabulated-list-sort-key '("Tag" . nil))
  (setq tabulated-list-padding 2)
  (tabulated-list-init-header)
  ;; Enable next-error support
  (setq-local next-error-function #'tagref-list-next-error)
  (setq-local next-error-last-buffer (current-buffer)))
