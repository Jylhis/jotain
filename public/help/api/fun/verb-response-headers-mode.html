Function: verb-response-headers-mode

verb-response-headers-mode is an interactive and natively compiled function defined in verb.el.

Signature

(verb-response-headers-mode)

Documentation

Major mode for displaying an HTTP response's headers.

In addition to any hooks its parent mode special-mode might have run, this mode runs the hook verb-response-headers-mode-hook, as the final or penultimate step during initialization.

q verb-kill-buffer-and-window
