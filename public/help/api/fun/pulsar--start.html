Function: pulsar--start

pulsar--start is a natively compiled function defined in pulsar.el.

Signature

(pulsar--start)

Documentation

Return appropriate line start.

When in the minibuffer, return the point-min, which includes the text of the prompt. This way, a pulse will be visible even if the minibuffer has no initial text (e.g. M-x with the default completion setup).

(defun pulsar--start ()
  "Return appropriate line start.
When in the minibuffer, return the `point-min', which includes
the text of the prompt.  This way, a pulse will be visible even
if the minibuffer has no initial text (e.g. `M-x' with the
default completion setup)."
  (let ((inhibit-field-text-motion t))
    (cond
     ((minibufferp)
      (save-excursion
        (goto-char (minibuffer-prompt-end))
        (line-beginning-position)))
     ((and (pulsar--buffer-end-p) (eq (char-before) ?\n))
      (line-beginning-position 0))
     (t
      (line-beginning-position)))))
