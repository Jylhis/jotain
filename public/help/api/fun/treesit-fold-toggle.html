Function: treesit-fold-toggle

treesit-fold-toggle is an interactive and byte-compiled function defined in treesit-fold.el.

Signature

(treesit-fold-toggle)

Documentation

Toggle the syntax node at point.

If the current syntax node is not foldable, do nothing.

This function has :after advice: treesit-fold--after-command.

Key Bindings

This command is not in any keymaps.

(defun treesit-fold-toggle ()
  "Toggle the syntax node at `point'.
If the current syntax node is not foldable, do nothing."
  (interactive)
  (treesit-fold--ensure-ts
    (if-let* ((node (treesit-fold--foldable-node-at-pos (point)))
              (ov (treesit-fold-overlay-at node)))
        (progn
          (delete-overlay ov)
          (run-hooks 'treesit-fold-on-fold-hook)
          t)
      (treesit-fold-close))))
