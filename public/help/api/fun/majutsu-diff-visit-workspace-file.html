Function: majutsu-diff-visit-workspace-file

majutsu-diff-visit-workspace-file is an interactive and natively compiled function defined in majutsu-diff.el.

Signature

(majutsu-diff-visit-workspace-file)

Documentation

From a diff, visit the workspace version of the file at point.

Always visits the actual file in the working tree, regardless of what the diff is about.

Key Bindings

majutsu-diff-section-map C-<return> majutsu-diff-section-map C-j
