Function: meson-syntax-count-quotes

meson-syntax-count-quotes is a byte-compiled function defined in meson-mode.el.

Signature

(meson-syntax-count-quotes &optional POINT LIMIT)

Documentation

Count number of quotes after point (max is 3).

POINT is the point where scan starts (defaults to current point), and LIMIT is used to limit the scan.

(defsubst meson-syntax-count-quotes (&optional point limit)
  "Count number of quotes after point (max is 3).
POINT is the point where scan starts (defaults to current point),
and LIMIT is used to limit the scan."
  (let ((i 0)
	(p (or point (point))))
    (while (and (< i 3)
                (or (not limit) (< (+ p i) limit))
                (eq (char-after (+ p i)) ?\'))
      (setq i (1+ i)))
    i))
