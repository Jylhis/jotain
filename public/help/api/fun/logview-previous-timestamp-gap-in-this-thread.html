Function: logview-previous-timestamp-gap-in-this-thread

logview-previous-timestamp-gap-in-this-thread is an interactive and natively compiled function defined in logview.el.

Signature

(logview-previous-timestamp-gap-in-this-thread &optional N)

Documentation

Move to the previous large gap in thread's entry timestamps.

If N is specified, use that as a gap count. Only consider entries within this thread that are not filtered out.

Point is positioned at the beginning of the message of the first entry after the gap.

Key Bindings

logview-mode-map z P

(defun logview-previous-timestamp-gap-in-this-thread (&optional n)
  "Move to the previous large gap in thread's entry timestamps.
If N is specified, use that as a gap count.  Only consider
entries within this thread that are not filtered out.

Point is positioned at the beginning of the message of the first
entry after the gap."
  (interactive "p")
  (logview--do-next-timestamp-gap (if n (- n) -1) t))
