Function: majutsu-log--module-columns

majutsu-log--module-columns is a natively compiled function defined in majutsu-log.el.

Signature

(majutsu-log--module-columns COMPILED MODULE)

Documentation

Return compiled column specs for MODULE from COMPILED metadata.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-log.el
(defun majutsu-log--module-columns (compiled module)
  "Return compiled column specs for MODULE from COMPILED metadata."
  (alist-get module (plist-get compiled :module-columns) nil nil #'eq))
