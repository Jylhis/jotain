Function: majutsu-workspace--completion-suffix-function

majutsu-workspace--completion-suffix-function is a natively compiled function defined in majutsu-workspace.el.

Signature

(majutsu-workspace--completion-suffix-function ENTRIES &optional DIRECTORY)

Documentation

Return candidate suffix function backed by workspace ENTRIES.

DIRECTORY is captured so suffix rendering stays stable in the minibuffer.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-workspace.el
(defun majutsu-workspace--completion-suffix-function (entries &optional directory)
  "Return candidate suffix function backed by workspace ENTRIES.
DIRECTORY is captured so suffix rendering stays stable in the minibuffer."
  (majutsu-completion-entry-suffix-function
   entries
   (lambda (entry)
     (majutsu-workspace--completion-suffix entry directory))))
