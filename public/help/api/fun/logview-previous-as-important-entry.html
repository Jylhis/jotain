Function: logview-previous-as-important-entry

logview-previous-as-important-entry is an interactive and natively compiled function defined in logview.el.

Signature

(logview-previous-as-important-entry &optional N)

Documentation

Move point vertically up N “as important” entries.

Point is positioned at the beginning of the message of the resulting entry.

See function logview-next-as-important-entry for definition of
“as important”.

Key Bindings

logview-mode-map P

(defun logview-previous-as-important-entry (&optional n)
  "Move point vertically up N “as important” entries.
Point is positioned at the beginning of the message of the
resulting entry.

See function `logview-next-as-important-entry' for definition of
“as important”."
  (interactive "p")
  (logview-next-as-important-entry (if n (- n) -1)))
