Function: majutsu-annotate-read-only-mode

majutsu-annotate-read-only-mode is an interactive and natively compiled function defined in majutsu-annotate.el.

Signature

(majutsu-annotate-read-only-mode &optional ARG)

Documentation

Provide keybindings for Majutsu-Annotate mode.

This minor-mode provides the key bindings for Majutsu-Annotate mode, but only when Read-Only mode is also enabled because these key bindings would otherwise conflict badly with regular bindings.

When both Majutsu-Annotate mode and Read-Only mode are enabled, then this mode gets automatically enabled too and when one of these modes is toggled, then this mode also gets toggled automatically.

DEL majutsu-annotate-show-or-scroll-down
M-w majutsu-annotate-copy-hash
N majutsu-annotate-next-chunk-same-commit
P majutsu-annotate-previous-chunk-same-commit
RET majutsu-annotate-show-commit
S-SPC majutsu-annotate-show-or-scroll-down
SPC majutsu-annotate-show-or-scroll-up
b majutsu-annotate-addition
c majutsu-annotate-cycle-style
n majutsu-annotate-next-chunk
p majutsu-annotate-previous-chunk
q majutsu-annotate-quit

This is a minor mode. If called interactively, toggle the Majutsu-Annotate-Read-Only mode mode. If the prefix argument is positive, enable the mode, and if it is zero or negative, disable the mode.

If called from Lisp, toggle the mode if ARG is toggle. Enable the mode if ARG is nil, omitted, or is a positive number. Disable the mode if ARG is a negative number.

To check whether the minor mode is enabled in the current buffer, evaluate the variable majutsu-annotate-read-only-mode(var)/majutsu-annotate-read-only-mode(fun).

The mode's hook is called both when the mode is enabled and when it is disabled.

Key Bindings

This command is not in any keymaps.
