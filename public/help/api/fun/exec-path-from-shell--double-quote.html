Function: exec-path-from-shell--double-quote

exec-path-from-shell--double-quote is a natively compiled function defined in exec-path-from-shell.el.

Signature

(exec-path-from-shell--double-quote S)

Documentation

Double-quote S, escaping any double-quotes already contained in it.

Source Code

;; Defined in /nix/store/lzrv36jn1gafnd9x3mmwlizw57dr87rp-emacs-packages-deps/share/emacs/site-lisp/elpa/exec-path-from-shell-20260423.1833/exec-path-from-shell.el
(defun exec-path-from-shell--double-quote (s)
  "Double-quote S, escaping any double-quotes already contained in it."
  (concat "\"" (replace-regexp-in-string "\"" "\\\\\"" s) "\""))
