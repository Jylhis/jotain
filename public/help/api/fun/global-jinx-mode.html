Function: global-jinx-mode

global-jinx-mode is an interactive and natively compiled function defined in jinx.el.

Signature

(global-jinx-mode &optional ARG)

Documentation

Toggle Jinx mode in many buffers.

Specifically, Jinx mode is enabled in all buffers where jinx--on would do it.

With prefix ARG, enable Global Jinx mode if ARG is positive; otherwise, disable it.

If called from Lisp, toggle the mode if ARG is toggle. Enable the mode if ARG is nil, omitted, or is a positive number. Disable the mode if ARG is a negative number.

See jinx-mode(var)/jinx-mode(fun) for more information on Jinx mode.

global-jinx-modes is used to control which modes this minor mode is used in.

Key Bindings

This command is not in any keymaps.
