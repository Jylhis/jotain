Function: neocaml--compilation-end-column

neocaml--compilation-end-column is a natively compiled function defined in neocaml.el.

Signature

(neocaml--compilation-end-column)

Documentation

Return the end-column from an OCaml compilation message.

OCaml reports an exclusive 0-indexed end-column; Emacs expects an inclusive 1-indexed end-column. The +1 (0-to-1 indexing) and -1
(exclusive-to-inclusive) cancel out, so we return the raw value.
