Function: majutsu-blob-edit-start

majutsu-blob-edit-start is an interactive and natively compiled function defined in majutsu-file.el.

Signature

(majutsu-blob-edit-start)

Documentation

Enter editable blob mode.

Edits are applied to the revision through jj diffedit when saving.

Key Bindings

majutsu-blob-mode-map C-x C-q majutsu-blob-mode-map e

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-file.el
(defun majutsu-blob-edit-start ()
  "Enter editable blob mode.
Edits are applied to the revision through jj diffedit when saving."
  (interactive)
  (unless (and (bound-and-true-p majutsu-blob-mode)
               majutsu-buffer-blob-root
               majutsu-buffer-blob-path
               majutsu-buffer-blob-revision)
    (user-error "Not in a blob buffer"))
  (unless majutsu-blob-edit-mode
    (majutsu-blob-edit-mode 1)))
