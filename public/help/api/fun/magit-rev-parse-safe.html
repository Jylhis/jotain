Function: magit-rev-parse-safe

magit-rev-parse-safe is a natively compiled function defined in magit-git.el.

Signature

(magit-rev-parse-safe &rest ARGS)

Documentation

Execute "git rev-parse ARGS", returning first line of output.

If there is no output, return nil. Like magit-rev-parse but ignore magit-git-debug.
