Function: majutsu-diff--set-left-margin

majutsu-diff--set-left-margin is a natively compiled function defined in majutsu-diff.el.

Signature

(majutsu-diff--set-left-margin WIDTH)

Documentation

Set left margin WIDTH for the current buffer's windows.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-diff.el
(defun majutsu-diff--set-left-margin (width)
  "Set left margin WIDTH for the current buffer's windows."
  (setq-local left-margin-width width)
  (dolist (window (get-buffer-window-list (current-buffer) nil t))
    (set-window-margins window width (cdr (window-margins window)))))
