Function: majutsu-workspace-update-stale

majutsu-workspace-update-stale is an interactive and natively compiled function defined in majutsu-workspace.el.

Signature

(majutsu-workspace-update-stale)

Documentation

Update the current workspace if it has become stale.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-workspace.el
;;;###autoload
(defun majutsu-workspace-update-stale ()
  "Update the current workspace if it has become stale."
  (interactive)
  (if (zerop (majutsu-run-jj "workspace" "update-stale"))
      (progn
        (message "Workspace updated"))
    (message "Workspace update failed")))
