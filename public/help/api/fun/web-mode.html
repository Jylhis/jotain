Function: web-mode

web-mode is an interactive and natively compiled function defined in web-mode.el.

Signature

(web-mode)

Documentation

Major mode for editing web templates.

In addition to any hooks its parent mode web-mode-prog-mode might have run, this mode runs the hook web-mode-hook, as the final or penultimate step during initialization.

          web-mode-change-end (point-max))

      (web-mode-buffer-fontify))

               (not (assoc major-mode hs-special-modes-alist)))

      ) ;when

    (if (fboundp 'prog-mode)

      ((not (buffer-file-name))
       )
      ((string-match-p "web-mode-benchmark.html" (buffer-file-name))
       (web-mode-measure "end"))
