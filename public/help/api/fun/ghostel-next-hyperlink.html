Function: ghostel-next-hyperlink

ghostel-next-hyperlink is an interactive and natively compiled function defined in ghostel-links.el.

Signature

(ghostel-next-hyperlink &optional N)

Documentation

Enter ghostel-readonly-default-mode and move to the Nth next hyperlink.

A hyperlink is any OSC 8 link, auto-detected URL, or file:line reference in the buffer. Wraps to point-min when no link is found after point. Press RET to follow the link at point.

Key Bindings

ghostel-hyperlink-repeat-map C-n ghostel-hyperlink-repeat-map n ghostel-mode-map C-c C-n

(defun ghostel-next-hyperlink (&optional n)
  "Enter `ghostel-readonly-default-mode' and move to the Nth next hyperlink.
A hyperlink is any OSC 8 link, auto-detected URL, or `file:line'
reference in the buffer.  Wraps to `point-min' when no link is found
after point.  Press RET to follow the link at point."
  (interactive "p")
  (unless (memq ghostel--input-mode '(copy emacs))
    (ghostel--enter-readonly-input-mode 'default))
  (dotimes (_ (or n 1))
    (ghostel--goto-hyperlink 'next)))
