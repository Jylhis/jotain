Function: embark-encode-url

embark-encode-url is an interactive and natively compiled function defined in embark.el.

Signature

(embark-encode-url START END)

Documentation

Properly URI-encode the region between START and END in current buffer.

Key Bindings

embark-encode-map u embark-region-map > u

Source Code

;; Defined in /nix/store/fs4fhphi5ajjmvzx1rm550ibr8slmvxd-emacs-packages-deps/share/emacs/site-lisp/elpa/embark-20260610.302/embark.el
(defun embark-encode-url (start end)
  "Properly URI-encode the region between START and END in current buffer."
  (interactive "r")
  (let ((encoded (url-encode-url (buffer-substring-no-properties start end))))
    (delete-region start end)
    (insert encoded)))
