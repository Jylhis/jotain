Function: haskell-yesod-parse-routes-mode

haskell-yesod-parse-routes-mode is an interactive and natively compiled function defined in haskell-font-lock.el.

Signature

(haskell-yesod-parse-routes-mode)

Documentation

Mode for parseRoutes from Yesod.

In addition to any hooks its parent mode text-mode might have run, this mode runs the hook haskell-yesod-parse-routes-mode-hook, as the final or penultimate step during initialization.

Key Bindings

This command is not in any keymaps.
