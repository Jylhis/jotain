Function: csv-yank-as-new-table

csv-yank-as-new-table is an interactive and natively compiled function defined in csv-mode.el.

Signature

(csv-yank-as-new-table)

Documentation

Yank fields as a new table starting at point.

The fields yanked are those last killed by csv-kill-fields.

Key Bindings

(defun csv-yank-as-new-table ()
  "Yank fields as a new table starting at point.
The fields yanked are those last killed by `csv-kill-fields'."
  (interactive "*")
  (let ((fields csv-killed-fields))
    (while fields
      (insert (car fields) ?\n)
      (setq fields (cdr fields)))))
