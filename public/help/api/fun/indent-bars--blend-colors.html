Function: indent-bars--blend-colors

indent-bars--blend-colors is a natively compiled function defined in indent-bars.el.

Signature

(indent-bars--blend-colors C1 C2 FAC)

Documentation

Return a fractional color between two colors C1 and C2.

Each is a string color. The fractional blend point is the float FAC, with 1.0 matching C1 and 0.0 C2.

(defun indent-bars--blend-colors (c1 c2 fac)
  "Return a fractional color between two colors C1 and C2.
Each is a string color.  The fractional blend point is the
float FAC, with 1.0 matching C1 and 0.0 C2."
  (apply #'color-rgb-to-hex
	 (cl-mapcar (lambda (a b)
		      (+ (* a fac) (* b (- 1.0 fac))))
		    (color-name-to-rgb c1) (color-name-to-rgb c2))))
