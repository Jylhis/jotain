Function: pdf-tools-enable-minor-modes

pdf-tools-enable-minor-modes is an interactive and natively compiled function defined in pdf-tools.el.

Signature

(pdf-tools-enable-minor-modes &optional MODES)

Documentation

Enable MODES in the current buffer.

MODES defaults to pdf-tools-enabled-modes.

Key Bindings

This command is not in any keymaps.

(defun pdf-tools-enable-minor-modes (&optional modes)
  "Enable MODES in the current buffer.

MODES defaults to `pdf-tools-enabled-modes'."
  (interactive)
  (pdf-util-assert-pdf-buffer)
  (pdf-tools-set-modes-enabled t modes)
  (run-hooks 'pdf-tools-enabled-hook))
