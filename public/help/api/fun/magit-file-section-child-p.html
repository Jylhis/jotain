Function: magit-file-section-child-p

magit-file-section-child-p is a function alias for magit-file-section--eieio-childp, defined in magit-base.el.

This function is obsolete since 25.1; use (cl-typep ... 'magit-file-section) instead

Signature

(magit-file-section-child-p OBJ)

Documentation

Return non-nil if OBJ is an object of type magit-file-section(var)/magit-file-section(fun) or a subclass.

Aliases

magit-file-section--eieio-childp
