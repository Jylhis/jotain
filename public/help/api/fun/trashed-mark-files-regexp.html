Function: trashed-mark-files-regexp

trashed-mark-files-regexp is an interactive and natively compiled function defined in trashed.el.

Signature

(trashed-mark-files-regexp &optional REGEXP)

Documentation

Mark all files matching REGEXP for use in later commands.

If called interactively or REGEXP is nil, prompt for REGEXP.

Key Bindings

trashed-mode-map % m

(defun trashed-mark-files-regexp (&optional regexp)
  "Mark all files matching REGEXP for use in later commands.
If called interactively or REGEXP is nil, prompt for REGEXP."
  (interactive)
  (trashed-tag-files-regexp trashed-marker-char regexp "Mark"))
