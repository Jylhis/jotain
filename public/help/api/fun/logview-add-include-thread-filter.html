Function: logview-add-include-thread-filter

logview-add-include-thread-filter is an interactive and natively compiled function defined in logview.el.

Signature

(logview-add-include-thread-filter)

Documentation

Show only entries with thread matching regular expression.

If this command is invoked multiple times, show entries with thread name matching at least one of entered expression.

Key Bindings

logview-mode-map t

Source Code

;; Defined in /nix/store/qid656ql5mh048bd0k84vvsbc2517lh9-emacs-packages-deps/share/emacs/site-lisp/elpa/logview-20260218.2013/logview.el
(defun logview-add-include-thread-filter ()
  "Show only entries with thread matching regular expression.
If this command is invoked multiple times, show entries with
thread name matching at least one of entered expression."
  (interactive)
  (logview--prompt-for-new-filter "Thread regexp to show entries" 'thread "t+"))
