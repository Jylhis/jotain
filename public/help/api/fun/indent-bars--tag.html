Function: indent-bars--tag

indent-bars--tag is a byte-compiled function defined in indent-bars.el.

Signature

(indent-bars--tag FORMAT-STR S &rest R)

Documentation

Tag FORMAT-STR with style S and return the associate interned symbol.

Additional format arguments can be passed as R.

Source Code

;; Defined in /nix/store/kmdsnipwffgk5c0fs4785bhqa9fl17c5-emacs-packages-deps/share/emacs/site-lisp/elpa/indent-bars-1.0.1/indent-bars.el
(defsubst indent-bars--tag (format-str s &rest r)
  "Tag FORMAT-STR with style S and return the associate interned symbol.
Additional `format' arguments can be passed as R."
  (intern (apply #'format format-str
		 (if (ibs/tag s) (concat "-" (ibs/tag s)) "") r)))
