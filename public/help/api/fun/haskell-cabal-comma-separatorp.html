Function: haskell-cabal-comma-separatorp

haskell-cabal-comma-separatorp is a natively compiled function defined in haskell-cabal.el.

Documentation

Return non-nil when the char at POS is a comma separator.

Characters that are not a comma, or commas inside a commment or string, are not comma separators.

(defun haskell-cabal-comma-separatorp (pos)
  "Return non-nil when the char at POS is a comma separator.
Characters that are not a comma, or commas inside a commment or
string, are not comma separators."
  (when (eq (char-after pos) ?,)
    (let ((ss (syntax-ppss pos)))
      (not
       (or
        ;; inside a string
        (nth 3 ss)
        ;; inside a comment
        (nth 4 ss))))))
