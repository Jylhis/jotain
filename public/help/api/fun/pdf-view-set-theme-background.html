Function: pdf-view-set-theme-background

pdf-view-set-theme-background is a natively compiled function defined in pdf-view.el.

Signature

(pdf-view-set-theme-background)

Documentation

Set the buffer's color filter to correspond to the current Emacs theme.

Source Code

;; Defined in /nix/store/wm0vc3dfi6c7pwjhcfpsnhyg4hd0b5yc-emacs-packages-deps/share/emacs/site-lisp/elpa/pdf-tools-20260102.1101/pdf-view.el
(defun pdf-view-set-theme-background ()
  "Set the buffer's color filter to correspond to the current Emacs theme."
  (pdf-util-assert-pdf-buffer)
  (pdf-info-setoptions
   :render/foreground (face-foreground 'default nil)
   :render/background (face-background 'default nil)
   :render/usecolors 1))
