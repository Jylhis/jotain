Function: nerd-icons-match-to-alist

nerd-icons-match-to-alist is a natively compiled function defined in nerd-icons.el.

(nerd-icons-match-to-alist STRING ALIST)

Documentation

Match STRING against an entry in ALIST using string-match.

;; Defined in /nix/store/5d32bwjxzn3xi8rsa6xvgzb9pk6pfcgk-emacs-packages-deps/share/emacs/site-lisp/elpa/nerd-icons-20260823.17/nerd-icons.el
(defun nerd-icons-match-to-alist (string alist)
  "Match STRING against an entry in ALIST using `string-match'."
  (let ((case-fold-search nil))
    (cdr (assoc string alist #'string-match))))
