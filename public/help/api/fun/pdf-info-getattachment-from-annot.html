Function: pdf-info-getattachment-from-annot

pdf-info-getattachment-from-annot is a natively compiled function defined in pdf-info.el.

Signature

(pdf-info-getattachment-from-annot ID &optional DO-SAVE FILE-OR-BUFFER)

Documentation

Return the attachment associated with annotation ID.

ID should be a symbol which was previously returned in a pdf-info-getannots query, and referencing an attachment of type file, otherwise an error is signaled.

See pdf-info-getattachments for the kind of return value of this function and the meaning of DO-SAVE.

(defun pdf-info-getattachment-from-annot (id &optional do-save file-or-buffer)
  "Return the attachment associated with annotation ID.

`pdf-info-getannots' query, and referencing an attachment of type
`file', otherwise an error is signaled.

See `pdf-info-getattachments' for the kind of return value of this

  (pdf-info-query

   (pdf-info--normalize-file-or-buffer file-or-buffer)
