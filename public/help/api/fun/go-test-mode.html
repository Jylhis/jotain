Function: go-test-mode

go-test-mode is an interactive and natively compiled function defined in gotest.el.

Signature

Documentation

Major mode for the Go-Test compilation buffer.

In addition to any hooks its parent mode compilation-mode might have run, this mode runs the hook go-test-mode-hook, as the final or penultimate step during initialization.
