Function: eca-settings-mode

eca-settings-mode is an interactive and natively compiled function defined in eca-settings.el.

Signature

(eca-settings-mode)

Documentation

Major mode for ECA settings panels.

C-c . eca-transient-menu
C-c C-, #<anonymous-function>
g eca-settings--refresh-current
q quit-window

In addition to any hooks its parent mode special-mode might have run, this mode runs the hook eca-settings-mode-hook, as the final or penultimate step during initialization.

Key Bindings

This command is not in any keymaps.
