Function: ghostel-send-C-z

ghostel-send-C-z is an interactive and natively compiled function defined in ghostel.el.

Signature

(ghostel-send-C-z)

Documentation

Send suspend signal to the terminal.

Sends the raw byte so the tty line discipline raises SIGTSTP even when the foreground program has kitty keyboard mode active.

Key Bindings

ghostel-mode-map C-c C-z

  "Send suspend signal to the terminal.

when the foreground program has kitty keyboard mode active."
  (interactive)
