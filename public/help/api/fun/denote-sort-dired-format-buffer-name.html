Function: denote-sort-dired-format-buffer-name

denote-sort-dired-format-buffer-name is a natively compiled function defined in denote.el.

Signature

(denote-sort-dired-format-buffer-name FILES-MATCHING-REGEXP SORT-BY-COMPONENT REVERSE EXCLUDE-REGEXP)

Documentation

Format buffer name for denote-sort-dired.

The FILES-MATCHING-REGEXP, SORT-BY-COMPONENT, REVERSE, and EXCLUDE-REGEXP all have the same meaning as denote-sort-dired. Process them to return the buffer name.

(defun denote-sort-dired-format-buffer-name (files-matching-regexp sort-by-component reverse exclude-regexp)
  "Format buffer name for `denote-sort-dired'.
The FILES-MATCHING-REGEXP, SORT-BY-COMPONENT, REVERSE, and
EXCLUDE-REGEXP all have the same meaning as `denote-sort-dired'.
Process them to return the buffer name."
  (denote-format-buffer-name
   (format-message
    "regexp `%s'; sort `%s'%s%s"
    files-matching-regexp
    sort-by-component
    (if reverse "; reverse t" "")
    (if exclude-regexp (format-message "; exclude-regexp `%s'" exclude-regexp) ""))
   :special-buffer))
