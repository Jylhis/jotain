Function: majutsu-log--refresh-tail-window

majutsu-log--refresh-tail-window is a natively compiled function defined in majutsu-log.el.

Signature

(majutsu-log--refresh-tail-window &optional WINDOW)

Documentation

Refresh tail alignment for the current log buffer using WINDOW.

When WINDOW is nil, use majutsu-log--tail-owner-window.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-log.el
(defun majutsu-log--refresh-tail-window (&optional window)
  "Refresh tail alignment for the current log buffer using WINDOW.
When WINDOW is nil, use `majutsu-log--tail-owner-window'."
  (when (derived-mode-p 'majutsu-log-mode)
    (setq window (or window (majutsu-log--tail-owner-window)))
    (majutsu-log--refresh-tail-spacers nil nil window)
    (when window
      (force-window-update window))))
