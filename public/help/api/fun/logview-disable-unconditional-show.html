Function: logview-disable-unconditional-show

logview-disable-unconditional-show is an interactive and natively compiled function defined in logview.el.

Signature

(logview-disable-unconditional-show)

Documentation

Disable unconditional display of entries.

All entries, regardless of level, will be shown only if they match the current text filters.

Key Bindings

logview-mode-map L 0 logview-mode-map L L

match the current text filters."
  (interactive)
