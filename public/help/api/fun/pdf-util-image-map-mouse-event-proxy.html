Function: pdf-util-image-map-mouse-event-proxy

pdf-util-image-map-mouse-event-proxy is an interactive and natively compiled function defined in pdf-util.el.

Signature

(pdf-util-image-map-mouse-event-proxy EVENT)

Documentation

Set POS-OR-AREA in EVENT to 1 and unread it.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/wm0vc3dfi6c7pwjhcfpsnhyg4hd0b5yc-emacs-packages-deps/share/emacs/site-lisp/elpa/pdf-tools-20260102.1101/pdf-util.el
(defun pdf-util-image-map-mouse-event-proxy (event)
  "Set POS-OR-AREA in EVENT to 1 and unread it."
  (interactive "e")
  (setcar (cdr (cadr event)) 1)
  (setq unread-command-events (list event)))
