Function: forge-topics-mode

forge-topics-mode is a natively compiled function defined in forge-topics.el.

Signature

(forge-topics-mode)

Documentation

Major mode for browsing a list of topics.

In addition to any hooks its parent mode magit-mode might have run, this mode runs the hook forge-topics-mode-hook, as the final or penultimate step during initialization.
