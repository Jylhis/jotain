Function: exec-path-from-shell-copy-env

exec-path-from-shell-copy-env is an interactive and natively compiled function defined in exec-path-from-shell.el.

Signature

(exec-path-from-shell-copy-env NAME)

Documentation

Set the environment variable $NAME from the user's shell.

As a special case, if the variable is $PATH, then the variables exec-path(var)/exec-path(fun) and eshell-path-env are also set appropriately. Return the value of the environment variable.

Key Bindings

This command is not in any keymaps.

As a special case, if the variable is $PATH, then the variables

Return the value of the environment variable."

  (cdar (exec-path-from-shell-copy-envs (list name))))
