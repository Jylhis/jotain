Function: combobulate-node-unique

combobulate-node-unique is a natively compiled function defined in combobulate-navigation.el.

(combobulate-node-unique NODES)

Source Code

;; Defined in /nix/store/9y0jasyzsqjcbfkwqsgdyxcnskjnsypg-emacs-packages-deps/share/emacs/site-lisp/combobulate-navigation.el
(defun combobulate-node-unique (nodes)
  "Removes duplicate NODES and keeps only uniques"
  (seq-uniq nodes (lambda (a b) (and (combobulate-node-eq a b)))))
