Function: pdf-view-printer-minor-mode

pdf-view-printer-minor-mode is an interactive and natively compiled function defined in pdf-view.el.

Signature

(pdf-view-printer-minor-mode &optional ARG)

Documentation

Display the PDF as it would be printed.

This is a minor mode. If called interactively, toggle the Pdf-View-Printer minor mode mode. If the prefix argument is positive, enable the mode, and if it is zero or negative, disable the mode.

If called from Lisp, toggle the mode if ARG is toggle. Enable the mode if ARG is nil, omitted, or is a positive number. Disable the mode if ARG is a negative number.

To check whether the minor mode is enabled in the current buffer, evaluate the variable pdf-view-printer-minor-mode(var)/pdf-view-printer-minor-mode(fun).

The mode's hook is called both when the mode is enabled and when it is disabled.

(define-minor-mode pdf-view-printer-minor-mode
  "Display the PDF as it would be printed."
  :group 'pdf-view
  :lighter " Prn"
  (pdf-util-assert-pdf-buffer)
  (let ((enable (lambda ()
                  (pdf-info-setoptions :render/printed t))))
    (cond
     (pdf-view-printer-minor-mode
      (add-hook 'after-save-hook enable nil t)
      (add-hook 'after-revert-hook enable nil t))
     (t
      (remove-hook 'after-save-hook enable t)
      (remove-hook 'after-revert-hook enable t))))
  (pdf-info-setoptions :render/printed pdf-view-printer-minor-mode)
  (pdf-cache-clear-images)
  (pdf-view-redisplay t))
