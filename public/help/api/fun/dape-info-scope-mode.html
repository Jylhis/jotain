Function: dape-info-scope-mode

dape-info-scope-mode is a natively compiled function defined in dape.el.

Signature

(dape-info-scope-mode)

Documentation

Major mode for viewing and editing scoped variables.

In addition to any hooks its parent mode dape-info-parent-mode might have run, this mode runs the hook dape-info-scope-mode-hook, as the final or penultimate step during initialization.
