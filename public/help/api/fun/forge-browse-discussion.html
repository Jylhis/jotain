Function: forge-browse-discussion

forge-browse-discussion is an interactive and natively compiled function defined in forge-commands.el.

Signature

(forge-browse-discussion DISCUSSION)

Documentation

Read a DISCUSSION and visit it using a browser.

By default only offer open discussions but with a prefix argument also offer closed issues.

Key Bindings

This command is not in any keymaps.

(defun forge-browse-discussion (discussion)
  "Read a DISCUSSION and visit it using a browser.
By default only offer open discussions but with a prefix argument
also offer closed issues."
  (interactive (list (forge-read-discussion "Browse discussion")))
  (forge--browse-topic discussion))
