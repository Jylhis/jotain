Function: pdf-view-mouse-set-region-rectangle

pdf-view-mouse-set-region-rectangle is an interactive and natively compiled function defined in pdf-view.el.

Signature

(pdf-view-mouse-set-region-rectangle EVENT)

Documentation

Like pdf-view-mouse-set-region but displays as a rectangle.

EVENT is the mouse event.

This is more useful for commands like pdf-view-extract-region-image.

Key Bindings

pdf-view-mode-map M-<down-mouse-1>

(defun pdf-view-mouse-set-region-rectangle (event)
  "Like `pdf-view-mouse-set-region' but displays as a rectangle.

EVENT is the mouse event.

This is more useful for commands like
`pdf-view-extract-region-image'."
  (interactive "@e")
  (pdf-view-mouse-set-region event nil t))
