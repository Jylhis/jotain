Function: dape-info-breakpoints-mode

dape-info-breakpoints-mode is a natively compiled function defined in dape.el.

Signature

(dape-info-breakpoints-mode)

Documentation

Major mode for viewing and editing breakpoints.

In addition to any hooks its parent mode dape-info-parent-mode might have run, this mode runs the hook dape-info-breakpoints-mode-hook, as the final or penultimate step during initialization.
