Function: dirvish-dwim

dirvish-dwim is an interactive and natively compiled function defined in dirvish.el.

Signature

(dirvish-dwim &optional PATH)

Documentation

Open PATH in a fullframe session if selected window is the only window.

Prompt for PATH if called with M-x universal-arguments (universal-arguments), otherwise PATH defaults to default-directory. If there are other windows exist in the selected frame, the session occupies only the selected window.

Key Bindings

This command is not in any keymaps.

(defun dirvish-dwim (&optional path)
  "Open PATH in a fullframe session if selected window is the only window.
Prompt for PATH if called with \\[universal-arguments], otherwise PATH
defaults to `default-directory'.  If there are other windows exist in the
selected frame, the session occupies only the selected window."

  (dirvish--try-reuse path 'dwim))
