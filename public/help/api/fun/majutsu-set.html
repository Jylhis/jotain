Function: majutsu-set

majutsu-set is a natively compiled function defined in majutsu-config.el.

Signature

(majutsu-set KEY VALUE &optional SCOPE)

Documentation

Set config KEY to VALUE in SCOPE (user/repo/workspace).

SCOPE defaults to user.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-config.el
(defun majutsu-set (key value &optional scope)
  "Set config KEY to VALUE in SCOPE (user/repo/workspace).
SCOPE defaults to user."
  (let ((args (list "config" "set"
                    (pcase scope
                      ('repo "--repo")
                      ('workspace "--workspace")
                      (_ "--user"))
                    key value)))
    (majutsu-run-jj args)))
