Function: pulsar-pulse-line-red

pulsar-pulse-line-red is an interactive and natively compiled function defined in pulsar.el.

Signature

(pulsar-pulse-line-red)

Documentation

Like pulsar-pulse-line but uses the pulsar-red face.

The idea with this is to run it in special hooks or contexts where you need a different color than what Pulsar normally uses (per the user option pulsar-face)

Key Bindings

This command is not in any keymaps.
