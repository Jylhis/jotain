Function: pdf-util-convert-page

pdf-util-convert-page is a natively compiled function defined in pdf-util.el.

Signature

(pdf-util-convert-page &rest SPECS)

Documentation

Convert image of current page according to SPECS.

Return the converted PNG image as a string. See also pdf-util-convert.

(defun pdf-util-convert-page (&rest specs)
  "Convert image of current page according to SPECS.

Return the converted PNG image as a string.  See also
`pdf-util-convert'."

  (pdf-util-assert-pdf-window)
  (apply #'pdf-util-convert-image (pdf-view-current-image) specs))
