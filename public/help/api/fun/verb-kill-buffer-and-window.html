Function: verb-kill-buffer-and-window

verb-kill-buffer-and-window is an interactive and natively compiled function defined in verb.el.

Signature

(verb-kill-buffer-and-window)

Documentation

Delete selected window and kill its current buffer.

Delete the window only if it isn't the only window in the frame.

Key Bindings

verb-response-headers-mode-map q

Source Code

;; Defined in /nix/store/1vhkdxrkj0c423ijah8wn2d489dd8rgw-emacs-packages-deps/share/emacs/site-lisp/elpa/verb-20260818.1921/verb.el
(defun verb-kill-buffer-and-window ()
  "Delete selected window and kill its current buffer.
Delete the window only if it isn't the only window in the frame."
  (interactive)
  (kill-buffer (current-buffer))
  (ignore-errors
    (delete-window)))
