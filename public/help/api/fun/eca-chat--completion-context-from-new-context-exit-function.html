Function: eca-chat--completion-context-from-new-context-exit-function

eca-chat--completion-context-from-new-context-exit-function is a natively compiled function defined in eca-chat-context.el.

(eca-chat--completion-context-from-new-context-exit-function ITEM STATUS)

Documentation

Add to context the selected ITEM.

Directories are not finalized: completion keeps going inside them; typing a space adds the directory itself as context.

(defun eca-chat--completion-context-from-new-context-exit-function (item _status)
  "Add to context the selected ITEM.
Directories are not finalized: completion keeps going inside
them; typing a space adds the directory itself as context."
  (if (eca-chat--completion-item-directory-p item)
      (eca-chat--completion-drill-in eca-chat-context-prefix)
    (eca-chat--add-context (get-text-property 0 'eca-chat-completion-item item))
    (end-of-line)))
