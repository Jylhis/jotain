Function: gnuplot-send-line-and-newline

gnuplot-send-line-and-newline is an interactive and natively compiled function defined in gnuplot.el.

Signature

(defun gnuplot-send-line-and-newline ()
  "Call `gnuplot-send-line-to-gnuplot' and insert a new line."
  (interactive nil gnuplot-mode)
  (end-of-line)
  (gnuplot-send-line-to-gnuplot)
  (insert "\n"))
