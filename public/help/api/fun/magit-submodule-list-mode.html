Function: magit-submodule-list-mode

Documentation

Major mode for browsing a list of Git submodules.

In addition to any hooks its parent mode magit-repolist-mode might have run, this mode runs the hook magit-submodule-list-mode-hook, as the final or penultimate step during initialization.
