Function: majutsu-diff--backend-uses-ansi-p

majutsu-diff--backend-uses-ansi-p is a natively compiled function defined in majutsu-diff.el.

Signature

(majutsu-diff--backend-uses-ansi-p BACKEND)

Documentation

Return non-nil when BACKEND should be ANSI-processed by process layer.

Color-words keeps raw debug output for marker parsing and applies ANSI later.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-diff.el
(defun majutsu-diff--backend-uses-ansi-p (backend)
  "Return non-nil when BACKEND should be ANSI-processed by process layer.
Color-words keeps raw debug output for marker parsing and applies ANSI later."
  (not (eq backend 'color-words)))
