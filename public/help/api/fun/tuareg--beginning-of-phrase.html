Function: tuareg--beginning-of-phrase

tuareg--beginning-of-phrase is a function alias for tuareg-backward-beginning-of-defun, defined in tuareg.el.

This function is obsolete since Apr 10, 2019; use tuareg-backward-beginning-of-defun instead.

Signature

(tuareg--beginning-of-phrase &optional STAY-IN-CURRENT)

Documentation

Move the point backward to the beginning of a definition.

Return the token starting the phrase (nil if it is an expression). If STAY-IN-CURRENT is non-nil, don't go to the previous defun if already at the start of one.

Aliases

tuareg-backward-beginning-of-defun
