Function: majutsu-template--type-check-runtime-expected

majutsu-template--type-check-runtime-expected is a natively compiled function defined in majutsu-template.el.

Signature

(majutsu-template--type-check-runtime-expected EXPECTED)

Documentation

Return semantic runtime type used to validate EXPECTED against a node.

Some surface-level type refs such as StringLiteral additionally impose node-shape constraints, but semantically behave like a simpler runtime type.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-template.el
(defun majutsu-template--type-check-runtime-expected (expected)
  "Return semantic runtime type used to validate EXPECTED against a node.
Some surface-level type refs such as `StringLiteral' additionally impose
node-shape constraints, but semantically behave like a simpler runtime type."
  (setq expected (majutsu-template--type-ref-normalize expected))
  (pcase expected
    ('StringLiteral 'String)
    (_ expected)))
