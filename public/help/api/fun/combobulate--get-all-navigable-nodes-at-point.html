Function: combobulate--get-all-navigable-nodes-at-point

combobulate--get-all-navigable-nodes-at-point is a natively compiled function defined in combobulate-navigation.el.

Signature

(combobulate--get-all-navigable-nodes-at-point)

Documentation

Returns all navigable nodes that start at point.

The returned list is ordered smallest-to-largest by the node's extent.

Source Code

(defun combobulate--get-all-navigable-nodes-at-point ()
  "Returns all navigable nodes that start at `point'.

The returned list is ordered smallest-to-largest by the node's
extent."
  (seq-filter #'combobulate-navigable-node-p (combobulate-all-nodes-at-point)))
