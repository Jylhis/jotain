Function: pdf-info-mvannot

pdf-info-mvannot is a natively compiled function defined in pdf-info.el.

Signature

(pdf-info-mvannot ID EDGES &optional FILE-OR-BUFFER)

Documentation

Move/Resize annotation ID to fit EDGES.

ID should be a symbol, which was previously returned in a pdf-info-getannots query. Signal an error, if annotation ID does not exist.

EDGES should be a list (LEFT TOP RIGHT BOT). RIGHT and/or BOT may also be negative, which means to keep the width resp. height.
