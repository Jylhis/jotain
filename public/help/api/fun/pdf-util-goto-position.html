Function: pdf-util-goto-position

pdf-util-goto-position is a natively compiled function defined in pdf-util.el.

Signature

(pdf-util-goto-position LINE &optional COLUMN)

Documentation

Goto LINE and COLUMN in the current buffer.

COLUMN defaults to 0. Widen the buffer, if the position is outside the current limits.

(defun pdf-util-goto-position (line &optional column)
  "Goto LINE and COLUMN in the current buffer.

COLUMN defaults to 0.  Widen the buffer, if the position is
outside the current limits."
  (let ((pos
         (when (> line 0)
           (save-excursion
             (save-restriction
               (widen)
               (goto-char 1)
               (when (= 0 (forward-line (1- line)))
                 (when (and column (> column 0))
                   (forward-char (1- column)))
                 (point)))))))
    (when pos
      (when (or (< pos (point-min))
                (> pos (point-max)))
        (widen))
      (goto-char pos))))
