Function: dape-step-in

dape-step-in is an interactive and natively compiled function defined in dape.el.

Signature

(dape-step-in CONN)

Documentation

Step into function/method. If not possible behaves like dape-next.

CONN is inferred for interactive invocations.

Key Bindings

ctl-x-map C-a s dape-global-map s global-map C-x C-a s help-quick-use-map C-x C-a s

(defun dape-step-in (conn)
  "Step into function/method.  If not possible behaves like `dape-next'.
CONN is inferred for interactive invocations."
  (interactive (list (dape--live-connection 'stopped)))
  (dape--next-like-command conn :stepIn))
