Function: combobulate-javascript-minor-mode

combobulate-javascript-minor-mode is a natively compiled function defined in combobulate-js-ts.el.

Signature

(combobulate-javascript-minor-mode &optional ARG)

Documentation

Combobulate minor mode for the javascript tree-sitter language.

This is a minor mode. If called interactively, toggle the Combobulate-Javascript minor mode mode. If the prefix argument is positive, enable the mode, and if it is zero or negative, disable the mode.

If called from Lisp, toggle the mode if ARG is toggle. Enable the mode if ARG is nil, omitted, or is a positive number. Disable the mode if ARG is a negative number.

To check whether the minor mode is enabled in the current buffer, evaluate the variable combobulate-javascript-minor-mode(var)/combobulate-javascript-minor-mode(fun).

The mode's hook is called both when the mode is enabled and when it is disabled.
