Function: ghostel--daemon-dummy-frame-p

ghostel--daemon-dummy-frame-p is a natively compiled function defined in ghostel.el.

Signature

(ghostel--daemon-dummy-frame-p FRAME)

Documentation

Non-nil if FRAME is the daemon's invisible initial frame.

Killing a buffer can substitute a ghostel buffer into that frame's sole window. Its 80x24 dummy size must never count as a display of the buffer. frame-visible-p and terminal-live-p are both t on it, so compare against terminal-frame instead.

(defun ghostel--daemon-dummy-frame-p (frame)
  "Non-nil if FRAME is the daemon's invisible initial frame.
Killing a buffer can substitute a ghostel buffer into that frame's sole window.
Its 80x24 dummy size must never count as a display of the buffer.
`frame-visible-p' and `terminal-live-p' are both t on it,
so compare against `terminal-frame' instead."
  (and (daemonp) (eq frame terminal-frame)))
