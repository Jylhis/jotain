Function: logview-reset-all-filters

logview-reset-all-filters is an interactive and natively compiled function defined in logview.el.

Signature

(logview-reset-all-filters)

Documentation

Reset all filters (level, name, thread).

After this command only entries hidden by the thread-narrowing filters, hidden explictly, and entries outside narrowing buffer restrictions remain invisible. Since narrowing to section headers doesn't count as a filter, it is also kept intact if active.

Key Bindings

logview-mode-map R
