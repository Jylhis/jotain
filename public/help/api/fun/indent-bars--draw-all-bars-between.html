Function: indent-bars--draw-all-bars-between

indent-bars--draw-all-bars-between is a natively compiled function defined in indent-bars.el.

Signature

(indent-bars--draw-all-bars-between START END)

Documentation

Search for and draw all bars between START and END.

The beginning of line at START is used to locate real and (if configured) blank-line bars, which are drawn in the appropriate style. This is basically a very tiny, bar-only version of what font-lock-fontify-region-keywords does.

(defun indent-bars--draw-all-bars-between (start end)
  "Search for and draw all bars between START and END.
The beginning of line at START is used to locate real and (if
configured) blank-line bars, which are drawn in the appropriate
style.  This is basically a very tiny, bar-only version of what
`font-lock-fontify-region-keywords' does."
  (save-excursion
    (goto-char start)
    (while (and (< (point) end)
		(re-search-forward indent-bars--regexp end t))
      (if (match-beginning 2)
	  (funcall indent-bars--display-blank-lines-function
		   (match-beginning 2) (match-end 2))
	(funcall indent-bars--display-function
		 (match-beginning 1) (match-end 1))))))
