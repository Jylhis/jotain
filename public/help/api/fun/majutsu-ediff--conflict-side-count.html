Function: majutsu-ediff--conflict-side-count

majutsu-ediff--conflict-side-count is a natively compiled function defined in majutsu-ediff.el.

Signature

(majutsu-ediff--conflict-side-count REV FILE)

Documentation

Return the sidedness for FILE conflict at REV.

When sidedness cannot be parsed, return 0.

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-ediff.el
(defun majutsu-ediff--conflict-side-count (rev file)
  "Return the sidedness for FILE conflict at REV.
When sidedness cannot be parsed, return 0."
  (let* ((default-directory (majutsu-file--root))
         (line (car (majutsu-jj-lines "resolve" "--list" "-r" rev "--" file))))
    (or (plist-get (majutsu-ediff--parse-conflict-line line) :sides)
        0)))
