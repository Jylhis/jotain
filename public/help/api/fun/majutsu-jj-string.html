Function: majutsu-jj-string

majutsu-jj-string is a natively compiled function defined in majutsu-jj.el.

Signature

(majutsu-jj-string &rest ARGS)

Documentation

Run jj command with ARGS and return the first line of output.

Color output is disabled so that the return value is plain text. If there is no output, return nil. If the output begins with a newline, return an empty string. This function aligns with magit-git-string behavior.

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-jj.el
(defun majutsu-jj-string (&rest args)
  "Run jj command with ARGS and return the first line of output.

Color output is disabled so that the return value is plain text.
If there is no output, return nil.  If the output begins with a
newline, return an empty string.  This function aligns with
`magit-git-string' behavior."
  (majutsu--with-no-color
    (with-temp-buffer
      (apply #'majutsu--jj-insert nil args)
      (unless (bobp)
        (goto-char (point-min))
        (buffer-substring-no-properties (point) (line-end-position))))))
