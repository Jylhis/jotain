Function: majutsu-ediff--resolve-target-buffer

majutsu-ediff--resolve-target-buffer is a natively compiled function defined in majutsu-ediff.el.

Signature

(majutsu-ediff--resolve-target-buffer REV FILE)

Documentation

Return the conflict target buffer for REV and FILE.

When REV is the working copy, visit FILE from the filesystem. Otherwise visit FILE as a blob buffer at REV.

(defun majutsu-ediff--resolve-target-buffer (rev file)
  "Return the conflict target buffer for REV and FILE.
When REV is the working copy, visit FILE from the filesystem. Otherwise
visit FILE as a blob buffer at REV."
  (if (majutsu-ediff--working-copy-revision-p rev)
      (find-file-noselect
       (expand-file-name file (majutsu-file--root)))
    (majutsu-find-file-noselect rev file)))
