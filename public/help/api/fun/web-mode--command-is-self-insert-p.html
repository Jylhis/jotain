Function: web-mode--command-is-self-insert-p

web-mode--command-is-self-insert-p is a natively compiled function defined in web-mode.el.

Signature

(web-mode--command-is-self-insert-p)

Documentation

Return non-nil if this-command is self-insert-command.

Also return non-nil if it is the command self-insert-command is remapped to.

Source Code

;; Defined in /nix/store/x925hd4kr65vw6221bf7bb2azagpjif5-emacs-packages-deps/share/emacs/site-lisp/elpa/web-mode-20260831.219/web-mode.el
(defun web-mode--command-is-self-insert-p ()
  "Return non-nil if `this-command' is `self-insert-command'.
Also return non-nil if it is the command `self-insert-command' is remapped to."
  (memq this-command (list 'self-insert-command
                           (key-binding [remap self-insert-command]))))
