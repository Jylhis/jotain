Function: logview-delete-view

logview-delete-view is an interactive and natively compiled function defined in logview.el.

Signature

(logview-delete-view VIEW)

Documentation

Delete a view definition.

Interactively, read the view name from the minibuffer. Views cannot be deleted using their quick access indices.

Key Bindings

logview-mode-map V d

Source Code

;; Defined in /nix/store/qid656ql5mh048bd0k84vvsbc2517lh9-emacs-packages-deps/share/emacs/site-lisp/elpa/logview-20260218.2013/logview.el
(defun logview-delete-view (view)
  "Delete a view definition.
Interactively, read the view name from the minibuffer.  Views
cannot be deleted using their quick access indices."
  ;; Intentionally not supporting prefix argument here: would be too error-prone.
  (interactive (list (logview--choose-view "Delete view: ")))
  (setq logview--views             (delq (logview--find-view view) (logview--views))
        logview--views-need-saving t)
  (logview--after-updating-view-definitions)
  (logview--update-mode-name))
