Function: neocaml-mark-sentence

neocaml-mark-sentence is an interactive and natively compiled function defined in neocaml.el.

Signature

(neocaml-mark-sentence)

Documentation

Mark the current statement around point.

Uses tree-sitter sentence navigation to select the entire statement
(e.g. a let binding, type definition, or module definition).

Key Bindings

This command is not in any keymaps.

(defun neocaml-mark-sentence ()
  "Mark the current statement around point.
Uses tree-sitter sentence navigation to select the entire statement
\(e.g. a `let' binding, type definition, or module definition)."
  (interactive)
  (backward-sentence)
  (push-mark (point) nil t)
  (forward-sentence))
