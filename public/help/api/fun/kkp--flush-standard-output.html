Function: kkp--flush-standard-output

kkp--flush-standard-output is a macro defined in kkp.el.

Signature

(kkp--flush-standard-output)

Documentation

Flush buffered terminal output, when possible.

flush-standard-output only exists on Emacs 29+, while kkp supports Emacs 27.1+ and compat does not backport it; this is a no-op on earlier versions.
