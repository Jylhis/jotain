Function: majutsu-absorb-execute

majutsu-absorb-execute is an interactive and natively compiled function defined in majutsu-absorb.el.

Signature

(majutsu-absorb-execute ARGS)

Documentation

Execute jj absorb with ARGS from the transient.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-absorb.el
;;;###autoload
(defun majutsu-absorb-execute (args)
  "Execute jj absorb with ARGS from the transient."
  (interactive (list (majutsu-absorb-arguments)))
  (let ((exit (apply #'majutsu-run-jj "absorb" args)))
    (when (zerop exit)
      (message "Absorb completed"))))
