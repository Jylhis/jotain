Function: majutsu-git-fetch

majutsu-git-fetch is an interactive and natively compiled function defined in majutsu-git.el.

Signature

(majutsu-git-fetch ARGS)

Documentation

Fetch from git remote with ARGS from transient.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-git.el
(defun majutsu-git-fetch (args)
  "Fetch from git remote with ARGS from transient."
  (interactive (list (transient-args 'majutsu-git-fetch-transient)))
  (majutsu--message-with-log "Fetching from remote...")
  (majutsu-git--start (append '("fetch") args) "Fetched from remote"))
