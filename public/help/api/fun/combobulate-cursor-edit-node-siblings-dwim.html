Function: combobulate-cursor-edit-node-siblings-dwim

combobulate-cursor-edit-node-siblings-dwim is an interactive and natively compiled function defined in combobulate-cursor.el.

Signature

(combobulate-cursor-edit-node-siblings-dwim ARG)

Documentation

Edit all siblings of the current node.

Combobulate will use its definition of siblings as per M-x combobulate-navigate-next (combobulate-navigate-next) and M-x combobulate-navigate-previous (combobulate-navigate-previous).

Key Bindings

combobulate-cursor-edit-key-map s combobulate-key-map C-c o t s combobulate-options-key-map t s

;; Defined in /nix/store/9y0jasyzsqjcbfkwqsgdyxcnskjnsypg-emacs-packages-deps/share/emacs/site-lisp/combobulate-cursor.el
(defun combobulate-cursor-edit-node-siblings-dwim (arg)
  "Edit all siblings of the current node.

Combobulate will use its definition of siblings as per
\\[combobulate-navigate-next] and
\\[combobulate-navigate-previous]."
  (interactive "P")
  (with-navigation-nodes (:procedures (combobulate-read procedures-sibling))
    (let ((node (combobulate--get-nearest-navigable-node)))
      (combobulate-cursor-edit-nodes (combobulate-nav-get-siblings node)
                                     (combobulate-cursor-edit-node-determine-action arg)
                                     (or (car-safe (combobulate-nav-get-parents node t))
                                         node)))))
