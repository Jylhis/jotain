Function: cmake-indent-line-to

cmake-indent-line-to is a natively compiled function defined in cmake-mode.el.

Signature

(cmake-indent-line-to COLUMN)

Documentation

Indent the current line to COLUMN.

If point is within the existing indentation it is moved to the end of the indentation. Otherwise it retains the same position on the line

(defun cmake-indent-line-to (column)
  "Indent the current line to COLUMN.
If point is within the existing indentation it is moved to the end of
the indentation.  Otherwise it retains the same position on the line"
  (if (cmake-point-in-indentation)
      (indent-line-to column)
    (save-excursion (indent-line-to column))))
