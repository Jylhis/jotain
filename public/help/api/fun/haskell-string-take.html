Function: haskell-string-take

haskell-string-take is a natively compiled function defined in haskell-string.el.

(haskell-string-take STRING N)

;; Defined in /nix/store/ccd92nyzdf3mi6kmi2pc75azlr90xvhk-emacs-packages-deps/share/emacs/site-lisp/elpa/haskell-mode-20260829.851/haskell-string.el
(defun haskell-string-take (string n)
  "Return (up to) N character length prefix of STRING."
  (substring string 0 (min (length string) n)))
