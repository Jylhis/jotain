Function: verb--setup-font-lock-keywords

verb--setup-font-lock-keywords is a natively compiled function defined in verb.el.

Signature

(verb--setup-font-lock-keywords &optional REMOVE)

Documentation

Configure font lock keywords for verb-mode(var)/verb-mode(fun).

If REMOVE is nil, add the necessary keywords to font-lock-keywords. Otherwise, remove them.

(defun verb--setup-font-lock-keywords (&optional remove)
  "Configure font lock keywords for `verb-mode'.
If REMOVE is nil, add the necessary keywords to
`font-lock-keywords'.  Otherwise, remove them."
  (funcall
   (if remove #'font-lock-remove-keywords #'font-lock-add-keywords)
   nil
   `(;; GET
     (,(concat "^\\s-*\\(" (verb--http-methods-regexp) "\\)$")
      (1 'verb-http-keyword))
     ;; GET www.example.com
     (,(concat "^\\s-*\\(" (verb--http-methods-regexp) "\\)\\s-+.+$")
      (1 'verb-http-keyword))
     ;; Content-type: application/json
     (,verb--http-header-regexp
      (1 'verb-header))
     ;; "something": 123
     ("\\s-\\(\"[[:graph:]]+?\"\\)\\s-*:."
      (1 'verb-json-key))
     ;; {{(format "%s" "Lisp code tag")}}
     (,(concat (car verb-code-tag-delimiters)
               ".*?"
               (cdr verb-code-tag-delimiters))
      (0 'verb-code-tag))))
  (font-lock-flush))
