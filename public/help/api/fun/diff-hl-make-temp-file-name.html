Function: diff-hl-make-temp-file-name

diff-hl-make-temp-file-name is a natively compiled function defined in diff-hl.el.

Signature

(diff-hl-make-temp-file-name FILE REV &optional MANUAL)

Documentation

Return a backup file name for REV or the current version of FILE.

If MANUAL is non-nil it means that a name for backups created by the user should be returned.

;; Defined in /nix/store/742jfhd6j9y7y1gqxy624dchx31gwmax-emacs-packages-deps/share/emacs/site-lisp/elpa/diff-hl-20260830.1400/diff-hl.el
(defun diff-hl-make-temp-file-name (file rev &optional manual)
  "Return a backup file name for REV or the current version of FILE.
If MANUAL is non-nil it means that a name for backups created by
the user should be returned."
  (let* ((auto-save-file-name-transforms
          `((".*" ,temporary-file-directory t)))
         (buffer-file-name file))
    (expand-file-name
     (concat (make-auto-save-file-name)
             ".~" (subst-char-in-string
                   ?/ ?_ rev)
             (unless manual ".") "~")
     temporary-file-directory)))
