Function: tuareg-find-alternate-file

tuareg-find-alternate-file is a function alias and interactive for ff-get-other-file, defined in find-file.el.gz.

Signature

(tuareg-find-alternate-file &optional IN-OTHER-WINDOW)

Documentation

Find the header or source file corresponding to this file.

See also the documentation for ff-find-other-file.

If optional IN-OTHER-WINDOW is non-nil, find the file in another window.

Key Bindings

tuareg-mode-map C-c C-a

Aliases

ff-get-other-file
