Function: verb-send-request-on-point-other-window

verb-send-request-on-point-other-window is an interactive and natively compiled function defined in verb.el.

Signature

(verb-send-request-on-point-other-window &optional ARG)

Documentation

Send the request specified by the selected heading's text contents.

Show the results on another window and switch to it, using verb-send-request-on-point. See that function's documentation for a description of prefix argument ARG.

Key Bindings

verb-command-map C-s
