Function: majutsu-section-show-headings

majutsu-section-show-headings is an interactive and natively compiled function defined in majutsu-section.el.

Signature

(majutsu-section-show-headings SECTION)

Documentation

Recursively show headings of SECTION's children.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-section.el
(defun majutsu-section-show-headings (section)
  "Recursively show headings of SECTION's children."
  (interactive (list (magit-current-section)))
  (majutsu-section-show-headings-1 section)
  (majutsu-section-show section))
