Function: combobulate--mark-node

combobulate--mark-node is a natively compiled function defined in combobulate-manipulation.el.

(combobulate--mark-node NODE &optional SWAP BEGINNING-OF-LINE)

Documentation

Mark NODE in the current buffer.

See combobulate--mark-extent for argument explanations.

;; Defined in /nix/store/9y0jasyzsqjcbfkwqsgdyxcnskjnsypg-emacs-packages-deps/share/emacs/site-lisp/combobulate-manipulation.el
(defun combobulate--mark-node (node &optional swap beginning-of-line)
  "Mark NODE in the current buffer.

See `combobulate--mark-extent' for argument explanations."
  (when node
    (combobulate--mark-extent (combobulate-node-start node)
                              (combobulate-node-end node)
                              swap
                              beginning-of-line)))
