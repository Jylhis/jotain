Function: org-roam-setup

org-roam-setup is a function alias for org-roam-db-autosync-enable, defined in org-roam-compat.el.

This function is obsolete since org-roam 2.0; use org-roam-db-autosync-enable instead.

Signature

(org-roam-setup)

Documentation

Activate org-roam-db-autosync-mode(var)/org-roam-db-autosync-mode(fun).

Aliases

org-roam-db-autosync-enable (obsolete since 2025-11-23)
