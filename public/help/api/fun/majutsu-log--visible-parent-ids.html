Function: majutsu-log--visible-parent-ids

majutsu-log--visible-parent-ids is a natively compiled function defined in majutsu-log.el.

Signature

(majutsu-log--visible-parent-ids ENTRY)

Documentation

Return visible parent ids for ENTRY in current buffer order.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-log.el
(defun majutsu-log--visible-parent-ids (entry)
  "Return visible parent ids for ENTRY in current buffer order."
  (seq-filter #'majutsu-log--entry-for-id
              (delete-dups (copy-sequence (or (plist-get entry :parent-ids) nil)))))
