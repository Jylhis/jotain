majutsu-template--lookup-function-name is a natively compiled function defined in majutsu-template.el.

(majutsu-template--lookup-function-name KEY)

Documentation

Return registered template name string for KEY, or nil if unknown.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-template.el
(defun majutsu-template--lookup-function-name (key)
  "Return registered template name string for KEY, or nil if unknown."
  (let ((meta (majutsu-template--lookup-function-meta key)))
    (when meta
      (majutsu-template--fn-name meta))))
