Function: dired-narrow-mode

dired-narrow-mode is an interactive and natively compiled function defined in dired-narrow.el.

Signature

(dired-narrow-mode &optional ARG)

Documentation

Minor mode for indicating when narrowing is in progress.

This is a minor mode. If called interactively, toggle the dired-narrow mode mode. If the prefix argument is positive, enable the mode, and if it is zero or negative, disable the mode.

If called from Lisp, toggle the mode if ARG is toggle. Enable the mode if ARG is nil, omitted, or is a positive number. Disable the mode if ARG is a negative number.

To check whether the minor mode is enabled in the current buffer, evaluate the variable dired-narrow-mode(var)/dired-narrow-mode(fun).

The mode's hook is called both when the mode is enabled and when it is disabled.

Key Bindings

This command is not in any keymaps.
