Function: majutsu-log--transient-read-revset

majutsu-log--transient-read-revset is a natively compiled function defined in majutsu-log.el.

Signature

(majutsu-log--transient-read-revset PROMPT INITIAL-INPUT HISTORY)

Documentation

Read a log revision argument.

INITIAL-INPUT is the current revision filter and is inserted into the minibuffer for editing. Empty input clears the filter.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-log.el
;;; Commands

(defun majutsu-log--transient-read-revset (prompt initial-input history)
  "Read a log revision argument.

INITIAL-INPUT is the current revision filter and is inserted into the
minibuffer for editing.  Empty input clears the filter."
  (unless current-prefix-arg
    (majutsu-read-optional-revset
     prompt nil initial-input history '("log" "-r"))))
