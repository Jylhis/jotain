Function: logview-reset-all-filters-restrictions-and-hidings

logview-reset-all-filters-restrictions-and-hidings is an interactive and natively compiled function defined in logview.el.

Signature

(logview-reset-all-filters-restrictions-and-hidings)

Documentation

Reset all visibility restrictions.

In other words, reset all filters, show all explictly hidden entries and cancel any narrowing restrictions, including narrowing to threads and to section headers.

Key Bindings

logview-mode-map r e
