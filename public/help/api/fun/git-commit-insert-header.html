Function: git-commit-insert-header

git-commit-insert-header is a function alias for git-commit--insert-ident-trailer, defined in git-commit.el.

This function is obsolete since git-commit 4.0.0; use git-commit--insert-ident-trailer instead.

Signature

(git-commit-insert-header TRAILER NAME EMAIL)

Aliases

git-commit--insert-ident-trailer
