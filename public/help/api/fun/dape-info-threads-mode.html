Function: dape-info-threads-mode

dape-info-threads-mode is a natively compiled function defined in dape.el.

Signature

(dape-info-threads-mode)

Documentation

Major mode for viewing and selecting threads.

In addition to any hooks its parent mode dape-info-parent-mode might have run, this mode runs the hook dape-info-threads-mode-hook, as the final or penultimate step during initialization.
