Function: trashed-flag-restore-files-regexp

trashed-flag-restore-files-regexp is an interactive and natively compiled function defined in trashed.el.

Signature

(trashed-flag-restore-files-regexp &optional REGEXP)

Documentation

Flag all files matching REGEXP for restoration.

If called interactively or REGEXP is nil, prompt for REGEXP.

Key Bindings

trashed-mode-map % r
