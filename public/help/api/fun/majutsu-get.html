Function: majutsu-get

majutsu-get is a natively compiled function defined in majutsu-config.el.

(majutsu-get KEY)

Documentation

Get config value for KEY from jj.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-config.el
(defun majutsu-get (key)
  "Get config value for KEY from jj."
  (let ((lines (majutsu-jj-lines "config" "get" key)))
    (when lines
      (string-trim (car lines)))))
