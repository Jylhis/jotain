Function: dirvish-data-for-dir

dirvish-data-for-dir is a byte-compiled function defined in dirvish.el.

Signature

(dirvish-data-for-dir DIR BUFFER INHIBIT-SETUP)

Documentation

Fetch data for DIR in BUFFER.

It is called when DIR is in localhost and is not being version-controlled. Run dirvish-setup-hook after data parsing unless INHIBIT-SETUP is non-nil.

(cl-defgeneric dirvish-data-for-dir (dir buffer inhibit-setup)
  "Fetch data for DIR in BUFFER.
It is called when DIR is in localhost and is not being
version-controlled.  Run `dirvish-setup-hook' after data parsing unless
INHIBIT-SETUP is non-nil."
  (when (buffer-live-p buffer)
    (with-current-buffer buffer
      (unless inhibit-setup (run-hooks 'dirvish-setup-hook))
      (ignore dir))))
