Function: haskell-indentation-indent-rigidly

haskell-indentation-indent-rigidly is an interactive and natively compiled function defined in haskell-indentation.el.

Signature

(haskell-indentation-indent-rigidly START END ARG)

Documentation

Indent all lines starting in the region sideways by ARG columns.

Called from a program, takes three arguments, START, END and ARG. You can remove all indentation from a region by giving a large negative ARG. Handles bird style literate Haskell too.

Key Bindings

This command is not in any keymaps.

(defun haskell-indentation-indent-rigidly (start end arg)
  "Indent all lines starting in the region sideways by ARG columns.
Called from a program, takes three arguments, START, END and ARG.
You can remove all indentation from a region by giving a large
negative ARG.  Handles bird style literate Haskell too."
  (interactive "*r\np")
  (save-excursion
    (goto-char end)
    (let ((end-marker (point-marker)))
      (goto-char start)
      (or (bolp) (forward-line 0))
      (while (< (point) end-marker)
        (let ((ci (haskell-indentation-current-indentation)))
          (when (and t
                     (eq (char-after) ?>))
            (forward-char 1))
          (skip-syntax-forward "-")
          (unless (eolp)
            (haskell-indentation-reindent-to (max 0 (+ ci arg))))
          (forward-line 1)))
      (move-marker end-marker nil))))
