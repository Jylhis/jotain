Function: majutsu-sparse-set-clear

majutsu-sparse-set-clear is an interactive and natively compiled function defined in majutsu-sparse.el.

Signature

(majutsu-sparse-set-clear PATTERNS)

Documentation

Clear all patterns and set to PATTERNS.

This is equivalent to jj sparse set --clear --add <patterns>.

Key Bindings

This command is not in any keymaps.

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-sparse.el
;;;###autoload
(defun majutsu-sparse-set-clear (patterns)
  "Clear all patterns and set to PATTERNS.
This is equivalent to `jj sparse set --clear --add <patterns>'."
  (interactive
   (list (majutsu-sparse--read-patterns
          "New sparse patterns"
          (majutsu-sparse--directory-candidates))))
  (majutsu-sparse-set patterns t))
