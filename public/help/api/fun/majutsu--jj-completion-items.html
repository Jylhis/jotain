Function: majutsu--jj-completion-items

majutsu--jj-completion-items is a natively compiled function defined in majutsu-command.el.

Signature

(majutsu--jj-completion-items COMMAND)

Documentation

Return completion items for COMMAND using jj's native completer.

Each item is (CANDIDATE . HELP).
