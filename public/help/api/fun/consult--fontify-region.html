Function: consult--fontify-region

consult--fontify-region is a byte-compiled function defined in consult.el.

Signature

(consult--fontify-region START END)

Documentation

Ensure that region between START and END is fontified.

Source Code

;; Defined in /nix/store/lmzd2dhgxc9ssqcxwibyq6xrmrvf80a4-emacs-packages-deps/share/emacs/site-lisp/elpa/consult-20260829.1558/consult.el
(defsubst consult--fontify-region (start end)
  "Ensure that region between START and END is fontified."
  (when (and consult-fontify-preserve jit-lock-mode)
    (jit-lock-fontify-now start end)))
