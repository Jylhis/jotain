Function: mc/mark-all-dwim

mc/mark-all-dwim is an interactive and natively compiled function defined in mc-mark-more.el.

Signature

(mc/mark-all-dwim ARG)

Documentation

Tries even harder to guess what you want to mark all of.

If the region is active and spans multiple lines, it will behave as if mc/mark-all-in-region. With the prefix ARG, it will call mc/edit-lines instead.

If the region is inactive or on a single line, it will behave like mc/mark-all-like-this-dwim.

Key Bindings

This command is not in any keymaps.

(defun mc/mark-all-dwim (arg)
  "Tries even harder to guess what you want to mark all of.

If the region is active and spans multiple lines, it will behave
as if `mc/mark-all-in-region'. With the prefix ARG, it will call
`mc/edit-lines' instead.

If the region is inactive or on a single line, it will behave like
`mc/mark-all-like-this-dwim'."
  (interactive "P")
  (if (and (use-region-p)
           (not (> (mc/num-cursors) 1))
           (not (= (mc/line-number-at-pos (region-beginning))
                   (mc/line-number-at-pos (region-end)))))
      (if arg
          (call-interactively 'mc/edit-lines)
        (call-interactively 'mc/mark-all-in-region))
    (progn
      (setq this-command 'mc/mark-all-like-this-dwim)
      (mc/mark-all-like-this-dwim arg))))
