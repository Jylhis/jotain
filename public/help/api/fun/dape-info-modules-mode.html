Function: dape-info-modules-mode

dape-info-modules-mode is a natively compiled function defined in dape.el.

Signature

(dape-info-modules-mode)

Documentation

Major mode for viewing loaded modules.

In addition to any hooks its parent mode dape-info-parent-mode might have run, this mode runs the hook dape-info-modules-mode-hook, as the final or penultimate step during initialization.
