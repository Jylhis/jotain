Function: magit-am-abort

magit-am-abort is an interactive and natively compiled function defined in magit-sequence.el.

Signature

(magit-am-abort)

Documentation

Abort the current patch applying sequence.

This discards all changes made since the sequence started.

Key Bindings

This command is not in any keymaps.

(defun magit-am-abort ()
  "Abort the current patch applying sequence.
This discards all changes made since the sequence started."
  (interactive)
  (unless (magit-am-in-progress-p)
    (user-error "Not applying any patches"))
  (magit-run-git "am" "--abort"))
