Function: ghostel--pos-on-cursor-p

ghostel--pos-on-cursor-p is a natively compiled function defined in ghostel.el.

Signature

(ghostel--pos-on-cursor-p POS)

Documentation

Non-nil if POS rides the live terminal cursor: on it, or at point-max.

Positions between the cursor and point-max do not count.

Source Code

;; Defined in /nix/store/1jkgkg7y6y6hp0xia3dsmcl5zaj0bnhq-emacs-packages-deps/share/emacs/site-lisp/ghostel.el
(defun ghostel--pos-on-cursor-p (pos)
  "Non-nil if POS rides the live terminal cursor: on it, or at `point-max'.
Positions between the cursor and `point-max' do not count."
  (and ghostel--cursor-char-pos
       (or (= pos ghostel--cursor-char-pos)
           (= pos (point-max)))))
