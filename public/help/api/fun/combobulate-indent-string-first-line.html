Function: combobulate-indent-string-first-line

combobulate-indent-string-first-line is a natively compiled function defined in combobulate-manipulation.el.

(combobulate-indent-string-first-line TEXT TARGET-COL)

Source Code

;; Defined in /nix/store/9y0jasyzsqjcbfkwqsgdyxcnskjnsypg-emacs-packages-deps/share/emacs/site-lisp/combobulate-manipulation.el
(defun combobulate-indent-string-first-line (text target-col)
  "Corrects the indentation of the first line of TEXT to TARGET-COL."
  (combobulate-indent-string text :first-line-operation 'absolute :first-line-amount target-col))
