Function: indent-bars-reset

indent-bars-reset is an interactive and natively compiled function defined in indent-bars.el.

(indent-bars-reset &rest R)

Documentation

Reset indent-bars config.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/kmdsnipwffgk5c0fs4785bhqa9fl17c5-emacs-packages-deps/share/emacs/site-lisp/elpa/indent-bars-1.0.1/indent-bars.el
(defun indent-bars-reset (&rest _r)
  "Reset indent-bars config."
  (interactive)
  (indent-bars-teardown)
  (setq indent-bars-style nil indent-bars--styles nil)
  (indent-bars-setup))
