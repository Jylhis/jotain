Function: dirvish

dirvish is an interactive and natively compiled function defined in dirvish.el.

Signature

(dirvish &optional PATH)

Documentation

Open PATH in a fullframe Dirvish session.

Prompt for PATH if called with M-x universal-arguments (universal-arguments), otherwise PATH defaults to default-directory.

Key Bindings

This command is not in any keymaps.

(defun dirvish (&optional path)
  "Open PATH in a fullframe Dirvish session.
Prompt for PATH if called with \\[universal-arguments], otherwise PATH
defaults to `default-directory'."
  (interactive (list (and current-prefix-arg (read-directory-name "Dirvish: "))))
  (dirvish--try-reuse path))
