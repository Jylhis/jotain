Function: projection--all-files-exists

projection--all-files-exists is a natively compiled function defined in projection-utils.el.

Signature

(projection--all-files-exists &rest FILES)

Documentation

Generate a predicate function which is true if all files in FILES exist.

Source Code

;; Defined in /nix/store/kqajmnl5vwqnlsg3vcmlj2d28ylc2n0n-emacs-packages-deps/share/emacs/site-lisp/elpa/projection-20260614.1822/projection-utils.el
(defun projection--all-files-exists (&rest files)
  "Generate a predicate function which is true if all files in FILES exist."
  (apply-partially #'cl-every #'file-exists-p files))
