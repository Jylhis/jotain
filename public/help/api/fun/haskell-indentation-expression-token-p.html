Function: haskell-indentation-expression-token-p

haskell-indentation-expression-token-p is a natively compiled function defined in haskell-indentation.el.

Signature

(haskell-indentation-expression-token-p TOKEN)

Documentation

Return non-NIL value if TOKEN is an expression token.

Source Code

;; Defined in /nix/store/ccd92nyzdf3mi6kmi2pc75azlr90xvhk-emacs-packages-deps/share/emacs/site-lisp/elpa/haskell-mode-20260829.851/haskell-indentation.el
(defun haskell-indentation-expression-token-p (token)
  "Return non-NIL value if TOKEN is an expression token."
  (member token
          '("if" "let" "do" "case" "\\" "(" "{" "[" "::"
            value operator no-following-token)))
