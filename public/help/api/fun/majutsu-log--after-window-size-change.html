Function: majutsu-log--after-window-size-change

majutsu-log--after-window-size-change is a natively compiled function defined in majutsu-log.el.

Signature

(majutsu-log--after-window-size-change WINDOW)

Documentation

Refresh tail alignment after the selected log WINDOW changes size.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-log.el
(defun majutsu-log--after-window-size-change (window)
  "Refresh tail alignment after the selected log WINDOW changes size."
  (when (eq window (selected-window))
    (majutsu-log--refresh-tail-window window)))
