Function: indent-bars--stipple-rot

indent-bars--stipple-rot is a natively compiled function defined in indent-bars.el.

Signature

(indent-bars--stipple-rot WIN W)

Documentation

Return the stipple rotation for window WIN and pattern width W.

WIN defaults to the selected window if nil.

Source Code

;; Defined in /nix/store/kmdsnipwffgk5c0fs4785bhqa9fl17c5-emacs-packages-deps/share/emacs/site-lisp/elpa/indent-bars-1.0.1/indent-bars.el
(defun indent-bars--stipple-rot (win w)
  "Return the stipple rotation for window WIN and pattern width W.
WIN defaults to the selected window if nil."
  (mod (car (window-edges win t nil t)) w))
