Function: majutsu-log--apply-postprocessor

majutsu-log--apply-postprocessor is a natively compiled function defined in majutsu-log.el.

Signature

(majutsu-log--apply-postprocessor FN VALUE CTX)

Documentation

Apply postprocessor FN to VALUE with context CTX.

FN may accept either (VALUE) or (VALUE CTX). Errors return VALUE unchanged.

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-log.el
(defun majutsu-log--apply-postprocessor (fn value ctx)
  "Apply postprocessor FN to VALUE with context CTX.

FN may accept either (VALUE) or (VALUE CTX). Errors return VALUE unchanged."
  (condition-case err
      (condition-case _
          (funcall fn value ctx)
        (wrong-number-of-arguments
         (funcall fn value)))
    (error
     (majutsu--debug "majutsu-log postprocessor failed (%S on %S): %s"
                     fn (plist-get ctx :field) (error-message-string err))
     value)))
