Function: pdf-view-mouse-extend-region

pdf-view-mouse-extend-region is an interactive and natively compiled function defined in pdf-view.el.

(pdf-view-mouse-extend-region EVENT)

(defun pdf-view-mouse-extend-region (event)
  "Extend the currently active region with mouse event EVENT."
  (interactive "@e")
  (pdf-view-mouse-set-region
   event t pdf-view--have-rectangle-region))
