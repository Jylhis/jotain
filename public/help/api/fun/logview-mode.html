Function: logview-mode

logview-mode is an interactive and natively compiled function defined in logview.el.

Signature

(logview-mode)

Documentation

Major mode for viewing and filtering various log files.

This mode runs the hook logview-mode-hook, as the final or penultimate step during initialization.

;; Defined in /nix/store/qid656ql5mh048bd0k84vvsbc2517lh9-emacs-packages-deps/share/emacs/site-lisp/elpa/logview-20260218.2013/logview.el
;;;###autoload
(define-derived-mode logview-mode nil "Logview"
  "Major mode for viewing and filtering various log files."
  (let (successful)
    (unwind-protect
        (progn (logview--set-up)
               (setf successful t))
      (unless successful
        ;; Don't leave the mode half-initialized if there is any unhandled error.  This is
        ;; not how Emacs normally works, but standard way is too confusing to users and
        ;; behavior depends on where exactly an error happened.  Also, as function
        ;; `normal-mode' effectively eats the error (at least its backtrace), debugging it
        ;; is nearly impossible anyway.
        (fundamental-mode)))))
