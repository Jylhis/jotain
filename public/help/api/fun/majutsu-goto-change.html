Function: majutsu-goto-change

majutsu-goto-change is an interactive and natively compiled function defined in majutsu-log.el.

Signature

(majutsu-goto-change CHANGE-ID)

Documentation

Jump to a specific CHANGE-ID in the log.

Key Bindings

This command is not in any keymaps.

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-log.el
(defun majutsu-goto-change (change-id)
  "Jump to a specific CHANGE-ID in the log."
  (interactive "sChange ID: ")
  (let ((start-pos (point)))
    (goto-char (point-min))
    (if (re-search-forward (regexp-quote change-id) nil t)
        (goto-char (line-beginning-position))
      (goto-char start-pos)
      (message "Change %s not found" change-id))))
