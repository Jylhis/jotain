Function: pdf-view-position-to-register

pdf-view-position-to-register is an interactive and natively compiled function defined in pdf-view.el.

Signature

(pdf-view-position-to-register REGISTER)

Documentation

Store current PDF position in register REGISTER.

See also point-to-register.

Key Bindings

pdf-view-mode-map m

;; Defined in /nix/store/wm0vc3dfi6c7pwjhcfpsnhyg4hd0b5yc-emacs-packages-deps/share/emacs/site-lisp/elpa/pdf-tools-20260102.1101/pdf-view.el
(defun pdf-view-position-to-register (register)
  "Store current PDF position in register REGISTER.

See also `point-to-register'."
  (interactive
   (list (pdf-view-with-register-alist
           (register-read-with-preview "Position to register: "))))
  (pdf-view-with-register-alist
    (set-register register (pdf-view-registerv-make))))
