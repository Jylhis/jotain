Function: super-save-org-src-buffer-p

super-save-org-src-buffer-p is a natively compiled function defined in super-save.el.

Signature

(super-save-org-src-buffer-p)

Documentation

Return non-nil if the current buffer is an org-src edit buffer.

Source Code

;; Defined in /nix/store/wqk38r7f0ly8xacdb8fb4xzdq0iqx7lz-emacs-packages-deps/share/emacs/site-lisp/elpa/super-save-20260318.1214/super-save.el
(defun super-save-org-src-buffer-p ()
  "Return non-nil if the current buffer is an org-src edit buffer."
  (and (bound-and-true-p org-src-mode)
       (fboundp 'org-edit-src-save)))
