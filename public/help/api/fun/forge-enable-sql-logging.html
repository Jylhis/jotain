Function: forge-enable-sql-logging

forge-enable-sql-logging is an interactive and natively compiled function defined in forge-db.el.

(forge-enable-sql-logging)

Enable logging Forge's SQL queries.

Key Bindings

This command is not in any keymaps.

;; Defined in /nix/store/mx379q5y0bq6kkjqnaw6lj3jlzzqk7hb-emacs-packages-deps/share/emacs/site-lisp/elpa/forge-20260831.1655/forge-db.el
(defun forge-enable-sql-logging ()
  "Enable logging Forge's SQL queries."
  (interactive)
  (let ((conn (oref (forge-db) connection)))
    (emacsql-enable-debugging conn)
    (switch-to-buffer-other-window (oref conn log-buffer))))
