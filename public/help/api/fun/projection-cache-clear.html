Function: projection-cache-clear

projection-cache-clear is an interactive and natively compiled function defined in projection-core-cache.el.

Signature

(projection-cache-clear CLEAR-ALL)

Documentation

Interactively clear cached variables for the current project.

Calls projection-cache-clear-all or projection-cache-clear-single based on the value of CLEAR-ALL.

Key Bindings

projection-map DEL

(defun projection-cache-clear (clear-all)
  "Interactively clear cached variables for the current project.
Calls `projection-cache-clear-all' or `projection-cache-clear-single' based on
the value of CLEAR-ALL."
  (interactive "P")
  (call-interactively
   (if clear-all
       #'projection-cache-clear-all
     #'projection-cache-clear-multiple)))
