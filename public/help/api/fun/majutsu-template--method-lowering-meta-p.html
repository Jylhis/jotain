Function: majutsu-template--method-lowering-meta-p

majutsu-template--method-lowering-meta-p is a natively compiled function defined in majutsu-template.el.

Signature

(majutsu-template--method-lowering-meta-p META)

Documentation

Return non-nil when META describes a local lowering method.

Body-less/native methods use majutsu-template--method-stub and render as literal .name(...) segments. Lowering methods carry a real Elisp function.

(defun majutsu-template--method-lowering-meta-p (meta)
  "Return non-nil when META describes a local lowering method.
Body-less/native methods use `majutsu-template--method-stub' and render as
literal `.name(...)' segments. Lowering methods carry a real Elisp function."
  (let ((fn-symbol (and meta (majutsu-template--fn-symbol meta))))
    (and fn-symbol
         (not (eq fn-symbol 'majutsu-template--method-stub)))))
