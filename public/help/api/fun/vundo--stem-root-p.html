Function: vundo--stem-root-p

vundo--stem-root-p is a natively compiled function defined in vundo.el.

Signature

(vundo--stem-root-p NODE)

Documentation

Return non-nil if NODE is the root of a stem.

Source Code

;; Defined in /nix/store/7c2696v2qdrdv2vf2im8alazibi7qq0z-emacs-packages-deps/share/emacs/site-lisp/elpa/vundo-2.4.0/vundo.el
(defun vundo--stem-root-p (node)
  "Return non-nil if NODE is the root of a stem."
  ;; Ie, parent has more than one children.
  (> (length (vundo-m-children (vundo-m-parent node))) 1))
