Function: majutsu-bookmark-move-allow-backwards

majutsu-bookmark-move-allow-backwards is an interactive and natively compiled function defined in majutsu-bookmark.el.

Signature

(majutsu-bookmark-move-allow-backwards NAMES COMMIT)

Documentation

Move bookmark(s) NAMES to COMMIT allowing backwards moves.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-bookmark.el
;;;###autoload
(defun majutsu-bookmark-move-allow-backwards (names commit)
  "Move bookmark(s) NAMES to COMMIT allowing backwards moves."
  (interactive (list (majutsu-read-bookmarks "Move bookmark(s)") (majutsu-read-revset "Target revset")))
  (majutsu--bookmark-move names commit t))
