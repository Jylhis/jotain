Function: pdf-info-getselection

pdf-info-getselection is a natively compiled function defined in pdf-info.el.

Signature

(pdf-info-getselection PAGE EDGES &optional SELECTION-STYLE FILE-OR-BUFFER)

Documentation

Return the edges of the selection EDGES on PAGE.

Arguments are the same as for pdf-info-gettext. Return a list of edges corresponding to the text that would be returned by the aforementioned function, when called with the same arguments.

(defun pdf-info-getselection (page edges
                                   &optional selection-style file-or-buffer)
  "Return the edges of the selection EDGES on PAGE.

Arguments are the same as for `pdf-info-gettext'.  Return a list
of edges corresponding to the text that would be returned by the
aforementioned function, when called with the same arguments."
  (pdf-info-query
   'getselection
   (pdf-info--normalize-file-or-buffer file-or-buffer)
   page
   (mapconcat #'number-to-string edges " ")
   (pdf-info--selection-style selection-style)))
