Function: majutsu-template--lookup-method

majutsu-template--lookup-method is a natively compiled function defined in majutsu-template.el.

Signature

(majutsu-template--lookup-method OWNER NAME)

Documentation

Return metadata for method NAME on OWNER type.

OWNER may be a nominal type symbol or a richer normalized type ref.
