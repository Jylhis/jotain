Function: majutsu-diff-more-context

majutsu-diff-more-context is an interactive and natively compiled function defined in majutsu-diff.el.

Signature

(majutsu-diff-more-context &optional COUNT)

Documentation

Increase the context for diff hunks by COUNT lines.

Key Bindings

majutsu-diff-mode-map +

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-diff.el
(defun majutsu-diff-more-context (&optional count)
  "Increase the context for diff hunks by COUNT lines."
  (interactive "p")
  (majutsu-diff-set-context (##+ (or % 0) count)))
