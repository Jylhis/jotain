Function: eca-chat-image-zoom-reset

eca-chat-image-zoom-reset is an interactive and natively compiled function defined in eca-chat-image.el.

Signature

(eca-chat-image-zoom-reset)

Documentation

Reset the inline-image zoom in this chat to 100%.

Key Bindings

eca-chat-mode-map C-c C-z 0

(defun eca-chat-image-zoom-reset ()
  "Reset the inline-image zoom in this chat to 100%."
  (interactive)
  (setq-local eca-chat-image-scale 1.0)
  (eca-chat--refresh-rendered-images)
  (eca-info "Image zoom: 100%%"))
