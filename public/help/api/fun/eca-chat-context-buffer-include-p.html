Function: eca-chat-context-buffer-include-p

eca-chat-context-buffer-include-p is a natively compiled function defined in eca-chat-context.el.

Signature

(eca-chat-context-buffer-include-p BUFFER)

Documentation

Return non-nil when BUFFER can be offered as a text context.

Excludes file-visiting, hidden, minibuffer and ECA own buffers.

(defun eca-chat-context-buffer-include-p (buffer)
  "Return non-nil when BUFFER can be offered as a text context.
Excludes file-visiting, hidden, minibuffer and ECA own buffers."
  (let ((name (buffer-name buffer)))
    (and (buffer-live-p buffer)
         (not (buffer-file-name buffer))
         (not (minibufferp buffer))
         (not (string-prefix-p " " name))
         (not (string-match-p "\\`\\(\\*eca\\|<eca-\\)" name)))))
