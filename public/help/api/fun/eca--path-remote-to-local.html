Function: eca--path-remote-to-local

eca--path-remote-to-local is a natively compiled function defined in eca-util.el.

Signature

(eca--path-remote-to-local PATH)

Documentation

Translate a remote server PATH to a local Emacs path.

Applies path mappings (explicit eca-local-to-remote-prefix-map plus TRAMP workspace folder mappings). The longest matching prefix wins; explicit user mappings take priority over TRAMP-derived ones.

(defun eca--path-remote-to-local (path)
  "Translate a remote server PATH to a local Emacs path.
Applies path mappings (explicit `eca-local-to-remote-prefix-map'
plus TRAMP workspace folder mappings).  The longest matching prefix
wins; explicit user mappings take priority over TRAMP-derived ones."
