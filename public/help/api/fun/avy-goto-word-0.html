Function: avy-goto-word-0

avy-goto-word-0 is an interactive and natively compiled function defined in avy.el.

Signature

(avy-goto-word-0 ARG &optional BEG END)

Documentation

Jump to a word start.

The window scope is determined by avy-all-windows. When ARG is non-nil, do the opposite of avy-all-windows. BEG and END narrow the scope where candidates are searched.

Key Bindings

This command is not in any keymaps.

(defun avy-goto-word-0 (arg &optional beg end)
  "Jump to a word start.
The window scope is determined by `avy-all-windows'.
When ARG is non-nil, do the opposite of `avy-all-windows'.
BEG and END narrow the scope where candidates are searched."
  (interactive "P")
  (avy-with avy-goto-word-0
    (avy-jump avy-goto-word-0-regexp
              :window-flip arg
              :beg beg
              :end end)))
