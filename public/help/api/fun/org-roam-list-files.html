Function: org-roam-list-files

org-roam-list-files is a natively compiled function defined in org-roam.el.

Signature

(org-roam-list-files)

Documentation

Return a list of all Org-roam files under org-roam-directory.

See org-roam-file-p for how each file is determined to be as part of Org-Roam.
