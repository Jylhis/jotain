Function: majutsu-log--entry-for-id

majutsu-log--entry-for-id is a natively compiled function defined in majutsu-log.el.

(majutsu-log--entry-for-id ID)

Documentation

Return visible parsed entry for ID, or nil.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-log.el
(defun majutsu-log--entry-for-id (id)
  "Return visible parsed entry for ID, or nil."
  (when (and id (not (string-empty-p id)))
    (majutsu-log--ensure-relation-indexes)
    (gethash id majutsu-log--entry-by-id)))
