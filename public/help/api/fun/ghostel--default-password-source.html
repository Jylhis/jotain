Function: ghostel--default-password-source

ghostel--default-password-source is a natively compiled function defined in ghostel.el.

Signature

(ghostel--default-password-source ROW)

Documentation

Default password source: prompt with read-passwd.

ROW is the cursor row text (used as the prompt label); falls back to "Password:" when nil. Always returns a string (or signals quit on keyboard-quit), so this source - at the tail of ghostel-password-prompt-functions - acts as the fallback once any prepended sources have returned nil.

(defun ghostel--default-password-source (row)
  "Default password source: prompt with `read-passwd'.
ROW is the cursor row text (used as the prompt label); falls back
to \"Password:\" when nil.  Always returns a string (or signals
quit on `keyboard-quit'), so this source - at the tail of
`ghostel-password-prompt-functions' - acts as the fallback once
any prepended sources have returned nil."
  (read-passwd (concat (or row "Password:") " ")))
