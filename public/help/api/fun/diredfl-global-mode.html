Function: diredfl-global-mode

diredfl-global-mode is an interactive and natively compiled function defined in diredfl.el.

Signature

(diredfl-global-mode &optional ARG)

Documentation

Toggle Diredfl mode in many buffers.

Specifically, Diredfl mode is enabled in all buffers where (lambda nil (when (derived-mode-p dired-mode) (diredfl-mode)))' would do it.

With prefix ARG, enable Diredfl-Global mode if ARG is positive; otherwise, disable it.

If called from Lisp, toggle the mode if ARG is toggle. Enable the mode if ARG is nil, omitted, or is a positive number. Disable the mode if ARG is a negative number.

See diredfl-mode(var)/diredfl-mode(fun) for more information on Diredfl mode.

Key Bindings

This command is not in any keymaps.
