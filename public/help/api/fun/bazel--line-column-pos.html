Function: bazel--line-column-pos

bazel--line-column-pos is a natively compiled function defined in bazel.el.

Signature

(bazel--line-column-pos LINE COLUMN)

Documentation

Return buffer position in the current buffer for LINE and COLUMN.

Restrict LINE to the buffer size and COLUMN to the number of characters in LINE. COLUMN is measured in characters, not visual columns.

(defun bazel--line-column-pos (line column)
  "Return buffer position in the current buffer for LINE and COLUMN.
Restrict LINE to the buffer size and COLUMN to the number of
characters in LINE.  COLUMN is measured in characters, not visual
columns."
  (cl-check-type line natnum)
  (cl-check-type column natnum)
  (save-excursion
    (without-restriction
      (goto-char (point-min))
      (forward-line (1- line))
      (min (line-end-position) (+ (point) column)))))
