Function: pulsar-highlight-line

pulsar-highlight-line is a function alias and interactive for pulsar-highlight-temporarily, defined in pulsar.el.

This command is obsolete since 1.3.0; use pulsar-highlight-temporarily instead.

Signature

(pulsar-highlight-line LOCUS)

Documentation

Temporarily highlight the current LOCUS.

Unlike pulsar-highlight-pulse, never pulse the current line. Keep the highlight in place until another command is invoked. This is what makes the highlight temporary.

For a permanent highlight, see pulsar-highlight-permanently.

Key Bindings

This command is not in any keymaps.

Aliases

pulsar-highlight-dwim (obsolete since 1.3.0) pulsar-highlight-temporarily
