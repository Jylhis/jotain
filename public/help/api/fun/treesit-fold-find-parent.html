Function: treesit-fold-find-parent

treesit-fold-find-parent is a natively compiled function defined in treesit-fold-util.el.

Signature

(treesit-fold-find-parent NODE TYPE)

Documentation

Find the TYPE of parent from NODE.

;; Defined in /nix/store/8bsxam5z769p2v85807qya1p1fb50bqx-emacs-packages-deps/share/emacs/site-lisp/elpa/treesit-fold-0.2.1/treesit-fold-util.el
(defun treesit-fold-find-parent (node type)
  "Find the TYPE of parent from NODE."
  (let ((parent (treesit-node-parent node))
        (break))
    (while (and parent (not break))
      (setq break (treesit-fold--compare-type parent type))
      (unless break
        (setq parent (treesit-node-parent parent))))
    parent))
