Function: csv-reverse-region

csv-reverse-region is an interactive and natively compiled function defined in csv-mode.el.

Signature

(csv-reverse-region BEG END)

Documentation

Reverse the order of the lines in the region.

This is just a CSV-mode style interface to reverse-region, which is the function that should be used non-interactively. It takes two point or marker arguments, BEG and END, delimiting the region.

Key Bindings

csv-mode-map C-c C-r

(defun csv-reverse-region (beg end)
  "Reverse the order of the lines in the region.
This is just a CSV-mode style interface to `reverse-region', which is
the function that should be used non-interactively.  It takes two
point or marker arguments, BEG and END, delimiting the region."
  ;; (interactive "*P\nr")

  (barf-if-buffer-read-only)
