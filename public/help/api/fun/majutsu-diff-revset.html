Function: majutsu-diff-revset

majutsu-diff-revset is an autoloaded, interactive and natively compiled function defined in majutsu-diff.el.

(majutsu-diff-revset REVSET &optional ARGS RANGE FILESETS)

Show changes for a REVSET.

REVSET is passed to jj diff using --revisions=.

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-diff.el
;;;###autoload
(defun majutsu-diff-revset (revset &optional args _range filesets)
  "Show changes for a REVSET.

REVSET is passed to jj diff using `--revisions='."
  (interactive (cons (majutsu-read-revset "Diff revset")
                     (majutsu-diff-arguments)))
  (let ((range (list (concat "--revisions=" (substring-no-properties revset)))))
    (majutsu-diff-setup-buffer args range filesets)))
