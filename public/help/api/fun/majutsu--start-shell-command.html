Function: majutsu--start-shell-command

majutsu--start-shell-command is a natively compiled function defined in majutsu-command.el.

Signature

(majutsu--start-shell-command COMMAND)

Documentation

Start COMMAND asynchronously and return the process.

Plain jj ... commands are started directly using Majutsu's jj process helpers. Other commands are run through shell-file-name.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-command.el
(defun majutsu--start-shell-command (command)
  "Start COMMAND asynchronously and return the process.
Plain `jj ...' commands are started directly using Majutsu's jj process
helpers.  Other commands are run through `shell-file-name'."
  (if-let* ((jj-args (majutsu--shell-command-jj-args command)))
      (apply #'majutsu-start-process
             (majutsu-jj--executable)
             nil
             (majutsu-process-jj-arguments jj-args))
    (majutsu-start-process shell-file-name nil shell-command-switch command)))
