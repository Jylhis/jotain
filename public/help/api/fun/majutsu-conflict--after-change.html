Function: majutsu-conflict--after-change

majutsu-conflict--after-change is a natively compiled function defined in majutsu-conflict.el.

Signature

(majutsu-conflict--after-change BEG END LEN)

Documentation

Refontify conflicts after edits in BEG..END.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-conflict.el
(defun majutsu-conflict--after-change (beg end _len)
  "Refontify conflicts after edits in BEG..END."
  (when (and majutsu-conflict-mode font-lock-mode)
    (font-lock-flush beg end)
    (font-lock-ensure beg end)))
