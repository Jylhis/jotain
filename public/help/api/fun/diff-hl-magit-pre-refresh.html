Function: diff-hl-magit-pre-refresh

diff-hl-magit-pre-refresh is a function alias and interactive for ignore, defined in subr.el.gz.

This command is obsolete since 1.11.0; use ignore instead.

Signature

(diff-hl-magit-pre-refresh &rest ARGUMENTS)

Documentation

Ignore ARGUMENTS, do nothing, and return nil.

This function accepts any number of arguments in ARGUMENTS. Also see always.
