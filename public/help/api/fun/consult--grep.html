Function: consult--grep

consult--grep is a natively compiled function defined in consult.el.

Signature

(consult--grep PROMPT MAKE-BUILDER DIR INITIAL)

Documentation

Run asynchronous grep.

MAKE-BUILDER is the function that returns the command line builder function. DIR is a directory or a list of file or directories. PROMPT is the prompt string. INITIAL is initial input.

(defun consult--grep (prompt make-builder dir initial)
  "Run asynchronous grep.

MAKE-BUILDER is the function that returns the command line
builder function.  DIR is a directory or a list of file or
directories.  PROMPT is the prompt string.  INITIAL is initial
input."
  (pcase-let* ((`(,prompt ,paths ,dir) (consult--directory-prompt prompt dir))
               (default-directory dir)
               (builder (funcall make-builder paths)))
    (consult--read
     (consult--process-collection builder
       :transform (consult--grep-format builder)
       :file-handler t)
     :prompt prompt
     :lookup #'consult--lookup-member
     :state (consult--grep-state)
     :initial initial
     :add-history (thing-at-point 'symbol)
     :require-match t
     :category 'consult-grep
     :group #'consult--prefix-group
     :history '(:input consult--grep-history)
     :sort nil)))
