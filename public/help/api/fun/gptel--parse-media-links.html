Function: gptel--parse-media-links

gptel--parse-media-links is a byte-compiled function defined in gptel-request.el.

Signature

(gptel--parse-media-links MODE BEG END)

Documentation

Find media links between BEG and END.

MODE is the major-mode of the buffer.

Returns a plist where each entry is of the form
  (:text "some text")
or
  (:media "media uri or file path").

Implementations

(gptel--parse-media-links (MODE (eql 'markdown-mode)) BEG END) in `gptel-request.el'.

Parse text and actionable links between BEG and END.

Return a list of the form ((:text "some text") (:media "/path/to/media.png" :mime "image/png") (:text "More text")) for inclusion into the user prompt for the gptel request.
