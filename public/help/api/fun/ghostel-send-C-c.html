Function: ghostel-send-C-c

ghostel-send-C-c is an interactive and natively compiled function defined in ghostel.el.

Signature

(ghostel-send-C-c)

Documentation

Send interrupt signal to the terminal.

Sends the raw byte so the tty line discipline raises SIGINT even when the foreground program has kitty keyboard mode active.

Key Bindings

ghostel-mode-map C-c C-c

  "Send interrupt signal to the terminal.

when the foreground program has kitty keyboard mode active."

  (ghostel--on-user-input)
