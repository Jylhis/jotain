Function: majutsu-jjdescription-next-message

majutsu-jjdescription-next-message is an interactive and natively compiled function defined in majutsu-jjdescription.el.

Signature

(majutsu-jjdescription-next-message ARG)

Documentation

Cycle forward through description history, saving current text first.

With a numeric prefix ARG, go forward ARG descriptions.

Key Bindings

majutsu-jjdescription-mode-map M-n

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-jjdescription.el
(defun majutsu-jjdescription-next-message (arg)
  "Cycle forward through description history, saving current text first.
With a numeric prefix ARG, go forward ARG descriptions."
  (interactive "*p")
  (majutsu-jjdescription-prev-message (- arg)))
