Function: eca-chat-status

eca-chat-status is a natively compiled function defined in eca-chat.el.

Signature

(eca-chat-status BUFFER)

Documentation

Return the status symbol of chat BUFFER.

One of waiting-approval, waiting-answer, stopping, running or idle.

;; Defined in /nix/store/53rcj4vx02sm8hj89vj9g7rhbbilbzvy-emacs-packages-deps/share/emacs/site-lisp/elpa/eca-20260828.1422/eca-chat.el
(defun eca-chat-status (buffer)
  "Return the status symbol of chat BUFFER.
One of `waiting-approval', `waiting-answer', `stopping',
`running' or `idle'."
  (with-current-buffer buffer
    (cond
     ((eca-chat--has-pending-approvals-p) 'waiting-approval)
     (eca-chat--pending-question 'waiting-answer)
     ((eq eca-chat--chat-loading 'stopping) 'stopping)
     (eca-chat--chat-loading 'running)
     (t 'idle))))
