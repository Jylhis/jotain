Function: verb-unset-vars

verb-unset-vars is an interactive and natively compiled function defined in verb.el.

Signature

(verb-unset-vars)

Documentation

Unset all variables set with verb-var or verb-set-var.

This affects only the current buffer.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/1vhkdxrkj0c423ijah8wn2d489dd8rgw-emacs-packages-deps/share/emacs/site-lisp/elpa/verb-20260818.1921/verb.el
(defun verb-unset-vars ()
  "Unset all variables set with `verb-var' or `verb-set-var'.
This affects only the current buffer."
  (interactive)
  (verb--ensure-verb-mode)
  (when (or (not (called-interactively-p 'any))
            (yes-or-no-p "Unset all Verb variables for current buffer? "))
    (setq verb--vars nil)))
