Function: pdf-util-image-file-size

pdf-util-image-file-size is a natively compiled function defined in pdf-util.el.

Signature

(pdf-util-image-file-size IMAGE-FILE)

Documentation

Determine the size of the image in IMAGE-FILE.

Returns a cons (WIDTH . HEIGHT).

(defun pdf-util-image-file-size (image-file)
  "Determine the size of the image in IMAGE-FILE.

Returns a cons \(WIDTH . HEIGHT\)."
  (pdf-util-assert-convert-program)
  (with-temp-buffer
    (when (save-excursion
            (= 0 (call-process
                  pdf-util-convert-program
                  nil (current-buffer) nil
                  image-file "-format" "%w %h" "info:")))
      (let ((standard-input (current-buffer)))
        (cons (read) (read))))))
