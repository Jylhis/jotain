Function: majutsu-annotate-next-chunk

majutsu-annotate-next-chunk is an interactive and natively compiled function defined in majutsu-annotate.el.

Signature

(majutsu-annotate-next-chunk)

Documentation

Move to the next chunk.

Key Bindings

majutsu-annotate-read-only-mode-map n

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-annotate.el
(defun majutsu-annotate-next-chunk ()
  "Move to the next chunk."
  (interactive)
  (if-let* ((next (next-single-char-property-change
                   (point) 'majutsu-annotate-chunk)))
      (goto-char next)
    (user-error "No more chunks")))
