Function: terraform--outline-level

terraform--outline-level is a natively compiled function defined in terraform-mode.el.

Signature

(terraform--outline-level)

Documentation

Return the depth to which a statement is nested in the outline.

See also outline-level(var)/outline-level(fun).

Source Code

;; Defined in /nix/store/4nxqp4jvms3n4azp2x2snypnn6xcgq9g-emacs-packages-deps/share/emacs/site-lisp/elpa/terraform-mode-20251115.2210/terraform-mode.el
(defun terraform--outline-level ()
  "Return the depth to which a statement is nested in the outline.

See also `outline-level'."
  (or (cdr (assoc (match-string 1) outline-heading-alist))
      (- (match-end 1) (match-beginning 1))))
