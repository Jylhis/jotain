Function: tagref-compilation-mode

tagref-compilation-mode is an interactive and natively compiled function defined in tagref.el.

Signature

(tagref-compilation-mode)

Documentation

Compilation mode for tagref check output.

In addition to any hooks its parent mode compilation-mode might have run, this mode runs the hook tagref-compilation-mode-hook, as the final or penultimate step during initialization.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/569pb56gyz7bfhc7d47q808dqp08qfsi-emacs-packages-deps/share/emacs/site-lisp/tagref.el
(define-compilation-mode tagref-compilation-mode "Tagref"
  "Compilation mode for tagref check output."
  (setq-local compilation-error-regexp-alist-alist
              (append tagref-error-regexp-alist
                      compilation-error-regexp-alist-alist))
  (setq-local compilation-error-regexp-alist '(tagref-error))
  ;; Enable ANSI color interpretation for tagref's colored output
  (add-hook 'compilation-filter-hook #'ansi-color-compilation-filter nil t))
