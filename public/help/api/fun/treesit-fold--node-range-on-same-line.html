Function: treesit-fold--node-range-on-same-line

treesit-fold--node-range-on-same-line is a natively compiled function defined in treesit-fold.el.

Signature

(treesit-fold--node-range-on-same-line NODE)

Documentation

Return non-nil when NODE range is on the same line.

Source Code

;; Defined in /nix/store/8bsxam5z769p2v85807qya1p1fb50bqx-emacs-packages-deps/share/emacs/site-lisp/elpa/treesit-fold-0.2.1/treesit-fold.el
(defun treesit-fold--node-range-on-same-line (node)
  "Return non-nil when NODE range is on the same line."
  (let ((range (treesit-fold--get-fold-range node)))
    (or (not range)                                  ; Range not defined, continue.
        (treesit-fold--range-on-same-line range))))  ; On same line, continue.
