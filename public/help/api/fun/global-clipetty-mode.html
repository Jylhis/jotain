Function: global-clipetty-mode

global-clipetty-mode is an interactive and natively compiled function defined in clipetty.el.

Signature

(global-clipetty-mode &optional ARG)

Documentation

Toggle Clipetty mode in many buffers.

Specifically, Clipetty mode is enabled in all buffers where (lambda nil (clipetty-mode 1)) would do it.

With prefix ARG, enable Global Clipetty mode if ARG is positive; otherwise, disable it.

If called from Lisp, toggle the mode if ARG is toggle. Enable the mode if ARG is nil, omitted, or is a positive number. Disable the mode if ARG is a negative number.

See clipetty-mode(var)/clipetty-mode(fun) for more information on Clipetty mode.

Key Bindings

This command is not in any keymaps.
