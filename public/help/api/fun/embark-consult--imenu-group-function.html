Function: embark-consult--imenu-group-function

embark-consult--imenu-group-function is a natively compiled function defined in embark-consult.el.

Signature

(embark-consult--imenu-group-function TYPE PROP)

Documentation

Return a suitable group-function for imenu.

TYPE is the completion category. PROP is the metadata property. Meant as :after-until advice for embark-collect--metadatum.

(defun embark-consult--imenu-group-function (type prop)
  "Return a suitable group-function for imenu.
TYPE is the completion category.
PROP is the metadata property.
Meant as :after-until advice for `embark-collect--metadatum'."
  (when (and (eq type 'imenu) (eq prop 'group-function))
    (consult-imenu--group)))
