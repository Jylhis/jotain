Function: dape-repl-watch

dape-repl-watch is a natively compiled function defined in dape.el.

(dape-repl-watch &rest EXPRESSION)

Documentation

List watched variables in REPL buffer.

If EXPRESSION is non blank add or remove expression to watch list.

;; Defined in /nix/store/l2knzmz5nqc323cf0hwsi3pa45p8w61v-emacs-packages-deps/share/emacs/site-lisp/elpa/dape-0.27.1/dape.el
(defun dape-repl-watch (&rest expression)
  "List watched variables in REPL buffer.
If EXPRESSION is non blank add or remove expression to watch list."
  (when expression
    (dape-watch-dwim (string-join expression " ")))
  (dape--repl-insert-info-buffer 'dape-info-watch-mode))
