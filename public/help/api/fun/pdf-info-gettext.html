Function: pdf-info-gettext

pdf-info-gettext is a natively compiled function defined in pdf-info.el.

Signature

(pdf-info-gettext PAGE EDGES &optional SELECTION-STYLE FILE-OR-BUFFER)

Documentation

Get text on PAGE according to EDGES.

EDGES should contain relative coordinates. The selection may extend over multiple lines, which works similar to a Emacs region. SELECTION-STYLE may be one of glyph, word or line and determines the smallest unit of the selected region.

Return the text contained in the selection.

(defun pdf-info-gettext (page edges &optional selection-style
                              file-or-buffer)
  "Get text on PAGE according to EDGES.

EDGES should contain relative coordinates.  The selection may
extend over multiple lines, which works similar to a Emacs
region. SELECTION-STYLE may be one of glyph, word or line and
determines the smallest unit of the selected region.

Return the text contained in the selection."

  (pdf-info-query
   'gettext
   (pdf-info--normalize-file-or-buffer file-or-buffer)
   page
   (mapconcat #'number-to-string edges " ")
   (pdf-info--selection-style selection-style)))
