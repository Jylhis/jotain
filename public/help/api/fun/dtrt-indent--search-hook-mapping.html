Function: dtrt-indent--search-hook-mapping

dtrt-indent--search-hook-mapping is a natively compiled function defined in dtrt-indent.el.

Signature

(dtrt-indent--search-hook-mapping MODE)

Documentation

Search hook-mapping for MODE or its derived-mode-parent.

;; Defined in /nix/store/07pi18l0q79xmgqf3amadq86iinldk0s-emacs-packages-deps/share/emacs/site-lisp/elpa/dtrt-indent-20260709.2011/dtrt-indent.el
(defun dtrt-indent--search-hook-mapping (mode)
  "Search hook-mapping for MODE or its derived-mode-parent."
  (if mode
      (or (assoc mode dtrt-indent-hook-mapping-list)
          (dtrt-indent--search-hook-mapping (get mode 'derived-mode-parent))
          (assoc 'default dtrt-indent-hook-mapping-list))))
