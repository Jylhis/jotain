Function: global-treesit-fold-mode

global-treesit-fold-mode is an interactive and natively compiled function defined in treesit-fold.el.

Signature

(global-treesit-fold-mode &optional ARG)

Documentation

Toggle Treesit-Fold mode in many buffers.

Specifically, Treesit-Fold mode is enabled in all buffers where treesit-fold--trigger would do it.

With prefix ARG, enable Global Treesit-Fold mode if ARG is positive; otherwise, disable it.

If called from Lisp, toggle the mode if ARG is toggle. Enable the mode if ARG is nil, omitted, or is a positive number. Disable the mode if ARG is a negative number.

See treesit-fold-mode(var)/treesit-fold-mode(fun) for more information on Treesit-Fold mode.

Key Bindings

This command is not in any keymaps.
