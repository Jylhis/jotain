Function: ghostel-identity-match-p

ghostel-identity-match-p is a natively compiled function defined in ghostel.el.

Signature

(ghostel-identity-match-p PATTERN IDENTITY)

Documentation

Return non-nil when every (KEY . VALUE) pair of PATTERN is in IDENTITY.

PATTERN and IDENTITY are ghostel-identity alists.

;; Defined in /nix/store/1jkgkg7y6y6hp0xia3dsmcl5zaj0bnhq-emacs-packages-deps/share/emacs/site-lisp/ghostel.el
(defun ghostel-identity-match-p (pattern identity)
  "Return non-nil when every (KEY . VALUE) pair of PATTERN is in IDENTITY.
PATTERN and IDENTITY are `ghostel-identity' alists."
  (seq-every-p (lambda (pair)
                 (equal (alist-get (car pair) identity) (cdr pair)))
               pattern))
