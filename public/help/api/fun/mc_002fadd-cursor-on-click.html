Function: mc/add-cursor-on-click

mc/add-cursor-on-click is a function alias and interactive for mc/toggle-cursor-on-click, defined in mc-mark-more.el.

Signature

(mc/add-cursor-on-click EVENT)

Documentation

Add a cursor where you click, or remove a fake cursor that is already there.

Key Bindings

This command is not in any keymaps.

Aliases

mc/toggle-cursor-on-click
