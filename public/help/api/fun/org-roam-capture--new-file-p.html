Function: org-roam-capture--new-file-p

org-roam-capture--new-file-p is a natively compiled function defined in org-roam-capture.el.

(org-roam-capture--new-file-p PATH)

;; Defined in /nix/store/qfyfp7k8wj4czdja2mlsqxrhlx7mvj76-emacs-packages-deps/share/emacs/site-lisp/elpa/org-roam-20260425.1623/org-roam-capture.el
(defun org-roam-capture--new-file-p (path)
  "Return t if PATH is for a new file with no visiting buffer."
  (not (or (file-exists-p path)
           (org-find-base-buffer-visiting path))))
