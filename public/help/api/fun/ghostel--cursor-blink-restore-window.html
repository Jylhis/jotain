Function: ghostel--cursor-blink-restore-window

ghostel--cursor-blink-restore-window is a natively compiled function defined in ghostel.el.

Signature

(ghostel--cursor-blink-restore-window WINDOW)

Documentation

Show WINDOW's cursor after this buffer enters or leaves it.

A buffer-local window-buffer-change-functions entry. The blink sets a per-window "cursor off" flag via internal-show-cursor, which would hide the cursor of whatever buffer the window shows next. The restore is deferred to a 0-delay timer because internal-show-cursor is inert during redisplay, which is when these functions run.

(defun ghostel--cursor-blink-restore-window (window)
  "Show WINDOW's cursor after this buffer enters or leaves it.
A buffer-local `window-buffer-change-functions' entry.  The blink sets
a per-window \"cursor off\" flag via `internal-show-cursor', which would
hide the cursor of whatever buffer the window shows next.  The restore
is deferred to a 0-delay timer because `internal-show-cursor' is inert
during redisplay, which is when these functions run."
  (run-at-time 0 nil
               (lambda ()
                 (when (window-live-p window)
                   (internal-show-cursor window t)))))
