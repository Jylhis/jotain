Function: projection--cache-file-modtime

projection--cache-file-modtime is a natively compiled function defined in projection-core-cache.el.

Signature

(projection--cache-file-modtime FILE)

Documentation

Fetch the last-modtime of FILE as a float.

Source Code

;; Defined in /nix/store/kqajmnl5vwqnlsg3vcmlj2d28ylc2n0n-emacs-packages-deps/share/emacs/site-lisp/elpa/projection-20260614.1822/projection-core-cache.el
(defun projection--cache-file-modtime (file)
  "Fetch the last-modtime of FILE as a float."
  (float-time
   (file-attribute-modification-time
    (file-attributes file 'integer))))
