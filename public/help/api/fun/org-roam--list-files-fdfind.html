Function: org-roam--list-files-fdfind

org-roam--list-files-fdfind is a function alias for org-roam--list-files-fd, defined in org-roam.el.

Signature

(org-roam--list-files-fdfind EXECUTABLE DIR)

Documentation

Return all Org-roam files under DIR, using "fd", provided as EXECUTABLE.

Aliases

org-roam--list-files-fd
