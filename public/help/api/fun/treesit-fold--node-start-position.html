Function: treesit-fold--node-start-position

treesit-fold--node-start-position is a natively compiled function defined in treesit-fold-util.el.

(treesit-fold--node-start-position NODE)

Documentation

;; Defined in /nix/store/8bsxam5z769p2v85807qya1p1fb50bqx-emacs-packages-deps/share/emacs/site-lisp/elpa/treesit-fold-0.2.1/treesit-fold-util.el
(defun treesit-fold--node-start-position (node)
  "Return NODE's start position."
  (save-excursion
    (goto-char (treesit-node-start node))
    (cons (line-number-at-pos) (current-column))))
