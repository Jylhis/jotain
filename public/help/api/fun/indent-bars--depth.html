Function: indent-bars--depth

indent-bars--depth is a byte-compiled function defined in indent-bars.el.

Signature

(indent-bars--depth LEN)

Documentation

Number of possible bars for initial blank string of length LEN.

Note that the first bar is expected at indent-bars-starting-column.

Source Code

;; Defined in /nix/store/kmdsnipwffgk5c0fs4785bhqa9fl17c5-emacs-packages-deps/share/emacs/site-lisp/elpa/indent-bars-1.0.1/indent-bars.el
(defsubst indent-bars--depth (len)
  "Number of possible bars for initial blank string of length LEN.
Note that the first bar is expected at `indent-bars-starting-column'."
  (if (> len indent-bars--offset)
      (1+ (/ (- len indent-bars--offset 1) indent-bars-spacing))
    0))
