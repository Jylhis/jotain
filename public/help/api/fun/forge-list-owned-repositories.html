Function: forge-list-owned-repositories

forge-list-owned-repositories is an interactive and natively compiled function defined in forge-repos.el.

Signature

(forge-list-owned-repositories)

Documentation

List your own known repositories in a separate buffer.

Here "known" means that an entry exists in the local database and options forge-owned-accounts and forge-owned-ignored controls which repositories are considered to be owned by you. Only Github is supported for now.

Key Bindings

This command is not in any keymaps.
