Function: apheleia--write-region-silently

apheleia--write-region-silently is a natively compiled function defined in apheleia-formatters.el.

Signature

(apheleia--write-region-silently START END FILENAME &optional APPEND VISIT LOCKNAME MUSTBENEW WRITE-REGION)

Documentation

Like write-region, but silent.

START, END, FILENAME, APPEND, VISIT, LOCKNAME, and MUSTBENEW are as in write-region. WRITE-REGION is used instead of the actual write-region function, if provided.

(defun apheleia--write-region-silently
    (start end filename &optional
           append visit lockname mustbenew write-region)
  "Like `write-region', but silent.
START, END, FILENAME, APPEND, VISIT, LOCKNAME, and MUSTBENEW are
as in `write-region'. WRITE-REGION is used instead of the actual
`write-region' function, if provided."
  (funcall (or write-region #'write-region)
           start end filename append 0 lockname mustbenew)
  (when (or (eq visit t) (stringp visit))
    (setq buffer-file-name (if (eq visit t)
                               filename
                             visit))
    (set-visited-file-modtime)
    (set-buffer-modified-p nil)))
