Function: combobulate-cursor-edit-sequence-dwim

combobulate-cursor-edit-sequence-dwim is an interactive and natively compiled function defined in combobulate-cursor.el.

Signature

(combobulate-cursor-edit-sequence-dwim ARG)

Documentation

Edit a sequence of nodes.

This looks for clusters of nodes to edit in procedures-sequence.

If you specify a prefix ARG, then the points are placed at the end of each edited node.

;; Defined in /nix/store/9y0jasyzsqjcbfkwqsgdyxcnskjnsypg-emacs-packages-deps/share/emacs/site-lisp/combobulate-cursor.el
(defun combobulate-cursor-edit-sequence-dwim (arg)
  "Edit a sequence of nodes.

This looks for clusters of nodes to edit in
`procedures-sequence'.

If you specify a prefix ARG, then the points are placed at the
end of each edited node."
  (interactive "P")
  (with-navigation-nodes (:procedures (combobulate-read procedures-sequence))
    (if-let ((node (combobulate--get-nearest-navigable-node)))
        (combobulate-cursor-edit-sequence
         node
         (combobulate-cursor-edit-node-determine-action arg))
      (error "There is no sequence of nodes here"))))
