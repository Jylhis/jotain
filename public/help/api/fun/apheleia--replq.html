Function: apheleia--replq

apheleia--replq is a natively compiled function defined in apheleia-formatters.el.

Signature

(apheleia--replq DEST IN OUT)

Documentation

Replace all references to IN with OUT in DEST.

This function does not modify DEST in place, it returns a copy.

;; Defined in /nix/store/dbykkl13khzh84lv9vw1bf1vijzg30fr-emacs-packages-deps/share/emacs/site-lisp/elpa/apheleia-20260817.2331/apheleia-formatters.el
(defun apheleia--replq (dest in out)
  "Replace all references to IN with OUT in DEST.
This function does not modify DEST in place, it returns a copy."
  (setq in (apheleia--ensure-list in))
  (mapcar (lambda (arg)
            (if (memq arg in)
                out
              arg))
          dest))
