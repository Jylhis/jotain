Function: pdf-util-scroll-to-edges

pdf-util-scroll-to-edges is a natively compiled function defined in pdf-util.el.

Signature

(pdf-util-scroll-to-edges EDGES &optional EAGER-P)

Documentation

Scroll window such that image EDGES are visible.

Scroll as little as necessary. Unless EAGER-P is non-nil, in which case scroll as much as possible.

(defun pdf-util-scroll-to-edges (edges &optional eager-p)
  "Scroll window such that image EDGES are visible.

Scroll as little as necessary.  Unless EAGER-P is non-nil, in
which case scroll as much as possible."

  (let ((vscroll (pdf-util-required-vscroll edges eager-p))
        (hscroll (pdf-util-required-hscroll edges eager-p)))
    (when vscroll
      (image-set-window-vscroll vscroll))
    (when hscroll
      (image-set-window-hscroll hscroll))))
