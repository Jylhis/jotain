Function: majutsu-section--hidden-bounds

majutsu-section--hidden-bounds is a byte-compiled function defined in majutsu-section.el.

Signature

(majutsu-section--hidden-bounds SECTION)

Documentation

Return invisible overlay bounds for SECTION as (BEG . END).

Return nil when SECTION has no hideable body. The returned END uses Emacs overlay conventions and is exclusive.
