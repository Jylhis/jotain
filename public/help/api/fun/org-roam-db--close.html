Function: org-roam-db--close

org-roam-db--close is a natively compiled function defined in org-roam-db.el.

Signature

(org-roam-db--close &optional DB)

Documentation

Closes the database connection for database DB.

If DB is nil, closes the database connection for the database in the current org-roam-directory.

(defun org-roam-db--close (&optional db)
  "Closes the database connection for database DB.
If DB is nil, closes the database connection for the database in
the current `org-roam-directory'."
  (unless db
    (setq db (org-roam-db--get-connection)))
  (when (and db (emacsql-live-p db))
    (emacsql-close db)))
