Function: cape-line

cape-line is an interactive and natively compiled function defined in cape.el.

Signature

(cape-line &optional INTERACTIVE)

Documentation

Complete current line from other lines.

The buffers returned by cape-line-buffer-function are scanned for lines. If INTERACTIVE is nil the function acts like a Capf.

Key Bindings

cape-prefix-map l

(defun cape-line (&optional interactive)
  "Complete current line from other lines.
The buffers returned by `cape-line-buffer-function' are scanned for lines.
If INTERACTIVE is nil the function acts like a Capf."
  (interactive (list t))
  (if interactive
      (cape-interactive #'cape-line)
    `(,(pos-bol) ,(point) ,(cape--line-list) ,@cape--line-properties)))
