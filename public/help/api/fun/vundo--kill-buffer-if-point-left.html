Function: vundo--kill-buffer-if-point-left

vundo--kill-buffer-if-point-left is a natively compiled function defined in vundo.el.

Signature

(vundo--kill-buffer-if-point-left WINDOW)

Documentation

Kill the vundo buffer if point left WINDOW.

WINDOW is the window that was/is displaying the vundo buffer.

;; Defined in /nix/store/7c2696v2qdrdv2vf2im8alazibi7qq0z-emacs-packages-deps/share/emacs/site-lisp/elpa/vundo-2.4.0/vundo.el
(defun vundo--kill-buffer-if-point-left (window)
  "Kill the vundo buffer if point left WINDOW.
WINDOW is the window that was/is displaying the vundo buffer."
  (if (and (eq (window-buffer window) (vundo--buffer))
           (not (eq window (selected-window))))
      (with-selected-window window
        (kill-buffer-and-window))))
