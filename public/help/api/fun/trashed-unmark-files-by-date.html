Function: trashed-unmark-files-by-date

trashed-unmark-files-by-date is an interactive and natively compiled function defined in trashed.el.

Signature

(trashed-unmark-files-by-date &optional CONDITION)

Documentation

Unmark all files matching date CONDITION.

If called interactively or CONDITION is nil, prompt for date condition. See trashed-tag-files-by-date for date condition details.

Key Bindings

trashed-mode-map $ u
