Function: haskell-flymake-create-temp-buffer-copy

haskell-flymake-create-temp-buffer-copy is a function alias for flymake-proc-init-create-temp-buffer-copy, defined in flymake-proc.el.gz.

Signature

(haskell-flymake-create-temp-buffer-copy CREATE-TEMP-F)

Documentation

Make a temporary copy of the current buffer, save its name in buffer data.

Return the name.
