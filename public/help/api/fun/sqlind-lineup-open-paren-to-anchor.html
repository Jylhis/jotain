Function: sqlind-lineup-open-paren-to-anchor

sqlind-lineup-open-paren-to-anchor is a natively compiled function defined in sql-indent.el.

Signature

(sqlind-lineup-open-paren-to-anchor SYNTAX BASE-INDENTATION)

Documentation

Align an open paranthesis with the anchor point of SYNTAX.

If the line starts with an open paren '(', return the column of the anchor point. If line does not start with an open paren, the function returns BASE-INDENTATION, acting as a no-op.

;; Defined in /nix/store/vgm6xb2iy00bs19rdw9z3nfi5nf8g873-emacs-packages-deps/share/emacs/site-lisp/elpa/sql-indent-1.7/sql-indent.el
(defun sqlind-lineup-open-paren-to-anchor (syntax base-indentation)
  "Align an open paranthesis with the anchor point of SYNTAX.
If the line starts with an open paren \\='(\\=', return the
column of the anchor point.  If line does not start with an open
paren, the function returns BASE-INDENTATION, acting as a no-op."
  (save-excursion
    (back-to-indentation)
    (if (looking-at "(")
        (sqlind-lineup-to-anchor syntax base-indentation)
      base-indentation)))
