Function: majutsu-bookmark-advance-to

majutsu-bookmark-advance-to is an interactive and natively compiled function defined in majutsu-bookmark.el.

Signature

(majutsu-bookmark-advance-to REVSET)

Documentation

Advance bookmarks using jj's default selection to REVSET.

Key Bindings

This command is not in any keymaps.

;;;###autoload
(defun majutsu-bookmark-advance-to (revset)
  "Advance bookmarks using jj's default selection to REVSET."
  (interactive (list (majutsu-read-revset "Advance to revset")))
  (majutsu-bookmark-advance nil revset))
