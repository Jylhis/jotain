Function: majutsu-conflict-label-description

majutsu-conflict-label-description is a natively compiled function defined in majutsu-conflict.el.

Signature

(majutsu-conflict-label-description LABEL)

Documentation

Return the description from LABEL, or nil when unavailable.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-conflict.el
(defun majutsu-conflict-label-description (label)
  "Return the description from LABEL, or nil when unavailable."
  (plist-get (majutsu-conflict-parse-label label) :description))
