Function: eca-chat--read-only-end-point

eca-chat--read-only-end-point is a natively compiled function defined in eca-chat.el.

Signature

(eca-chat--read-only-end-point)

Documentation

Return the position where the read-only region ends.

This is the start of the progress area, so the history, the separator and the task area are all read-only while the progress, context and prompt input stay editable. Falls back to the prompt area start when the progress overlay does not exist yet.

separator and the task area are all read-only while the progress,
context and prompt input stay editable.  Falls back to the prompt
area start when the progress overlay does not exist yet."

      (eca-chat--prompt-area-start-point)))
