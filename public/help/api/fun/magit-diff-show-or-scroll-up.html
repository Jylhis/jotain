Function: magit-diff-show-or-scroll-up

magit-diff-show-or-scroll-up is an interactive and natively compiled function defined in magit-diff.el.

Signature

(magit-diff-show-or-scroll-up)

Documentation

Update the commit or diff buffer for the thing at point.

Either show the commit or stash at point in the appropriate buffer, or if that buffer is already being displayed in the current frame and contains information about that commit or stash, then instead scroll the buffer up. If there is no commit or stash at point, then prompt for a commit.

magit-blame-read-only-mode-map SPC magit-mode-map SPC

(defun magit-diff-show-or-scroll-up ()
  "Update the commit or diff buffer for the thing at point.

Either show the commit or stash at point in the appropriate
buffer, or if that buffer is already being displayed in the
current frame and contains information about that commit or
stash, then instead scroll the buffer up.  If there is no
commit or stash at point, then prompt for a commit."
  (interactive)
  (magit-diff-show-or-scroll #'scroll-up))
