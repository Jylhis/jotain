Function: majutsu-diff--range-value

majutsu-diff--range-value is a natively compiled function defined in majutsu-diff.el.

Signature

(majutsu-diff--range-value RANGE PREFIX)

Documentation

Return the value in RANGE for argument starting with PREFIX.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-diff.el
(defun majutsu-diff--range-value (range prefix)
  "Return the value in RANGE for argument starting with PREFIX."
  (when range
    (when-let* ((arg (seq-find (lambda (item) (string-prefix-p prefix item)) range)))
      (substring arg (length prefix)))))
