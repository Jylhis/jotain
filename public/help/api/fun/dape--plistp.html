Function: dape--plistp

dape--plistp is a natively compiled function defined in dape.el.

Signature

(dape--plistp OBJECT)

Documentation

Non-nil if and only if OBJECT is a valid plist.

Source Code

;; Defined in /nix/store/l2knzmz5nqc323cf0hwsi3pa45p8w61v-emacs-packages-deps/share/emacs/site-lisp/elpa/dape-0.27.1/dape.el
(defun dape--plistp (object)
  "Non-nil if and only if OBJECT is a valid plist."
  (and (listp object) (zerop (% (length object) 2))))
