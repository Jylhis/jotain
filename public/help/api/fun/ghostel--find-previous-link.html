Function: ghostel--find-previous-link

ghostel--find-previous-link is a natively compiled function defined in ghostel-links.el.

Signature

(ghostel--find-previous-link FROM)

Documentation

Return start position of the first hyperlink before FROM, or nil.

Source Code

;; Defined in /nix/store/1jkgkg7y6y6hp0xia3dsmcl5zaj0bnhq-emacs-packages-deps/share/emacs/site-lisp/ghostel-links.el
(defun ghostel--find-previous-link (from)
  "Return start position of the first hyperlink before FROM, or nil."
  (ghostel--find-link-1 'previous from))
