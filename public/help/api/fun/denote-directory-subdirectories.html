Function: denote-directory-subdirectories

denote-directory-subdirectories is a natively compiled function defined in denote.el.

Signature

(denote-directory-subdirectories)

Documentation

Return list of subdirectories in variable denote-directory(var)/denote-directory(fun).

Omit dotfiles (such as .git) unconditionally. Also exclude whatever matches denote-excluded-directories-regexp.

(defun denote-directory-subdirectories ()
  "Return list of subdirectories in variable `denote-directory'.
Omit dotfiles (such as .git) unconditionally.  Also exclude
whatever matches `denote-excluded-directories-regexp'."
  (let ((dirs (denote-directories)))
    (seq-remove
     (lambda (filename)
       (let ((rel (denote--get-file-name-relative-to-directories filename dirs)))
         (or (not (file-directory-p filename))
             (string-match-p "\\`\\." rel)
             (string-match-p "/\\." rel)
             (denote--exclude-directory-regexp-p rel))))
     (denote--directory-all-files-recursively))))
