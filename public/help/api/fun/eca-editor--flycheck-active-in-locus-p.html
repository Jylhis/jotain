Function: eca-editor--flycheck-active-in-locus-p

eca-editor--flycheck-active-in-locus-p is a natively compiled function defined in eca-editor.el.

Signature

(eca-editor--flycheck-active-in-locus-p LOCUS)

Documentation

Return non-nil if LOCUS is a live buffer with flycheck-mode on.

Used to suppress flymake diagnostics for buffers where flycheck is already the active diagnostic surface, mirroring how the flycheck branch suppresses its own output in lsp-managed buffers. The resulting precedence is: lsp-mode > flycheck > flymake.

(defun eca-editor--flycheck-active-in-locus-p (locus)
  "Return non-nil if LOCUS is a live buffer with `flycheck-mode' on.
Used to suppress flymake diagnostics for buffers where flycheck is
already the active diagnostic surface, mirroring how the flycheck
branch suppresses its own output in lsp-managed buffers.  The
resulting precedence is: lsp-mode > flycheck > flymake."
  (and (buffer-live-p locus)
       (with-current-buffer locus
         (bound-and-true-p flycheck-mode))))
