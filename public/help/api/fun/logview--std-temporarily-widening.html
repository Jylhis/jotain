Function: logview--std-temporarily-widening

logview--std-temporarily-widening is a macro defined in logview.el.

Signature

(logview--std-temporarily-widening &rest BODY)

Documentation

Execute BODY with the current buffer fully widened.

Original point restrictions are available as return values of functions logview--point-min(var)/logview--point-min(fun) and logview--point-max(var)/logview--point-max(fun). This macro can be nested, with inner calls not changing results of the two functions (available since the first call) further.

  "Execute BODY with the current buffer fully widened.

functions `logview--point-min' and `logview--point-max'.  This
macro can be nested, with inner calls not changing results of the
