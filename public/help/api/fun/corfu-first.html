Function: corfu-first

corfu-first is an interactive and natively compiled function defined in corfu.el.

Signature

(corfu-first)

Documentation

Go to first candidate.

If the first candidate is already selected, go to the prompt.

(defun corfu-first ()
  "Go to first candidate.
If the first candidate is already selected, go to the prompt."
  (interactive)
  (corfu--goto (if (> corfu--index 0) 0 -1)))
