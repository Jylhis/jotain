Function: auto-dark--update-frame-backgrounds

auto-dark--update-frame-backgrounds is a natively compiled function defined in auto-dark.el.

Signature

(auto-dark--update-frame-backgrounds APPEARANCE)

Documentation

Set the frame-background-mode for all frames to APPEARANCE.

Source Code

;; Defined in /nix/store/bsy6s0b3kb4pmxsgxn385p8xfkhwnj6b-emacs-packages-deps/share/emacs/site-lisp/elpa/auto-dark-20260313.2356/auto-dark.el
(defun auto-dark--update-frame-backgrounds (appearance)
  "Set the `frame-background-mode' for all frames to APPEARANCE."
  (setq frame-background-mode appearance)
  (mapc #'frame-set-background-mode (frame-list)))
