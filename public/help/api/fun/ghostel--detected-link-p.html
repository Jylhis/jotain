Function: ghostel--detected-link-p

ghostel--detected-link-p is a natively compiled function defined in ghostel-links.el.

(ghostel--detected-link-p POS)

Documentation

Non-nil when the link at POS is one this scan attached earlier.

;; Defined in /nix/store/1jkgkg7y6y6hp0xia3dsmcl5zaj0bnhq-emacs-packages-deps/share/emacs/site-lisp/ghostel-links.el
(defun ghostel--detected-link-p (pos)
  "Non-nil when the link at POS is one this scan attached earlier."
  (eq (car-safe (get-text-property pos 'ghostel-link-id)) 'ghostel-detected))
