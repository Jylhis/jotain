Function: verb-shell

verb-shell is a natively compiled function defined in verb.el.

(verb-shell COMMAND &optional TRIM)

Documentation

Return output of running shell-command-to-string with COMMAND.

If TRIM is non-nil, trim leading and trailing whitespace before returning.

;; Defined in /nix/store/1vhkdxrkj0c423ijah8wn2d489dd8rgw-emacs-packages-deps/share/emacs/site-lisp/elpa/verb-20260818.1921/verb.el
(defun verb-shell (command &optional trim)
  "Return output of running `shell-command-to-string' with COMMAND.
If TRIM is non-nil, trim leading and trailing whitespace before returning."
  (let ((s (shell-command-to-string command)))
    (if trim
        (string-trim s)
      s)))
