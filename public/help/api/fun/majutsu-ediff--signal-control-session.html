Function: majutsu-ediff--signal-control-session

majutsu-ediff--signal-control-session is a natively compiled function defined in majutsu-ediff.el.

Signature

(majutsu-ediff--signal-control-session PID OK)

Documentation

Signal PID when control session completes.

When OK is non-nil send USR1, otherwise send USR2.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-ediff.el
(defun majutsu-ediff--signal-control-session (pid ok)
  "Signal PID when control session completes.
When OK is non-nil send USR1, otherwise send USR2."
  (process-file "kill" nil nil nil
                "-s" (if ok "USR1" "USR2") pid))
