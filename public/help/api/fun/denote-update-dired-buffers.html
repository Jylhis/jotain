Function: denote-update-dired-buffers

denote-update-dired-buffers is a natively compiled function defined in denote.el.

Signature

(denote-update-dired-buffers)

Documentation

Update Dired buffers of variable denote-directory(var)/denote-directory(fun).

Also revert the current Dired buffer even if it is not inside the variable denote-directory(var)/denote-directory(fun).

(defun denote-update-dired-buffers ()
  "Update Dired buffers of variable `denote-directory'.
Also revert the current Dired buffer even if it is not inside the
variable `denote-directory'."
  (let ((current (current-buffer)))
    (dolist (buffer (buffer-list))
      (denote--revert-dired buffer current))))
