Function: sqlind-adjust-comma

sqlind-adjust-comma is a natively compiled function defined in sql-indent.el.

Signature

(sqlind-adjust-comma SYNTAX BASE-INDENTATION)

Documentation

Lineup lines starting with a comma ',' to the word start.

Adjust BASE-INDENTATION so that the actual word is lined up. For example:

  SELECT col1
     , col2 -- ignore the comma and align the actual word.

(defun sqlind-adjust-comma (_syntax base-indentation)
  "Lineup lines starting with a comma ',' to the word start.
Adjust BASE-INDENTATION so that the actual word is lined up.  For
example:

  SELECT col1
     ,   col2 -- ignore the comma and align the actual word."
  (save-excursion
    (back-to-indentation)
    (let ((ofs (if (looking-at ",\\s-*") (length (match-string 0)) 0)))
      (max 0 (- base-indentation ofs)))))
