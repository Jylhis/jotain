Function: vertico--remote-p

vertico--remote-p is a natively compiled function defined in vertico.el.

(vertico--remote-p PATH)

Documentation

(defun vertico--remote-p (path)
  "Return t if PATH is a remote path."
  (string-match-p "\\`/[^/|:]+:" (substitute-in-file-name path)))
