Function: copy-dape--source-breakpoint

copy-dape--source-breakpoint is a function alias for copy-sequence, defined in fns.c.

Signature

(copy-dape--source-breakpoint ARG)

Documentation

Return a copy of a list, vector, string, char-table or record.

The elements of a list, vector or record are not copied; they are shared with the original. See Info node (elisp) Sequence Functions for more details about this sharing and its effects. If the original sequence is empty, this function may return the same empty object instead of its copy.
