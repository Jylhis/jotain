Function: eca-table--button

eca-table--button is a natively compiled function defined in eca-table.el.

Signature

(eca-table--button TEXT COMMAND HELP)

Documentation

Return TEXT as a clickable action-bar button running COMMAND.

HELP is shown as the tooltip on hover. COMMAND is also reachable from the keyboard via eca-table-actions-map when point is inside the table.

(defun eca-table--button (text command help)
  "Return TEXT as a clickable action-bar button running COMMAND.
HELP is shown as the tooltip on hover.  COMMAND is also reachable
from the keyboard via `eca-table-actions-map' when point is inside
the table."
  (let ((map (make-sparse-keymap)))
    (define-key map [mouse-1] command)
    (define-key map [mouse-2] command)
    (propertize text
                'face 'eca-table-action-key-face
                'mouse-face 'highlight
                'keymap map
                'help-echo help)))
