Function: ghostel-next

ghostel-next is an interactive and natively compiled function defined in ghostel.el.

Signature

(ghostel-next)

Documentation

Switch to the next ghostel buffer (sorted by name, wraps around).

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/1jkgkg7y6y6hp0xia3dsmcl5zaj0bnhq-emacs-packages-deps/share/emacs/site-lisp/ghostel.el
;;;###autoload
(defun ghostel-next ()
  "Switch to the next ghostel buffer (sorted by name, wraps around)."
  (interactive)
  (ghostel--cycle (ghostel--all-buffers) +1
                  "No ghostel buffers"
                  "Only one ghostel buffer"))
