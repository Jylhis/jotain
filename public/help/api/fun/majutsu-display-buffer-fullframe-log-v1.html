Function: majutsu-display-buffer-fullframe-log-v1

majutsu-display-buffer-fullframe-log-v1 is a natively compiled function defined in majutsu-base.el.

Signature

(majutsu-display-buffer-fullframe-log-v1 BUFFER)

Documentation

Display BUFFER, filling entire frame if BUFFER is a log buffer.

Otherwise, behave like majutsu-display-buffer-traditional.

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-base.el
(defun majutsu-display-buffer-fullframe-log-v1 (buffer)
  "Display BUFFER, filling entire frame if BUFFER is a log buffer.
Otherwise, behave like `majutsu-display-buffer-traditional'."
  (if (eq (with-current-buffer buffer major-mode)
          'majutsu-log-mode)
      (display-buffer buffer '(majutsu--display-buffer-fullframe))
    (majutsu-display-buffer-traditional buffer)))
