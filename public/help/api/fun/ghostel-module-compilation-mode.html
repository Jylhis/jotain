Function: ghostel-module-compilation-mode

ghostel-module-compilation-mode is an interactive and natively compiled function defined in ghostel-module-install.el.

Signature

(ghostel-module-compilation-mode)

Documentation

Compilation mode for ghostel-module-compile.

In addition to any hooks its parent mode compilation-mode might have run, this mode runs the hook ghostel-module-compilation-mode-hook, as the final or penultimate step during initialization.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/1jkgkg7y6y6hp0xia3dsmcl5zaj0bnhq-emacs-packages-deps/share/emacs/site-lisp/ghostel-module-install.el
(define-derived-mode ghostel-module-compilation-mode compilation-mode "Compilation"
  "Compilation mode for `ghostel-module-compile'."
  (add-hook 'compilation-finish-functions
            #'ghostel--install-built-module-after-compilation
            nil t))
