Function: majutsu-log-post-decode-line-separator

majutsu-log-post-decode-line-separator is a natively compiled function defined in majutsu-log.el.

Signature

(majutsu-log-post-decode-line-separator VALUE &optional CTX)

Documentation

Decode majutsu-log--field-line-separator inside VALUE.

This is the default postprocessor for log fields so all modules can transport logical newlines safely through single-line payload segments.

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-log.el
(defun majutsu-log-post-decode-line-separator (value &optional _ctx)
  "Decode `majutsu-log--field-line-separator' inside VALUE.

This is the default postprocessor for log fields so all modules can
transport logical newlines safely through single-line payload segments."
  (if (stringp value)
      (subst-char-in-string
       (aref majutsu-log--field-line-separator 0)
       ?\n
       value t)
    value))
