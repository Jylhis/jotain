Function: org-modern--unfontify

org-modern--unfontify is a natively compiled function defined in org-modern.el.

Signature

(org-modern--unfontify BEG END &optional LOUD)

Documentation

Unfontify prettified elements between BEG and END.

;; Defined in /nix/store/c2c3l8drcnybmya5zjrxb6fifrfpi1c0-emacs-packages-deps/share/emacs/site-lisp/elpa/org-modern-20260722.1411/org-modern.el
(defun org-modern--unfontify (beg end &optional _loud)
  "Unfontify prettified elements between BEG and END."
  (let ((font-lock-extra-managed-props
         (append
          ;; Only remove line/wrap-prefix if block fringes are used
          (if (and org-modern-block-fringe (not (bound-and-true-p org-indent-mode)))
              '(wrap-prefix line-prefix display invisible)
            '(display invisible))
          font-lock-extra-managed-props)))
    (org-unfontify-region beg end)))
