Function: ghostel-force-redraw

ghostel-force-redraw is an interactive and natively compiled function defined in ghostel.el.

Signature

(ghostel-force-redraw)

Documentation

Force an immediate terminal redraw, bypassing synchronized-output batching.

Repaints now even while the terminal program holds mode 2026 open, so a buffer left showing stale content (e.g. revealed mid-frame) recovers. Requires the buffer to be visible in a window; has no effect otherwise.

Key Bindings

This command is not in any keymaps.
