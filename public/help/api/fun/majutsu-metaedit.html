Function: majutsu-metaedit

majutsu-metaedit is an interactive and natively compiled function defined in majutsu-metaedit.el.

Signature

(majutsu-metaedit &optional ARG)

Documentation

Open the metaedit transient.

With prefix ARG, pre-enable --ignore-immutable.

Key Bindings

This command is not in any keymaps.

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-metaedit.el
;;;###autoload
(defun majutsu-metaedit (&optional arg)
  "Open the metaedit transient.
With prefix ARG, pre-enable --ignore-immutable."
  (interactive "P")
  (transient-setup
   'majutsu-metaedit-transient nil nil
   :value (append (majutsu-metaedit-arguments)
                  (when arg '("--ignore-immutable")))))
