Function: majutsu--start-jj-command

majutsu--start-jj-command is a natively compiled function defined in majutsu-command.el.

Signature

(majutsu--start-jj-command COMMAND)

Documentation

Start jj COMMAND asynchronously and return the process.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-command.el
(defun majutsu--start-jj-command (command)
  "Start jj COMMAND asynchronously and return the process."
  (apply #'majutsu-start-process
         (majutsu-jj--executable)
         nil
         (majutsu-process-jj-arguments (majutsu--jj-command-args command))))
