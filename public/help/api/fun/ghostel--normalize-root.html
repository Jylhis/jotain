Function: ghostel--normalize-root

ghostel--normalize-root is a natively compiled function defined in ghostel.el.

Signature

(ghostel--normalize-root ROOT)

Documentation

Return ROOT as a normalized directory path for project-root keys.

Remote ROOTs are used as-is; TRAMP expansion and abbreviation depend on connection state and would make the key unstable.

Source Code

;; Defined in /nix/store/1jkgkg7y6y6hp0xia3dsmcl5zaj0bnhq-emacs-packages-deps/share/emacs/site-lisp/ghostel.el
(defun ghostel--normalize-root (root)
  "Return ROOT as a normalized directory path for `project-root' keys.
Remote ROOTs are used as-is; TRAMP expansion and abbreviation
depend on connection state and would make the key unstable."
  (if (file-remote-p root)
      (file-name-as-directory root)
    (abbreviate-file-name (file-name-as-directory (expand-file-name root)))))
