Function: majutsu--buffer-root

majutsu--buffer-root is a natively compiled function defined in majutsu-base.el.

Signature

(majutsu--buffer-root &optional BUFFER)

Documentation

Return the cached root for BUFFER (default current-buffer).

This is used to match buffers to repositories when refreshing.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-base.el
(defun majutsu--buffer-root (&optional buffer)
  "Return the cached root for BUFFER (default `current-buffer').

This is used to match buffers to repositories when refreshing."
  (with-current-buffer (or buffer (current-buffer))
    (and (boundp 'majutsu--default-directory) majutsu--default-directory)))
