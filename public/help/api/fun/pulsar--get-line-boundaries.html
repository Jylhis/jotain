Function: pulsar--get-line-boundaries

pulsar--get-line-boundaries is a natively compiled function defined in pulsar.el.

Signature

(pulsar--get-line-boundaries)

Documentation

Return cons cell of line beginning and end positions.

If possible, make the end be 1+ its value, so that the highlight can be extended to the edge of the window.

(defun pulsar--get-line-boundaries ()
