Function: corfu-previous

corfu-previous is an interactive and natively compiled function defined in corfu.el.

Signature

(corfu-previous &optional N)

Documentation

(defun corfu-previous (&optional n)
  "Go backward N candidates."
  (interactive "p")
  (corfu-next (- (or n 1))))
