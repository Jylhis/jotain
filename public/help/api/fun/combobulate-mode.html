Function: combobulate-mode

combobulate-mode is an interactive and natively compiled function defined in combobulate-setup.el.

Signature

(combobulate-mode &optional ARG &rest _)

Documentation

Navigate and edit by syntactic constructs.

This is a helper command that tries to activate the right Combobulate minor mode suitable for the current buffer.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/9y0jasyzsqjcbfkwqsgdyxcnskjnsypg-emacs-packages-deps/share/emacs/site-lisp/combobulate-setup.el
;;;###autoload
(defun combobulate-mode (&optional arg &rest _)
  "Navigate and edit by syntactic constructs.

This is a helper command that tries to activate the right
Combobulate minor mode suitable for the current buffer."
  (interactive "p")
  ;; This is no longer an actual minor mode, but instead a function.
  (combobulate-maybe-activate nil (not (null arg))))
