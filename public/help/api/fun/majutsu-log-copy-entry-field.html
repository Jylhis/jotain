Function: majutsu-log-copy-entry-field

majutsu-log-copy-entry-field is an interactive and natively compiled function defined in majutsu-log.el.

Signature

(majutsu-log-copy-entry-field)

Documentation

Copy a canonical field from the current log entry.

Unlike majutsu-log-copy-field, this can target fields that are parsed and stored on the entry but not currently visible in the rendered log line. When called interactively, prompt with completion over the current entry's available canonical fields. If the region is active, copy it literally using copy-region-as-kill.

Key Bindings

This command is not in any keymaps.

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-log.el
;;;###autoload
(defun majutsu-log-copy-entry-field ()
  "Copy a canonical field from the current log entry.

Unlike `majutsu-log-copy-field', this can target fields that are parsed and
stored on the entry but not currently visible in the rendered log line.  When
called interactively, prompt with completion over the current entry's
available canonical fields.  If the region is active, copy it literally using
`copy-region-as-kill'."
  (interactive)
  (if (use-region-p)
      (call-interactively #'copy-region-as-kill)
    (let* ((compiled (majutsu-log--current-compiled))
           (entry (or (majutsu-log--entry-at-point)
                      (user-error "No log entry at point")))
           (field (majutsu-log--read-entry-field entry compiled)))
      (majutsu-log--copy-entry-field-value entry field))))
