Function: indent-bars-mode

indent-bars-mode is an interactive and natively compiled function defined in indent-bars.el.

Signature

(indent-bars-mode &optional ARG)

Documentation

Indicate indentation with configurable bars.

This is a minor mode. If called interactively, toggle the Indent-Bars mode mode. If the prefix argument is positive, enable the mode, and if it is zero or negative, disable the mode.

If called from Lisp, toggle the mode if ARG is toggle. Enable the mode if ARG is nil, omitted, or is a positive number. Disable the mode if ARG is a negative number.

To check whether the minor mode is enabled in the current buffer, evaluate the variable indent-bars-mode(var)/indent-bars-mode(fun).

The mode's hook is called both when the mode is enabled and when it is disabled.

Key Bindings

This command is not in any keymaps.

;;;###autoload
(define-minor-mode indent-bars-mode
  "Indicate indentation with configurable bars."
  :global nil
  (if indent-bars-mode
      (if (and (daemonp) (not (frame-parameter nil 'client)))
	  (add-hook 'after-make-frame-functions #'indent-bars-setup-and-remove
		    nil t)
	(if indent-bars-defer-setup
	    (add-hook 'after-change-major-mode-hook #'indent-bars-setup nil t)
	  (indent-bars-setup)))
    (indent-bars-teardown)))
