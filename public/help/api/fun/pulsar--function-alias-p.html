Function: pulsar--function-alias-p

pulsar--function-alias-p is a natively compiled function defined in pulsar.el.

Signature

(pulsar--function-alias-p FUNC)

Documentation

Return nil if FUNC is not a function alias.

If FUNC is a function alias, return the function alias chain.

This is a copy of function-alias-p for backward-compatibility and will be deleted from Pulsar in future versions of Emacs.

(defun pulsar--function-alias-p (func &optional _noerror)
  "Return nil if FUNC is not a function alias.
If FUNC is a function alias, return the function alias chain.

This is a copy of `function-alias-p' for backward-compatibility and will
be deleted from Pulsar in future versions of Emacs."
  (declare (advertised-calling-convention (func) "30.1")
           (side-effect-free error-free))
  (let ((chain nil))
    (while (and (symbolp func)
                (setq func (symbol-function func))
                (symbolp func))
      (push func chain))
    (nreverse chain)))
