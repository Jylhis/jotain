Function: org-roam-db-map-citations

org-roam-db-map-citations is a natively compiled function defined in org-roam-db.el.

Signature

(org-roam-db-map-citations INFO FNS)

Documentation

Run FNS over all citations in the current buffer.

INFO is the org-element parsed buffer.

Source Code

;; Defined in /nix/store/qfyfp7k8wj4czdja2mlsqxrhlx7mvj76-emacs-packages-deps/share/emacs/site-lisp/elpa/org-roam-20260425.1623/org-roam-db.el
(defun org-roam-db-map-citations (info fns)
  "Run FNS over all citations in the current buffer.
INFO is the org-element parsed buffer."
  (org-element-map info 'citation-reference
    (lambda (cite)
      (dolist (fn fns)
        (funcall fn cite)))))
