Function: forge-browse-issue

forge-browse-issue is an interactive and natively compiled function defined in forge-commands.el.

Signature

(forge-browse-issue ISSUE)

Documentation

Read an ISSUE and visit it using a browser.

By default only offer open issues but with a prefix argument also offer closed issues.

Key Bindings

This command is not in any keymaps.

(defun forge-browse-issue (issue)
  "Read an ISSUE and visit it using a browser.
By default only offer open issues but with a prefix argument
also offer closed issues."
  (interactive (list (forge-read-issue "Browse issue")))
  (forge--browse-topic issue))
