Function: diff-hl--use-git-index-base-p

diff-hl--use-git-index-base-p is a natively compiled function defined in diff-hl.el.

(diff-hl--use-git-index-base-p BACKEND)

Documentation

Whether diff-hl should use the Git index as the reference base.

;; Defined in /nix/store/742jfhd6j9y7y1gqxy624dchx31gwmax-emacs-packages-deps/share/emacs/site-lisp/elpa/diff-hl-20260830.1400/diff-hl.el
(defun diff-hl--use-git-index-base-p (backend)
  "Whether diff-hl should use the Git index as the reference base."
  (and (eq backend 'Git)
       (not diff-hl-reference-revision)
       (not diff-hl-show-staged-changes)))
