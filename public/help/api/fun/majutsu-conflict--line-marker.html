Function: majutsu-conflict--line-marker

majutsu-conflict--line-marker is a natively compiled function defined in majutsu-conflict.el.

Signature

(majutsu-conflict--line-marker LINE EXPECTED-LEN)

Documentation

Return marker information for LINE with EXPECTED-LEN.

The return value is a cons cell of the form (KIND . LABEL), or nil.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-conflict.el
(defun majutsu-conflict--line-marker (line expected-len)
  "Return marker information for LINE with EXPECTED-LEN.
The return value is a cons cell of the form (KIND . LABEL), or nil."
  (when-let* ((parsed (majutsu-conflict--parse-marker-line line expected-len))
              (kind (majutsu-conflict--marker-kind (plist-get parsed :char))))
    (cons kind (plist-get parsed :label))))
