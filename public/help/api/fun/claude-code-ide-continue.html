Function: claude-code-ide-continue

claude-code-ide-continue is an interactive and natively compiled function defined in claude-code-ide.el.

Signature

(claude-code-ide-continue)

Documentation

Continue the most recent Claude Code conversation in the current directory.

This starts Claude with the -c (continue) flag to continue the most recent conversation in the current directory.

Key Bindings

This command is not in any keymaps.
