Function: gnuplot-delchar-or-maybe-eof

gnuplot-delchar-or-maybe-eof is an interactive and natively compiled function defined in gnuplot.el.

Signature

(gnuplot-delchar-or-maybe-eof ARG)

Documentation

Delete ARG characters forward, or (if at eob) send an EOF to subprocess.

This is very similar to comint-delchar-or-maybe-eof.

Key Bindings

gnuplot-comint-mode-map C-d

(defun gnuplot-delchar-or-maybe-eof (arg)
  "Delete ARG characters forward, or (if at eob) send an EOF to subprocess.
This is very similar to `comint-delchar-or-maybe-eof'."
  (interactive "p" gnuplot-comint-mode)
  (if (eobp)
      (gnuplot-kill-comint-buffer)
    (delete-char arg)))
