Function: claude-code-ide--set-window-width

claude-code-ide--set-window-width is an interactive and natively compiled function defined in claude-code-ide-transient.el.

Source Code

;; Defined in /nix/store/ca4a4maamih3h4ksbbhy6racb61djy6q-emacs-packages-deps/share/emacs/site-lisp/claude-code-ide-transient.el
(transient-define-suffix claude-code-ide--set-window-width (width)
  "Set window width."
  :description "Set window width"
  (interactive (list (read-number "Window width: " claude-code-ide-window-width)))
  (setq claude-code-ide-window-width width)
  (claude-code-ide-log "Window width set to %d" width))
