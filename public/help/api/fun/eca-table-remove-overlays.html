Function: eca-table-remove-overlays

eca-table-remove-overlays is a natively compiled function defined in eca-table.el.

Signature

(eca-table-remove-overlays BEG END)

Documentation

Remove all table-beautify overlays between BEG and END.

;; Overlay management -----------------------------------------------------

(defun eca-table-remove-overlays (beg end)
  "Remove all table-beautify overlays between BEG and END."
  (dolist (ov (overlays-in beg end))
    (when (overlay-get ov 'eca-table-overlay)
      (delete-overlay ov))))
