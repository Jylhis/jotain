Function: embark-rename-buffer

embark-rename-buffer is an interactive and natively compiled function defined in embark.el.

Signature

(embark-rename-buffer BUFFER NEWNAME &optional UNIQUE)

Documentation

Rename BUFFER to NEWNAME, optionally making it UNIQUE.

Interactively, you can set UNIQUE with a prefix argument. Returns the new name actually used.

Key Bindings

(defun embark-rename-buffer (buffer newname &optional unique)
  "Rename BUFFER to NEWNAME, optionally making it UNIQUE.
Interactively, you can set UNIQUE with a prefix argument.
Returns the new name actually used."
  (interactive "bBuffer: \nBRename %s to: \nP")
  (when-let* ((buf (get-buffer buffer)))
    (with-current-buffer buf
      (rename-buffer newname unique))))
