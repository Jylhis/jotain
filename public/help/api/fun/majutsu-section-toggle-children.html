Function: majutsu-section-toggle-children

majutsu-section-toggle-children is an interactive and natively compiled function defined in majutsu-section.el.

Signature

(majutsu-section-toggle-children SECTION)

Documentation

Toggle visibility of bodies of SECTION's direct children.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-section.el
(defun majutsu-section-toggle-children (section)
  "Toggle visibility of bodies of SECTION's direct children."
  (interactive (list (magit-current-section)))
  (let* ((children (oref section children))
         (show (seq-some (lambda (child) (oref child hidden)) children)))
    (dolist (child children)
      (oset child hidden show)))
  (majutsu-section-show section))
