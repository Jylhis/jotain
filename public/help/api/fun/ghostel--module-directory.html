Function: ghostel--module-directory

ghostel--module-directory is a natively compiled function defined in ghostel-module-install.el.

Signature

(ghostel--module-directory)

Documentation

Return the absolute directory where the native module lives.

Honours ghostel-module-directory when set, otherwise falls back to the shipped resource root.

Source Code

;; Defined in /nix/store/1jkgkg7y6y6hp0xia3dsmcl5zaj0bnhq-emacs-packages-deps/share/emacs/site-lisp/ghostel-module-install.el
(defun ghostel--module-directory ()
  "Return the absolute directory where the native module lives.
Honours `ghostel-module-directory' when set, otherwise falls back to
the shipped resource root."
  (when-let* ((dir (or ghostel-module-directory
                       (ghostel--resource-root))))
    (file-name-as-directory (expand-file-name dir))))
