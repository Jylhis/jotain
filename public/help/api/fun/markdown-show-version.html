Function: markdown-show-version

markdown-show-version is an interactive and natively compiled function defined in markdown-mode.el.

(defun markdown-show-version ()
  "Show the version number in the minibuffer."
  (interactive)
  (message "markdown-mode, version %s" markdown-mode-version))
