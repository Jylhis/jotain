Function: gitlab-ci-lint

gitlab-ci-lint is an interactive and natively compiled function defined in gitlab-ci-mode.el.

Signature

(gitlab-ci-lint)

Documentation

Lint the current buffer using the GitLab API.

Running this command will upload your buffer to the site specified in ‘gitlab-ci-url’. If your buffer contains sensitive data, this is not recommended. (Storing sensitive data in your CI configuration file is also not recommended.)

If your GitLab API requires a private token, set
‘gitlab-ci-api-token’.

Key Bindings

This command is not in any keymaps.
