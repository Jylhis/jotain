Function: mc/make-cursor-overlay-at-point

mc/make-cursor-overlay-at-point is a natively compiled function defined in multiple-cursors-core.el.

Signature

(mc/make-cursor-overlay-at-point)

Documentation

Create overlay to look like cursor.

Special case for end of line, because overlay over a newline highlights the entire width of the window.

(defun mc/make-cursor-overlay-at-point ()
  "Create overlay to look like cursor.
Special case for end of line, because overlay over a newline
highlights the entire width of the window."
  (if (eolp)
      (mc/make-cursor-overlay-at-eol (point))
    (mc/make-cursor-overlay-inline (point))))
