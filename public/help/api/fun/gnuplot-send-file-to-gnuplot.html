Function: gnuplot-send-file-to-gnuplot

gnuplot-send-file-to-gnuplot is an interactive and natively compiled function defined in gnuplot.el.

Signature

(gnuplot-send-file-to-gnuplot)

Documentation

Sends a selected file to the gnuplot program using the "load" command.

This sets gnuplot-recently-sent to file.

Key Bindings

gnuplot-mode-map C-c C-f

(defun gnuplot-send-file-to-gnuplot ()
  "Sends a selected file to the gnuplot program using the \"load\" command.
This sets `gnuplot-recently-sent' to `file'."
  (interactive)
  (let ((string (read-file-name "Name of file to send to gnuplot > " nil nil t)))
    (setq string (concat "load '" (expand-file-name string) "'\n"))
    (message "%S" string)
    (gnuplot--make-comint-buffer)       ; make sure a gnuplot buffer exists
    (gnuplot-send-string-to-gnuplot string 'file)))
