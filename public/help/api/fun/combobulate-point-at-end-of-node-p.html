Function: combobulate-point-at-end-of-node-p

combobulate-point-at-end-of-node-p is a natively compiled function defined in combobulate-navigation.el.

Signature

(combobulate-point-at-end-of-node-p NODE &optional ERROR-MARGIN)

Documentation

Returns non-nil if the end position of NODE is equal to point

If ERROR-MARGIN is given an integer an allowance of up to ERRROR-MARGIN in the end point position is used to determine if point is considered at the end of a node.

;; Defined in /nix/store/9y0jasyzsqjcbfkwqsgdyxcnskjnsypg-emacs-packages-deps/share/emacs/site-lisp/combobulate-navigation.el
(defun combobulate-point-at-end-of-node-p (node &optional error-margin)
  "Returns non-nil if the end position of NODE is equal to `point'

If ERROR-MARGIN is given an integer an allowance of up to
ERRROR-MARGIN in the end point position is used to determine if
`point' is considered at the end of a node."
  (or (= (combobulate-node-point node t) (point))
      (<= (abs (- (point) (combobulate-node-point node t)))
          (or error-margin 0))))
