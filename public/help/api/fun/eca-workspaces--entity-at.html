Function: eca-workspaces--entity-at

eca-workspaces--entity-at is a natively compiled function defined in eca-workspaces.el.

Signature

(eca-workspaces--entity-at POS)

Documentation

Return the (SESSION-ID . CHAT-ID) entity of the line at POS, or nil.

;; Defined in /nix/store/53rcj4vx02sm8hj89vj9g7rhbbilbzvy-emacs-packages-deps/share/emacs/site-lisp/elpa/eca-20260828.1422/eca-workspaces.el
(defun eca-workspaces--entity-at (pos)
  "Return the (SESSION-ID . CHAT-ID) entity of the line at POS, or nil."
  (when (and pos (>= pos (point-min)) (<= pos (point-max)))
    (save-excursion
      (goto-char pos)
      (let ((session-id (get-text-property (line-beginning-position)
                                           'eca-workspaces-session-id)))
        (when session-id
          (cons session-id
                (get-text-property (line-beginning-position)
                                   'eca-workspaces-chat-id)))))))
