Function: denote-get-identifier-at-point

denote-get-identifier-at-point is a function alias for denote-get-link-identifier-or-query-term-at-point, defined in denote.el.

This function is obsolete since 4.0.0; use denote-get-link-identifier-or-query-term-at-point instead.

Signature

(denote-get-identifier-at-point &optional POSITION)

Documentation

Return the Denote identifier or query term at point or optional POSITION.
