Function: magit-process-git

magit-process-git is a natively compiled function defined in magit-process.el.

Signature

(magit-process-git DESTINATION &rest ARGS)

Documentation

Call Git synchronously in a separate process, returning its exit code.

DESTINATION specifies how to handle the output, like for call-process, except that file handlers are supported. Enable Cygwin's "noglob" option during the call and ensure unix eol conversion.
