Function: doom-modeline-segment--bar

doom-modeline-segment--bar is a natively compiled function defined in doom-modeline-segments.el.

Signature

(doom-modeline-segment--bar)

Documentation

The bar regulates the height of the doom-modeline in GUI.

;; Defined in /nix/store/mxkjlhf33q1xxjiii3w5v8nn7avms0p9-emacs-packages-deps/share/emacs/site-lisp/elpa/doom-modeline-20260828.1146/doom-modeline-segments.el
(doom-modeline-def-segment bar
  "The bar regulates the height of the `doom-modeline' in GUI."
  (when (display-graphic-p)
    (concat
     (if doom-modeline-hud
         (doom-modeline--hud)
       (doom-modeline--bar))
     (doom-modeline-spc))))
