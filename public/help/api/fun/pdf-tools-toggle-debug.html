Function: pdf-tools-toggle-debug

pdf-tools-toggle-debug is an interactive and natively compiled function defined in pdf-tools.el.

Signature

(pdf-tools-toggle-debug)

Documentation

Turn debugging on/off for pdf-tools.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/wm0vc3dfi6c7pwjhcfpsnhyg4hd0b5yc-emacs-packages-deps/share/emacs/site-lisp/elpa/pdf-tools-20260102.1101/pdf-tools.el
(defun pdf-tools-toggle-debug ()
  "Turn debugging on/off for pdf-tools."
  (interactive)
  (setq pdf-tools-debug (not pdf-tools-debug))
  (when (called-interactively-p 'any)
    (message "Toggled debugging %s" (if pdf-tools-debug "on" "off"))))
