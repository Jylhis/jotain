Function: treesit-fold--last-eol

treesit-fold--last-eol is a natively compiled function defined in treesit-fold-util.el.

(treesit-fold--last-eol POS)

Documentation

Go to POS then find previous line break, and return its position.

(defun treesit-fold--last-eol (pos)
  "Go to POS then find previous line break, and return its position."
  (save-excursion
    (goto-char pos)
    (max 1 (1- (line-beginning-position)))))
