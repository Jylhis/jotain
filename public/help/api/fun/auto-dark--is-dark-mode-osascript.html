Function: auto-dark--is-dark-mode-osascript

auto-dark--is-dark-mode-osascript is a natively compiled function defined in auto-dark.el.

Signature

(auto-dark--is-dark-mode-osascript)

Documentation

Invoke applescript using Emacs using external shell command; this is less efficient, but works for non-GUI Emacs.

;; Defined in /nix/store/bsy6s0b3kb4pmxsgxn385p8xfkhwnj6b-emacs-packages-deps/share/emacs/site-lisp/elpa/auto-dark-20260313.2356/auto-dark.el
(defun auto-dark--is-dark-mode-osascript ()
  "Invoke applescript using Emacs using external shell command;
this is less efficient, but works for non-GUI Emacs."
  (string-equal "true"
                (string-trim (shell-command-to-string
                              "osascript -e 'tell application \"System Events\" to tell appearance preferences to return dark mode'"))))
