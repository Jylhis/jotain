Function: auto-dark--themes-for-mode

auto-dark--themes-for-mode is a natively compiled function defined in auto-dark.el.

Signature

(auto-dark--themes-for-mode MODE)

Documentation

Return the set of themes to be used in MODE.

MODE should be light or dark. If none of the Auto-Dark theme variables are set, this returns nil, which means that custom-enabled-themes will be used as the theme list.

(defun auto-dark--themes-for-mode (mode)
  "Return the set of themes to be used in MODE.
MODE should be light or dark. If none of the Auto-Dark theme variables are set,
this returns nil, which means that `custom-enabled-themes' will be used as the
theme list."
  (pcase mode
    ('dark (car auto-dark-themes))
    ('light (cadr auto-dark-themes))))
