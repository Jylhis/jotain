Function: majutsu-template--conditional-node-p

majutsu-template--conditional-node-p is a natively compiled function defined in majutsu-template.el.

(majutsu-template--conditional-node-p NODE)

Documentation

Return non-nil if NODE represents an upstream-style conditional Any value.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-template.el
(defun majutsu-template--conditional-node-p (node)
  "Return non-nil if NODE represents an upstream-style conditional Any value."
  (and (majutsu-template-node-p node)
       (eq (majutsu-template-node-kind node) :call)
       (equal (majutsu-template-node-value node) "if")
       (plist-get (majutsu-template-node-props node) :conditional)))
