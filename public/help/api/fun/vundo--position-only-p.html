Function: vundo--position-only-p

vundo--position-only-p is a natively compiled function defined in vundo.el.

Signature

(vundo--position-only-p UNDO-LIST)

Documentation

Check if the records at the start of UNDO-LIST are position-only.

Position-only means all records until to the next undo boundary are position records. Position record is just an integer (see buffer-undo-list). Assumes the first element of UNDO-LIST is not nil.

(defun vundo--position-only-p (undo-list)
  "Check if the records at the start of UNDO-LIST are position-only.
Position-only means all records until to the next undo
boundary are position records. Position record is just an
integer (see `buffer-undo-list'). Assumes the first element
of UNDO-LIST is not nil."
  (let ((pos-only t))
    (while (car undo-list)
      (when (not (integerp (pop undo-list)))
        (setq pos-only nil)
        (setq undo-list nil)))
    pos-only))
