Function: majutsu-jj-lines

majutsu-jj-lines is a natively compiled function defined in majutsu-jj.el.

Signature

(majutsu-jj-lines &rest ARGS)

Documentation

Run jj with ARGS and return output as a list of lines.

Color output is disabled so that return values are plain text. Empty lines are omitted from the result. If the command fails, return nil or partial output depending on what was produced.

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-jj.el
(defun majutsu-jj-lines (&rest args)
  "Run jj with ARGS and return output as a list of lines.

Color output is disabled so that return values are plain text.
Empty lines are omitted from the result.  If the command fails,
return nil or partial output depending on what was produced."
  (majutsu--with-no-color
    (with-temp-buffer
      (apply #'majutsu-jj-insert args)
      (split-string (buffer-string) "\n" t))))
