Function: marginalia-annotate-imenu

marginalia-annotate-imenu is a natively compiled function defined in marginalia.el.

(marginalia-annotate-imenu CAND)

Documentation

Annotate imenu CAND with its documentation string.

;; Defined in /nix/store/ckv423l2dy50bfwsy6xzdz7l2a9ah46b-emacs-packages-deps/share/emacs/site-lisp/elpa/marginalia-20260831.1055/marginalia.el
(defun marginalia-annotate-imenu (cand)
  "Annotate imenu CAND with its documentation string."
  (when (derived-mode-p 'emacs-lisp-mode)
    ;; Strip until the last whitespace in order to support flat imenu
    (marginalia-annotate-symbol (replace-regexp-in-string "\\`.* " "" cand))))
