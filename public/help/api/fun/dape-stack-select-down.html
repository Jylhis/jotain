Function: dape-stack-select-down

dape-stack-select-down is an interactive and natively compiled function defined in dape.el.

Signature

(dape-stack-select-down CONN N)

Documentation

Select N (numeric arg) stacks below current selected stack.

Use CONN to specify adapter connection.

Key Bindings

ctl-x-map C-a > dape-global-map > global-map C-x C-a > help-quick-use-map C-x C-a >

(defun dape-stack-select-down (conn n)
  "Select N (numeric arg) stacks below current selected stack.
Use CONN to specify adapter connection."
  (interactive (list (dape--live-connection 'stopped) 1))
  (dape-stack-select-up conn (* n -1)))
