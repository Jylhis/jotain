Function: indent-bars-reset-styles

indent-bars-reset-styles is an interactive and natively compiled function defined in indent-bars.el.

Signature

(indent-bars-reset-styles &rest R)

Documentation

Reset all styles' colors and faces.

Useful for calling after theme changes.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/kmdsnipwffgk5c0fs4785bhqa9fl17c5-emacs-packages-deps/share/emacs/site-lisp/elpa/indent-bars-1.0.1/indent-bars.el
(defun indent-bars-reset-styles (&rest _r)
  "Reset all styles' colors and faces.
Useful for calling after theme changes."
  (interactive)
  (unless (equal (terminal-name) "initial_terminal")
    (mapc #'indent-bars--initialize-style indent-bars--styles)))
