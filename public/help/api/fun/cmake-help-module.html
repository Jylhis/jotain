Function: cmake-help-module

cmake-help-module is an interactive and natively compiled function defined in cmake-mode.el.

Signature

(cmake-help-module)

Documentation

Prints out the help message for the module the cursor is on.

Key Bindings

This command is not in any keymaps.

(defun cmake-help-module ()
  "Prints out the help message for the module the cursor is on."
  (interactive)
  (cmake-command-run-help "--help-module" (cmake-help-type "module") "*CMake Help*"))
