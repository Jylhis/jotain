Function: pulsar-pulse-with-face

pulsar-pulse-with-face is a function alias for pulsar-define-pulse-with-face, defined in pulsar.el.

This macro is obsolete since 1.0.0; use pulsar-define-pulse-with-face instead.

Signature

(pulsar-pulse-with-face FACE)

Documentation

Produce function to pulse the current line with FACE.

If FACE starts with the pulsar- prefix, remove it and keep only the remaining text. The assumption is that something like pulsar-red will be convered to red, thus deriving a function named pulsar-pulse-line-red. Any other FACE is taken as-is.

Aliases

pulsar-define-pulse-with-face
