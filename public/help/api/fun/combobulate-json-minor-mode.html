Function: combobulate-json-minor-mode

combobulate-json-minor-mode is a natively compiled function defined in combobulate-json.el.

Signature

(combobulate-json-minor-mode &optional ARG)

Documentation

Combobulate minor mode for the json tree-sitter language.

This is a minor mode. If called interactively, toggle the Combobulate-Json minor mode mode. If the prefix argument is positive, enable the mode, and if it is zero or negative, disable the mode.

If called from Lisp, toggle the mode if ARG is toggle. Enable the mode if ARG is nil, omitted, or is a positive number. Disable the mode if ARG is a negative number.

To check whether the minor mode is enabled in the current buffer, evaluate the variable combobulate-json-minor-mode(var)/combobulate-json-minor-mode(fun).

The mode's hook is called both when the mode is enabled and when it is disabled.
