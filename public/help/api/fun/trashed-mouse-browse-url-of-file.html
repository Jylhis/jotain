Function: trashed-mouse-browse-url-of-file

trashed-mouse-browse-url-of-file is an interactive and natively compiled function defined in trashed.el.

Signature

(trashed-mouse-browse-url-of-file EVENT)

Documentation

Ask a browser to display the file you click on.

EVENT is the mouse click event.

Key Bindings

trashed-mode-map <double-mouse-1>

(defun trashed-mouse-browse-url-of-file (event)
  "Ask a browser to display the file you click on.
EVENT is the mouse click event."
  (interactive "e")
  (with-current-buffer (window-buffer (posn-window (event-end event)))
    (goto-char (posn-point (event-end event)))
    (trashed-open-file 'trashed-browse-url-of-file-internal)))
