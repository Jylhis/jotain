Function: clipetty--tty

clipetty--tty is a natively compiled function defined in clipetty.el.

Signature

(clipetty--tty SSH-TTY TMUX)

Documentation

Return which TTY we should send our OSC payload to.

Both the SSH-TTY and TMUX arguments should come from the selected frame's environment.

(defun clipetty--tty (ssh-tty tmux)
  "Return which TTY we should send our OSC payload to.
Both the SSH-TTY and TMUX arguments should come from the selected
frame's environment."
  (if (not ssh-tty)
      (terminal-name)
    (if tmux
        (let ((tmux-ssh-tty (clipetty--get-tmux-ssh-tty)))
          (if tmux-ssh-tty tmux-ssh-tty ssh-tty))
      ssh-tty)))
