Function: super-save-command

super-save-command is a natively compiled function defined in super-save.el.

Signature

(super-save-command)

Documentation

Save the relevant buffers if needed.

When super-save-all-buffers is non-nil, save all modified buffers, else, save only the current buffer.

Binds super-save-in-progress to t so that save hook functions can detect automatic saves and skip expensive processing.

(defun super-save-command ()
  "Save the relevant buffers if needed.

When `super-save-all-buffers' is non-nil, save all modified buffers, else, save
only the current buffer.

Binds `super-save-in-progress' to t so that save hook functions can
detect automatic saves and skip expensive processing."
  (let ((super-save-in-progress t))
    (mapc #'super-save-buffer (if super-save-all-buffers (buffer-list) (list (current-buffer))))))
