Function: ghostel--scroll-intercept-down

ghostel--scroll-intercept-down is an interactive and natively compiled function defined in ghostel.el.

Signature

(ghostel--scroll-intercept-down EVENT)

Documentation

Intercept wheel-down EVENT for terminal mouse tracking.

If the terminal is tracking mouse events, forward as button 5. Otherwise, re-dispatch EVENT through the normal event loop so the user's scroll package handles it.

(defun ghostel--scroll-intercept-down (event)
  "Intercept wheel-down EVENT for terminal mouse tracking.
If the terminal is tracking mouse events, forward as button 5.
Otherwise, re-dispatch EVENT through the normal event loop so the
user's scroll package handles it."
  (interactive "e")
  (with-current-buffer (window-buffer (posn-window (event-start event)))
    (unless (ghostel--forward-scroll-event event 5)
      (ghostel--redispatch-scroll-event event))))
