Function: ghostel--link-uri-at-point

ghostel--link-uri-at-point is a natively compiled function defined in ghostel-links.el.

Signature

(ghostel--link-uri-at-point)

Documentation

Return the URI of the ghostel link at point, or nil.

The keymap check tells ghostel's own links from a foreign help-echo some other source put in the buffer.

Source Code

;; Defined in /nix/store/1jkgkg7y6y6hp0xia3dsmcl5zaj0bnhq-emacs-packages-deps/share/emacs/site-lisp/ghostel-links.el
(defun ghostel--link-uri-at-point ()
  "Return the URI of the ghostel link at point, or nil.
The `keymap' check tells ghostel's own links from a foreign
`help-echo' some other source put in the buffer."
  (and (eq (get-text-property (point) 'keymap) ghostel-link-map)
       (ghostel--uri-at-pos (point))))
