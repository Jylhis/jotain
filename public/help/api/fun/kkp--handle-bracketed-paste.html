Function: kkp--handle-bracketed-paste

kkp--handle-bracketed-paste is a natively compiled function defined in kkp.el.

Signature

(kkp--handle-bracketed-paste TERMINAL-INPUT)

Documentation

Handle bracketed paste mode sequences.

TERMINAL-INPUT is a list of characters representing the terminal input sequence. This function checks if TERMINAL-INPUT matches the bracketed paste mode sequence ('200~') and calls `xterm-translate-bracketed-paste` if it does.

(defun kkp--handle-bracketed-paste (terminal-input)
  "Handle bracketed paste mode sequences.
TERMINAL-INPUT is a list of characters representing the terminal input
sequence. This function checks if TERMINAL-INPUT matches the bracketed
paste mode sequence ('200~') and calls `xterm-translate-bracketed-paste`
if it does."
  (when (equal (concat terminal-input) "200~")
    (xterm-translate-bracketed-paste nil)))
