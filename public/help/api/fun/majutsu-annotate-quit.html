Function: majutsu-annotate-quit

majutsu-annotate-quit is an interactive and natively compiled function defined in majutsu-annotate.el.

Signature

(majutsu-annotate-quit)

Documentation

Turn off Majutsu-Annotate mode.

If the buffer was created during a recursive blame, then also kill the buffer.

Key Bindings

majutsu-annotate-mode-map C-c C-q majutsu-annotate-read-only-mode-map q

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-annotate.el
(defun majutsu-annotate-quit ()
  "Turn off Majutsu-Annotate mode.
If the buffer was created during a recursive blame,
then also kill the buffer."
  (interactive)
  (majutsu-annotate-mode -1)
  (when majutsu-annotate-recursive-p
    (kill-buffer)))
