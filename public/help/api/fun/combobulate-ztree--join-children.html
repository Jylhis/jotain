Function: combobulate-ztree--join-children

combobulate-ztree--join-children is a natively compiled function defined in combobulate-ztree.el.

Signature

(combobulate-ztree--join-children LEFT-CHILDREN RIGHT-CHILDREN)

Documentation

Return a joining of LEFT-CHILDREN and RIGHT-CHILDREN.

Reverses LEFT-CHILDREN so that they are correctly ordered as in the tree.

;; Defined in /nix/store/9y0jasyzsqjcbfkwqsgdyxcnskjnsypg-emacs-packages-deps/share/emacs/site-lisp/combobulate-ztree.el
(defun combobulate-ztree--join-children (left-children right-children)
  "Return a joining of LEFT-CHILDREN and RIGHT-CHILDREN.
Reverses LEFT-CHILDREN so that they are correctly ordered as in
the tree."
  (append (reverse left-children) right-children))
