Function: majutsu-diff--line-matching-p

majutsu-diff--line-matching-p is a natively compiled function defined in majutsu-diff.el.

Signature

(majutsu-diff--line-matching-p REGEXP LINES)

Documentation

Return non-nil if any string in LINES matches REGEXP.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-diff.el
(defun majutsu-diff--line-matching-p (regexp lines)
  "Return non-nil if any string in LINES matches REGEXP."
  (seq-some (lambda (line) (and line (string-match-p regexp line))) lines))
