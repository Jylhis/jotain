Function: auth-source-1password--1password-construct-entry-path

auth-source-1password--1password-construct-entry-path is a natively compiled function defined in auth-source-1password.el.

Signature

(auth-source-1password--1password-construct-entry-path BACKEND TYPE HOST USER PORT)

Documentation

Construct the full entry-path for the 1password entry for HOST and USER.

Usually starting with the auth-source-1password-vault, followed by host and user.

(defun auth-source-1password--1password-construct-entry-path (_backend _type host user _port)
  "Construct the full entry-path for the 1password entry for HOST and USER.
Usually starting with the `auth-source-1password-vault', followed
by host and user."
  (mapconcat #'identity (list auth-source-1password-vault host user) "/"))
