Function: pdf-cache--data-get

pdf-cache--data-get is a natively compiled function defined in pdf-cache.el.

Signature

(pdf-cache--data-get KEY &optional PAGE)

Documentation

Get value of KEY in the cache of PAGE.

Returns a cons (HIT . VALUE), where HIT is non-nil if KEY was stored previously for PAGE and VALUE its value. Otherwise HIT is nil and VALUE undefined.

(defun pdf-cache--data-get (key &optional page)
  "Get value of KEY in the cache of PAGE.

Returns a cons \(HIT . VALUE\), where HIT is non-nil if KEY was
stored previously for PAGE and VALUE its value.  Otherwise HIT
is nil and VALUE undefined."
  (pdf-cache--initialize)
  (let ((elt (assq key (gethash page pdf-cache--data))))
    (if elt
        (cons t (cdr elt))
      (cons nil nil))))
