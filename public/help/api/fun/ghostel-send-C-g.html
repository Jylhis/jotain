Function: ghostel-send-C-g

ghostel-send-C-g is an interactive and natively compiled function defined in ghostel.el.

Signature

(ghostel-send-C-g)

Documentation

Send \C-g to the terminal.

Clears quit-flag which Emacs sets when \C-g is pressed with inhibit-quit non-nil, and deactivates the mark so the region overlay clears the way \keyboard-quit would in other buffers.

Key Bindings

ghostel-char-mode-map C-g ghostel-mode-map C-g

(defun ghostel-send-C-g ()
  "Send \\`C-g' to the terminal.
Clears `quit-flag' which Emacs sets when \\`C-g' is pressed with
`inhibit-quit' non-nil, and deactivates the mark so the region
overlay clears the way \\`keyboard-quit' would in other buffers."
  (interactive)
  (setq quit-flag nil)
  (deactivate-mark)
  (ghostel--send-encoded "g" "ctrl"))
