Function: tuareg-eval-region

tuareg-eval-region is an interactive and natively compiled function defined in tuareg.el.

(defun tuareg-eval-region (start end)
  "Eval the current region in the OCaml REPL."
  (interactive "r")
  (tuareg-interactive--send-region start end))
