Function: majutsu-metaedit-execute

majutsu-metaedit-execute is an interactive and natively compiled function defined in majutsu-metaedit.el.

Signature

(majutsu-metaedit-execute ARGS)

Documentation

Execute jj metaedit with ARGS from the transient.

Key Bindings

This command is not in any keymaps.

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-metaedit.el
;;;###autoload
(defun majutsu-metaedit-execute (args)
  "Execute jj metaedit with ARGS from the transient."
  (interactive (list (majutsu-metaedit-arguments)))
  (let ((exit (apply #'majutsu-run-jj "metaedit" args)))
    (when (zerop exit)
      (message "Metaedit completed"))))
