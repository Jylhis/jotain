Function: markdown-next-visible-heading

markdown-next-visible-heading is an interactive and natively compiled function defined in markdown-mode.el.

Signature

(markdown-next-visible-heading ARG)

Documentation

Move to the next visible heading line of any level.

With argument, repeats or can move backward if negative. ARG is passed to outline-next-visible-heading.

Key Bindings

This command is not in any keymaps.

(defun markdown-next-visible-heading (arg)
  "Move to the next visible heading line of any level.
With argument, repeats or can move backward if negative. ARG is
passed to `outline-next-visible-heading'."
  (interactive "p")
  (markdown-move-heading-common #'outline-next-visible-heading arg 'adjust))
