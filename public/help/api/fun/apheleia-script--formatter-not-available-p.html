Function: apheleia-script--formatter-not-available-p

apheleia-script--formatter-not-available-p is a natively compiled function defined in apheleia-formatters.el.

Signature

(apheleia-script--formatter-not-available-p CTX STDERR)

Documentation

Check if script reports that no formatter has been found.

CTX is a formatter process context. STDERR is the stderr output of process.

Source Code

;; Defined in /nix/store/dbykkl13khzh84lv9vw1bf1vijzg30fr-emacs-packages-deps/share/emacs/site-lisp/elpa/apheleia-20260817.2331/apheleia-formatters.el
(defun apheleia-script--formatter-not-available-p (ctx stderr)
  "Check if script reports that no formatter has been found.
CTX is a formatter process context.
STDERR is the stderr output of process."
  (and (eq (apheleia-formatter--exit-status ctx)
           (plist-get apheleia-script--formatter-not-available :exit-code))
       (string= stderr
                (concat
                 (apheleia-formatter--arg1 ctx) ":"
                 (plist-get apheleia-script--formatter-not-available
                            :stderr)))))
