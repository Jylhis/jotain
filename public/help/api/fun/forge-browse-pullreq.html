Function: forge-browse-pullreq

forge-browse-pullreq is an interactive and natively compiled function defined in forge-commands.el.

Signature

(forge-browse-pullreq PULL-REQUEST)

Documentation

Read a PULL-REQUEST and visit it using a browser.

By default only offer open pull-requests but with a prefix argument also offer closed pull-requests.

Key Bindings

This command is not in any keymaps.

(defun forge-browse-pullreq (pull-request)
  "Read a PULL-REQUEST and visit it using a browser.
By default only offer open pull-requests but with a prefix
argument also offer closed pull-requests."
  (interactive (list (forge-read-pullreq "Browse pull-request")))
  (forge--browse-topic pull-request))
