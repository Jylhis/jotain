Function: vundo-backward

vundo-backward is an interactive and natively compiled function defined in vundo.el.

Signature

(vundo-backward ARG)

Documentation

Move back ARG nodes in the undo tree.

If ARG < 0, move forward.

Key Bindings

vundo-mode-map <left> vundo-mode-map b

Source Code

;; Defined in /nix/store/7c2696v2qdrdv2vf2im8alazibi7qq0z-emacs-packages-deps/share/emacs/site-lisp/elpa/vundo-2.4.0/vundo.el
(defun vundo-backward (arg)
  "Move back ARG nodes in the undo tree.
If ARG < 0, move forward."
  (interactive "p")
  (vundo-forward (- arg)))
