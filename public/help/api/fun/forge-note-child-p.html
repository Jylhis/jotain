Function: forge-note-child-p

forge-note-child-p is a function alias for forge-note--eieio-childp, defined in forge-post.el.

This function is obsolete since 25.1; use (cl-typep ... 'forge-note) instead

Signature

(forge-note-child-p OBJ)

Documentation

Return non-nil if OBJ is an object of type forge-note(var)/forge-note(fun) or a subclass.

Aliases

forge-note--eieio-childp
