Function: avy--make-backgrounds

avy--make-backgrounds is a natively compiled function defined in avy.el.

Signature

(avy--make-backgrounds WND-LIST)

Documentation

Create a dim background overlay for each window on WND-LIST.

(defun avy--make-backgrounds (wnd-list)
  "Create a dim background overlay for each window on WND-LIST."
  (when avy-background
    (setq avy--overlays-back
          (mapcar (lambda (w)
                    (let ((ol (make-overlay
                               (window-start w)
                               (window-end w)
                               (window-buffer w))))
                      (overlay-put ol 'face 'avy-background-face)
                      (overlay-put ol 'window w)
                      ol))
                  wnd-list))))
