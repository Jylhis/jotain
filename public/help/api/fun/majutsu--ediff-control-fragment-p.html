Function: majutsu--ediff-control-fragment-p

majutsu--ediff-control-fragment-p is a natively compiled function defined in majutsu-process.el.

Signature

(majutsu--ediff-control-fragment-p FRAGMENT)

Documentation

Return non-nil when FRAGMENT looks like a partial Ediff packet.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-process.el
(defun majutsu--ediff-control-fragment-p (fragment)
  "Return non-nil when FRAGMENT looks like a partial Ediff packet."
  (and (not (string-empty-p fragment))
       (or (string-prefix-p "MAJUTSU-EDIFF:" fragment)
           (string-prefix-p fragment "MAJUTSU-EDIFF:"))))
