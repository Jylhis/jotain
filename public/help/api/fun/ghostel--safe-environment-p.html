Function: ghostel--safe-environment-p

ghostel--safe-environment-p is a natively compiled function defined in ghostel.el.

Signature

(ghostel--safe-environment-p VALUE)

Documentation

Return non-nil if VALUE is a valid ghostel-environment list.

Used to gate dir-locals application — only a list of strings is accepted without prompting.

Source Code

;; Defined in /nix/store/1jkgkg7y6y6hp0xia3dsmcl5zaj0bnhq-emacs-packages-deps/share/emacs/site-lisp/ghostel.el
(defun ghostel--safe-environment-p (value)
  "Return non-nil if VALUE is a valid `ghostel-environment' list.
Used to gate dir-locals application — only a list of strings is
accepted without prompting."
  (and (listp value)
       (seq-every-p #'stringp value)))
