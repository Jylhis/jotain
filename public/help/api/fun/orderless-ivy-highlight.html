Function: orderless-ivy-highlight

orderless-ivy-highlight is a natively compiled function defined in orderless.el.

Signature

(orderless-ivy-highlight STR)

Documentation

Highlight a match in STR of each regexp in ivy-regex.

This function is for integration of orderless with ivy.

Source Code

;; Defined in /nix/store/w4nd3vqafwr5yv9m3q76kmi7a9pr8jas-emacs-packages-deps/share/emacs/site-lisp/elpa/orderless-20260830.1156/orderless.el
(defun orderless-ivy-highlight (str)
  "Highlight a match in STR of each regexp in `ivy-regex'.
This function is for integration of orderless with ivy."
  (orderless--highlight (mapcar #'car ivy-regex) t str) str)
