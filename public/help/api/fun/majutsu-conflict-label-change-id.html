Function: majutsu-conflict-label-change-id

majutsu-conflict-label-change-id is a natively compiled function defined in majutsu-conflict.el.

Signature

(majutsu-conflict-label-change-id LABEL)

Documentation

Return the change-id from LABEL, or nil when unavailable.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-conflict.el
(defun majutsu-conflict-label-change-id (label)
  "Return the change-id from LABEL, or nil when unavailable."
  (plist-get (majutsu-conflict-parse-label label) :change-id))
