Function: gnuplot-send-line-and-forward

gnuplot-send-line-and-forward is an interactive and natively compiled function defined in gnuplot.el.

Signature

(gnuplot-send-line-and-forward &optional NUM)

Documentation

Call gnuplot-send-line-to-gnuplot and move forward 1 line.

You can use a numeric prefix to send more than one line. Blank lines and lines with only comments are skipped when moving forward. NUM is optional arg.

Key Bindings

gnuplot-mode-map C-c C-v

;; I chose a very easy to type but slightly non-mnemonic key-binding
;; for this (C-c C-v).  It seems like the kind of thing one would want
;; to do repeatedly without incurring RSI. 8^)
(defun gnuplot-send-line-and-forward (&optional num)
  "Call `gnuplot-send-line-to-gnuplot' and move forward 1 line.
You can use a numeric prefix to send more than one line.  Blank lines and
lines with only comments are skipped when moving forward.
NUM is optional arg."
  (interactive "p" gnuplot-mode)
  (let (end)
    (while (> num 0)
      (setq end (gnuplot-send-line-to-gnuplot))
      (goto-char end)
      (backward-char 1)
      (gnuplot-forward-script-line 1)
      (setq num (1- num)))))
