Function: global-sops-mode

global-sops-mode is an interactive and natively compiled function defined in sops.el.

Signature

(global-sops-mode &optional ARG)

Documentation

Toggle Sops mode in many buffers.

Specifically, Sops mode is enabled in all buffers where (lambda nil nil) would do it.

With prefix ARG, enable Global Sops mode if ARG is positive; otherwise, disable it.

If called from Lisp, toggle the mode if ARG is toggle. Enable the mode if ARG is nil, omitted, or is a positive number. Disable the mode if ARG is a negative number.

See sops-mode(var)/sops-mode(fun) for more information on Sops mode.

Key Bindings

This command is not in any keymaps.

(define-globalized-minor-mode global-sops-mode
  sops-mode
  (lambda () nil)  ; sops-mode itself is enabled inside sops--find-file-hook, not here
  :group 'sops
  (if global-sops-mode
      (progn
        (sops--check-v0.1.X-config)
        (add-hook 'find-file-hook #'sops--find-file-hook))
    (remove-hook 'find-file-hook #'sops--find-file-hook)))
