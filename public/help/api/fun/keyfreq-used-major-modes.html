Function: keyfreq-used-major-modes

keyfreq-used-major-modes is a natively compiled function defined in keyfreq.el.

Signature

(keyfreq-used-major-modes TABLE)

Documentation

Return a list with the used major modes (major modes contained in the TABLE).

Source Code

;; Defined in /nix/store/nw5qmniwc6r7bs6r68drlfgkhdppv4z5-emacs-packages-deps/share/emacs/site-lisp/elpa/keyfreq-20231107.106/keyfreq.el
(defun keyfreq-used-major-modes (table)
  "Return a list with the used major modes (major modes
contained in the TABLE)."
  (let ((list))
    (maphash (lambda (k v)
	       (add-to-list 'list (car k)))
	     table)
    list))
