Function: org-appear--after-change

org-appear--after-change is a natively compiled function defined in org-appear.el.

Signature

(org-appear--after-change &rest ARGS)

Documentation

This function is executed by after-change-functions in org-appear-mode(var)/org-appear-mode(fun).

It signals that elements in the current buffer must be toggled.
