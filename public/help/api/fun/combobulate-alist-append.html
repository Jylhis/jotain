Function: combobulate-alist-append

combobulate-alist-append is a macro defined in combobulate-misc.el.

Signature

(combobulate-alist-append KEY VALUE ALIST)

Documentation

Append to KEY (or create) KEY with VALUE in ALIST.

Source Code

;; Defined in /nix/store/9y0jasyzsqjcbfkwqsgdyxcnskjnsypg-emacs-packages-deps/share/emacs/site-lisp/combobulate-misc.el
(defmacro combobulate-alist-append (key value alist)
  "Append to KEY (or create) KEY with VALUE in ALIST."
  `(map-put ,alist ,key (cons ,value (map-elt ,alist ,key))))
