Function: eca--with-backtrace

eca--with-backtrace is a macro defined in eca.el.

Signature

(eca--with-backtrace VAR &rest BODY)

Documentation

Execute BODY, capturing backtrace into VAR on error.

On Emacs 30+ uses handler-bind to capture a pre-unwind backtrace. On older Emacs, runs BODY without capture.

(defmacro eca--with-backtrace (var &rest body)
  "Execute BODY, capturing backtrace into VAR on error.
On Emacs 30+ uses `handler-bind' to capture a pre-unwind
backtrace.  On older Emacs, runs BODY without capture."
  (declare (indent 1))
  (if (fboundp 'handler-bind)
      `(handler-bind
           ((error (lambda (_err)
                     (setq ,var
                           (backtrace-get-frames
                            'handler-bind)))))
         ,@body)
    `(progn ,@body)))
