Function: casual-lib-browse-backward-paragraph

casual-lib-browse-backward-paragraph is an interactive and natively compiled function defined in casual-lib.el.

Signature

(casual-lib-browse-backward-paragraph)

Documentation

Move point backward paragraph such that the first line is highlighted.

This function is intended to be used with hl-line-mode.

Key Bindings

This command is not in any keymaps.

(defun casual-lib-browse-backward-paragraph ()
  "Move point backward paragraph such that the first line is highlighted.
\nThis function is intended to be used with `hl-line-mode'."
  (interactive)
  (backward-paragraph 2)
  (forward-line))
