Function: gptel--request-data

gptel--request-data is a byte-compiled function defined in gptel-request.el.

Signature

(gptel--request-data BACKEND PROMPTS)

Documentation

Generate a plist of all data for an LLM query.

BACKEND is the LLM backend in use.

PROMPTS is the plist of previous user queries and LLM responses.
