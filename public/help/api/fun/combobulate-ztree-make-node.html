Function: combobulate-ztree-make-node

combobulate-ztree-make-node is a natively compiled function defined in combobulate-ztree.el.

Signature

(combobulate-ztree-make-node LOC NODE CHILDREN)

Documentation

Return a new branch node.

Given an existing LOC, NODE and new CHILDREN, creates a new LOC with them. The LOC is only used to supply the constructor.

;; Defined in /nix/store/9y0jasyzsqjcbfkwqsgdyxcnskjnsypg-emacs-packages-deps/share/emacs/site-lisp/combobulate-ztree.el
(defun combobulate-ztree-make-node (loc node children)
  "Return a new branch node.
Given an existing LOC, NODE and new CHILDREN, creates a new LOC
with them.  The LOC is only used to supply the constructor."
  (funcall (combobulate-ztree--meta loc ':make-node) node children))
