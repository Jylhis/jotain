Function: wgrep-remove-change

wgrep-remove-change is an interactive and natively compiled function defined in wgrep.el.

(wgrep-remove-change BEG END)

(defun wgrep-remove-change (beg end)
  "Remove changes in the region between BEG and END."
  (interactive "r")
  (wgrep-cleanup-overlays beg end)
