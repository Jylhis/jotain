Function: denote-menu-bar-mode

denote-menu-bar-mode is an interactive and natively compiled function defined in denote.el.

Signature

(denote-menu-bar-mode &optional ARG)

Documentation

Show Denote menu bar.

This is a global minor mode. If called interactively, toggle the Denote-Menu-Bar mode mode. If the prefix argument is positive, enable the mode, and if it is zero or negative, disable the mode.

If called from Lisp, toggle the mode if ARG is toggle. Enable the mode if ARG is nil, omitted, or is a positive number. Disable the mode if ARG is a negative number.

To check whether the minor mode is enabled in the current buffer, evaluate (default-value \=denote-menu-bar-mode)'.

The mode's hook is called both when the mode is enabled and when it is disabled.

Key Bindings

This command is not in any keymaps.

;;;###autoload
(define-minor-mode denote-menu-bar-mode "Show Denote menu bar."
  :global t
  :init-value t
  (if denote-menu-bar-mode
      (denote--menu-bar-enable)
    (define-key global-map [menu-bar denote] nil)))
