Function: logview-switch-to-view-by-index

logview-switch-to-view-by-index is an interactive and natively compiled function defined in logview.el.

Signature

(logview-switch-to-view-by-index)

Documentation

Switch to a view by its quick access index.

This command must be bound to a key with a numeric values, possibly with modifiers, e.g. 3 or M-3.

It is only for interactive use. Non-interactively, use logview-switch-to-view instead.

(defun logview-switch-to-view-by-index ()
  "Switch to a view by its quick access index.
This command must be bound to a key with a numeric values,
possibly with modifiers, e.g. `3' or `M-3'.

It is only for interactive use.  Non-interactively, use
`logview-switch-to-view' instead."
  (interactive)
  (let* ((char  (if (integerp last-command-event)
                    last-command-event
                  (get last-command-event 'ascii-character)))
     (index (- (logand char #x7f) ?0)))
    (unless (<= 0 index 9)
      (user-error "This command must invoked by a numeric key, possibly with modifiers"))
    (logview-switch-to-view index)))
