Function: diff-hl--buffer-file-name

diff-hl--buffer-file-name is a natively compiled function defined in diff-hl.el.

Signature

(diff-hl--buffer-file-name &optional BUFFER)

Documentation

Return the file name of the BUFFER or its base buffer.

BUFFER defaults to the current buffer.
