Function: combobulate-ztree-prewalk

combobulate-ztree-prewalk is a natively compiled function defined in combobulate-ztree.el.

Signature

(combobulate-ztree-prewalk F FORM)

Documentation

Perform a depth-first, pre-order traversal of F applied to FORM.

Like combobulate-ztree-postwalk.

Source Code

;; Defined in /nix/store/9y0jasyzsqjcbfkwqsgdyxcnskjnsypg-emacs-packages-deps/share/emacs/site-lisp/combobulate-ztree.el
(defun combobulate-ztree-prewalk (f form)
  "Perform a depth-first, pre-order traversal of F applied to FORM.
Like `combobulate-ztree-postwalk'."
  (combobulate-ztree-walk (apply-partially #'combobulate-ztree-prewalk f) #'identity (funcall f form)))
