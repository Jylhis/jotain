Function: vundo--stem-end-p

vundo--stem-end-p is a natively compiled function defined in vundo.el.

(vundo--stem-end-p NODE)

Documentation

Return non-nil if NODE is the end of a stem.

;; Defined in /nix/store/7c2696v2qdrdv2vf2im8alazibi7qq0z-emacs-packages-deps/share/emacs/site-lisp/elpa/vundo-2.4.0/vundo.el
(defun vundo--stem-end-p (node)
  "Return non-nil if NODE is the end of a stem."
  ;; No children, or more than one children.
  (let ((len (length (vundo-m-children node))))
    (or (> len 1) (eq len 0))))
