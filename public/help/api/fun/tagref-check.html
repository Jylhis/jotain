Function: tagref-check

tagref-check is an interactive and natively compiled function defined in tagref.el.

Signature

(tagref-check)

Documentation

Run tagref check and display results in a compilation buffer.

This command is project-aware and will enable tagref-mode(var)/tagref-mode(fun) for the current project if not already enabled.

Key Bindings

This command is not in any keymaps.

;; Defined in /nix/store/569pb56gyz7bfhc7d47q808dqp08qfsi-emacs-packages-deps/share/emacs/site-lisp/tagref.el
;;;###autoload
(defun tagref-check ()
  "Run tagref check and display results in a compilation buffer.
This command is project-aware and will enable `tagref-mode' for
the current project if not already enabled."
  (interactive)
  (unless (tagref--project-root)
    (user-error "Not in a project"))
  (tagref-mode 1)
  (let ((default-directory (tagref--project-root))
        (command (mapconcat #'shell-quote-argument
                            (append (list tagref-executable)
                                    tagref-arguments
                                    (list "check"))
                            " ")))
    (compilation-start command 'tagref-compilation-mode)))
