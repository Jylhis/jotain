Function: magit-git-false

magit-git-false is a natively compiled function defined in magit-git.el.

Signature

(magit-git-false &rest ARGS)

Documentation

Execute Git with ARGS, returning t if it prints "false".

If it prints "true", then return nil. For any other output signal magit-invalid-git-boolean.

(defun magit-git-false (&rest args)
  "Execute Git with ARGS, returning t if it prints \"false\".
If it prints \"true\", then return nil.  For any other output
signal `magit-invalid-git-boolean'."
  (pcase (magit-git-output args)
    ((or "true"  "true\n")  nil)
    ((or "false" "false\n") t)
    (output (signal 'magit-invalid-git-boolean (list output)))))
