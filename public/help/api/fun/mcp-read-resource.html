Function: mcp-read-resource

mcp-read-resource is a natively compiled function defined in mcp.el.

Signature

(mcp-read-resource CONNECTION URI)

Documentation

Call a resource on the remote CONNECTION with URI.

CONNECTION is the MCP connection object. URI is the uri of the resource to call.

(defun mcp-read-resource (connection uri)
  "Call a resource on the remote CONNECTION with URI.

CONNECTION is the MCP connection object.
URI is the uri of the resource to call."
  (jsonrpc-request connection
                   :resources/read
                   (list :uri uri)))
