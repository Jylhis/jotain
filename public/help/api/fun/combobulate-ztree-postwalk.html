Function: combobulate-ztree-postwalk

combobulate-ztree-postwalk is a natively compiled function defined in combobulate-ztree.el.

Signature

(combobulate-ztree-postwalk F FORM)

Documentation

Perform a depth-first, post-order traversal of F applied to FORM.

Call F on each sub-form, use F's return value in place of the original. Recognize cons, lists, alists, vectors and hash tables.

original.  Recognize cons, lists, alists, vectors and
hash tables."
