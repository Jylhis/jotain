Function: magit-y-or-n-p

magit-y-or-n-p is a natively compiled function defined in magit-base.el.

Signature

(magit-y-or-n-p PROMPT &optional ACTION)

Documentation

Ask user a "y or n" or a "yes or no" question using PROMPT.

Which kind of question is used depends on whether ACTION is a member of option magit-slow-confirm.

(defun magit-y-or-n-p (prompt &optional action)
  "Ask user a \"y or n\" or a \"yes or no\" question using PROMPT.
Which kind of question is used depends on whether
ACTION is a member of option `magit-slow-confirm'."
  (if (or (eq magit-slow-confirm t)
          (and action (member action magit-slow-confirm)))
      (yes-or-no-p prompt)
    (y-or-n-p prompt)))
