Function: majutsu-run-jj

majutsu-run-jj is a natively compiled function defined in majutsu-process.el.

Signature

(majutsu-run-jj &rest ARGS)

Documentation

Call jj synchronously in a separate process, and refresh.

Process output goes into a new section in the buffer returned by majutsu-process-buffer. Return the exit code.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-process.el
(defun majutsu-run-jj (&rest args)
  "Call jj synchronously in a separate process, and refresh.

Process output goes into a new section in the buffer returned by
`majutsu-process-buffer'.  Return the exit code."
  (let ((exit (apply #'majutsu-call-jj args)))
    (majutsu-refresh)
    exit))
