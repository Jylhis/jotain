Function: pdf-info--selection-style

pdf-info--selection-style is a natively compiled function defined in pdf-info.el.

Signature

(pdf-info--selection-style SELECTION-STYLE)

Documentation

SELECTION-STYLE is the smallest unit of the selected region.

It must be one of glyph, word or line. If it is none of these, we fallback to glyph.

(defun pdf-info--selection-style (selection-style)
  "SELECTION-STYLE is the smallest unit of the selected region.

It must be one of glyph, word or line. If it is none of these, we
fallback to glyph."
  (cl-case selection-style
    (glyph 0)
    (word 1)
    (line 2)
    (t 0)))
