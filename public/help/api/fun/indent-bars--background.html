Function: indent-bars--background

indent-bars--background is a natively compiled function defined in indent-bars.el.

Signature

(indent-bars--background &optional NO-REMAP)

Documentation

Return the background color.

NO-REMAP is passed to indent-bars--background-color.

Source Code

;; Defined in /nix/store/kmdsnipwffgk5c0fs4785bhqa9fl17c5-emacs-packages-deps/share/emacs/site-lisp/elpa/indent-bars-1.0.1/indent-bars.el
;;;;; Color Utilities
(defun indent-bars--background (&optional no-remap)
  "Return the background color.
NO-REMAP is passed to `indent-bars--background-color'."
  (when-let ((bg-cons (indent-bars--background-color no-remap)))
    (if (consp bg-cons) (cdr bg-cons) bg-cons)))
