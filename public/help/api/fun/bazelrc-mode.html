Function: bazelrc-mode

bazelrc-mode is an interactive and natively compiled function defined in bazel.el.

Signature

(bazelrc-mode)

Documentation

Major mode for editing .bazelrc files.

In addition to any hooks its parent mode conf-space-mode might have run, this mode runs the hook bazelrc-mode-hook, as the final or penultimate step during initialization.

Key Bindings

This command is not in any keymaps.
