Function: majutsu-sparse-edit

majutsu-sparse-edit is an interactive and natively compiled function defined in majutsu-sparse.el.

Signature

(majutsu-sparse-edit)

Documentation

Edit sparse patterns in an editor.

This opens your configured editor with the current patterns.
