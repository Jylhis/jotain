Function: org-roam-buffer-render

org-roam-buffer-render is a function alias for org-roam-buffer-render-contents, defined in org-roam-mode.el.

This function is obsolete since org-roam 2.0; use org-roam-buffer-render-contents instead.

Signature

(org-roam-buffer-render)

Documentation

Recompute and render the contents of an Org-roam buffer.

Assumes that the current buffer is an org-roam-mode based buffer.

Aliases

org-roam-buffer-render-contents
