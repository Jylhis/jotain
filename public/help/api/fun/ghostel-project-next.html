Function: ghostel-project-next

ghostel-project-next is an interactive and natively compiled function defined in ghostel.el.

Signature

(ghostel-project-next)

Documentation

Switch to the next ghostel buffer in the current project (wraps around).

Project membership is determined by ghostel-project-buffer-scope.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/1jkgkg7y6y6hp0xia3dsmcl5zaj0bnhq-emacs-packages-deps/share/emacs/site-lisp/ghostel.el
;;;###autoload
(defun ghostel-project-next ()
  "Switch to the next ghostel buffer in the current project (wraps around).
Project membership is determined by `ghostel-project-buffer-scope'."
  (interactive)
  (ghostel--cycle (ghostel--project-buffers) +1
                  "No ghostel buffers in this project"
                  "Only one ghostel buffer in this project"))
