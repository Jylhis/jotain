Function: denote-directories--make-paths

denote-directories--make-paths is a natively compiled function defined in denote.el.

Signature

(denote-directories--make-paths DIRECTORIES)

Documentation

Call make-directory on each element of DIRECTORIES unless it exists.

Make any parent directories as well.

Source Code

;; Defined in /nix/store/5x9606vmybcj80x6qrajp43rma9pa1i7-emacs-packages-deps/share/emacs/site-lisp/elpa/denote-4.2.3/denote.el
(defun denote-directories--make-paths (directories)
  "Call `make-directory' on each element of DIRECTORIES unless it exists.
Make any parent directories as well."
  (dolist (directory directories)
    (unless (file-directory-p directory)
      (make-directory directory :parents))))
