Function: majutsu--shell-command-needs-shell-p

majutsu--shell-command-needs-shell-p is a natively compiled function defined in majutsu-command.el.

Signature

(majutsu--shell-command-needs-shell-p COMMAND)

Documentation

Return non-nil when COMMAND should be handed to the shell.

This conservatively detects shell operators that cannot be preserved by split-string-shell-command.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-command.el
(defun majutsu--shell-command-needs-shell-p (command)
  "Return non-nil when COMMAND should be handed to the shell.
This conservatively detects shell operators that cannot be preserved by
`split-string-shell-command'."
  (string-match-p "[|&;<>`]" command))
