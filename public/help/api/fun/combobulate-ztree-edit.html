Function: combobulate-ztree-edit

combobulate-ztree-edit is a natively compiled function defined in combobulate-ztree.el.

Signature

(combobulate-ztree-edit LOC F &rest ARGS)

Documentation

Replace the node at this LOC with the value of (F node ARGS).

Source Code

;; Defined in /nix/store/9y0jasyzsqjcbfkwqsgdyxcnskjnsypg-emacs-packages-deps/share/emacs/site-lisp/combobulate-ztree.el
(defun combobulate-ztree-edit (loc f &rest args)
  "Replace the node at this LOC with the value of (F node ARGS)."
  (combobulate-ztree-replace loc (apply f (combobulate-ztree-node loc) args)))
