Function: eca-chat--get-chat-buffer

eca-chat--get-chat-buffer is a natively compiled function defined in eca-chat.el.

Signature

(eca-chat--get-chat-buffer SESSION CHAT-ID)

Documentation

Get chat buffer for SESSION and CHAT-ID, or nil when none registered.

Since the client now generates the chat-id at buffer creation time (see eca-chat-open), every known chat is registered under its real id and there is no empty' placeholder to migrate from.
