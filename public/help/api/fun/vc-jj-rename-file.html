Function: vc-jj-rename-file

vc-jj-rename-file is a natively compiled function defined in vc-jj.el.

Signature

(vc-jj-rename-file OLD NEW)

Documentation

Rename file OLD to NEW and make sure jj registers the change.

;;;; rename-file

(defun vc-jj-rename-file (old new)
  "Rename file OLD to NEW and make sure jj registers the change."
  (rename-file old new)
  (vc-jj--command-dispatched nil 0 nil "status"))
