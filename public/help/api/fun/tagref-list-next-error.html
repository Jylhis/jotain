Function: tagref-list-next-error

tagref-list-next-error is an interactive and natively compiled function defined in tagref.el.

Signature

(tagref-list-next-error N &optional RESET)

Documentation

Move to the Nth next tag in the list and visit it.

This function is used by next-error and previous-error. If RESET is non-nil, go to the first tag.

Key Bindings

This command is not in any keymaps.

(defun tagref-list-next-error (n &optional reset)
  "Move to the Nth next tag in the list and visit it.
This function is used by `next-error' and `previous-error'.
If RESET is non-nil, go to the first tag."
  (interactive "p")
  (when reset
    (goto-char (point-min))
    (forward-line 2))  ; Skip header
  (forward-line n)
  ;; Ensure we're on a valid entry
  (when (eobp)
    (forward-line -1))
  (when (< (line-number-at-pos) 3)
    (goto-char (point-min))
    (forward-line 2))
  (tagref-list-goto-tag))
