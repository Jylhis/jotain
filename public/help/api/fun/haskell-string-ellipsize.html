Function: haskell-string-ellipsize

haskell-string-ellipsize is a natively compiled function defined in haskell-string.el.

Signature

(haskell-string-ellipsize STRING N)

Documentation

Return STRING truncated to (at most) N characters.

If truncation occurred, last character in string is replaced by …. See also haskell-string-take.

(defun haskell-string-ellipsize (string n)
  "Return STRING truncated to (at most) N characters.
If truncation occurred, last character in string is replaced by `…'.
See also `haskell-string-take'."
  (cond
   ((<= (length string) n) string) ;; no truncation needed
   ((< n 1) "")
   (t (concat (substring string 0 (1- n)) "…"))))
