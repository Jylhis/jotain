Function: terraform-toggle-or-indent

terraform-toggle-or-indent is an interactive and natively compiled function defined in terraform-mode.el.

Signature

(terraform-toggle-or-indent &optional ARG)

Documentation

Toggle visibility of block under point or indent.

If the point is not at the heading, call indent-for-tab-command.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/4nxqp4jvms3n4azp2x2snypnn6xcgq9g-emacs-packages-deps/share/emacs/site-lisp/elpa/terraform-mode-20251115.2210/terraform-mode.el
(defun terraform-toggle-or-indent (&optional arg)
  "Toggle visibility of block under point or indent.

If the point is not at the heading, call
`indent-for-tab-command'."
  (interactive)
  (if (and outline-minor-mode (outline-on-heading-p))
      (outline-toggle-children)
    (indent-for-tab-command arg)))
