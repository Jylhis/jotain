Function: combobulate-ztree-children

combobulate-ztree-children is a natively compiled function defined in combobulate-ztree.el.

(combobulate-ztree-children LOC)

Documentation

Return a children list of the node at LOC, which must be a branch.

Source Code

;; Defined in /nix/store/9y0jasyzsqjcbfkwqsgdyxcnskjnsypg-emacs-packages-deps/share/emacs/site-lisp/combobulate-ztree.el
(defun combobulate-ztree-children (loc)
  "Return a children list of the node at LOC, which must be a branch."
  (if (combobulate-ztree-branch-p loc)
      (funcall (combobulate-ztree--meta loc ':children) (combobulate-ztree-node loc))
    (error "Called children on a leaf node")))
