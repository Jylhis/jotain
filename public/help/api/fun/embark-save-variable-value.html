Function: embark-save-variable-value

embark-save-variable-value is an interactive and natively compiled function defined in embark.el.

Signature

(embark-save-variable-value VAR)

Documentation

Save value of VAR in the kill-ring.

Key Bindings

embark-variable-map v

Source Code

;; Defined in /nix/store/fs4fhphi5ajjmvzx1rm550ibr8slmvxd-emacs-packages-deps/share/emacs/site-lisp/elpa/embark-20260610.302/embark.el
(defun embark-save-variable-value (var)
  "Save value of VAR in the `kill-ring'."
  (interactive "SVariable: ")
  (kill-new (string-trim (pp-to-string (symbol-value var)))))
