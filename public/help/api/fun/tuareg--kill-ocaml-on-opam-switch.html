Function: tuareg--kill-ocaml-on-opam-switch

tuareg--kill-ocaml-on-opam-switch is a natively compiled function defined in tuareg.el.

Signature

(tuareg--kill-ocaml-on-opam-switch)

Documentation

Kill the OCaml toplevel before the opam switch changes.

This function is for the opam-switch-mode hook opam-switch-before-change-opam-switch-hook, which runs just before the user changes the opam switch through opam-switch-mode.
