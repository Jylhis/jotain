Function: denote-sort-keywords-lessp

denote-sort-keywords-lessp is a natively compiled function defined in denote.el.

Signature

(denote-sort-keywords-lessp FILE1 FILE2)

Documentation

Return smallest among FILE1, FILE2 based on their keywords.

The denote-sort-keywords-comparison-function performs the comparison.
