Function: vc-jj-region-history-mode

vc-jj-region-history-mode is an interactive and natively compiled function defined in vc-jj.el.

Signature

(vc-jj-region-history-mode)

Documentation

Major mode derived from vc-git-region-history-mode by define-derived-mode.

It inherits all of the parent's attributes, but has its own keymap, abbrev table and syntax table:

  vc-jj-region-history-mode-map,
vc-jj-region-history-mode-abbrev-table and vc-jj-region-history-mode-syntax-table

which more-or-less shadow vc-git-region-history-mode's corresponding tables.

In addition to any hooks its parent mode might have run, this mode runs the hook vc-jj-region-history-mode-hook, as the final or penultimate step during initialization.

Key Bindings

This command is not in any keymaps.
