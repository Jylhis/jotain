Function: meson--search-in-reference-manual

meson--search-in-reference-manual is a natively compiled function defined in meson-mode.el.

Signature

(meson--search-in-reference-manual IDENTIFIER)

Documentation

Search for the function or object IDENTIFIER in the current buffer.

The current buffer is assumed to contain the Meson reference manual. Return either line-beginning-position of the matching line or nil.

(defun meson--search-in-reference-manual (identifier)
  "Search for the function or object IDENTIFIER in the current buffer.
The current buffer is assumed to contain the Meson reference manual.
Return either `line-beginning-position' of the matching line or nil."
  (goto-char (point-min))
  (and (re-search-forward (meson--make-lookup-regexp identifier) nil t)
       (line-beginning-position)))
