Function: majutsu-log-copy-commit-id

majutsu-log-copy-commit-id is an interactive and natively compiled function defined in majutsu-log.el.

Signature

(majutsu-log-copy-commit-id)

Documentation

Copy the current entry's commit hash.

This copies the canonical hidden commit-id field, even when it is not shown in the visible log layout. If the region is active, copy it literally using copy-region-as-kill.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-log.el
;;;###autoload
(defun majutsu-log-copy-commit-id ()
  "Copy the current entry's commit hash.

This copies the canonical hidden `commit-id' field, even when it is not shown
in the visible log layout.  If the region is active, copy it literally using
`copy-region-as-kill'."
  (interactive)
  (if (use-region-p)
      (call-interactively #'copy-region-as-kill)
    (let ((entry (or (majutsu-log--entry-at-point)
                     (user-error "No log entry at point"))))
      (majutsu-log--copy-entry-field-value entry 'commit-id))))
