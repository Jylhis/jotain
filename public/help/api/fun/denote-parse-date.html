Function: denote-parse-date

denote-parse-date is a function alias for denote-valid-date-p, defined in denote.el.

This function is obsolete since 4.0.0; use denote-valid-date-p instead.

Signature

(denote-parse-date DATE)

Documentation

Return DATE as a valid date.

A valid DATE is a value that can be parsed by either decode-time or date-to-time. Those functions signal an error if DATE is a value they do not recognise.

If DATE is nil or an empty string, return nil.

Aliases

denote-valid-date-p
