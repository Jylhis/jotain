Function: denote-query-exclude-files

denote-query-exclude-files is an interactive and natively compiled function defined in denote.el.

Signature

(denote-query-exclude-files REGEXP)

Documentation

Exclude files matching REGEXP from the current Denote query buffer.

REGEXP is matched against the file name.

Key Bindings

denote-query-mode-map x

Source Code

;; Defined in /nix/store/5x9606vmybcj80x6qrajp43rma9pa1i7-emacs-packages-deps/share/emacs/site-lisp/elpa/denote-4.2.3/denote.el
(defun denote-query-exclude-files (regexp)
  "Exclude files matching REGEXP from the current Denote query buffer.
REGEXP is matched against the file name."
  (interactive
   (or (denote--user-error-if-not-major-mode 'denote-query-mode)
       (list (denote-query-prompt :exclude)))
   denote-query-mode)
  (denote-query--filter-files regexp nil))
