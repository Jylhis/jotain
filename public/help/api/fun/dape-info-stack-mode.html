Function: dape-info-stack-mode

dape-info-stack-mode is a natively compiled function defined in dape.el.

Signature

(dape-info-stack-mode)

Documentation

Major mode for viewing and navigating the call stack.

In addition to any hooks its parent mode dape-info-parent-mode might have run, this mode runs the hook dape-info-stack-mode-hook, as the final or penultimate step during initialization.

  "Major mode for viewing and navigating the call stack."
  :interactive nil
  (setq font-lock-defaults '(dape--info-stack-font-lock-keywords)
        truncate-lines t
        dape--info-stack-position (make-marker))
  (add-to-list 'overlay-arrow-variable-list 'dape--info-stack-position))
