Function: ghostel--send-key

ghostel--send-key is a function alias for ghostel--send-string, defined in ghostel.el.

This function is obsolete since 0.16.0; use ghostel--send-string instead.

Signature

(ghostel--send-key STRING)

Documentation

Send STRING as raw bytes to the terminal's PTY.

Records the send time for immediate-redraw detection.

Aliases

ghostel--send-string
