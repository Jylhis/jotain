Function: magit-read-worktree-directory-nested

magit-read-worktree-directory-nested is a natively compiled function defined in magit-worktree.el.

Signature

(magit-read-worktree-directory-nested PROMPT COMMIT)

Documentation

Call read-directory-name in current worktree.

For read-directory-names INITIAL argument use a string based on COMMIT, replacing slashes with dashes. If COMMIT is nil, use nil as INITIAL. Always forward PROMPT as-is.

(defun magit-read-worktree-directory-nested (prompt commit)
  "Call `read-directory-name' in current worktree.
For `read-directory-name's INITIAL argument use a string based on
COMMIT, replacing slashes with dashes.  If COMMIT is nil, use nil
as INITIAL.  Always forward PROMPT as-is."
  (read-directory-name prompt nil nil nil
                       (and commit (string-replace "/" "-" commit))))
