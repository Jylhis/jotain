Function: magit-git-true

magit-git-true is a natively compiled function defined in magit-git.el.

Signature

(magit-git-true &rest ARGS)

Documentation

Execute Git with ARGS, returning t if it prints "true".

If it prints "false", then return nil. For any other output signal magit-invalid-git-boolean.

;; Defined in /nix/store/k1kwf51rwhxc2r08pvslpgkhbnr4nxnr-emacs-packages-deps/share/emacs/site-lisp/elpa/magit-20260822.1158/magit-git.el
(defun magit-git-true (&rest args)
  "Execute Git with ARGS, returning t if it prints \"true\".
If it prints \"false\", then return nil.  For any other output
signal `magit-invalid-git-boolean'."
  (pcase (magit-git-output args)
    ((or "true"  "true\n")  t)
    ((or "false" "false\n") nil)
    (output (signal 'magit-invalid-git-boolean (list output)))))
