Function: pulsar-global-mode

pulsar-global-mode is an interactive and natively compiled function defined in pulsar.el.

Signature

(pulsar-global-mode &optional ARG)

Documentation

Toggle Pulsar mode in many buffers.

Specifically, Pulsar mode is enabled in all buffers where pulsar--on would do it.

With prefix ARG, enable Pulsar-Global mode if ARG is positive; otherwise, disable it.

If called from Lisp, toggle the mode if ARG is toggle. Enable the mode if ARG is nil, omitted, or is a positive number. Disable the mode if ARG is a negative number.

See pulsar-mode(var)/pulsar-mode(fun) for more information on Pulsar mode.

Key Bindings

This command is not in any keymaps.
