Function: pdf-view-center-in-window

pdf-view-center-in-window is an interactive and natively compiled function defined in pdf-view.el.

Signature

(pdf-view-center-in-window)

Documentation

Center PDF in window horizontally.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/wm0vc3dfi6c7pwjhcfpsnhyg4hd0b5yc-emacs-packages-deps/share/emacs/site-lisp/elpa/pdf-tools-20260102.1101/pdf-view.el
(defun pdf-view-center-in-window ()
  "Center PDF in window horizontally."
  (interactive)
  (image-set-window-hscroll
   (/ (* (- (car (pdf-view-image-size))
            (window-pixel-width))
         (window-width))
      2 (window-pixel-width))) ; convert from pixel to character width
  (pdf-view-redisplay t))
