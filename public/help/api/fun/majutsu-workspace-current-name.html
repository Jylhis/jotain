Function: majutsu-workspace-current-name

majutsu-workspace-current-name is a natively compiled function defined in majutsu-workspace.el.

Signature

(majutsu-workspace-current-name &optional DIRECTORY)

Documentation

Return current workspace name for DIRECTORY, or nil if it can't be determined.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-workspace.el
(defun majutsu-workspace-current-name (&optional directory)
  "Return current workspace name for DIRECTORY, or nil if it can't be determined."
  (when-let* ((entry (cl-find-if (lambda (ws)
                                   (plist-get ws :current))
                                 (majutsu-workspace-list-entries directory))))
    (plist-get entry :name)))
