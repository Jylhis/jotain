Function: csv-not-looking-at-record

csv-not-looking-at-record is a byte-compiled function defined in csv-mode.el.

Signature

(csv-not-looking-at-record)

Documentation

Return t if looking at blank or comment line, nil otherwise.

Assumes point is at beginning of line.
