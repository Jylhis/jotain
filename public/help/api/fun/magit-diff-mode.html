Function: magit-diff-mode

magit-diff-mode is a natively compiled function defined in magit-diff.el.

Signature

(magit-diff-mode)

Documentation

Mode for looking at a Git diff.

This mode is documented in info node (magit)Diff Buffer.

Type g (magit-refresh) to refresh the current buffer. Type TAB (magit-section-toggle) to expand or hide the section at point. Type RET (magit-visit-thing) to visit the hunk or file at point.

Staging and applying changes is documented in info node
(magit)Staging and Unstaging and info node (magit)Applying.

Type <1> (magit-apply) to apply the change at point, <2> (magit-stage) to stage,
<3> (magit-unstage) to unstage, <4> (magit-discard) to discard, or <5> (magit-reverse) to reverse it.
