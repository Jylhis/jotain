Function: majutsu-git--pathish-url-p

majutsu-git--pathish-url-p is a natively compiled function defined in majutsu-git.el.

Signature

(majutsu-git--pathish-url-p VALUE)

Documentation

Return non-nil if VALUE should be converted as a local path for jj.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-git.el
(defun majutsu-git--pathish-url-p (value)
  "Return non-nil if VALUE should be converted as a local path for jj."
  (and (stringp value)
       (or (file-remote-p value)
           (file-name-absolute-p value)
           (string= value "~")
           (string-prefix-p "~/" value))))
