Function: pdf-view-refresh-themed-buffer

pdf-view-refresh-themed-buffer is a natively compiled function defined in pdf-view.el.

Signature

(pdf-view-refresh-themed-buffer &optional GET-THEME)

Documentation

Refresh the current buffer to activate applied colors.

When GET-THEME is non-nil, also reset the applied colors to the current theme's colors.

(defun pdf-view-refresh-themed-buffer (&optional get-theme)
  "Refresh the current buffer to activate applied colors.

When GET-THEME is non-nil, also reset the applied colors to the
current theme's colors."
  (pdf-util-assert-pdf-buffer)
  (pdf-cache-clear-images)
  (when get-theme
    (pdf-view-set-theme-background))
  (pdf-view-redisplay t))
