Function: majutsu-sparse-reset

majutsu-sparse-reset is an interactive and natively compiled function defined in majutsu-sparse.el.

Signature

(majutsu-sparse-reset)

Documentation

Reset sparse patterns to include all files.

This is equivalent to jj sparse reset.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-sparse.el
;;;###autoload
(defun majutsu-sparse-reset ()
  "Reset sparse patterns to include all files.
This is equivalent to `jj sparse reset'."
  (interactive)
  (when (yes-or-no-p "Reset sparse patterns to include all files? ")
    (majutsu-run-jj "sparse" "reset")))
