Function: dape--with-request

dape--with-request is a macro defined in dape.el.

Signature

(dape--with-request FN-ARGS &rest BODY)

Documentation

Call dape-request like FN with ARGS and execute BODY on callback.

FN-ARGS is be an cons pair as FN . ARGS. BODY is guaranteed to be evaluated with the current buffer if live. See cl-destructuring-bind for bind forms.
