Function: majutsu-diff--file-heading

majutsu-diff--file-heading is a natively compiled function defined in majutsu-diff.el.

Signature

(majutsu-diff--file-heading FILE LINES)

Documentation

Return a formatted heading string for FILE using parsed LINES.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-diff.el
(defun majutsu-diff--file-heading (file lines)
  "Return a formatted heading string for FILE using parsed LINES."
  (format "%-11s %s" (majutsu--diff-file-status lines) file))
