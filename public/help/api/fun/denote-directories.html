Function: denote-directories

denote-directories is a natively compiled function defined in denote.el.

Signature

(denote-directories)

Documentation

Return path of variable denote-directory(var)/denote-directory(fun) as a proper directory.

If the variable denote-directory(var)/denote-directory(fun) is set to a list of file paths, return the list with each element expanded to be a directory. Create any directories and their parents, if needed.

Custom Lisp code can let bind the variable denote-directory(var)/denote-directory(fun) to override what this function returns.

(defun denote-directories ()
  "Return path of variable `denote-directory' as a proper directory.
If the variable `denote-directory' is set to a list of file paths,
return the list with each element expanded to be a directory.  Create
any directories and their parents, if needed.

Custom Lisp code can `let' bind the variable `denote-directory'
to override what this function returns."
  (if-let* (((or (eq denote-directory 'default-directory) (eq denote-directory 'local)))
            (silo-dir (denote--default-directory-is-silo-p)))
      (progn
        (display-warning
         'denote
         "Silo value must be a string; `local' or `default-directory' are obsolete"
         :error)
        (list silo-dir))
    (let ((denote-directories (denote-directories--get-paths denote-directory)))
      (denote-directories--make-paths denote-directories)
      denote-directories)))
