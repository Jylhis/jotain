Function: dape-shell-mode

dape-shell-mode is a natively compiled function defined in dape.el.

Signature

(dape-shell-mode)

Documentation

Major mode for interacting with an debugged program.

In addition to any hooks its parent mode shell-mode might have run, this mode runs the hook dape-shell-mode-hook, as the final or penultimate step during initialization.
