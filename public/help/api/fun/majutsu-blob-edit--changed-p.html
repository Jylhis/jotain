Function: majutsu-blob-edit--changed-p

majutsu-blob-edit--changed-p is a natively compiled function defined in majutsu-file.el.

Signature

(majutsu-blob-edit--changed-p)

Documentation

Return non-nil when blob edit buffer content differs from snapshot.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-file.el
(defun majutsu-blob-edit--changed-p ()
  "Return non-nil when blob edit buffer content differs from snapshot."
  (not (equal (buffer-substring-no-properties (point-min) (point-max))
              (or majutsu-blob-edit--original-content ""))))
