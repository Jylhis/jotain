Function: vc-jj-responsible-p

vc-jj-responsible-p is a function alias for vc-jj-root, defined in vc-jj.el.

Signature

(vc-jj-responsible-p FILE)

Documentation

Return the root of the repository containing FILE.

Return NIL if FILE is not in a jj repository.

Aliases

vc-jj-root
