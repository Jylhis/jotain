Function: auto-dark--current-mode-dbus

auto-dark--current-mode-dbus is a natively compiled function defined in auto-dark.el.

Signature

(auto-dark--current-mode-dbus)

Documentation

Use Emacs built-in D-Bus function to determine if dark theme is enabled.

Source Code

;; Defined in /nix/store/bsy6s0b3kb4pmxsgxn385p8xfkhwnj6b-emacs-packages-deps/share/emacs/site-lisp/elpa/auto-dark-20260313.2356/auto-dark.el
(defun auto-dark--current-mode-dbus ()
  "Use Emacs built-in D-Bus function to determine if dark theme is enabled."
  (pcase (caar (dbus-ignore-errors
                 (dbus-call-method
                  :session
                  "org.freedesktop.portal.Desktop"
                  "/org/freedesktop/portal/desktop"
                  "org.freedesktop.portal.Settings" "Read"
                  "org.freedesktop.appearance" "color-scheme")))
    (1 'dark)
    ((or 0 2) 'light)))
