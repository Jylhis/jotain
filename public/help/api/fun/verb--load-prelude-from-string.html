Function: verb--load-prelude-from-string

verb--load-prelude-from-string is a natively compiled function defined in verb.el.

Signature

(verb--load-prelude-from-string VALUE)

Documentation

Load Emacs Lisp or JSON prelude data from VALUE.

First, try to read VALUE as JSON. If that fails, evaluate the code as Emacs Lisp.

Source Code

;; Defined in /nix/store/1vhkdxrkj0c423ijah8wn2d489dd8rgw-emacs-packages-deps/share/emacs/site-lisp/elpa/verb-20260818.1921/verb.el
(defun verb--load-prelude-from-string (value)
  "Load Emacs Lisp or JSON prelude data from VALUE.
First, try to read VALUE as JSON.  If that fails, evaluate the code as
Emacs Lisp."
  (condition-case nil
      (verb--process-json-prelude value)
    (json-readtable-error (verb--eval-string value))))
