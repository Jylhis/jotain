Function: pulsar-highlight-pulse

pulsar-highlight-pulse is an interactive and natively compiled function defined in pulsar.el.

Signature

(pulsar-highlight-pulse &optional LOCUS)

Documentation

Highlight the current LOCUS by pulsing it.

To pulse is to add a colour and then gradually fade it away. The pulse is subject to pulsar-delay and pulsar-iterations.

When the region is active, LOCUS covers the region boundaries. Otherwise, LOCUS spans the current line.

For highlights without a pulse, see pulsar-highlight-temporarily and pulsar-highlight-permanently.

Key Bindings

This command is not in any keymaps.

Aliases

pulsar-pulse-region (obsolete since 1.3.0)
