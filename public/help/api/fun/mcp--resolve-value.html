Function: mcp--resolve-value

mcp--resolve-value is a natively compiled function defined in mcp.el.

Signature

(mcp--resolve-value VALUE)

Documentation

Resolve VALUE's value.

If it is function - call it. If it is a variable - return it's value Otherwise returns value itself.

(defun mcp--resolve-value (value)
  "Resolve VALUE's value.
If it is function - call it.
If it is a variable - return it's value
Otherwise returns value itself."
  (cond
   ((functionp value) (funcall value))
   ((and (symbolp value) (boundp value)) (symbol-value value))
   (value)))
