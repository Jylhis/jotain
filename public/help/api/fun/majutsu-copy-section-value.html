Function: majutsu-copy-section-value

majutsu-copy-section-value is an interactive and natively compiled function defined in majutsu-log.el.

Signature

(majutsu-copy-section-value)

Documentation

Copy the current section's stable value.

When the region is active, copy it literally using copy-region-as-kill.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-log.el
;;;###autoload
(defun majutsu-copy-section-value ()
  "Copy the current section's stable value.

When the region is active, copy it literally using `copy-region-as-kill'."
  (interactive)
  (if (use-region-p)
      (call-interactively #'copy-region-as-kill)
    (if-let* ((section (magit-current-section))
              (value (oref section value)))
        (majutsu-log--copy-string (format "%s" value))
      (user-error "No section value at point"))))
