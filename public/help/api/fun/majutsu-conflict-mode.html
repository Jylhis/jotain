Function: majutsu-conflict-mode

majutsu-conflict-mode is an interactive and natively compiled function defined in majutsu-conflict.el.

Signature

(majutsu-conflict-mode &optional ARG)

Documentation

Minor mode for jj conflict markers.

Provides highlighting and navigation for conflict regions.

This is a minor mode. If called interactively, toggle the Majutsu-Conflict mode mode. If the prefix argument is positive, enable the mode, and if it is zero or negative, disable the mode.

If called from Lisp, toggle the mode if ARG is toggle. Enable the mode if ARG is nil, omitted, or is a positive number. Disable the mode if ARG is a negative number.

To check whether the minor mode is enabled in the current buffer, evaluate the variable majutsu-conflict-mode(var)/majutsu-conflict-mode(fun).

The mode's hook is called both when the mode is enabled and when it is disabled.

Key Bindings

This command is not in any keymaps.

;;;###autoload
(define-minor-mode majutsu-conflict-mode
  "Minor mode for jj conflict markers.
Provides highlighting and navigation for conflict regions."
  :lighter " Conflict"
  :keymap majutsu-conflict-mode-map
  (if majutsu-conflict-mode
      (majutsu-conflict--enable)
    (majutsu-conflict--disable)))
