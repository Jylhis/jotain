Function: gptel--inject-media

gptel--inject-media is a byte-compiled function defined in gptel-request.el.

Signature

(gptel--inject-media BACKEND PROMPTS)

Documentation

Wrap the last prompt in PROMPTS with gptel's context.

PROMPTS is a structure as returned by gptel--parse-buffer. Typically this is a list of plists.

BACKEND is the gptel backend in use.

Implementations

(gptel--inject-media BACKEND PROMPTS) in `gptel-request.el'.
