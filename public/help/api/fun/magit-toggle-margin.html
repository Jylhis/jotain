Function: magit-toggle-margin

magit-toggle-margin is an interactive and natively compiled function defined in magit-margin.el.

(magit-toggle-margin)

;; Defined in /nix/store/k1kwf51rwhxc2r08pvslpgkhbnr4nxnr-emacs-packages-deps/share/emacs/site-lisp/elpa/magit-20260822.1158/magit-margin.el
(transient-define-suffix magit-toggle-margin ()
  "Show or hide the right margin."
  :description "Toggle visibility"
  :key "L"
  :transient t
  (interactive)
  (unless (magit--right-margin-option)
    (user-error "Magit margin isn't supported in this buffer"))
  (setcar magit--right-margin-config (not (magit--right-margin-active)))
  (magit-set-buffer-margins))
