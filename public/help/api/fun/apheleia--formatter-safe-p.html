Function: apheleia--formatter-safe-p

apheleia--formatter-safe-p is a natively compiled function defined in apheleia-formatters.el.

Signature

(apheleia--formatter-safe-p VAL)

Documentation

Return non-nil if VAL is a good value for apheleia-formatter.

;; Defined in /nix/store/dbykkl13khzh84lv9vw1bf1vijzg30fr-emacs-packages-deps/share/emacs/site-lisp/elpa/apheleia-20260817.2331/apheleia-formatters.el
(defun apheleia--formatter-safe-p (val)
  "Return non-nil if VAL is a good value for `apheleia-formatter'."
  (or (symbolp val)
      (and (listp val)
           (cl-every #'symbolp val))))
