Function: majutsu-log--canonical-field-value

majutsu-log--canonical-field-value is a natively compiled function defined in majutsu-log.el.

(majutsu-log--canonical-field-value FIELD VALUE)

Documentation

Return canonical semantic value for FIELD based on VALUE.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-log.el
(defun majutsu-log--canonical-field-value (field value)
  "Return canonical semantic value for FIELD based on VALUE."
  (majutsu-log--apply-postprocessors
   value
   (majutsu-log--default-postprocessors-for-field field)
   (list :field field :module 'canonical :raw-value value :canonical t)))
