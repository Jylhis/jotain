Function: tempel-previous

tempel-previous is an interactive and natively compiled function defined in tempel.el.

Signature

(tempel-previous &optional N)

Documentation

Move N fields backward.

Quit at the beginning if tempel-done-on-next is non-nil.

Key Bindings

tempel-map C-<up> tempel-map M-<up> tempel-map M-{

(defun tempel-previous (&optional n)
  "Move N fields backward.
Quit at the beginning if `tempel-done-on-next' is non-nil."
  (declare (completion tempel--active-p))
  (interactive "p")
  (tempel-next (- (or n 1))))
