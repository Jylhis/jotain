Function: majutsu-template--lambda-node

majutsu-template--lambda-node is a natively compiled function defined in majutsu-template.el.

Signature

(majutsu-template--lambda-node PARAMS BODY &optional PROPS TYPE)

Documentation

Return lambda node binding PARAMS around BODY.

PARAMS is a list of symbols. BODY must already be a template node. TYPE defaults to Lambda and may be a richer internal lambda type ref.

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-template.el
(defun majutsu-template--lambda-node (params body &optional props type)
  "Return lambda node binding PARAMS around BODY.
PARAMS is a list of symbols. BODY must already be a template node.
TYPE defaults to `Lambda' and may be a richer internal lambda type ref."
  (majutsu-template-node-create
   :kind :lambda
   :type (or type 'Lambda)
   :value params
   :args (list body)
   :props props))
