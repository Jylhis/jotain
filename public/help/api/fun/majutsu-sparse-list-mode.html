Function: majutsu-sparse-list-mode

majutsu-sparse-list-mode is an interactive and natively compiled function defined in majutsu-sparse.el.

Signature

(majutsu-sparse-list-mode)

Documentation

Major mode for viewing jj sparse patterns.

In addition to any hooks its parent mode majutsu-mode might have run, this mode runs the hook majutsu-sparse-list-mode-hook, as the final or penultimate step during initialization.
