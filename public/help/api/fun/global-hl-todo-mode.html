Function: global-hl-todo-mode

global-hl-todo-mode is an interactive and natively compiled function defined in hl-todo.el.

Signature

(global-hl-todo-mode &optional ARG)

Documentation

Toggle Hl-Todo mode in many buffers.

Specifically, Hl-Todo mode is enabled in all buffers where hl-todo--turn-on-mode-if-desired would do it.

With prefix ARG, enable Global Hl-Todo mode if ARG is positive; otherwise, disable it.

If called from Lisp, toggle the mode if ARG is toggle. Enable the mode if ARG is nil, omitted, or is a positive number. Disable the mode if ARG is a negative number.

See hl-todo-mode(var)/hl-todo-mode(fun) for more information on Hl-Todo mode.

Key Bindings

This command is not in any keymaps.
