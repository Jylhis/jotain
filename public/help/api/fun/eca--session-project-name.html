Function: eca--session-project-name

eca--session-project-name is a natively compiled function defined in eca-util.el.

Signature

(eca--session-project-name SESSION)

Documentation

Return the project name for SESSION.

Extracts the last directory component from the first workspace folder. Falls back to "unknown".

(defun eca--session-project-name (session)
  "Return the project name for SESSION.
Extracts the last directory component from the first
workspace folder. Falls back to \"unknown\"."
  (if-let* ((roots (eca--session-workspace-folders session))
            (root (car roots)))
      (file-name-nondirectory (directory-file-name root))
    "unknown"))
