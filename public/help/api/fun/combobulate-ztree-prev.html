Function: combobulate-ztree-prev

combobulate-ztree-prev is a natively compiled function defined in combobulate-ztree.el.

Signature

(combobulate-ztree-prev LOC &optional ORDER)

Documentation

Move to the previous LOC in the hierarchy, depth-first.

Use ORDER if given. Possible values for ORDER are :preorder and :postorder, defaults to the former.

Source Code

;; Defined in /nix/store/9y0jasyzsqjcbfkwqsgdyxcnskjnsypg-emacs-packages-deps/share/emacs/site-lisp/combobulate-ztree.el
(defun combobulate-ztree-prev (loc &optional order)
  "Move to the previous LOC in the hierarchy, depth-first.
Use ORDER if given.  Possible values for ORDER are `:preorder' and `:postorder',
defaults to the former."
  (cl-case (or order ':preorder)
    (:preorder (combobulate-ztree--preorder-prev loc))
    (:postorder (combobulate-ztree--postorder-prev loc))
    (t (error "Unrecognized order"))))
