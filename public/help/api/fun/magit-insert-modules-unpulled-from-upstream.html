Function: magit-insert-modules-unpulled-from-upstream

magit-insert-modules-unpulled-from-upstream is a natively compiled function defined in magit-submodule.el.

Signature

(magit-insert-modules-unpulled-from-upstream)

Documentation

Insert sections for modules that haven't been pulled from the upstream.

These sections can be expanded to show the respective commits.

(defun magit-insert-modules-unpulled-from-upstream ()
  "Insert sections for modules that haven't been pulled from the upstream.
These sections can be expanded to show the respective commits."
  (magit--insert-modules-logs "Modules unpulled from @{upstream}"
                              'modules-unpulled-from-upstream
                              "HEAD..@{upstream}"))
