Function: zoxide-remove

zoxide-remove is an interactive and natively compiled function defined in zoxide.el.

Signature

(zoxide-remove &optional PATH)

Documentation

Remove PATH from zoxide database.

Notice: expand-file-name is used on path here. If your path aren't compatible with it, a new wrapper with zoxide-run should be done manually.

Key Bindings

This command is not in any keymaps.

(defun zoxide-remove (&optional path)
  "Remove PATH from zoxide database.

Notice: `expand-file-name' is used on path here.  If your path aren't compatible
with it, a new wrapper with `zoxide-run' should be done manually."
  (interactive "Dpath: ")
  (unless path
    (setq path (funcall zoxide-get-path-function 'remove)))
  (zoxide-run t "remove" (expand-file-name path)))
