Function: mcp-call-tool

mcp-call-tool is a natively compiled function defined in mcp.el.

Signature

(mcp-call-tool CONNECTION NAME ARGUMENTS)

Documentation

Call a tool on the remote CONNECTION with NAME and ARGUMENTS.

CONNECTION is the MCP connection object. NAME is the name of the tool to call. ARGGUMENTS is a list of arguments to pass to the tool.

(defun mcp-call-tool (connection name arguments)
  "Call a tool on the remote CONNECTION with NAME and ARGUMENTS.

CONNECTION is the MCP connection object.
NAME is the name of the tool to call.
ARGGUMENTS is a list of arguments to pass to the tool."
  (jsonrpc-request connection
                   :tools/call
                   (list :name name
                         :arguments (if arguments
                                        arguments
                                      #s(hash-table)))))
