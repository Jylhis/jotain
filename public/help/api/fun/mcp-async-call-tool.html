Function: mcp-async-call-tool

mcp-async-call-tool is a natively compiled function defined in mcp.el.

Signature

(mcp-async-call-tool CONNECTION NAME ARGUMENTS CALLBACK ERROR-CALLBACK)

Documentation

Async Call a tool on the remote CONNECTION with NAME and ARGUMENTS.

CONNECTION is the MCP connection object. NAME is the name of the tool to call. ARGUMENTS is a list of arguments to pass to the tool. CALLBACK is a function to call on success. ERROR-CALLBACK is a function to call on error.

(defun mcp-async-call-tool (connection name arguments callback error-callback)
  "Async Call a tool on the remote CONNECTION with NAME and ARGUMENTS.

CONNECTION is the MCP connection object.
NAME is the name of the tool to call.
ARGUMENTS is a list of arguments to pass to the tool.
CALLBACK is a function to call on success.
ERROR-CALLBACK is a function to call on error."
  (jsonrpc-async-request connection
                         :tools/call
                         (list :name name
                               :arguments (if arguments
                                              arguments
                                            #s(hash-table)))
                         :timeout (mcp--timeout connection)
                         :success-fn
                         (lambda (res)
                           (funcall callback res))
                         :error-fn
                         (jsonrpc-lambda (&key code message _data)
                           (funcall error-callback code message))))
