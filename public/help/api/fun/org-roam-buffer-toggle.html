Function: org-roam-buffer-toggle

org-roam-buffer-toggle is an interactive and natively compiled function defined in org-roam-mode.el.

Signature

(org-roam-buffer-toggle)

Documentation

Toggle display of the persistent org-roam-buffer(var)/org-roam-buffer(fun).

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/qfyfp7k8wj4czdja2mlsqxrhlx7mvj76-emacs-packages-deps/share/emacs/site-lisp/elpa/org-roam-20260425.1623/org-roam-mode.el
(defun org-roam-buffer-toggle ()
  "Toggle display of the persistent `org-roam-buffer'."
  (interactive)
  (pcase (org-roam-buffer--visibility)
    ('visible
     (progn
       (quit-window nil (get-buffer-window org-roam-buffer))
       (remove-hook 'post-command-hook #'org-roam-buffer--redisplay-h)))
    ((or 'exists 'none)
     (progn
       (display-buffer (get-buffer-create org-roam-buffer))
       (org-roam-buffer-persistent-redisplay)))))
