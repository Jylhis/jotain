Function: org-modern--cycle

org-modern--cycle is a natively compiled function defined in org-modern.el.

Signature

(org-modern--cycle STATE)

Documentation

Flush font-lock for buffer or line at point for org-cycle-hook.

When STATE is overview, contents, or all, flush for the whole buffer; otherwise, for the line at point.

;; Defined in /nix/store/c2c3l8drcnybmya5zjrxb6fifrfpi1c0-emacs-packages-deps/share/emacs/site-lisp/elpa/org-modern-20260722.1411/org-modern.el
(defun org-modern--cycle (state)
  "Flush font-lock for buffer or line at point for `org-cycle-hook'.
When STATE is `overview', `contents', or `all', flush for the
whole buffer; otherwise, for the line at point."
  (pcase state
    ((or 'overview 'contents 'all) (font-lock-flush))
    (_ (font-lock-flush (pos-bol) (pos-eol)))))
