Function: super-save-remove-advice-from-trigger-commands

super-save-remove-advice-from-trigger-commands is a natively compiled function defined in super-save.el.

Signature

(super-save-remove-advice-from-trigger-commands)

Documentation

Remove super-save advice from the commands listed in super-save-triggers.

;; Defined in /nix/store/wqk38r7f0ly8xacdb8fb4xzdq0iqx7lz-emacs-packages-deps/share/emacs/site-lisp/elpa/super-save-20260318.1214/super-save.el
(defun super-save-remove-advice-from-trigger-commands ()
  "Remove super-save advice from the commands listed in `super-save-triggers'."
  (mapc
   (lambda (command)
     (advice-remove command #'super-save-command-advice))
   super-save-triggers))
