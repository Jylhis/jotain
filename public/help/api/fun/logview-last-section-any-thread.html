Function: logview-last-section-any-thread

logview-last-section-any-thread is an interactive and natively compiled function defined in logview.el.

Signature

(logview-last-section-any-thread &optional SET-VIEW-IF-NEEDED)

Documentation

Move point to the last (visible) section regardless of thread.

This is like logview-last-section, only temporary pretending that sections are not thread-bound.

Key Bindings

logview-mode-map c >

;; Defined in /nix/store/qid656ql5mh048bd0k84vvsbc2517lh9-emacs-packages-deps/share/emacs/site-lisp/elpa/logview-20260218.2013/logview.el
(defun logview-last-section-any-thread (&optional set-view-if-needed)
  "Move point to the last (visible) section regardless of thread.
This is like `logview-last-section', only temporary pretending
that sections are not thread-bound."
  ;; The "p" is only needed so that SET-VIEW-IF-NEEDED is non-nil when called
  ;; interactively.
  (interactive "p")
  (let ((logview--sections-thread-bound nil))
    (logview-last-section set-view-if-needed)))
