Function: ghostel-paste

ghostel-paste is an interactive and natively compiled function defined in ghostel.el.

Signature

(ghostel-paste)

Documentation

Paste text from the Emacs kill ring into the terminal.

Uses bracketed paste mode so that shells can distinguish pasted text from typed input.

Key Bindings

ghostel-mode-map C-c C-y

;; Defined in /nix/store/1jkgkg7y6y6hp0xia3dsmcl5zaj0bnhq-emacs-packages-deps/share/emacs/site-lisp/ghostel.el
(defun ghostel-paste ()
  "Paste text from the Emacs kill ring into the terminal.
Uses bracketed paste mode so that shells can distinguish
pasted text from typed input."
  (interactive)
  (ghostel--on-user-input)
  (ghostel--paste-text (current-kill 0)))
