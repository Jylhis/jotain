Function: majutsu-split-option-child-p

majutsu-split-option-child-p is a function alias for majutsu-split-option--eieio-childp, defined in majutsu-split.el.

This function is obsolete since 25.1; use (cl-typep ... 'majutsu-split-option) instead

Signature

(majutsu-split-option-child-p OBJ)

Documentation

Return non-nil if OBJ is an object of type majutsu-split-option(var)/majutsu-split-option(fun) or a subclass.

Aliases

majutsu-split-option--eieio-childp
