Function: majutsu

majutsu is a function alias and interactive for majutsu-log, defined in majutsu-log.el.

Signature

(majutsu &optional ARG1)

Documentation

Begin using Majutsu.

This alias for majutsu-log exists for better discoverability.

Instead of invoking this alias for majutsu-log using
"M-x majutsu RET", you should bind a key to majutsu-log.

Key Bindings

This command is not in any keymaps.

Aliases

majutsu-log
