Function: docker-compose-mode

docker-compose-mode is an interactive and natively compiled function defined in docker-compose-mode.el.

Signature

(docker-compose-mode)

Documentation

Major mode to edit docker-compose files.

In addition to any hooks its parent mode yaml-mode might have run, this mode runs the hook docker-compose-mode-hook, as the final or penultimate step during initialization.

Key Bindings

This command is not in any keymaps.
