Function: haskell-cabal-guess-setting

haskell-cabal-guess-setting is a function alias and interactive for haskell-cabal-get-field, defined in haskell-cabal.el.

This command is obsolete since March 14, 2016; use haskell-cabal-get-field instead.

Signature

(haskell-cabal-guess-setting ARG1)

Documentation

Read the value of field with NAME from project's cabal file.

Obsolete function. Defined for backward compatibility. Use haskell-cabal-get-field instead.
