Function: pdf-view-reset-slice

pdf-view-reset-slice is an interactive and natively compiled function defined in pdf-view.el.

Signature

(pdf-view-reset-slice &optional WINDOW)

Documentation

Reset the current slice and redisplay WINDOW.

WINDOW defaults to selected-window if not provided.

After calling this function the whole page will be visible again.

Key Bindings

pdf-view-mode-map s r

(defun pdf-view-reset-slice (&optional window)
  "Reset the current slice and redisplay WINDOW.

WINDOW defaults to `selected-window' if not provided.

After calling this function the whole page will be visible
again."
  (interactive)
  (when (pdf-view-current-slice window)
    (setf (pdf-view-current-slice window) nil)
    (pdf-view-redisplay window))
  nil)
