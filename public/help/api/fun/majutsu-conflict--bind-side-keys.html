Function: majutsu-conflict--bind-side-keys

majutsu-conflict--bind-side-keys is a natively compiled function defined in majutsu-conflict.el.

Signature

(majutsu-conflict--bind-side-keys MAP PREFIX BEFORE)

Documentation

Bind PREFIX 1-9 in MAP to conflict side commands.

When BEFORE is non-nil, keep the before side.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-conflict.el
(defun majutsu-conflict--bind-side-keys (map prefix before)
  "Bind PREFIX 1-9 in MAP to conflict side commands.
When BEFORE is non-nil, keep the before side."
  (dotimes (i 9)
    (let ((n (1+ i)))
      (keymap-set map (format "%s%d" prefix n)
                  (lambda () (interactive)
                    (majutsu-conflict-keep-side n before))))))
