Function: terraform--get-resource-provider-source-in-buffer

terraform--get-resource-provider-source-in-buffer is a natively compiled function defined in terraform-mode.el.

Signature

(terraform--get-resource-provider-source-in-buffer PROVIDER)

Documentation

Search and return provider namespace for PROVIDER in current buffer.

Return nil if not found.

Source Code

;; Defined in /nix/store/4nxqp4jvms3n4azp2x2snypnn6xcgq9g-emacs-packages-deps/share/emacs/site-lisp/elpa/terraform-mode-20251115.2210/terraform-mode.el
(defun terraform--get-resource-provider-source-in-buffer (provider)
  "Search and return provider namespace for PROVIDER in current buffer.
Return nil if not found."
  (goto-char (point-min))
  (if (and (re-search-forward "^terraform[[:blank:]]*{" nil t)
           (re-search-forward "^[[:blank:]]*required_providers[[:blank:]]*{" nil t)
           (re-search-forward (concat "^[[:blank:]]*" provider "[[:blank:]]*=[[:blank:]]*{") nil t)
           (re-search-forward "^[[:blank:]]*source[[:blank:]]*=[[:blank:]]*\"\\([a-z/]+\\)\"" nil t))
      (match-string 1)))
