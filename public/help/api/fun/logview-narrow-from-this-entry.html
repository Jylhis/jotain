Function: logview-narrow-from-this-entry

logview-narrow-from-this-entry is an interactive and natively compiled function defined in logview.el.

Signature

(logview-narrow-from-this-entry &optional N)

Documentation

Narrow the buffer so that previous log entries are hidden.

If invoked interactively with a prefix argument, leave that many entries above the current visible after narrowing. As an exception to the standard numeric prefix value conventions, here no prefix means zero.

;;; Narrowing/widening commands.

(defun logview-narrow-from-this-entry (&optional n)
  "Narrow the buffer so that previous log entries are hidden.
If invoked interactively with a prefix argument, leave that many
entries above the current visible after narrowing.  As an
exception to the standard numeric prefix value conventions, here
no prefix means zero."
  (interactive (list (when current-prefix-arg
                       (prefix-numeric-value current-prefix-arg))))
  (logview--do-narrow-one-side t n))
