Function: neocaml--defun-valid-p

neocaml--defun-valid-p is a natively compiled function defined in neocaml.el.

Signature

(neocaml--defun-valid-p NODE)

Documentation

Return non-nil if NODE is a top-level definition.

Filters out nodes nested inside let_expression, parenthesized_module_expression, or package_expression.

;; Defined in /nix/store/6yvzbjq5ljnchx97n8s5w91crk1nh47b-emacs-packages-deps/share/emacs/site-lisp/elpa/neocaml-20260710.532/neocaml.el
(defun neocaml--defun-valid-p (node)
  "Return non-nil if NODE is a top-level definition.
Filters out nodes nested inside `let_expression',
`parenthesized_module_expression', or `package_expression'."
  (and (treesit-node-check node 'named)
       (not (treesit-node-top-level
             node neocaml--nested-context-regexp))))
