Function: dockerfile-standard-filename

dockerfile-standard-filename is a natively compiled function defined in dockerfile-mode.el.

Signature

(dockerfile-standard-filename FILE)

Documentation

Convert the FILE name to OS standard.

If in Cygwin environment, uses Cygwin specific function to convert the file name. Otherwise, uses Emacs' standard conversion function.

Source Code

;; Defined in /nix/store/r1ar6k5jqxvw9mv0g6rq6h6hk8j9zhli-emacs-packages-deps/share/emacs/site-lisp/elpa/dockerfile-mode-20251221.1644/dockerfile-mode.el
(defun dockerfile-standard-filename (file)
  "Convert the FILE name to OS standard.
If in Cygwin environment, uses Cygwin specific function to convert the
file name.  Otherwise, uses Emacs' standard conversion function."
  (if (fboundp 'cygwin-convert-file-name-to-windows)
      (replace-regexp-in-string
       (rx "\\") "\\\\" (cygwin-convert-file-name-to-windows file) t t)
    (convert-standard-filename file)))
