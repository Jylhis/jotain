Function: logview-widen

logview-widen is an interactive and natively compiled function defined in logview.el.

Signature

(logview-widen)

Documentation

Remove narrowing, including thread narrowing, from current buffer.

Narrowing to section headers is canceled as well.

Key Bindings

logview-mode-map w

;; Defined in /nix/store/qid656ql5mh048bd0k84vvsbc2517lh9-emacs-packages-deps/share/emacs/site-lisp/elpa/logview-20260218.2013/logview.el
(defun logview-widen ()
  "Remove narrowing, including thread narrowing, from current buffer.
Narrowing to section headers is canceled as well."
  (interactive)
  (logview--assert)
  (widen)
  (setf logview--thread-narrowing-filter-text ""
        logview--narrow-to-section-headers    nil)
  (logview--parse-filters))
