Function: gptel--parse-response

gptel--parse-response is a byte-compiled function defined in gptel-request.el.

Signature

(gptel--parse-response BACKEND RESPONSE PROC-INFO)

Documentation

Response extractor for LLM requests.

BACKEND is the LLM backend in use.

RESPONSE is the parsed JSON of the response, as a plist.

PROC-INFO is a plist with process information and other context. See gptel-curl--get-response for its contents.
