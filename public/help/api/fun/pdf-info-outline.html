Function: pdf-info-outline

pdf-info-outline is a natively compiled function defined in pdf-info.el.

Signature

(pdf-info-outline &optional FILE-OR-BUFFER)

Documentation

Return the PDF outline of document FILE-OR-BUFFER.

This function returns a list of alists like pdf-info-pagelinks. Additionally every alist has a DEPTH (>= 1) entry with the depth of this element in the tree.

(defun pdf-info-outline (&optional file-or-buffer)
  "Return the PDF outline of document FILE-OR-BUFFER.

This function returns a list of alists like `pdf-info-pagelinks'.
Additionally every alist has a DEPTH (>= 1) entry with the depth
of this element in the tree."

  (pdf-info-query
   'outline
   (pdf-info--normalize-file-or-buffer file-or-buffer)))
