Function: helpful--keymaps-containing-aliases

helpful--keymaps-containing-aliases is a natively compiled function defined in helpful.el.

(helpful--keymaps-containing-aliases COMMAND-SYM ALIASES)

Documentation

Return a list of pairs mapping keymap symbols to the keybindings for COMMAND-SYM in each keymap.

Includes keybindings for aliases, unlike helpful--keymaps-containing.

(defun helpful--keymaps-containing-aliases (command-sym aliases)
  "Return a list of pairs mapping keymap symbols to the
keybindings for COMMAND-SYM in each keymap.

Includes keybindings for aliases, unlike
`helpful--keymaps-containing'."
  (let* ((syms (cons command-sym aliases))
         (syms-keymaps (-map #'helpful--keymaps-containing syms)))
    (-reduce #'helpful--merge-alists syms-keymaps)))
