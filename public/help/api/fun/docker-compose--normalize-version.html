Function: docker-compose--normalize-version

docker-compose--normalize-version is a natively compiled function defined in docker-compose-mode.el.

Signature

(docker-compose--normalize-version VERSION)

Documentation

Normalize VERSION to conform to <major>.<minor>.

(defun docker-compose--normalize-version (version)
  "Normalize VERSION to conform to <major>.<minor>."
  (if (string-match-p "^[0-9]$" version)
      (concat version ".0")
    version))
