Function: markdown-complete

markdown-complete is an interactive and natively compiled function defined in markdown-mode.el.

Signature

(markdown-complete)

Documentation

Complete markup of object near point or in region when active.

Handle all objects in markdown-complete-alist, in order. See markdown-complete-at-point and markdown-complete-region.

Key Bindings

markdown-mode-map C-c C-]

(defun markdown-complete ()
  "Complete markup of object near point or in region when active.
Handle all objects in `markdown-complete-alist', in order.
See `markdown-complete-at-point' and `markdown-complete-region'."
  (interactive "*")
  (if (use-region-p)
      (markdown-complete-region (region-beginning) (region-end))
    (markdown-complete-at-point)))
