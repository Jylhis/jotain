Function: majutsu-log--entry-column

majutsu-log--entry-column is a natively compiled function defined in majutsu-log.el.

Signature

(majutsu-log--entry-column ENTRY FIELD)

Documentation

Return canonical value for FIELD stored on ENTRY.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-log.el
(defun majutsu-log--entry-column (entry field)
  "Return canonical value for FIELD stored on ENTRY."
  (alist-get field (plist-get entry :columns) nil nil #'eq))
