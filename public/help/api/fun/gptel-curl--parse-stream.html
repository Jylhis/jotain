Function: gptel-curl--parse-stream

gptel-curl--parse-stream is a byte-compiled function defined in gptel-request.el.

Signature

(gptel-curl--parse-stream BACKEND PROC-INFO)

Documentation

Stream parser for gptel-curl.

Implementations of this function run as part of the process filter for the active query, and return partial responses from the LLM.

BACKEND is the LLM backend in use.

PROC-INFO is a plist with process information and other context. See gptel-curl--get-response for its contents.
