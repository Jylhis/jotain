Function: majutsu-template--normalize-call-name

majutsu-template--normalize-call-name is a natively compiled function defined in majutsu-template.el.

Signature

(majutsu-template--normalize-call-name NAME)

Documentation

Return template function name string derived from NAME.

NAME may be a symbol, keyword, string, or a quoted symbol form.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-template.el
(defun majutsu-template--normalize-call-name (name)
  "Return template function name string derived from NAME.
NAME may be a symbol, keyword, string, or a quoted symbol form."
  (cond
   ((and (consp name) (eq (car name) 'quote))
    (majutsu-template--symbol->template-name (cadr name)))
   ((symbolp name) (majutsu-template--symbol->template-name name))
   ((stringp name) name)
   (t (user-error "majutsu-template: unsupported call name %S" name))))
