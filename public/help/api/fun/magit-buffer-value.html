Function: magit-buffer-value

magit-buffer-value is a byte-compiled function defined in magit-mode.el.

Signature

(magit-buffer-value)

Documentation

Return the value of the current buffer.

The "value" identifies what is being displayed in the buffer. The buffer's major-mode should derive from magit-section-mode.
