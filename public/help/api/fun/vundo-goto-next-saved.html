Function: vundo-goto-next-saved

vundo-goto-next-saved is an interactive and natively compiled function defined in vundo.el.

Signature

(vundo-goto-next-saved ARG)

Documentation

Go to the ARGth saved node after the current node (default 1).

For ARG<0, got the last saved node prior to the current node.

Key Bindings

vundo-mode-map r

Source Code

;; Defined in /nix/store/7c2696v2qdrdv2vf2im8alazibi7qq0z-emacs-packages-deps/share/emacs/site-lisp/elpa/vundo-2.4.0/vundo.el
(defun vundo-goto-next-saved (arg)
  "Go to the ARGth saved node after the current node (default 1).
For ARG<0, got the last saved node prior to the current node."
  (interactive "p")
  (vundo-goto-last-saved (- arg)))
