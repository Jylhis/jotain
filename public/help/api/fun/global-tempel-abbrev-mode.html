Function: global-tempel-abbrev-mode

global-tempel-abbrev-mode is an interactive and natively compiled function defined in tempel.el.

Signature

(global-tempel-abbrev-mode &optional ARG)

Documentation

Toggle Tempel-Abbrev mode in many buffers.

Specifically, Tempel-Abbrev mode is enabled in all buffers where tempel--abbrev-on would do it.

With prefix ARG, enable Global Tempel-Abbrev mode if ARG is positive; otherwise, disable it.

If called from Lisp, toggle the mode if ARG is toggle. Enable the mode if ARG is nil, omitted, or is a positive number. Disable the mode if ARG is a negative number.

See tempel-abbrev-mode(var)/tempel-abbrev-mode(fun) for more information on Tempel-Abbrev mode.

Key Bindings

This command is not in any keymaps.
