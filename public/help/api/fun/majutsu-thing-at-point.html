Function: majutsu-thing-at-point

majutsu-thing-at-point is a natively compiled function defined in majutsu-jj.el.

Signature

(majutsu-thing-at-point THING &optional NO-PROPERTIES)

Documentation

Return THING at point.

This thin wrapper exists so Majutsu can later extend point semantics without changing call sites.
