Function: verb--get-accept-header

verb--get-accept-header is a natively compiled function defined in verb.el.

Signature

(verb--get-accept-header HEADERS)

Documentation

Retrieve the value of the "Accept" header from alist HEADERS.

If the header is not present, return "*/*" as default.

Source Code

;; Defined in /nix/store/1vhkdxrkj0c423ijah8wn2d489dd8rgw-emacs-packages-deps/share/emacs/site-lisp/elpa/verb-20260818.1921/verb.el
(defun verb--get-accept-header (headers)
  "Retrieve the value of the \"Accept\" header from alist HEADERS.
If the header is not present, return \"*/*\" as default."
  (verb--to-ascii (or (verb-headers-get headers "Accept" t)
                      "*/*")))
