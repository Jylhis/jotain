Function: ansible-decrypt-region

ansible-decrypt-region is an interactive and natively compiled function defined in ansible.el.

Signature

(ansible-decrypt-region START END)

Documentation

Decrypt from START to END (current region).

Key Bindings

This command is not in any keymaps.

(defun ansible-decrypt-region (start end)
  "Decrypt from START to END (current region)."
  (interactive "r")
  (ansible-vault-region "decrypt" start end)
  ;; force buffer to be marked as unmodified
  (set-buffer-modified-p nil))
