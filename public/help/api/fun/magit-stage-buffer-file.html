Function: magit-stage-buffer-file

magit-stage-buffer-file is a function alias and interactive for magit-file-stage, defined in magit-files.el.

This command is obsolete since Magit 4.3.2; use magit-file-stage instead.

Signature

(magit-stage-buffer-file)

Documentation

Stage all changes to the file being visited in the current buffer.

Key Bindings

This command is not in any keymaps.

Aliases

magit-file-stage
