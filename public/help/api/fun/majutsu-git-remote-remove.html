Function: majutsu-git-remote-remove

majutsu-git-remote-remove is an interactive and natively compiled function defined in majutsu-git.el.

Signature

(majutsu-git-remote-remove)

Documentation

Remove a Git remote and forget its bookmarks.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-git.el
(defun majutsu-git-remote-remove ()
  "Remove a Git remote and forget its bookmarks."
  (interactive)
  (let* ((remote (majutsu-read-remote-name "Remove remote" t))
         (cmd-args (list "remote" "remove" remote))
         (exit (majutsu-run-jj "git" cmd-args)))
    (when (zerop exit)
      (message "Removed remote %s" remote))))
