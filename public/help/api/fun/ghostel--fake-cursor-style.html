Function: ghostel--fake-cursor-style

ghostel--fake-cursor-style is a natively compiled function defined in ghostel.el.

Signature

(ghostel--fake-cursor-style)

Documentation

Resolve cursor-in-non-selected-windows to hollow, box, or nil.

Honours the variable's full range: nil returns nil; t derives from ghostel--saved-cursor-type with box variants becoming hollow; hollow and box pass through; bar and hbar fall back to hollow.

(defun ghostel--fake-cursor-style ()
  "Resolve `cursor-in-non-selected-windows' to `hollow', `box', or nil.
Honours the variable's full range: nil returns nil; t derives
from `ghostel--saved-cursor-type' with box variants becoming
hollow; hollow and box pass through; bar and hbar fall back to
hollow."
  (pcase cursor-in-non-selected-windows
    ('nil nil)
    ('t (pcase ghostel--saved-cursor-type
          ('nil nil)
          (_ 'hollow)))
    ('hollow 'hollow)
    ((or 'box `(box . ,_)) 'box)
    (_ 'hollow)))
