Function: haskell-string-trim-suffix

haskell-string-trim-suffix is a natively compiled function defined in haskell-string.el.

Signature

(haskell-string-trim-suffix SUFFIX STR)

Documentation

If SUFFIX is suffix of STR, the string is trimmed.

;; Defined in /nix/store/ccd92nyzdf3mi6kmi2pc75azlr90xvhk-emacs-packages-deps/share/emacs/site-lisp/elpa/haskell-mode-20260829.851/haskell-string.el
(defun haskell-string-trim-suffix (suffix str)
  "If SUFFIX is suffix of STR, the string is trimmed."
  (when (and (stringp suffix)
             (stringp str))
    (if (string-suffix-p suffix str)
        (substring str 0 (* -1 (length suffix))))))
