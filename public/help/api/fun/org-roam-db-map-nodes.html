Function: org-roam-db-map-nodes

org-roam-db-map-nodes is a natively compiled function defined in org-roam-db.el.

Signature

(org-roam-db-map-nodes FNS)

Documentation

Run FNS over all nodes in the current buffer.

;; Defined in /nix/store/qfyfp7k8wj4czdja2mlsqxrhlx7mvj76-emacs-packages-deps/share/emacs/site-lisp/elpa/org-roam-20260425.1623/org-roam-db.el
(defun org-roam-db-map-nodes (fns)
  "Run FNS over all nodes in the current buffer."
  (org-with-wide-buffer
   (org-map-region
    (lambda ()
      (when (org-roam-db-node-p)
        (dolist (fn fns)
          (funcall fn))))
    (point-min) (point-max))))
