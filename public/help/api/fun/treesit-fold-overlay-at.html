Function: treesit-fold-overlay-at

treesit-fold-overlay-at is a natively compiled function defined in treesit-fold.el.

Signature

(treesit-fold-overlay-at NODE)

Documentation

Return the treesit-fold overlay at NODE if NODE is foldable and folded.

Return nil otherwise.

;; Defined in /nix/store/8bsxam5z769p2v85807qya1p1fb50bqx-emacs-packages-deps/share/emacs/site-lisp/elpa/treesit-fold-0.2.1/treesit-fold.el
(defun treesit-fold-overlay-at (node)
  "Return the treesit-fold overlay at NODE if NODE is foldable and folded.
Return nil otherwise."
  (when-let* ((range (treesit-fold--get-fold-range node)))
    (thread-last (overlays-in (car range) (cdr range))
                 (seq-filter (lambda (ov)
                               (and (eq (overlay-get ov 'invisible) 'treesit-fold)
                                    (= (overlay-start ov) (car range))
                                    (= (overlay-end ov) (cdr range)))))
                 car)))
