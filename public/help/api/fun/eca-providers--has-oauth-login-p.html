Function: eca-providers--has-oauth-login-p

eca-providers--has-oauth-login-p is a natively compiled function defined in eca-providers.el.

Signature

(eca-providers--has-oauth-login-p LOGIN-METHODS)

Documentation

Return non-nil if LOGIN-METHODS includes an OAuth or device flow.

When all methods are just API key entry, returns nil.

(defun eca-providers--has-oauth-login-p (login-methods)
  "Return non-nil if LOGIN-METHODS includes an OAuth or device flow.
When all methods are just API key entry, returns nil."
  (seq-some (lambda (m)
              (not (member (plist-get m :key) '("manual" "api-key"))))
            login-methods))
