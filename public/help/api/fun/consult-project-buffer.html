Function: consult-project-buffer

consult-project-buffer is an interactive and natively compiled function defined in consult.el.

Signature

(consult-project-buffer)

Documentation

Enhanced project-switch-to-buffer command with support for virtual buffers.

The command may prompt you for a project directory if it is invoked from outside a project. See consult-buffer for more details.

Key Bindings

This command is not in any keymaps.

outside a project.  See `consult-buffer' for more details."

  (consult--with-project
