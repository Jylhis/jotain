Function: eca-editor--lsp-workspaces-ready-p

eca-editor--lsp-workspaces-ready-p is a natively compiled function defined in eca-editor.el.

Signature

(eca-editor--lsp-workspaces-ready-p WORKSPACES)

Documentation

Return non-nil when some of WORKSPACES finished initializing.

A lsp-mode workspace only gets its server capabilities after the initialize handshake, so none having them means the server is still starting. Fails open: workspaces that cannot be inspected count as ready so the request is still attempted.

(defun eca-editor--lsp-workspaces-ready-p (workspaces)
  "Return non-nil when some of WORKSPACES finished initializing.
A lsp-mode workspace only gets its server capabilities after the
initialize handshake, so none having them means the server is
still starting.  Fails open: workspaces that cannot be inspected
count as ready so the request is still attempted."
  (seq-some (lambda (workspace)
              (condition-case nil
                  (and (lsp--workspace-server-capabilities workspace) t)
                (error t)))
            workspaces))
