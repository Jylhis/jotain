Function: org-roam-message

org-roam-message is a natively compiled function defined in org-roam-utils.el.

Signature

(org-roam-message FORMAT-STRING &rest ARGS)

Documentation

Pass FORMAT-STRING and ARGS to message when org-roam-verbose is t.

Source Code

;; Defined in /nix/store/qfyfp7k8wj4czdja2mlsqxrhlx7mvj76-emacs-packages-deps/share/emacs/site-lisp/elpa/org-roam-20260425.1623/org-roam-utils.el
(defun org-roam-message (format-string &rest args)
  "Pass FORMAT-STRING and ARGS to `message' when `org-roam-verbose' is t."
  (when org-roam-verbose
    (apply #'message `(,(concat "(org-roam) " format-string) ,@args))))
