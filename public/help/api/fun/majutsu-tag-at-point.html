Function: majutsu-tag-at-point

majutsu-tag-at-point is a natively compiled function defined in majutsu-jj.el.

Signature

(majutsu-tag-at-point)

Documentation

Return the tag name at point, or nil when none is found.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-jj.el
(defun majutsu-tag-at-point ()
  "Return the tag name at point, or nil when none is found."
  (or (magit-section-value-if 'jj-tag)
      (and (majutsu--face-at-point-p majutsu-tag-faces)
           (majutsu-thing-at-point 'jj-revision t))))
