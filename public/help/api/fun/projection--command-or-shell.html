Function: projection--command-or-shell

projection--command-or-shell is a natively compiled function defined in projection-utils.el.

Signature

(projection--command-or-shell FUNC SHELL-COMMAND)

Documentation

Generate a command function which will run either FUNC or SHELL-COMMAND.

The result is a lambda which, if FUNC is bound and interactive returns FUNC, otherwise it will return SHELL-COMMAND.

;; Shell

(defun projection--command-or-shell (func shell-command)
  "Generate a command function which will run either FUNC or SHELL-COMMAND.
The result is a lambda which, if FUNC is bound and interactive returns FUNC,
otherwise it will return SHELL-COMMAND."
  (lambda ()
    (if (commandp func)
        func
      shell-command)))
