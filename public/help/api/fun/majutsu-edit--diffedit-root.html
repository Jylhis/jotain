Function: majutsu-edit--diffedit-root

majutsu-edit--diffedit-root is a natively compiled function defined in majutsu-edit.el.

Signature

(majutsu-edit--diffedit-root FILE)

Documentation

Return diffedit root directory for FILE, or nil if none.

Detects jj diffedit temp directories by locating JJ-INSTRUCTIONS.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-edit.el
(defun majutsu-edit--diffedit-root (file)
  "Return diffedit root directory for FILE, or nil if none.
Detects jj diffedit temp directories by locating JJ-INSTRUCTIONS."
  (when file
    (locate-dominating-file (file-name-directory file) "JJ-INSTRUCTIONS")))
