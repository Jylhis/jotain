Function: haskell-indentation-list

haskell-indentation-list is a natively compiled function defined in haskell-indentation.el.

Signature

(haskell-indentation-list PARSER END SEP &optional STMT-SEP)

Documentation

Parse a list, pair or other expression containing multiple items parsed by PARSER, separated by SEP or STMT-SEP, and ending with END.

;; Defined in /nix/store/ccd92nyzdf3mi6kmi2pc75azlr90xvhk-emacs-packages-deps/share/emacs/site-lisp/elpa/haskell-mode-20260829.851/haskell-indentation.el
(defun haskell-indentation-list (parser end sep &optional stmt-sep)
  "Parse a list, pair or other expression containing multiple
items parsed by PARSER, separated by SEP or STMT-SEP, and ending
with END."
  ;; note that we use macro expansion here to preserver Emacs 23
  ;; compatibility and its lack of lexical binding
  (haskell-indentation-with-starter
   `(lambda ()
      (let ((implicit-layout-active nil))
        (haskell-indentation-separated
         #',parser ,sep ,stmt-sep)))
   end))
