Function: haskell-mode-message-line

haskell-mode-message-line is a natively compiled function defined in haskell-string.el.

Signature

(haskell-mode-message-line STR)

Documentation

Echo STR in mini-buffer.

Given string is shrinken to single line, multiple lines just disturbs the programmer.

(defun haskell-mode-message-line (str)
  "Echo STR in mini-buffer.
Given string is shrinken to single line, multiple lines just
disturbs the programmer."
  (unless (active-minibuffer-window)
    (message "%s" (haskell-mode-one-line str (frame-width)))))
