Function: breadcrumb-mode

breadcrumb-mode is an interactive and natively compiled function defined in breadcrumb.el.

Signature

(breadcrumb-mode &optional ARG)

Documentation

Toggle Breadcrumb-Local mode in many buffers.

Specifically, Breadcrumb-Local mode is enabled in all buffers where breadcrumb--turn-on-local-mode-on-behalf-of-global-mode would do it.

With prefix ARG, enable Breadcrumb mode if ARG is positive; otherwise, disable it.

If called from Lisp, toggle the mode if ARG is toggle. Enable the mode if ARG is nil, omitted, or is a positive number. Disable the mode if ARG is a negative number.

See breadcrumb-local-mode(var)/breadcrumb-local-mode(fun) for more information on Breadcrumb-Local mode.

Key Bindings

This command is not in any keymaps.
