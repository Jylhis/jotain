Function: pdf-util-scale-points-to-relative

pdf-util-scale-points-to-relative is a natively compiled function defined in pdf-util.el.

Signature

(pdf-util-scale-points-to-relative LIST-OF-POINTS-EDGES &optional ROUNDING-FN WINDOW)

Documentation

Scale LIST-OF-POINTS-EDGES to relative values.

See also pdf-util-scale.

(defun pdf-util-scale-points-to-relative (list-of-points-edges
                                          &optional rounding-fn window)
  "Scale LIST-OF-POINTS-EDGES to relative values.

See also `pdf-util-scale'."
  (pdf-util-assert-pdf-window window)
  (pdf-util-scale-to
   list-of-points-edges
   (pdf-cache-pagesize (pdf-view-current-page window))
   '(1.0 . 1.0)
   rounding-fn))
