Function: org-roam-ref-remove

org-roam-ref-remove is an interactive and natively compiled function defined in org-roam-node.el.

Signature

(org-roam-ref-remove &optional REF)

Documentation

Remove a REF from the node at point.

Key Bindings

This command is not in any keymaps.

;; Defined in /nix/store/qfyfp7k8wj4czdja2mlsqxrhlx7mvj76-emacs-packages-deps/share/emacs/site-lisp/elpa/org-roam-20260425.1623/org-roam-node.el
(defun org-roam-ref-remove (&optional ref)
  "Remove a REF from the node at point."
  (interactive)
  (let ((node (org-roam-node-at-point 'assert)))
    (save-excursion
      (goto-char (org-roam-node-point node))
      (org-roam-property-remove "ROAM_REFS" ref))))
