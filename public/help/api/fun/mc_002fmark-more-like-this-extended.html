Function: mc/mark-more-like-this-extended

mc/mark-more-like-this-extended is an interactive and natively compiled function defined in mc-mark-more.el.

Signature

(mc/mark-more-like-this-extended)

Documentation

Like mark-more-like-this, but then lets you adjust with arrow keys.

The adjustments work like this:

   <up> Mark previous like this and set direction to 'up
   <down> Mark next like this and set direction to 'down

If direction is 'up:

   <left> Skip past the cursor furthest up
   <right> Remove the cursor furthest up

If direction is 'down:

   <left> Remove the cursor furthest down
   <right> Skip past the cursor furthest down

The bindings for these commands can be changed. See mc/mark-more-like-this-extended-keymap.

Key Bindings

This command is not in any keymaps.
