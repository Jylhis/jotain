Function: eca-chat-inline--select-setting

eca-chat-inline--select-setting is a natively compiled function defined in eca-chat-inline.el.

Signature

(eca-chat-inline--select-setting PROMPT CURRENT OPTIONS)

Documentation

Read via completion one of OPTIONS for the setting named PROMPT.

CURRENT is shown in the prompt; empty input returns nil, meaning the server decides.

(defun eca-chat-inline--select-setting (prompt current options)
  "Read via completion one of OPTIONS for the setting named PROMPT.
CURRENT is shown in the prompt; empty input returns nil, meaning
the server decides."
  (let ((choice (string-trim
                 (completing-read
                  (format "%s (current: %s, empty for server default): "
                          prompt (or current "server default"))
                  (append options nil)))))
    (unless (string-empty-p choice) choice)))
