Function: ghostel--identity-equal

ghostel--identity-equal is a natively compiled function defined in ghostel.el.

Signature

(ghostel--identity-equal A B)

Documentation

Return non-nil when identities A and B contain the same pairs.

Source Code

;; Defined in /nix/store/1jkgkg7y6y6hp0xia3dsmcl5zaj0bnhq-emacs-packages-deps/share/emacs/site-lisp/ghostel.el
(defun ghostel--identity-equal (a b)
  "Return non-nil when identities A and B contain the same pairs."
  (equal (ghostel--identity-normalize a) (ghostel--identity-normalize b)))
