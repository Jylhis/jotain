Function: gnuplot--in-comment

gnuplot--in-comment is a natively compiled function defined in gnuplot.el.

Signature

(gnuplot--in-comment &optional WHERE)

Documentation

Return non-nil if the text at WHERE is within a comment.

If WHERE is omitted, defaults to text at point. This is a simple wrapper for syntax-ppss.

(defun gnuplot--in-comment (&optional where)
  "Return non-nil if the text at WHERE is within a comment.

If WHERE is omitted, defaults to text at point.
This is a simple wrapper for `syntax-ppss'."
  (save-excursion
    (let ((parse-state (syntax-ppss where)))
      (nth 4 parse-state))))
