Function: vc-jj--process-lines

vc-jj--process-lines is a natively compiled function defined in vc-jj.el.

Signature

(vc-jj--process-lines &rest ARGS)

Documentation

Run jj with ARGS, returning its output to stdout as a list of strings.

In contrast to process-lines, discard output to stderr since jj prints warnings to stderr even when run with '--quiet'.

(defun vc-jj--process-lines (&rest args)
  "Run jj with ARGS, returning its output to stdout as a list of strings.
In contrast to `process-lines', discard output to stderr since jj prints
warnings to stderr even when run with '--quiet'."
  (with-temp-buffer
    (let ((status (apply #'call-process vc-jj-program nil
                         ;; (current-buffer)
                         (list (current-buffer) nil)
                         nil args)))
      (unless (eq status 0)
        (error "'jj' exited with status %s" status))
      (goto-char (point-min))
      (let (lines)
        (while (not (eobp))
          (setq lines (cons (buffer-substring-no-properties
                             (line-beginning-position)
                             (line-end-position))
                            lines))
          (forward-line 1))
        (nreverse lines)))))
