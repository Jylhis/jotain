Function: majutsu-jjdescription--change-id

majutsu-jjdescription--change-id is a natively compiled function defined in majutsu-jjdescription.el.

Signature

(majutsu-jjdescription--change-id)

Documentation

Return the first JJ Change ID in the current buffer, or nil.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-jjdescription.el
(defun majutsu-jjdescription--change-id ()
  "Return the first JJ Change ID in the current buffer, or nil."
  (save-excursion
    (goto-char (point-min))
    (when (re-search-forward (majutsu-jjdescription--change-id-line-re) nil t)
      (string-trim (match-string-no-properties 2)))))
