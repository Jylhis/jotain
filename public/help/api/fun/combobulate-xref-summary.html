Function: combobulate-xref-summary

combobulate-xref-summary is a natively compiled function defined in combobulate-query.el.

Signature

(combobulate-xref-summary NODE)

Documentation

Build a summary for NODE.

Combobulate will seek out parents of NODE until it finds a node that exceeds a single line of text in the target buffer.

That node's text is then truncated to 100 characters.

;; Defined in /nix/store/9y0jasyzsqjcbfkwqsgdyxcnskjnsypg-emacs-packages-deps/share/emacs/site-lisp/combobulate-query.el
(defun combobulate-xref-summary (node)
  "Build a summary for NODE.

Combobulate will seek out parents of NODE until it finds a node
that exceeds a single line of text in the target buffer.

That node's text is then truncated to 100 characters."
  (combobulate-string-truncate
   (combobulate-node-text
    ;; Try to find the largest parent node of node that fills a single
    ;; line.
    (or (combobulate-parent-while node #'combobulate-node-occupies-single-line-p)
        node)
    t)
   100))
