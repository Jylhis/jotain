Function: clipetty-mode

clipetty-mode is an interactive and natively compiled function defined in clipetty.el.

Signature

(clipetty-mode &optional ARG)

Documentation

Minor mode to send every kill from a TTY frame to the system clipboard.

This is a minor mode. If called interactively, toggle the Clipetty mode mode. If the prefix argument is positive, enable the mode, and if it is zero or negative, disable the mode.

If called from Lisp, toggle the mode if ARG is toggle. Enable the mode if ARG is nil, omitted, or is a positive number. Disable the mode if ARG is a negative number.

To check whether the minor mode is enabled in the current buffer, evaluate the variable clipetty-mode(var)/clipetty-mode(fun).

The mode's hook is called both when the mode is enabled and when it is disabled.

Key Bindings

This command is not in any keymaps.

(define-minor-mode clipetty-mode
  "Minor mode to send every kill from a TTY frame to the system clipboard."
  :lighter " Clp"
  :init-value nil
  :global nil
  (if clipetty-mode
      (add-function :around (local 'interprogram-cut-function) #'clipetty-cut)
    (remove-function (local 'interprogram-cut-function) #'clipetty-cut)))
