Function: indent-bars--style

indent-bars--style is a natively compiled function defined in indent-bars.el.

Signature

(indent-bars--style STYLE NAME)

Documentation

Return the value of style variable NAME for STYLE.

Determines variables to use based on the style tag. For style variable values of the form (inherit|no-inherit . plist), inheritance of the plist is handled. If style is the symbol any, return the first non-nil value for all styles in indent-bars--styles.

(defun indent-bars--style (style name)
  "Return the value of style variable NAME for STYLE.
Determines variables to use based on the style tag.  For style
variable values of the form (`inherit'|`no-inherit' . plist),
inheritance of the plist is handled.  If style is the symbol
`any', return the first non-nil value for all styles in
`indent-bars--styles'."
  (if (eq style 'any)
      (cl-some (lambda (s) (indent-bars--style1 s name))
	       indent-bars--styles)
    (indent-bars--style1 style name)))
