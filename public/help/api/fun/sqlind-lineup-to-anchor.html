Function: sqlind-lineup-to-anchor

sqlind-lineup-to-anchor is a natively compiled function defined in sql-indent.el.

Signature

(sqlind-lineup-to-anchor SYNTAX BASE-INDENTATION)

Documentation

Return the column of the anchor point of SYNTAX.

This need not be the indentation of the actual line that contains anchor.

Source Code

;; Defined in /nix/store/vgm6xb2iy00bs19rdw9z3nfi5nf8g873-emacs-packages-deps/share/emacs/site-lisp/elpa/sql-indent-1.7/sql-indent.el
(defun sqlind-lineup-to-anchor (syntax _base-indentation)
  "Return the column of the anchor point of SYNTAX.
This need not be the indentation of the actual line that contains
anchor."
  (save-excursion
    (goto-char (sqlind-anchor-point syntax))
    (current-column)))
