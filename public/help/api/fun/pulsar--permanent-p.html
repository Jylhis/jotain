Function: pulsar--permanent-p

pulsar--permanent-p is a natively compiled function defined in pulsar.el.

Signature

(pulsar--permanent-p LOCUS)

Documentation

Return overlays if LOCUS has overlays with pulsar-permanent property.

LOCUS is a cons cell with two buffer positions.

Source Code

;; Defined in /nix/store/5ghc3mrk9n5sq5kqfx4pb127z2bixa2f-emacs-packages-deps/share/emacs/site-lisp/elpa/pulsar-1.4.1/pulsar.el
(defun pulsar--permanent-p (locus)
  "Return overlays if LOCUS has overlays with `pulsar-permanent' property.
LOCUS is a cons cell with two buffer positions."
  (seq-filter
   (lambda (overlay)
     (overlay-get overlay 'pulsar-permanent))
   (overlays-in (car locus) (cdr locus))))
