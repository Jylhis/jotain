Function: embark--descriptive-buffer-name

embark--descriptive-buffer-name is a natively compiled function defined in embark.el.

Signature

(embark--descriptive-buffer-name TYPE)

Documentation

Return a descriptive name for an Embark collect or export buffer.

TYPE should be either collect or export.

Source Code

;; Defined in /nix/store/fs4fhphi5ajjmvzx1rm550ibr8slmvxd-emacs-packages-deps/share/emacs/site-lisp/elpa/embark-20260610.302/embark.el
(defun embark--descriptive-buffer-name (type)
  "Return a descriptive name for an Embark collect or export buffer.
TYPE should be either `collect' or `export'."
  (format "*Embark %s: %s*"
          (capitalize (symbol-name type))
          (if (minibufferp)
              (format "%s - %s" embark--command
                      (minibuffer-contents-no-properties))
            (buffer-name))))
