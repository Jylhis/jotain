Function: dtrt-indent-global-mode

dtrt-indent-global-mode is an interactive and natively compiled function defined in dtrt-indent.el.

Signature

(dtrt-indent-global-mode &optional ARG)

Documentation

Toggle Dtrt-Indent mode in many buffers.

Specifically, Dtrt-Indent mode is enabled in all buffers where
(lambda nil (dtrt-indent-mode 1)) would do it.

With prefix ARG, enable Dtrt-Indent-Global mode if ARG is positive; otherwise, disable it.

If called from Lisp, toggle the mode if ARG is toggle. Enable the mode if ARG is nil, omitted, or is a positive number. Disable the mode if ARG is a negative number.

See dtrt-indent-mode(var)/dtrt-indent-mode(fun) for more information on Dtrt-Indent mode.

dtrt-indent-global-modes is used to control which modes this minor mode is used in.

Key Bindings

This command is not in any keymaps.
