Function: combobulate-envelope-get-register

combobulate-envelope-get-register is a natively compiled function defined in combobulate-envelope.el.

Signature

(combobulate-envelope-get-register REGISTER &optional DEFAULT)

Documentation

Retrieve the value of REGISTER from combobulate-envelope--registers.

If the register does not exist, return DEFAULT or nil.

Source Code

;; Defined in /nix/store/9y0jasyzsqjcbfkwqsgdyxcnskjnsypg-emacs-packages-deps/share/emacs/site-lisp/combobulate-envelope.el
(defun combobulate-envelope-get-register (register &optional default)
  "Retrieve the value of REGISTER from `combobulate-envelope--registers'.

If the register does not exist, return DEFAULT or nil."
  (map-elt combobulate-envelope--registers register default))
