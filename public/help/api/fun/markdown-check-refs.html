Function: markdown-check-refs

markdown-check-refs is an interactive and natively compiled function defined in markdown-mode.el.

Signature

(markdown-check-refs &optional SILENT)

Documentation

Show all undefined Markdown references in current markdown-mode buffer.

Links which have empty reference definitions are considered to be defined.

If SILENT is non-nil, do not message anything when no such references found.

markdown-mode-command-map c markdown-mode-map C-c C-c c
