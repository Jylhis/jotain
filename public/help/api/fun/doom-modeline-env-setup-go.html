Function: doom-modeline-env-setup-go

doom-modeline-env-setup-go is a byte-compiled function defined in doom-modeline-env.el.

Signature

(doom-modeline-env-setup-go)

Documentation

Prepares the modeline to later display the go version string.

Source Code

;; Defined in /nix/store/mxkjlhf33q1xxjiii3w5v8nn7avms0p9-emacs-packages-deps/share/emacs/site-lisp/elpa/doom-modeline-20260828.1146/doom-modeline-env.el
;;;###autoload (autoload 'doom-modeline-env-setup-go "doom-modeline-env")
(doom-modeline-def-env go
  :hooks   '(go-mode-hook go-ts-mode-hook)
  :command (lambda () (list (or doom-modeline-env-go-executable "go") "version"))
  :parser  (lambda (line)
             (cadr
              (split-string
               (cadr
                (cdr
                 (split-string line)))
               "go"))))
