Function: bazeliskrc-mode

bazeliskrc-mode is an interactive and natively compiled function defined in bazel.el.

Signature

(bazeliskrc-mode)

Documentation

Major mode derived from conf-unix-mode by define-derived-mode.

It inherits all of the parent's attributes, but has its own keymap, abbrev table and syntax table:

  bazeliskrc-mode-map, bazeliskrc-mode-abbrev-table and
bazeliskrc-mode-syntax-table

which more-or-less shadow conf-unix-mode's corresponding tables.

In addition to any hooks its parent mode might have run, this mode runs the hook bazeliskrc-mode-hook, as the final or penultimate step during initialization.

Key Bindings

This command is not in any keymaps.
