Function: gptel--parse-buffer

gptel--parse-buffer is a byte-compiled function defined in gptel-request.el.

Signature

(gptel--parse-buffer BACKEND MAX-ENTRIES)

Documentation

Parse current buffer backwards from point and return a list of prompts.

BACKEND is the LLM backend in use.

MAX-ENTRIES is the number of queries/responses to include for contexbt.
