Function: haskell-mode-kill-scc-at-point

haskell-mode-kill-scc-at-point is an interactive and natively compiled function defined in haskell-mode.el.

This command is obsolete since 2015-11-11; use haskell-mode-toggle-scc-at-point instead.

Signature

(haskell-mode-kill-scc-at-point)

Documentation

Kill the SCC annotation at point.

Key Bindings

This command is not in any keymaps.

(defun haskell-mode-kill-scc-at-point ()
  "Kill the SCC annotation at point."
  (interactive)
  (if (not (haskell-mode-try-kill-scc-at-point))
      (error "No SCC at point")))
