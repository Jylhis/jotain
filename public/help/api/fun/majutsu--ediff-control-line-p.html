Function: majutsu--ediff-control-line-p

majutsu--ediff-control-line-p is a natively compiled function defined in majutsu-process.el.

Signature

(majutsu--ediff-control-line-p LINE)

Documentation

Return non-nil when LINE is a Majutsu Ediff control packet.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-process.el
(defun majutsu--ediff-control-line-p (line)
  "Return non-nil when LINE is a Majutsu Ediff control packet."
  (string-match-p "^MAJUTSU-EDIFF: [0-9]+ \\(DIFF\\|MERGE\\) " line))
