Function: pdf-info-open

pdf-info-open is a natively compiled function defined in pdf-info.el.

Signature

(pdf-info-open &optional FILE-OR-BUFFER PASSWORD)

Documentation

Open the document FILE-OR-BUFFER using PASSWORD.

Generally, documents are opened and closed automatically on demand, so this function is rarely needed, unless a PASSWORD is set on the document.

Manually opened documents are never closed automatically.

(defun pdf-info-open (&optional file-or-buffer password)
  "Open the document FILE-OR-BUFFER using PASSWORD.

Generally, documents are opened and closed automatically on
demand, so this function is rarely needed, unless a PASSWORD is
set on the document.

Manually opened documents are never closed automatically."

  (pdf-info-query
   'open (pdf-info--normalize-file-or-buffer file-or-buffer)
   password))
