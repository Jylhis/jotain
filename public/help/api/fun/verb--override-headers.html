Function: verb--override-headers

verb--override-headers is a natively compiled function defined in verb.el.

Signature

(verb--override-headers ORIGINAL OTHER)

Documentation

Override headers alist ORIGINAL with OTHER.

Return the results in a new alist. Work using the rules described in verb-request-spec-override. Note that case is ignored when comparing header keys (names).
