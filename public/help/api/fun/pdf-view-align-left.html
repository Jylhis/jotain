Function: pdf-view-align-left

pdf-view-align-left is an interactive and natively compiled function defined in pdf-view.el.

Signature

(pdf-view-align-left)

Documentation

Align left edge of pdf with left edge of window.

Key Bindings

This command is not in any keymaps.
