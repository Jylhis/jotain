Function: combobulate-ztree-rightmost

combobulate-ztree-rightmost is a natively compiled function defined in combobulate-ztree.el.

Signature

(combobulate-ztree-rightmost LOC)

Documentation

Return the loc of the rightmost sibling of the node at this LOC.

If LOC is already the rightmost sibling, return self.

Source Code

;; Defined in /nix/store/9y0jasyzsqjcbfkwqsgdyxcnskjnsypg-emacs-packages-deps/share/emacs/site-lisp/combobulate-ztree.el
(defun combobulate-ztree-rightmost (loc)
  "Return the loc of the rightmost sibling of the node at this LOC.
If LOC is already the rightmost sibling, return self."
  (combobulate-ztree--with-loc loc (node context l r)
    (if (and context r)
        (combobulate-ztree--with-meta
         (cons (car (last r))
               (combobulate-ztree--context-assoc context
                                      ':l (combobulate-ztree--join-children l (cons node (butlast r)))
                                      ':r nil))
         (combobulate-ztree--meta loc))
      loc)))
