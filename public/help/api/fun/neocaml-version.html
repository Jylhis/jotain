Function: neocaml-version

neocaml-version is an interactive and natively compiled function defined in neocaml.el.

Signature

(neocaml-version)

Documentation

Display the current package version in the minibuffer.

Fallback to neocaml-version(var)/neocaml-version(fun) when the package version is missing. When called from other Elisp code returns the version instead of displaying it.

Key Bindings

This command is not in any keymaps.

;; Defined in /nix/store/6yvzbjq5ljnchx97n8s5w91crk1nh47b-emacs-packages-deps/share/emacs/site-lisp/elpa/neocaml-20260710.532/neocaml.el
(defun neocaml-version ()
  "Display the current package version in the minibuffer.
Fallback to `neocaml-version' when the package version is missing.
When called from other Elisp code returns the version instead of
displaying it."
  (interactive)
  (let ((pkg-version (package-get-version)))
    (if (called-interactively-p 'interactively)
        (if pkg-version
            (message "neocaml %s (package: %s)" neocaml-version pkg-version)
          (message "neocaml %s" neocaml-version))
      (or pkg-version neocaml-version))))
