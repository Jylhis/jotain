Function: denote--retrieve-files-in-xrefs

denote--retrieve-files-in-xrefs is a function alias for denote-retrieve-files-xref-query, defined in denote.el.

This function is obsolete since 4.0.0; use denote-retrieve-files-xref-query instead.

Signature

(denote--retrieve-files-in-xrefs QUERY &optional FILES-MATCHING-REGEXP)

Documentation

Return sorted, deduplicated file names with matches for QUERY in their contents.

Limit the search to text files. With optional FILES-MATCHING-REGEXP, pass it to denote-directory-files.

Aliases

denote-retrieve-files-xref-query
