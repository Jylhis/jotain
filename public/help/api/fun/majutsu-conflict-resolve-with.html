Function: majutsu-conflict-resolve-with

majutsu-conflict-resolve-with is a natively compiled function defined in majutsu-conflict.el.

Signature

(majutsu-conflict-resolve-with CONFLICT CONTENT)

Documentation

Replace CONFLICT region with CONTENT.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-conflict.el
;;; Resolution Helpers

(defun majutsu-conflict-resolve-with (conflict content)
  "Replace CONFLICT region with CONTENT."
  (save-excursion
    (delete-region (majutsu-conflict-begin-pos conflict)
                   (majutsu-conflict-end-pos conflict))
    (goto-char (majutsu-conflict-begin-pos conflict))
    (insert content)))
