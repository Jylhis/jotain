Function: apheleia--ensure-list

apheleia--ensure-list is a natively compiled function defined in apheleia-formatters.el.

Signature

(apheleia--ensure-list ARG)

Documentation

Ensure ARG is a list of length at least 1.

When ARG is not a list its turned into a list.

Source Code

(defun apheleia--ensure-list (arg)
  "Ensure ARG is a list of length at least 1.
When ARG is not a list its turned into a list."
  (if (listp arg)
      arg
    (list arg)))
