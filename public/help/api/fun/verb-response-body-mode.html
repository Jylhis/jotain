Function: verb-response-body-mode

verb-response-body-mode is an interactive and natively compiled function defined in verb.el.

Signature

(verb-response-body-mode &optional ARG)

Documentation

Minor mode for displaying an HTTP response's body.

This is a minor mode. If called interactively, toggle the Verb-Response-Body mode mode. If the prefix argument is positive, enable the mode, and if it is zero or negative, disable the mode.

If called from Lisp, toggle the mode if ARG is toggle. Enable the mode if ARG is nil, omitted, or is a positive number. Disable the mode if ARG is a negative number.

To check whether the minor mode is enabled in the current buffer, evaluate the variable verb-response-body-mode(var)/verb-response-body-mode(fun).

The mode's hook is called both when the mode is enabled and when it is disabled.

Key Bindings

This command is not in any keymaps.

(define-minor-mode verb-response-body-mode
  "Minor mode for displaying an HTTP response's body."
  :lighter " Verb[Body]"
  :group 'verb
  (if verb-response-body-mode
      (progn
        (setq header-line-format
              (verb--response-header-line-string verb-http-response))
        (when verb-auto-show-headers-buffer
          (if (eq verb-auto-show-headers-buffer 'when-empty)
              (when (zerop (oref verb-http-response body-bytes))
                (verb-toggle-show-headers))
            (verb-toggle-show-headers))))
    (setq header-line-format nil)))
