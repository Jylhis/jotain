Function: dape-info-watch-mode

dape-info-watch-mode is a natively compiled function defined in dape.el.

Signature

(dape-info-watch-mode)

Documentation

Major mode for viewing watch expressions.

In addition to any hooks its parent mode dape-info-parent-mode might have run, this mode runs the hook dape-info-watch-mode-hook, as the final or penultimate step during initialization.
