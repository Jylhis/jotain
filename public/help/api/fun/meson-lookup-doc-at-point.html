Function: meson-lookup-doc-at-point

meson-lookup-doc-at-point is a function alias, interactive and natively compiled for meson-lookup-doc, defined in meson-mode.el.

Signature

(meson-lookup-doc-at-point IDENTIFIER)

Documentation

Open Meson reference manual and find IDENTIFIER.

Return the buffer containing the reference manual. IDENTIFIER is the name of a Meson function or object as a string. Signal a user-error if the manual could not be found or does not contain IDENTIFIER.

Key Bindings

meson-mode-map <f1>

Aliases

meson-lookup-doc
