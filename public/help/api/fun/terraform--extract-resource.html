Function: terraform--extract-resource

terraform--extract-resource is a natively compiled function defined in terraform-mode.el.

Signature

(terraform--extract-resource RESOURCE-NAME)

Documentation

Return the resource associated with a RESOURCE-NAME.

Source Code

;; Defined in /nix/store/4nxqp4jvms3n4azp2x2snypnn6xcgq9g-emacs-packages-deps/share/emacs/site-lisp/elpa/terraform-mode-20251115.2210/terraform-mode.el
(defun terraform--extract-resource (resource-name)
  "Return the resource associated with a RESOURCE-NAME."
  (mapconcat #'identity (cdr (split-string resource-name "_")) "_"))
