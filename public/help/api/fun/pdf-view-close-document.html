Function: pdf-view-close-document

pdf-view-close-document is a natively compiled function defined in pdf-view.el.

Signature

(pdf-view-close-document)

Documentation

Return immediately after closing document.

This function always succeeds. See also pdf-info-close, which does not return immediately.

Source Code

;; Defined in /nix/store/wm0vc3dfi6c7pwjhcfpsnhyg4hd0b5yc-emacs-packages-deps/share/emacs/site-lisp/elpa/pdf-tools-20260102.1101/pdf-view.el
(defun pdf-view-close-document ()
  "Return immediately after closing document.

This function always succeeds.  See also `pdf-info-close', which
does not return immediately."
  (when (pdf-info-running-p)
    (let ((pdf-info-asynchronous 'ignore))
      (ignore-errors
        (pdf-info-close)))))
