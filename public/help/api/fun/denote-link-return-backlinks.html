Function: denote-link-return-backlinks

denote-link-return-backlinks is a function alias for denote-get-backlinks, defined in denote.el.

This function is obsolete since 4.1.0; use denote-get-backlinks instead.

Signature

(denote-link-return-backlinks &optional FILE)

Documentation

Return list of backlinks in current or optional FILE.

Also see denote-get-links.

Aliases

denote-get-backlinks
