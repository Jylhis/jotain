Function: majutsu--process-diffstat-command-p

majutsu--process-diffstat-command-p is a natively compiled function defined in majutsu-process.el.

Signature

(majutsu--process-diffstat-command-p ARGS)

Documentation

Return non-nil when ARGS represent a jj diff --stat command.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-process.el
(defun majutsu--process-diffstat-command-p (args)
  "Return non-nil when ARGS represent a `jj diff --stat' command."
  (and (member "diff" args)
       (member "--stat" args)))
