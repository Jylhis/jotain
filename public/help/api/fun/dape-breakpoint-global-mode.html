Function: dape-breakpoint-global-mode

dape-breakpoint-global-mode is an interactive and natively compiled function defined in dape.el.

Signature

(dape-breakpoint-global-mode &optional ARG)

Documentation

Toggle Dape-Breakpoint mode in many buffers.

Specifically, Dape-Breakpoint mode is enabled in all buffers where turn-on-dape-breakpoint-mode would do it.

With prefix ARG, enable Dape-Breakpoint-Global mode if ARG is positive; otherwise, disable it.

If called from Lisp, toggle the mode if ARG is toggle. Enable the mode if ARG is nil, omitted, or is a positive number. Disable the mode if ARG is a negative number.

See dape-breakpoint-mode(var)/dape-breakpoint-mode(fun) for more information on Dape-Breakpoint mode.

Key Bindings

This command is not in any keymaps.
