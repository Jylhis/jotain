Function: consult-eglot-embark-mode

consult-eglot-embark-mode is an interactive and natively compiled function defined in consult-eglot-embark.el.

Signature

(consult-eglot-embark-mode &optional ARG)

Documentation

Setup consult-eglot actions for embark.

This is a global minor mode. If called interactively, toggle the Consult-Eglot-Embark mode mode. If the prefix argument is positive, enable the mode, and if it is zero or negative, disable the mode.

If called from Lisp, toggle the mode if ARG is toggle. Enable the mode if ARG is nil, omitted, or is a positive number. Disable the mode if ARG is a negative number.

To check whether the minor mode is enabled in the current buffer, evaluate (default-value \=consult-eglot-embark-mode)'.

The mode's hook is called both when the mode is enabled and when it is disabled.

Key Bindings

This command is not in any keymaps.

;;;###autoload
(define-minor-mode consult-eglot-embark-mode
  "Setup `consult-eglot' actions for embark."
  :global t
  :group 'consult-eglot-embark
  (progn
    (defvar embark-default-action-overrides)
    (defvar embark-exporters-alist)

    (if consult-eglot-embark-mode
        (progn
          (setf (alist-get 'consult-eglot-symbols embark-default-action-overrides)
                #'consult-eglot-embark-goto-symbol)
          (setf (alist-get 'consult-eglot-symbols embark-exporters-alist)
                #'consult-eglot-embark-export-grep))
      (setq embark-default-action-overrides
            (assq-delete-all 'consult-eglot-symbols embark-default-action-overrides)
            embark-exporters-alist
            (assq-delete-all 'consult-eglot-symbols embark-exporters-alist)))))
