Function: indent-bars--rot

indent-bars--rot is a natively compiled function defined in indent-bars.el.

Signature

(indent-bars--rot NUM W N)

Documentation

Shift number NUM of W bits up by N bits, carrying around to the low bits.

N should be strictly less than W and the returned value will fit within W bits.

(defun indent-bars--rot (num w n)
  "Shift number NUM of W bits up by N bits, carrying around to the low bits.
N should be strictly less than W and the returned value will fit
within W bits."
  (logand (indent-bars--block w) (logior (ash num n) (ash num (- n w)))))
