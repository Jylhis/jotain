Function: majutsu-completion-payload-table

majutsu-completion-payload-table is a natively compiled function defined in majutsu-completion.el.

Signature

(majutsu-completion-payload-table PAYLOAD &optional CATEGORY)

Documentation

Return a completion table for structured PAYLOAD.

CATEGORY overrides PAYLOAD's :category when non-nil. PAYLOAD may carry standard completion metadata plus Majutsu's internal
=:annotation-suffix-function= helper key.

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-completion.el
(defun majutsu-completion-payload-table (payload &optional category)
  "Return a completion table for structured PAYLOAD.
CATEGORY overrides PAYLOAD's :category when non-nil.  PAYLOAD may carry
standard completion metadata plus Majutsu's internal
=:annotation-suffix-function= helper key."
  (completion-table-with-metadata
   (plist-get payload :candidates)
   (majutsu-completion-payload-metadata payload category)))
