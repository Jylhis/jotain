Function: eca-chat-compose-tab

eca-chat-compose-tab is an interactive and natively compiled function defined in eca-chat-compose.el.

Signature

(eca-chat-compose-tab)

Documentation

Complete the @/# mention at point, else do markdown cycling.

With point after an @context or #filepath prefix this triggers completion-at-point; anywhere else it behaves like TAB in markdown-mode.

Key Bindings

eca-chat-compose-mode-map <tab> eca-chat-compose-mode-map TAB

(defun eca-chat-compose-tab ()
  "Complete the @/# mention at point, else do markdown cycling.
With point after an @context or #filepath prefix this triggers
`completion-at-point'; anywhere else it behaves like TAB in
`markdown-mode'."
  (interactive)
  (if (eca-chat--completion-type-at-point)
      (completion-at-point)
    (call-interactively #'markdown-cycle)))
