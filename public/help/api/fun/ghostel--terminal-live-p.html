Function: ghostel--terminal-live-p

ghostel--terminal-live-p is a byte-compiled function defined in ghostel.el.

Signature

(ghostel--terminal-live-p)

Documentation

Non-nil when live output is propagated into the Emacs buffer.

False only in copy mode, which freezes the terminal entirely. Line mode keeps redrawing — the snapshot/restore path in ghostel--redraw-now preserves the user's in-progress input across the rewrite.
