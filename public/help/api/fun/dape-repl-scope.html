Function: dape-repl-scope

dape-repl-scope is a natively compiled function defined in dape.el.

Signature

(dape-repl-scope &optional INDEX)

Documentation

List variables of scope INDEX in REPL buffer.

If INDEX is non-nil parse into number and show n+1th scope.

Source Code

;; Defined in /nix/store/l2knzmz5nqc323cf0hwsi3pa45p8w61v-emacs-packages-deps/share/emacs/site-lisp/elpa/dape-0.27.1/dape.el
(defun dape-repl-scope (&optional index)
  "List variables of scope INDEX in REPL buffer.
If INDEX is non-nil parse into number and show n+1th scope."
  (dape--repl-insert-info-buffer 'dape-info-scope-mode
                                 (string-to-number (or index ""))))
