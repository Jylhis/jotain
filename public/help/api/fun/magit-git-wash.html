Function: magit-git-wash

magit-git-wash is a natively compiled function defined in magit-git.el.

Signature

(magit-git-wash WASHER &rest ARGS)

Documentation

Execute git with ARGS, inserting washed output at point.

First insert the raw output at point. If there is no output, call magit-cancel-section. Otherwise temporarily narrow the buffer to the inserted text, move to its beginning, and finally call function WASHER with ARGS as its sole argument.

If git exits with a non-zero exit status, apply the error face to the error message, instead of calling WASHER. To instead cancel the section use magit--git-wash.
