Function: combobulate-walk-tree

combobulate-walk-tree is a natively compiled function defined in combobulate-navigation.el.

Signature

(combobulate-walk-tree TREE NODE-FN &optional RESULT-FN)

Documentation

Walk TREE applying NODE-FN to each node.

RESULT-FN is called post-order with the left and right-hand side of the result from the recursive call. By default it calls cons on the result.

NODE-FN can throw stop to stop walking; or skip to skip
 that part of the branch.

(defun combobulate-walk-tree (tree node-fn &optional result-fn)
  "Walk TREE applying NODE-FN to each node.

RESULT-FN is called post-order with the left and right-hand side
of the result from the recursive call. By default it calls `cons'
on the result.

NODE-FN can throw `stop' to stop walking; or `skip' to skip
 that part of the branch."
  (catch 'stop
    (combobulate-walk-tree-1 tree node-fn
                             nil
                             (or result-fn #'cons)
                             0)))
