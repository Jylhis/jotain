Function: majutsu-refresh-buffer

majutsu-refresh-buffer is an interactive and natively compiled function defined in majutsu-mode.el.

Signature

(majutsu-refresh-buffer &optional IGNORE-AUTO NOCONFIRM)

Documentation

Refresh the current Majutsu buffer.

This is suitable for use as revert-buffer-function.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-mode.el
(defun majutsu-refresh-buffer (&optional _ignore-auto _noconfirm)
  "Refresh the current Majutsu buffer.

This is suitable for use as `revert-buffer-function'."
  (interactive)
  (majutsu--assert-mode 'majutsu-mode)
  (if (majutsu--refresh-buffer-function)
      (majutsu-refresh-buffer-internal)
    (user-error "No refresh function defined for %s" major-mode)))
