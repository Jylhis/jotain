Function: claude-code-ide--toggle-show-claude-in-ediff

claude-code-ide--toggle-show-claude-in-ediff is an interactive and natively compiled function defined in claude-code-ide-transient.el.

Signature

(claude-code-ide--toggle-show-claude-in-ediff)

Documentation

Toggle showing Claude window during ediff.

Key Bindings

Source Code

;; Defined in /nix/store/ca4a4maamih3h4ksbbhy6racb61djy6q-emacs-packages-deps/share/emacs/site-lisp/claude-code-ide-transient.el
(transient-define-suffix claude-code-ide--toggle-show-claude-in-ediff ()
  "Toggle showing Claude window during ediff."
  (interactive)
  (setq claude-code-ide-show-claude-window-in-ediff (not claude-code-ide-show-claude-window-in-ediff))
  (claude-code-ide-log "Show Claude window in ediff %s" (if claude-code-ide-show-claude-window-in-ediff "enabled" "disabled")))
