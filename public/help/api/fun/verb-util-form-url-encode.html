Function: verb-util-form-url-encode

verb-util-form-url-encode is a natively compiled function defined in verb-util.el.

Signature

(verb-util-form-url-encode VALUES)

Documentation

URL-encode VALUES for a form submission (x-www-form-urlencoded).

VALUES must be an alist of (KEY . VALUE) elements, with KEY and VALUE being strings.

(defun verb-util-form-url-encode (values)
  "URL-encode VALUES for a form submission (x-www-form-urlencoded).
VALUES must be an alist of (KEY . VALUE) elements, with KEY and VALUE
being strings."
  (mapconcat (lambda (elem)
               (concat (url-hexify-string (car elem))
                       "="
                       (url-hexify-string (cdr elem))))
             values "&"))
