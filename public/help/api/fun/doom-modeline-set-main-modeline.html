Function: doom-modeline-set-main-modeline

doom-modeline-set-main-modeline is a natively compiled function defined in doom-modeline.el.

Signature

(doom-modeline-set-main-modeline &optional DEFAULT)

Documentation

Set main mode-line.

If DEFAULT is non-nil, set the default mode-line for all buffers.
