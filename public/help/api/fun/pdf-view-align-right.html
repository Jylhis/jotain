Function: pdf-view-align-right

pdf-view-align-right is an interactive and natively compiled function defined in pdf-view.el.

Signature

(pdf-view-align-right)

Documentation

Align right edge of pdf with right edge of window.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/wm0vc3dfi6c7pwjhcfpsnhyg4hd0b5yc-emacs-packages-deps/share/emacs/site-lisp/elpa/pdf-tools-20260102.1101/pdf-view.el
(defun pdf-view-align-right ()
  "Align right edge of pdf with right edge of window."
  (interactive)
  (image-set-window-hscroll
   (/ (* (- (car (pdf-view-image-size))
            (window-pixel-width))
         (window-width))
      (window-pixel-width))) ; convert from pixel to character width
  (pdf-view-redisplay t))
