Function: magit-merge-preview-mode

magit-merge-preview-mode is a natively compiled function defined in magit-diff.el.

Signature

(magit-merge-preview-mode)

Documentation

Mode for previewing a merge.

In addition to any hooks its parent mode magit-diff-mode might have run, this mode runs the hook magit-merge-preview-mode-hook, as the final or penultimate step during initialization.
