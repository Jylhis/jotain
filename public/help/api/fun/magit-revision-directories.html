Function: magit-revision-directories

magit-revision-directories is a natively compiled function defined in magit-git.el.

(magit-revision-directories REV)

Documentation

List directories that contain a tracked file in revision REV.

;; Defined in /nix/store/k1kwf51rwhxc2r08pvslpgkhbnr4nxnr-emacs-packages-deps/share/emacs/site-lisp/elpa/magit-20260822.1158/magit-git.el
(defun magit-revision-directories (rev)
  "List directories that contain a tracked file in revision REV."
  (mapcar #'file-name-as-directory
          (magit-git-items "ls-tree" "-z" "--full-tree" "-r" "-d" "--name-only"
                           rev)))
