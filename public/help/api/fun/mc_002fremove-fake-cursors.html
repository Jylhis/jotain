Function: mc/remove-fake-cursors

mc/remove-fake-cursors is a natively compiled function defined in multiple-cursors-core.el.

Signature

(mc/remove-fake-cursors)

Documentation

Remove all fake cursors.

Do not use to conclude editing with multiple cursors. For that you should disable multiple-cursors-mode.

;; Defined in /nix/store/bwmgnvnjv89idk13xc843r24h4ygwjwz-emacs-packages-deps/share/emacs/site-lisp/elpa/multiple-cursors-20260419.931/multiple-cursors-core.el
(defun mc/remove-fake-cursors ()
  "Remove all fake cursors.
Do not use to conclude editing with multiple cursors. For that
you should disable multiple-cursors-mode."
  (mc/for-each-fake-cursor
   (mc/remove-fake-cursor cursor))
  (when mc--max-cursors-original
    (setq mc/max-cursors mc--max-cursors-original))
  (setq mc--max-cursors-original nil))
