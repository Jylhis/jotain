Function: bazel--locate-build-file

bazel--locate-build-file is a natively compiled function defined in bazel.el.

Signature

(bazel--locate-build-file DIRECTORY)

Documentation

Return the file name of the Bazel BUILD file in DIRECTORY.

Return nil if DIRECTORY is not a Bazel package (i.e., doesn’t contain a BUILD file). Assume that DIRECTORY is within a Bazel repository. DIRECTORY can be a directory name or directory file name.

(defun bazel--locate-build-file (directory)
  "Return the file name of the Bazel BUILD file in DIRECTORY.
Return nil if DIRECTORY is not a Bazel package (i.e., doesn’t
contain a BUILD file).  Assume that DIRECTORY is within a Bazel
repository.  DIRECTORY can be a directory name or directory file
name."
  (cl-check-type directory string)
  (bazel--locate-file "BUILD" (list directory) '(".bazel" "")))
