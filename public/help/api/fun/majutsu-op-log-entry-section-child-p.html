Function: majutsu-op-log-entry-section-child-p

majutsu-op-log-entry-section-child-p is a function alias for majutsu-op-log-entry-section--eieio-childp, defined in majutsu-op.el.

This function is obsolete since 25.1; use (cl-typep ... 'majutsu-op-log-entry-section) instead

Signature

(majutsu-op-log-entry-section-child-p OBJ)

Documentation

Return non-nil if OBJ is an object of type majutsu-op-log-entry-section(var)/majutsu-op-log-entry-section(fun) or a subclass.
