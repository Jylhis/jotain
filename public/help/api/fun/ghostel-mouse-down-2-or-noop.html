Function: ghostel-mouse-down-2-or-noop

ghostel-mouse-down-2-or-noop is an interactive and natively compiled function defined in ghostel.el.

Signature

(ghostel-mouse-down-2-or-noop EVENT)

Documentation

Offer middle-button press EVENT to the terminal.

If the terminal does not consume it, do nothing; the matching release handler is responsible for primary-selection paste.

Key Bindings

ghostel-mode-map <down-mouse-2>

Source Code

;; Defined in /nix/store/1jkgkg7y6y6hp0xia3dsmcl5zaj0bnhq-emacs-packages-deps/share/emacs/site-lisp/ghostel.el
(defun ghostel-mouse-down-2-or-noop (event)
  "Offer middle-button press EVENT to the terminal.
If the terminal does not consume it, do nothing; the matching
release handler is responsible for primary-selection paste."
  (interactive "e")
  (ghostel--mouse-press event))
