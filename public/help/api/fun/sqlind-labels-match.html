Function: sqlind-labels-match

sqlind-labels-match is a byte-compiled function defined in sql-indent.el.

Signature

(sqlind-labels-match LB1 LB2)

Documentation

Return t when LB1 equals LB2 or LB1 is an empty string.

This is used to compare start/end block labels where the end block label might be empty.

Source Code

;; Defined in /nix/store/vgm6xb2iy00bs19rdw9z3nfi5nf8g873-emacs-packages-deps/share/emacs/site-lisp/elpa/sql-indent-1.7/sql-indent.el
(defsubst sqlind-labels-match (lb1 lb2)
  "Return t when LB1 equals LB2 or LB1 is an empty string.
This is used to compare start/end block labels where the end
block label might be empty."
  (or (string= lb1 lb2)
      (string= lb1 "")))
