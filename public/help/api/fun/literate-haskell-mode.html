Function: literate-haskell-mode

literate-haskell-mode is a function alias and interactive for haskell-literate-mode, defined in haskell-mode.el.

This command is obsolete since 2020-04; use haskell-literate-mode instead.

Signature

(literate-haskell-mode)

Documentation

As haskell-mode but for literate scripts.

In addition to any hooks its parent mode might have run, this mode runs the hook haskell-literate-mode-hook, as the final or penultimate step during initialization.

Key Bindings

This command is not in any keymaps.

Aliases

haskell-literate-mode
