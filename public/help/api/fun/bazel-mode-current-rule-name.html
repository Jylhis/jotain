Function: bazel-mode-current-rule-name

bazel-mode-current-rule-name is a function alias for bazel-current-target-name, defined in bazel.el.

This function is obsolete since 2026-04-16; use bazel-current-target-name instead.

Signature

(bazel-mode-current-rule-name)

Documentation

Return the name of the Bazel rule target defined at point.
