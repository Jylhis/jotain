Function: majutsu-bury-or-kill-buffer

majutsu-bury-or-kill-buffer is an interactive and natively compiled function defined in majutsu-file.el.

Signature

(majutsu-bury-or-kill-buffer &optional BURY-BUFFER)

Documentation

Bury the current buffer if displayed in multiple windows, else kill it.

With a prefix argument BURY-BUFFER only bury the buffer even if it is only displayed in a single window.

Key Bindings

majutsu-blob-mode-map q

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-file.el
(defun majutsu-bury-or-kill-buffer (&optional bury-buffer)
  "Bury the current buffer if displayed in multiple windows, else kill it.
With a prefix argument BURY-BUFFER only bury the buffer even if it is only
displayed in a single window."
  (interactive "P")
  (if (or bury-buffer (cdr (get-buffer-window-list nil nil t)))
      (bury-buffer)
    (kill-buffer)))
