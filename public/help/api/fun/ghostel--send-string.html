Function: ghostel--send-string

ghostel--send-string is a natively compiled function defined in ghostel.el.

Signature

(ghostel--send-string STRING)

Documentation

Send STRING as raw bytes to the terminal's PTY.

Records the send time for immediate-redraw detection.

Aliases

ghostel--send-key (obsolete since 0.16.0)

Source Code

;; Defined in /nix/store/1jkgkg7y6y6hp0xia3dsmcl5zaj0bnhq-emacs-packages-deps/share/emacs/site-lisp/ghostel.el
(defun ghostel--send-string (string)
  "Send STRING as raw bytes to the terminal's PTY.
Records the send time for immediate-redraw detection."
  (setq ghostel--last-send-time (current-time))
  (ghostel--write-pty ghostel--term string))
