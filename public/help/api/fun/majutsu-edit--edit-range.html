Function: majutsu-edit--edit-range

majutsu-edit--edit-range is a natively compiled function defined in majutsu-edit.el.

(majutsu-edit--edit-range ARGS)

Documentation

Return (FROM . TO) range for diffedit from ARGS or context.

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-edit.el
(defun majutsu-edit--edit-range (args)
  "Return (FROM . TO) range for diffedit from ARGS or context."
  (or (majutsu-jj--parse-diff-range args)
      (and (derived-mode-p 'majutsu-diff-mode)
           (majutsu-jj--parse-diff-range majutsu-buffer-diff-range))
      (when-let* ((rev (majutsu-revision-at-point)))
        (cons (concat rev "-") rev))
      (cons "@-" "@")))
