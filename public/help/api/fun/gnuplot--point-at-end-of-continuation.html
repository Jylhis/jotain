Function: gnuplot--point-at-end-of-continuation

gnuplot--point-at-end-of-continuation is a natively compiled function defined in gnuplot.el.

Signature

(gnuplot--point-at-end-of-continuation &optional POS)

Documentation

Return value of point at the end of the continued block containing point.

If there are no continuation lines, returns line-end-position. If specify POS, move POS before execution.

(defun gnuplot--point-at-end-of-continuation (&optional pos)
  "Return value of point at the end of the continued block containing point.

If there are no continuation lines, returns `line-end-position'.
If specify POS, move POS before execution."
  (save-excursion
    (when pos (goto-char pos))
    (gnuplot--end-of-continuation)
    (point)))
