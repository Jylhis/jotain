Function: global-diff-hl-mode

global-diff-hl-mode is an interactive and natively compiled function defined in diff-hl.el.

Signature

(global-diff-hl-mode &optional ARG)

Documentation

Toggle Diff-Hl mode in many buffers.

Specifically, Diff-Hl mode is enabled in all buffers where diff-hl--global-turn-on would do it.

With prefix ARG, enable Global Diff-Hl mode if ARG is positive; otherwise, disable it.

If called from Lisp, toggle the mode if ARG is toggle. Enable the mode if ARG is nil, omitted, or is a positive number. Disable the mode if ARG is a negative number.

See diff-hl-mode(var)/diff-hl-mode(fun) for more information on Diff-Hl mode.

Key Bindings

This command is not in any keymaps.
