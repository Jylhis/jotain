Function: vundo--sans-nil

vundo--sans-nil is a natively compiled function defined in vundo.el.

Signature

(vundo--sans-nil UNDO-LIST)

Documentation

Return UNDO-LIST sans leading nils.

If UNDO-LIST is nil, return nil.

Source Code

;; Defined in /nix/store/7c2696v2qdrdv2vf2im8alazibi7qq0z-emacs-packages-deps/share/emacs/site-lisp/elpa/vundo-2.4.0/vundo.el
(defun vundo--sans-nil (undo-list)
  "Return UNDO-LIST sans leading nils.
If UNDO-LIST is nil, return nil."
  (while (and (consp undo-list) (null (car undo-list)))
    (setq undo-list (cdr undo-list)))
  undo-list)
