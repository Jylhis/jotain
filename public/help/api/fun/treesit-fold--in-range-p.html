Function: treesit-fold--in-range-p

treesit-fold--in-range-p is a natively compiled function defined in treesit-fold-util.el.

(treesit-fold--in-range-p IN-VAL IN-MIN IN-MAX)

Check to see if IN-VAL is between IN-MIN and IN-MAX.

(defun treesit-fold--in-range-p (in-val in-min in-max)
  "Check to see if IN-VAL is between IN-MIN and IN-MAX."
  (and (<= in-min in-val) (<= in-val in-max)))
