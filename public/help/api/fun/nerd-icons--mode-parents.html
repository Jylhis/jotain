Function: nerd-icons--mode-parents

nerd-icons--mode-parents is a function alias for derived-mode-all-parents, defined in subr.el.gz.

Signature

(nerd-icons--mode-parents MODE)

Documentation

Return all the parents of MODE, starting with MODE.

This includes the parents set by define-derived-mode and additional ones set by derived-mode-add-parents. The returned list is not fresh, don't modify it.

Aliases

derived-mode-all-parents
