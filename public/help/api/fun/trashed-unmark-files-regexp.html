Function: trashed-unmark-files-regexp

trashed-unmark-files-regexp is an interactive and natively compiled function defined in trashed.el.

Signature

(trashed-unmark-files-regexp &optional REGEXP)

Documentation

Unmark all files matching REGEXP.

If called interactively or REGEXP is nil, prompt for REGEXP.

Key Bindings

trashed-mode-map % u

(defun trashed-unmark-files-regexp (&optional regexp)
  "Unmark all files matching REGEXP.
If called interactively or REGEXP is nil, prompt for REGEXP."

  (trashed-tag-files-regexp ?  regexp "Unmark"))
