Function: haskell-delete-indentation

haskell-delete-indentation is an interactive and natively compiled function defined in haskell-mode.el.

Signature

(haskell-delete-indentation &optional ARG)

Documentation

Like delete-indentation but ignoring Bird-style ">".

Prefix ARG is handled as per delete-indentation.

(defun haskell-delete-indentation (&optional arg)
  "Like `delete-indentation' but ignoring Bird-style \">\".
Prefix ARG is handled as per `delete-indentation'."
  (interactive "*P")
  (let ((fill-prefix (or fill-prefix (if (eq haskell-literate 'bird) ">"))))
    (delete-indentation arg)))
