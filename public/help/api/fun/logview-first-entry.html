Function: logview-first-entry

logview-first-entry is an interactive and natively compiled function defined in logview.el.

Signature

(logview-first-entry &optional NO-MARK)

Documentation

Move point to the first log entry.

Point is positioned at the beginning of the message of the entry. Otherwise this function is similar to beginning-of-buffer.

Unless issued with a prefix argument or the mark is active, push mark at the current position.

Key Bindings

logview-mode-map <

(defun logview-first-entry (&optional no-mark)
  "Move point to the first log entry.
Point is positioned at the beginning of the message of the entry.
Otherwise this function is similar to `beginning-of-buffer'.

Unless issued with a prefix argument or the mark is active, push
mark at the current position."
  (interactive "P")
  (logview--do-relocate #'logview--point-min no-mark))
