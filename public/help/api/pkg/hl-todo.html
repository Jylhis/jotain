Defined faces (2)

hl-todoBase face used to highlight TODO and similar keywords. The faces used to highlight certain keywords are, by default, created by inheriting this face and using the appropriate color specified using the option `hl-todo-keyword-faces' as foreground color.
hl-todo-flymake-typeFace used for the Flymake diagnostics type `hl-todo-flymake'. This is used for the word "todo" appearing in the "Type" column of buffers created by `flymake-show-buffer-diagnostics' and similar.
