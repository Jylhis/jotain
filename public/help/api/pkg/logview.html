logview-nameFace to use for logger name.
logview-pulseFace to briefly highlight entries to draw attention. Variable `logview-pulse-entries' controls in which situations this face is used.
logview-level-debugFace to use for debug level strings.
logview-unsearchableFace used to “dim” unsearchable text when searching incrementally. Currently used only if `logview-search-only-in-messages' is active. That option can be activated in multiple ways, including by typing `M-m' during the search.
logview-unprocessedFace to highlight otherwise unfontified and unfiltered entries. Logview tries to make Emacs more responsive by periodically making "pauses" in its fontification and filtering process. In large buffers with strict filters that exclude most entries, this can mean that you can sometimes see not-yet-processed entries. Those will be highlighted (or rather dimmed, with the default settings) with this face.
logview-error-entryFace to use for error log entries.
logview-highlightFace to highlight entries of a view chosen with `V h'. Variable `logview-highlighted-entry-part' controls how exactly this face is applied.

logview-debug-entryFace to use for debug log entries.
logview-information-entryFace to use for information log entries.
