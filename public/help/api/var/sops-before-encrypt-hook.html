Variable: sops-before-encrypt-hook

sops-before-encrypt-hook is a customizable variable defined in sops.el.

Value

nil

Documentation

Hook run before each sops encrypt invocation.

Runs in the buffer being encrypted; the variable buffer-file-name(var)/buffer-file-name(fun) holds the target file's path. Use to set AWS_PROFILE, age key paths. The hook fires unconditionally before sops--run.
