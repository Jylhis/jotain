Variable: ghostel--link-detection-chunk

ghostel--link-detection-chunk is a variable defined in ghostel-links.el.

Value

100000

Documentation

Characters ghostel--run-queued-plain-link-detection scans per tick.

A single redraw can materialize megabytes of output at once; scanning all of it in one pass would block Emacs for as long as that takes. The drain takes this much from the newest end of the queued range and re-arms for the rest.
