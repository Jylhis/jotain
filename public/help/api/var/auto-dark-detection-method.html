Variable: auto-dark-detection-method

auto-dark-detection-method is a customizable variable defined in auto-dark.el.

Value

nil

Documentation

The method auto-dark should use to detect the system theme.

Defaults to nil and will be populated through feature detection if left as such. Only change this value if you know what you're doing!
