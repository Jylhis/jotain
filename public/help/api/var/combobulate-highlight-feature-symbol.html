Variable: combobulate-highlight-feature-symbol

combobulate-highlight-feature-symbol is a variable defined in combobulate-query.el.

Value

combobulate-highlight

Documentation

The symbol used to identify the font lock feature for Combobulate highlighting.

This is used to identify the font lock feature that is used to highlight Combobulate highlighters.
