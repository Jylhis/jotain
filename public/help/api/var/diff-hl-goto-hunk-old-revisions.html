Variable: diff-hl-goto-hunk-old-revisions

diff-hl-goto-hunk-old-revisions is a customizable variable defined in diff-hl.el.

Value

nil

Documentation

When non-nil, diff-hl-diff-goto-hunk will always try to navigate to the line in the diff that corresponds to the current line in the file buffer (or as close as it can get to it).

When this variable is nil (default), diff-hl-diff-goto-hunk only does that when called without the prefix argument, or when the NEW revision is not specified (meaning, the diff is against the current version of the file).
