Variable: mc-hide-unmatched-lines-mode-hook

mc-hide-unmatched-lines-mode-hook is a customizable variable defined in mc-hide-unmatched-lines-mode.el.

Value

nil

Documentation

Hook run after entering or leaving mc-hide-unmatched-lines-mode(var)/mc-hide-unmatched-lines-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
