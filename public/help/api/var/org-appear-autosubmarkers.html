Variable: org-appear-autosubmarkers

org-appear-autosubmarkers is a customizable variable defined in org-appear.el.

Value

nil

Documentation

Non-nil enables automatic toggling of subscript and superscript markers.

Does not have an effect if org-pretty-entities is nil.
