Variable: auto-dark-mode-hook

auto-dark-mode-hook is a customizable variable defined in auto-dark.el.

Value

nil

Documentation

Hook run after entering or leaving auto-dark-mode(var)/auto-dark-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
