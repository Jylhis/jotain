Variable: eca-server-releases-cache-ttl

eca-server-releases-cache-ttl is a customizable variable defined in eca-process.el.

Value

3600

Documentation

Time-to-live (seconds) for the cached eca server releases list.

Once expired, the next call that needs the releases list will refetch from the GitHub API. Set to nil to disable expiry (legacy behavior: cache lives until Emacs is restarted). Set to 0 to always refetch. This affects update detection at session start and on eca-restart, so longer-running Emacs sessions can still pick up newer eca releases. See also eca-server-check-updates.
