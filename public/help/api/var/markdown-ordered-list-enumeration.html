Variable: markdown-ordered-list-enumeration

markdown-ordered-list-enumeration is a customizable variable defined in markdown-mode.el.

Value

t

Documentation

When non-nil, use enumerated numbers(1. 2. 3. etc.) for ordered list marker.

While nil, always uses '1.' for the marker

This variable was added, or its default value changed, in markdown-mode version 2.5.
