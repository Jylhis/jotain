Variable: majutsu-remote-jj-executable

majutsu-remote-jj-executable is a customizable variable defined in majutsu-jj.el.

Value

"jj"

Documentation

Path to jj executable on remote hosts.

When default-directory is remote, this executable is used instead of majutsu-jj-executable.

  "Path to jj executable on remote hosts.
