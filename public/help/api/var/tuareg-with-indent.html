Variable: tuareg-with-indent

tuareg-with-indent is a customizable variable defined in tuareg.el.

Value

0

Documentation

How many spaces to indent from a with keyword.

The examples at <https://ocaml.org/docs/guidelines> show the | is aligned with match, thus 0 is the default value.
