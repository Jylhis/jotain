Variable: diff-hl-fringe-flat-bmp

diff-hl-fringe-flat-bmp is a customizable variable defined in diff-hl.el.

Value

diff-hl-bmp-empty

Documentation

The bitmap symbol to use in diff-hl-highlight-on-fringe-flat.

Some options are diff-hl-bmp-empty, diff-hl-bmp-i, or any of the built-in bitmaps.
