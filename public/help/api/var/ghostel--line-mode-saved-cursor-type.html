Variable: ghostel--line-mode-saved-cursor-type

ghostel--line-mode-saved-cursor-type is a buffer-local variable defined in ghostel-line-mode.el.

Documentation

Saved cursor-type from before line mode entry, as a singleton list.

A list (VALUE) when saved, nil when not — distinguishes "not saved" from "saved nil" (the value the terminal asks for after a CSI ?25l). Line mode forces cursor-type to the editor's default so point stays visible while the user navigates and edits, and ghostel--line-mode-teardown restores VALUE so any terminal-driven cursor visibility resumes on exit.
