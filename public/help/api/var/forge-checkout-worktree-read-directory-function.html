Variable: forge-checkout-worktree-read-directory-function

forge-checkout-worktree-read-directory-function is a customizable variable defined in forge-commands.el.

Value

forge-checkout-worktree-default-read-directory-function

Documentation

Function used by forge-checkout-worktree to read worktree directory.

Takes the pull-request as only argument and must return a directory.

This variable was added, or its default value changed, in forge version 0.4.0.
