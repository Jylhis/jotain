Variable: ghostel--mouse-press-was-selected

ghostel--mouse-press-was-selected is a variable defined in ghostel.el.

Value

nil

Documentation

Non-nil if the last left-press hit an already-selected window.

Nil also when the press is the click that focused the frame. Read at release to tell a focus click from an interaction click.
