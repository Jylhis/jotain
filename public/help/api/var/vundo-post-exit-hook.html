Variable: vundo-post-exit-hook

vundo-post-exit-hook is a customizable variable defined in vundo.el.

Value

nil

Documentation

List of functions to call when exiting vundo.

This hook runs in the original buffer the user invoked ‘vundo’, after all the clean up the exiting function does. Ie, it is the very last thing that happens when vundo exists.
