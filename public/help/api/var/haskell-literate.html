Variable: haskell-literate

haskell-literate is a buffer-local variable defined in haskell-mode.el.

Documentation

If not nil, the current buffer contains a literate Haskell script.

Possible values are: bird and tex, for Bird-style and LaTeX-style literate scripts respectively. Set by haskell-mode and haskell-literate-mode. For an ambiguous literate buffer -- i.e. does not contain either "\\begin{code}" or "\\end{code}" on a line on its own, nor does it contain ">" at the start of a line -- the value of haskell-literate-default is used.
