Variable: neocaml-redirect-build-files

neocaml-redirect-build-files is a customizable variable defined in neocaml.el.

Value

t

Documentation

When non-nil, offer to switch to the source file from _build/.

Set to nil if you work with build artifacts directly, e.g. when debugging.

This variable was added, or its default value changed, in neocaml version 0.8.0.
