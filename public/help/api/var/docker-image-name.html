Variable: docker-image-name

docker-image-name is an alias for dockerfile-image-name, defined in dockerfile-mode.el.

This variable is obsolete since 2017-10-22; use dockerfile-image-name instead.

Value

nil

Documentation

Name of the dockerfile currently being used.

This can be set in file or directory-local variables.

Aliases

dockerfile-image-name
