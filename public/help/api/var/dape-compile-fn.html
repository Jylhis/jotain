Variable: dape-compile-fn

dape-compile-fn is an alias and customizable for dape-compile-function, defined in dape.el.

This variable is obsolete since 0.21.0; use dape-compile-function instead.

Value

compile

Documentation

Function to compile with.

The function is called with a command string.

Aliases

dape-compile-function
