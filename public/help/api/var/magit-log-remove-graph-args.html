Variable: magit-log-remove-graph-args

magit-log-remove-graph-args is a customizable variable defined in magit-log.el.

Value

("--follow" "-G" "-S" "-L")

Documentation

The log arguments that cause the "--graph" argument to be dropped.

The default value lists the arguments that are incompatible with
"--graph" and therefore must be dropped when that is used. You
can add additional arguments that are available in magit-log, but I recommend that you don't do that. Nowadays I would define this as a constant, but I am preserving it as an option, in case someone actually customized it.

This variable was added, or its default value changed, in magit version 4.3.7.
