Variable: nerd-icons-completion-mode

nerd-icons-completion-mode is a customizable variable defined in nerd-icons-completion.el.

Value

nil

Documentation

Non-nil if Nerd-Icons-Completion mode is enabled.

See the nerd-icons-completion-mode(var)/nerd-icons-completion-mode(fun) command for a description of this minor mode. Setting this variable directly does not take effect; either customize it (see the info node (emacs)Easy Customization) or call the function nerd-icons-completion-mode(var)/nerd-icons-completion-mode(fun).

Key Bindings

This command is not in any keymaps.

(define-minor-mode nerd-icons-completion-mode
  "Add icons to completion candidates."
  :global t
  (if nerd-icons-completion-mode
      (progn
        (advice-add #'completion-metadata-get :around #'nerd-icons-completion-completion-metadata-get)
        (advice-add (compat-function completion-metadata-get) :around #'nerd-icons-completion-completion-metadata-get))
    (progn
      (advice-remove #'completion-metadata-get #'nerd-icons-completion-completion-metadata-get)
      (advice-remove (compat-function completion-metadata-get) #'nerd-icons-completion-completion-metadata-get))))
