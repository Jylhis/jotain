Variable: ghostel-notification-function

ghostel-notification-function is a customizable variable defined in ghostel.el.

Value

ghostel-default-notify

Documentation

Function called for OSC 9 / OSC 777 desktop notifications.

Called with two string arguments: TITLE and BODY. Title is empty for iTerm2-style OSC 9 notifications, which only carry a body. Set to nil to ignore notifications.

The handler is invoked asynchronously via run-at-time, with the originating ghostel buffer as current-buffer, so it may block or spawn processes freely without stalling the terminal.
