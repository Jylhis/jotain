Variable: magit-todos-branch-list

magit-todos-branch-list is a customizable variable defined in magit-todos.el.

Value

branch

Documentation

Show branch diff to-do list.

This can be toggled locally in Magit buffers with command magit-todos-branch-list-toggle.

(defcustom magit-todos-branch-list 'branch
  "Show branch diff to-do list.

This can be toggled locally in Magit buffers with command
`magit-todos-branch-list-toggle'."
  :type '(choice (const :tag "Never" nil)
                 (const :tag "In non-master branches" branch)
                 (const :tag "Always" t)))
