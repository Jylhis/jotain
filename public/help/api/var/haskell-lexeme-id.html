Variable: haskell-lexeme-id

haskell-lexeme-id is a variable defined in haskell-lexeme.el.

Value

"[[:alpha:]_][[:alnum:]'_]*"

Documentation

Regexp matching a valid Haskell identifier.

GHC accepts a string starting with any alphabetic character or underscore followed by any alphanumeric character or underscore or apostrophe.
