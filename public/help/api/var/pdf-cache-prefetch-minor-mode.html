Variable: pdf-cache-prefetch-minor-mode

pdf-cache-prefetch-minor-mode is a buffer-local variable defined in pdf-cache.el.

Documentation

Non-nil if Pdf-Cache-Prefetch minor mode is enabled.

Use the command pdf-cache-prefetch-minor-mode(var)/pdf-cache-prefetch-minor-mode(fun) to change this variable.

Key Bindings

This command is not in any keymaps.

;; Defined in /nix/store/wm0vc3dfi6c7pwjhcfpsnhyg4hd0b5yc-emacs-packages-deps/share/emacs/site-lisp/elpa/pdf-tools-20260102.1101/pdf-cache.el
(define-minor-mode pdf-cache-prefetch-minor-mode
  "Try to load images which will probably be needed in a while."
  :group 'pdf-cache
  (pdf-cache--prefetch-cancel)
  (cond
   (pdf-cache-prefetch-minor-mode
    (pdf-util-assert-pdf-buffer)
    (add-hook 'pre-command-hook #'pdf-cache--prefetch-stop nil t)
    ;; FIXME: Disable the time when the buffer is killed or its
    ;; major-mode changes.
    (setq pdf-cache--prefetch-timer
          (run-with-idle-timer (or pdf-cache-prefetch-delay 1) t
                               #'pdf-cache--prefetch-start (current-buffer))))
   (t
    (remove-hook 'pre-command-hook #'pdf-cache--prefetch-stop t))))
