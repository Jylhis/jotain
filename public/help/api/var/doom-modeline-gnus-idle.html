Variable: doom-modeline-gnus-idle

doom-modeline-gnus-idle is a customizable variable defined in doom-modeline-core.el.

Value

nil

Documentation

Whether to wait an idle time to scan for news.

When t, sets doom-modeline-gnus-timer as an idle timer. If a number, Emacs must have been idle this given time, checked after reach the defined timer, to fetch news. The time step can be configured in gnus-demon-timestep.
