Variable: logview-highlighted-entry-part

logview-highlighted-entry-part is a customizable variable defined in logview.el.

Value

whole

Documentation

Which parts of an entry get highlighted with \<logview-mode-map>M-x logview-highlight-view-entries (logview-highlight-view-entries).

;; Defined in /nix/store/qid656ql5mh048bd0k84vvsbc2517lh9-emacs-packages-deps/share/emacs/site-lisp/elpa/logview-20260218.2013/logview.el
(defcustom logview-highlighted-entry-part 'whole
  "Which parts of an entry get highlighted with `\\<logview-mode-map>\\[logview-highlight-view-entries]'."
  :type  '(choice (const :tag "The whole entry"                  whole)
                  (const :tag "Entry header (date, level, etc.)" header)
                  (const :tag "Entry message"                    message))
  :set   #'logview--set-highlight-affecting-variable)
