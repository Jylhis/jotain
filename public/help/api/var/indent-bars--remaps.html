Variable: indent-bars--remaps

indent-bars--remaps is a buffer-local variable defined in indent-bars.el.

Documentation

An alist of active face-remap cookies for faces.

Keyed by style tag (nil for the main style). These remaps are used to change the current depth highlight (aside from stipple changes).
