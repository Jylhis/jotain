Variable: nix-ts-mode-hook

nix-ts-mode-hook is a variable defined in nix-ts-mode.el.

Value

nil

Documentation

Hook run after entering nix-ts-mode.

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
