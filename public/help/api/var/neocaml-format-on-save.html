Variable: neocaml-format-on-save

neocaml-format-on-save is a customizable variable defined in neocaml.el.

Value

nil

Documentation

When non-nil, format the buffer with ocamlformat before saving.

Only applies in neocaml-mode and neocaml-interface-mode buffers.

This variable was added, or its default value changed, in neocaml version 0.9.0.
