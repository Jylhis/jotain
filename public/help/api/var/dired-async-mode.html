Variable: dired-async-mode

dired-async-mode is a customizable variable defined in dired-async.el.

Value

nil

Documentation

Non-nil if Dired-Async mode is enabled.

See the dired-async-mode(var)/dired-async-mode(fun) command for a description of this minor mode. Setting this variable directly does not take effect; either customize it (see the info node (emacs)Easy Customization) or call the function dired-async-mode(var)/dired-async-mode(fun).

Key Bindings

This command is not in any keymaps.

(define-minor-mode dired-async-mode
  "Do dired actions asynchronously."
  :lighter dired-async-mode-lighter
  :global t
  (if dired-async-mode
      (progn
        (advice-add 'dired-create-files :around #'dired-async--smart-create-files)
        (advice-add 'wdired-do-renames :around #'dired-async-wdired-do-renames))
    (progn
      (advice-remove 'dired-create-files #'dired-async--smart-create-files)
      (advice-remove 'wdired-do-renames #'dired-async-wdired-do-renames))))
