Variable: dape-compile-compile-hooks

dape-compile-compile-hooks is an alias and customizable for dape-compile-hook, defined in dape.el.

This variable is obsolete since 0.13.0; use dape-compile-hook instead.

Value

nil

Documentation

Called after dape compilation finishes.

The hook is run with one argument, the compilation buffer when compilation is successful.

Aliases

dape-compile-hook
