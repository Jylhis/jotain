Variable: nerd-icons-completion-mode-hook

nerd-icons-completion-mode-hook is a customizable variable defined in nerd-icons-completion.el.

Value

nil

Documentation

Hook run after entering or leaving nerd-icons-completion-mode(var)/nerd-icons-completion-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
