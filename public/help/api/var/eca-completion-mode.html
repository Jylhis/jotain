Variable: eca-completion-mode

eca-completion-mode is a buffer-local variable defined in eca-completion.el.

Documentation

Non-nil if Eca-Completion mode is enabled.

Use the command eca-completion-mode(var)/eca-completion-mode(fun) to change this variable.

Key Bindings

This command is not in any keymaps.

;;;###autoload
(define-minor-mode eca-completion-mode
  "Minor mode for ECA completions."
  :init-value nil
  :lighter " ECA completion"
  (eca-completion--clear-overlay)
  (advice-add 'posn-at-point :before-until #'eca-completion--posn-advice)
  (if eca-completion-mode
      (eca-completion--mode-activate)
    (eca-completion--mode-deactivate)))
