Variable: mixed-pitch-mode-hook

mixed-pitch-mode-hook is a customizable variable defined in mixed-pitch.el.

Value

nil

Documentation

Hook run after entering or leaving mixed-pitch-mode(var)/mixed-pitch-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
