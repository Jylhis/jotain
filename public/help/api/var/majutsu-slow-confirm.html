Variable: majutsu-slow-confirm

majutsu-slow-confirm is a customizable variable defined in majutsu-base.el.

nil

Documentation

A list of actions that should use yes-or-no-p instead of y-or-n-p.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-base.el
(defcustom majutsu-slow-confirm nil
  "A list of actions that should use `yes-or-no-p' instead of `y-or-n-p'."
  :type `(choice (const :tag "Use yes-or-no for all" t)
          (set   :tag "Use yes-or-no for"
                 ,@majutsu--confirm-actions))
  :group 'majutsu)
