Variable: zoxide-travel-callback-function

zoxide-travel-callback-function is a customizable variable defined in zoxide.el.

Value

find-file

Documentation

The callback function for the target path in zoxide-travel.

Unlike zoxide-find-file-function, this always be called with the selected path as its first argument noninteractively.
