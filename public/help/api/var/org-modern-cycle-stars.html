Variable: org-modern-cycle-stars

org-modern-cycle-stars is a customizable variable defined in org-modern.el.

Value

nil

Documentation

For deeply nested headlines use cycling.

If set to nil, the last star is used for all deep headlines. See org-modern-fold-stars and org-modern-replace-stars.
