Variable: tuareg-interactive-mode-hook

tuareg-interactive-mode-hook is a variable defined in tuareg.el.

Value

nil

Documentation

Hook run after entering tuareg-interactive-mode.

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
