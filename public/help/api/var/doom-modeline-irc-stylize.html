Variable: doom-modeline-irc-stylize

doom-modeline-irc-stylize is a customizable variable defined in doom-modeline-core.el.

Value

doom-modeline-shorten-irc

Documentation

Which function to call to stylize IRC buffer names.

Buffer names are stylized using the selected function. By default buffer names are shortened, you may want to disable or call your own function. The function must accept buffer-name and return shortened-name.

(defcustom doom-modeline-irc-stylize #'doom-modeline-shorten-irc
  "Which function to call to stylize IRC buffer names.

Buffer names are stylized using the selected `function'.
By default buffer names are shortened, you may want to disable or call
your own function.
The function must accept `buffer-name' and return `shortened-name'."
  :type '(radio (function-item :tag "Shorten"
                               :format "%t: %v\n %h"
                               doom-modeline-shorten-irc)
                (function-item
                 :tag "Leave unchanged"
                 :format "%t: %v\n"
                 identity)
                (function
                 :tag "Other function"))
  :group 'doom-modeline)
