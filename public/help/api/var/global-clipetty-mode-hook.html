Variable: global-clipetty-mode-hook

global-clipetty-mode-hook is a customizable variable defined in clipetty.el.

Value

nil

Documentation

Hook run after entering or leaving global-clipetty-mode(var)/global-clipetty-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
