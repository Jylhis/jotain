Variable: ghostel-buffer-identification-format

ghostel-buffer-identification-format is a customizable variable defined in ghostel.el.

Value

"%b (%.30t)"

Documentation

Format for mode-line-buffer-identification in ghostel buffers.

A format-spec string with these specs:
  %b buffer name (stays live across renames)
  %t terminal title (OSC 0/2)
  %d abbreviated default-directory
format-spec width and truncation modifiers apply to %t and %d (the default caps the title at 30 columns) but are ignored on %b. When the format references %t and the terminal has no title, only the buffer name is shown. Set to nil to leave mode-line-buffer-identification alone.
