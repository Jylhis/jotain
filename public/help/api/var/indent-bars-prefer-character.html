Variable: indent-bars-prefer-character

indent-bars-prefer-character is a customizable variable defined in indent-bars.el.

Value

nil

Documentation

Use characters instead of stipple to draw bars.

Normally characters are used on terminal only. A non-nil value specifies using character bars exclusively. See indent-bars-no-stipple-char.
