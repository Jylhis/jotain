Documentation

Alist specifying gptel's default state transition table for requests.

Each entry is a list whose car is a request state (any symbol) and whose cdr is an alist listing possible next states. Each key is either a predicate function or t. When gptel--fsm-next is called, the predicates are called in the order they appear here to find the next state. Each predicate is called with the state machine's INFO, see gptel-fsm. A predicate of t is considered a success and acts as a default.
