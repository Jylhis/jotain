Variable: claude-code-ide-focus-claude-after-ediff

claude-code-ide-focus-claude-after-ediff is a customizable variable defined in claude-code-ide.el.

Value

t

Documentation

Whether to focus the Claude Code window after opening ediff.

When non-nil (default), focus returns to the Claude Code window after opening ediff. When nil, focus remains on the ediff control window, allowing direct interaction with the diff controls.
