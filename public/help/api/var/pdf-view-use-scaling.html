Variable: pdf-view-use-scaling

pdf-view-use-scaling is a customizable variable defined in pdf-view.el.

Value

t

Documentation

Whether images should be allowed to be scaled for rendering.

This variable affects both the reuse of higher-resolution images as lower-resolution ones by down-scaling the image. As well as the rendering of higher-resolution for high-resolution displays, if available.
