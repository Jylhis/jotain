Variable: ghostel-timer-delay

ghostel-timer-delay is a customizable variable defined in ghostel.el.

Value

0.033

Documentation

Delay in seconds before redrawing after output (roughly 30fps).

When ghostel-adaptive-fps is non-nil, this serves as the base delay between frames during sustained output.
