Variable: markdown-wiki-link-search-parent-directories

markdown-wiki-link-search-parent-directories is a customizable variable defined in markdown-mode.el.

This variable is obsolete since 2.5; use markdown-wiki-link-search-type instead.

Value

nil

Documentation

When non-nil, search for wiki link targets in parent directories.

This is the default search behavior of Ikiwiki.

This variable was added, or its default value changed, in markdown-mode version 2.2.
