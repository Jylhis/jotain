Variable: global-tempel-abbrev-mode

global-tempel-abbrev-mode is a customizable variable defined in tempel.el.

Value

nil

Documentation

Non-nil if Global Tempel-Abbrev mode is enabled.

See the global-tempel-abbrev-mode(var)/global-tempel-abbrev-mode(fun) command for a description of this minor mode. Setting this variable directly does not take effect; either customize it (see the info node (emacs)Easy Customization) or call the function global-tempel-abbrev-mode(var)/global-tempel-abbrev-mode(fun).

Key Bindings

This command is not in any keymaps.
