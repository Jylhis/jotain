Variable: neocaml-interface-mode-hook

neocaml-interface-mode-hook is a variable defined in neocaml.el.

Value

nil

Documentation

Hook run after entering neocaml-interface-mode.

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
