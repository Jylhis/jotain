Variable: ghostel-kitty-graphics-mediums

ghostel-kitty-graphics-mediums is a customizable variable defined in ghostel-kitty.el.

Value

nil

Documentation

Image-loading mediums to enable for the Kitty graphics protocol.

The kitty protocol supports four ways for a program to ship image data to the terminal:
- direct: base64-encoded inline (always enabled, what timg / yazi use)
- file: program names a local file, terminal reads it
- temp-file: program names a temp file, terminal reads and unlinks it
- shared-mem: program names a POSIX shared-memory region

The non-direct mediums let a *remote* program (over SSH, tmux passthrough, etc.) instruct ghostel to read arbitrary paths or shared memory regions on the local machine — a privilege-escalation surface. The default is nil (none enabled), keeping ghostel safe in remote sessions while still supporting timg, yazi, and other tools that ship data inline. Enable individual mediums by adding file, temp-file, or shared-mem to the list, e.g. (file) for trusted local-only use.
