Variable: ghostel--line-input-start

ghostel--line-input-start is a buffer-local variable defined in ghostel-line-mode.el.

Documentation

Marker pointing at the start of the user's in-progress input line.

Nil when line mode is not active. Text between this marker and ghostel--line-input-end is the editable input line.
