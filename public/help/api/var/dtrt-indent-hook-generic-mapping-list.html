Variable: dtrt-indent-hook-generic-mapping-list

dtrt-indent-hook-generic-mapping-list is a customizable variable defined in dtrt-indent.el.

Value

((evil-mode evil-shift-width))

Documentation

A mapping from hook variables to indentation variables.

For each true key variable, its value variable is set to the same indentation offset as the variable in dtrt-indent-hook-mapping-list (e.g., c-basic-offset). Every pair in the list is processed. To disable processing of any one pair, remove the pair from the list. Processing the list obeys dtrt-indent-require-confirmation-flag.

The key can be any variable. This list is used for cases such as when a minor-mode defines a variable to control its own indentation functionality (e.g. evil-mode using evil-shift-width), so the value variable must updated in addition to the syntax indentation variable.
