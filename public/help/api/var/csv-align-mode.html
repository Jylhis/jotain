Variable: csv-align-mode

csv-align-mode is a buffer-local variable defined in csv-mode.el.

Documentation

Non-nil if Csv-Align mode is enabled.

Use the command csv-align-mode(var)/csv-align-mode(fun) to change this variable.

Key Bindings

This command is not in any keymaps.

;; Defined in /nix/store/mrygxsladaca2yfyr2cy0am5zm9lzddg-emacs-packages-deps/share/emacs/site-lisp/elpa/csv-mode-1.27/csv-mode.el
(define-minor-mode csv-align-mode
  "Align columns on the fly."
  :global nil
  (csv-unalign-fields nil (point-min) (point-max)) ;Just in case.
  (cond
   (csv-align-mode
    (add-to-invisibility-spec '(csv-truncate . t))
    (kill-local-variable 'csv--jit-columns)
    (cursor-sensor-mode 1)
    (when (fboundp 'header-line-indent-mode)
      (header-line-indent-mode))
    (jit-lock-register #'csv--jit-align)
    (jit-lock-refontify))
   (t
    (remove-from-invisibility-spec '(csv-truncate . t))
    (jit-lock-unregister #'csv--jit-align)
    (csv--jit-unalign (point-min) (point-max))))
  (csv--header-flush))
