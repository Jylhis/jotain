Variable: doom-modeline-time-clock-size

doom-modeline-time-clock-size is a customizable variable defined in doom-modeline-core.el.

Value

0.7

Documentation

Size of the analogue clock drawn, either in pixels or as a proportional height.

An integer value is used as the diameter of clock in pixels. A floating point value sets the diameter of the clock relative to doom-modeline-height.

Only relevant when doom-modeline-time-analogue-clock is non-nil, which see.
