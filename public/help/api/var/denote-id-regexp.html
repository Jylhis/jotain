Variable: denote-id-regexp

denote-id-regexp is an alias for denote-date-identifier-regexp, defined in denote.el.

This variable is obsolete since 4.1.0; use denote-date-identifier-regexp instead.

Value

"\\([0-9]\\{8\\}\\)\\(T[0-9]\\{6\\}\\)"

Documentation

Regular expression to match denote-date-identifier-format.

Aliases

denote-date-identifier-regexp
