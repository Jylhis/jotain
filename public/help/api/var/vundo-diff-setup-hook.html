Variable: vundo-diff-setup-hook

vundo-diff-setup-hook is a customizable variable defined in vundo.el.

Value

nil

Documentation

List of functions to call after creating a diff buffer.

This hook runs in the ‘vundo-diff’ buffer immediately after it's setup, both for new or existing buffers. This may be used to manipulate the diff or transform it's contents.
