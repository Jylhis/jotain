Variable: eca-process--releases-fetch-failed-at

eca-process--releases-fetch-failed-at is a variable defined in eca-process.el.

Value

nil

Documentation

Value of float-time when the last releases fetch failed, or nil.

While within eca-process--releases-failure-cooldown seconds of it, eca-process--fetch-releases skips the network and returns any stale cached value, so repeated eca starts during a GitHub outage stay fast.
