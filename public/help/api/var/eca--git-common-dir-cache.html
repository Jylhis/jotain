Variable: eca--git-common-dir-cache

eca--git-common-dir-cache is a variable defined in eca-util.el.

Value

#s(hash-table test equal)

Documentation

Cache of expanded dir -> git common dir (or :none) lookups.

Avoids spawning a git process on every eca-session resolution; cleared whenever a session is created or deleted.
