Variable: magit-remote-git-executable

magit-remote-git-executable is a customizable variable defined in magit-git.el.

Value

"git"

Documentation

The Git executable used by Magit on remote machines.

On the local host magit-git-executable(var)/magit-git-executable(fun) is used instead. Consider customizing tramp-remote-path instead of this option.

This variable was added, or its default value changed, in magit version 3.2.0.
