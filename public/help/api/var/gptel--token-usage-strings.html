Variable: gptel--token-usage-strings

gptel--token-usage-strings is a buffer-local variable defined in gptel.el.

Documentation

Token usage strings formatted for display.

This is a list (IDX REQUEST BUFFER), where IDX is the usage type to display (0 or 1), and REQUEST and BUFFER are the token usage for the last request and the buffer/session.
