Variable: clipetty--max-cut

clipetty--max-cut is a variable defined in clipetty.el.

Value

74994

Documentation

The maximum length of a string you can send to the clipboard via OSC52.

The max OSC 52 message is 100,000 bytes. This means we can support base64 encoded strings of up to 74,994 bytes long.
