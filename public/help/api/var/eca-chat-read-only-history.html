Variable: eca-chat-read-only-history

eca-chat-read-only-history is a customizable variable defined in eca-chat.el.

Value

t

Documentation

When non-nil, make the chat history/output area read-only.

Only the prompt block at the bottom stays editable, which prevents accidental edits to previous messages and assistant output. Set to nil to keep the whole chat buffer writable.
