Variable: treesit-fold-line-comment-mode-hook

treesit-fold-line-comment-mode-hook is a customizable variable defined in treesit-fold.el.

Value

nil

Documentation

Hook run after entering or leaving treesit-fold-line-comment-mode(var)/treesit-fold-line-comment-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
