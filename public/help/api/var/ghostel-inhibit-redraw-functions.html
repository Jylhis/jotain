Variable: ghostel-inhibit-redraw-functions

ghostel-inhibit-redraw-functions is a customizable variable defined in ghostel.el.

Value

nil

Documentation

Abnormal hook run before a ghostel buffer redraw.

Each function is called with the buffer as its sole argument, with that buffer current. If any function returns non-nil, the redraw is deferred and rescheduled. Errors are demoted and treated as nil. Add-on features can use this to keep core ghostel from rewriting the buffer during transient states such as Emacs Lisp input-method composition.
