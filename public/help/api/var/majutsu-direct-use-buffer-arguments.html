Variable: majutsu-direct-use-buffer-arguments

majutsu-direct-use-buffer-arguments is a customizable variable defined in majutsu-core.el.

Value

selected

Documentation

Whether direct commands reuse arguments from relevant buffers.

This affects commands that can be invoked from a transient prefix, but are also commonly invoked directly.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-core.el
(defcustom majutsu-direct-use-buffer-arguments 'selected
  "Whether direct commands reuse arguments from relevant buffers.

This affects commands that can be invoked from a transient prefix, but
are also commonly invoked directly."
  :group 'majutsu
  :type '(choice (const :tag "Always" always)
          (const :tag "Selected" selected)
          (const :tag "Current" current)
          (const :tag "Never" never)))
