Documentation

Functions that call pulsar-pulse-line after invocation.

This only takes effect when pulsar-mode(var)/pulsar-mode(fun) (buffer-local) or pulsar-global-mode(var)/pulsar-global-mode(fun) is enabled.

This variable was added, or its default value changed, in pulsar version 1.1.0.
