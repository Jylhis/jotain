Variable: majutsu-log-sections-hook

majutsu-log-sections-hook is a customizable variable defined in majutsu-log.el.

Value

(majutsu-log-insert-error-header
 majutsu-log-insert-logs
 majutsu-log-insert-status
 majutsu-insert-workspaces)

Documentation

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-log.el
(defcustom majutsu-log-sections-hook
  (list #'majutsu-log-insert-error-header
        #'majutsu-log-insert-logs
        #'majutsu-log-insert-status
        #'majutsu-insert-workspaces)
  "Hook run to insert sections in the log buffer."
  :type 'hook
  :group 'majutsu)
