Variable: neocaml--debug

neocaml--debug is a variable defined in neocaml.el.

Value

nil

Documentation

Enable debugging messages and show the current node in the mode-line.

When set to t, show indentation debug info. When set to font-lock, show fontification info as well.

Only intended for use at development time.
