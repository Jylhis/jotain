Variable: combobulate-python-indent-mark-region

combobulate-python-indent-mark-region is a customizable variable defined in combobulate-python.el.

Value

nil

Documentation

Mark the region when indenting and leave it enabled after.

When non-nil, Combobulate will mark the region when indenting with combobulate-python-indent-for-tab-command.

When nil, the mark is instead deactivated after indenting.
