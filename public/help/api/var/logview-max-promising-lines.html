Variable: logview-max-promising-lines

logview-max-promising-lines is a customizable variable defined in logview.el.

Value

3

Documentation

Abort submode guessing after this many "promising" lines.

If a line generally looks like a start of log entry to Logview, it is considered "promising". If several such lines still give no matching submode, Logview aborts guessing. This helps avoiding very long unsuccessful guessing times even when logview-guess-lines is large.

Setting this to zero makes the mode match against all logview-guess-lines.
