Variable: zoxide-find-file-function

zoxide-find-file-function is a customizable variable defined in zoxide.el.

Value

find-file

Documentation

The callback function for the target path in zoxide-find-file.

If the function is interactive, it will be called by call-interactively in efault-directory with target path. Otherwise, the target path is passed as argument.

For example, you set this to counsel-fzf to open file with fzf through counsel or dired to open directory instead of a file.
