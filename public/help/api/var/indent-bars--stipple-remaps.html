Variable: indent-bars--stipple-remaps

indent-bars--stipple-remaps is a buffer-local variable defined in indent-bars.el.

Documentation

A hash table of active stipple face-remap cookies.

The hash table is keyed by the whr, an integer composing font width, height, and window starting offset (see indent-bars--whr). Elements of the hash table are plists with the following keys:

  (:main[-styletag] ... :current[-styletag] ...)

These are used to update relevant stipples for main and current stipple faces for the various styles as character size and/or window pixel start (pattern rotation "rot") change, due to window layout or font size changes. Note that all stipple attributes are set via filtered face remaps.
