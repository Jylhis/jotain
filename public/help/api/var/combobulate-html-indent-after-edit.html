Variable: combobulate-html-indent-after-edit

combobulate-html-indent-after-edit is a variable defined in combobulate-html.el.

Value

nil

Documentation

Non-nil indents the inserted text after a Combobulate refactor text operation.

This should probably be nil in whitespace-sensitive languages.
