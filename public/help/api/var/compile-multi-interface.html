Variable: compile-multi-interface

compile-multi-interface is a customizable variable defined in compile-multi.el.

Value

nil

Documentation

Set the default interface for compile-multi.

To override the interface you must define a variant of compile-multi-read-actions that accepts an interface argument matching the value set here.
