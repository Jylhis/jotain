combobulate-typescript-envelope-indent-region-function is a variable defined in combobulate-js-ts.el.

indent-region

Documentation

Function to call to indent an envelope after it is inserted.

Note that this defaults to indent-region, but that may work well in indentation-sensitive languages like YAML or Python.
