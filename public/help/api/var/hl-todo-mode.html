Variable: hl-todo-mode

hl-todo-mode is a buffer-local variable defined in hl-todo.el.

Documentation

Non-nil if Hl-Todo mode is enabled.

Use the command hl-todo-mode(var)/hl-todo-mode(fun) to change this variable.

Key Bindings

This command is not in any keymaps.

(define-minor-mode hl-todo-mode
  "Highlight TODO and similar keywords in comments and strings."
  :lighter ""
  :keymap hl-todo-mode-map
  :group 'hl-todo
  (if hl-todo-mode
      (font-lock-add-keywords nil hl-todo--keywords t)
    (font-lock-remove-keywords nil hl-todo--keywords))
  (font-lock-flush))
