Variable: casual-lib-hide-navigation

casual-lib-hide-navigation is a customizable variable defined in casual-lib.el.

Value

nil

Documentation

If non-nil then hide navigation controls.

If non-nil, customize Casual user interfaces to hide navigation controls for transient-quit-all (control-q) and transient-quit-one (control-g).
