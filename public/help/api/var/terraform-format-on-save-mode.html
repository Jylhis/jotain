Variable: terraform-format-on-save-mode

terraform-format-on-save-mode is a buffer-local variable defined in terraform-mode.el.

Documentation

Non-nil if Terraform-Format-On-Save mode is enabled.

Use the command terraform-format-on-save-mode(var)/terraform-format-on-save-mode(fun) to change this variable.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/4nxqp4jvms3n4azp2x2snypnn6xcgq9g-emacs-packages-deps/share/emacs/site-lisp/elpa/terraform-mode-20251115.2210/terraform-mode.el
(define-minor-mode terraform-format-on-save-mode
  "Run terraform-format-buffer before saving current buffer."
  :lighter ""
  (if terraform-format-on-save-mode
      (add-hook 'before-save-hook #'terraform-format-buffer nil t)
    (remove-hook 'before-save-hook #'terraform-format-buffer t)))
