Variable: haskell-interactive-prompt2

haskell-interactive-prompt2 is an alias and customizable for haskell-interactive-prompt-cont, defined in haskell-customize.el.

This variable is obsolete since 17.1; use haskell-interactive-prompt-cont instead.

Value

"λ| "

Documentation

The multi-line prompt to use.

The default is haskell-interactive-prompt with the last > replaced with |.

Aliases

haskell-interactive-prompt-cont
