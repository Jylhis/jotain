Variable: clipetty-tmux-ssh-tty

clipetty-tmux-ssh-tty is a customizable variable defined in clipetty.el.

Value

"tmux show-environment SSH_TTY"

Documentation

The command we send to tmux to determine the SSH_TTY.

This default assumes that tmux is on your PATH. If tmux lives elsewhere for you, or it is named something else, you can change it here.
