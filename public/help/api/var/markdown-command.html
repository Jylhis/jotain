Variable: markdown-command

markdown-command is a customizable variable defined in markdown-mode.el.

Value

"markdown"

Documentation

Command to run markdown.

;; Defined in /nix/store/s4bvm9kdxw2hixpjqbqj3gi5xi7kr8wh-emacs-packages-deps/share/emacs/site-lisp/elpa/markdown-mode-20260827.909/markdown-mode.el
(defcustom markdown-command (let ((command (cl-loop for cmd in '("markdown" "pandoc" "markdown_py" "cmark" "cmark-gfm")
                                                    when (executable-find cmd)
                                                    return (file-name-nondirectory it))))
                              (or command "markdown"))
  "Command to run markdown."
  :group 'markdown
  :type '(choice (string :tag "Shell command") (repeat (string)) function))
