Variable: eca-chat-image-scale

eca-chat-image-scale is a buffer-local variable defined in eca-chat-image.el.

Documentation

Per-chat zoom multiplier for inline images.

Multiplied into the resolved width cap from eca-chat-image-max-width so the user can interactively scale all images in the current chat buffer up or down via eca-chat-image-zoom-in, eca-chat-image-zoom-out, and eca-chat-image-zoom-reset. Buffer-local so each chat keeps its own zoom level.
