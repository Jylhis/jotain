Variable: logview-target-gap-length

logview-target-gap-length is a customizable variable defined in logview.el.

Value

60

Documentation

Default target gap length for \<logview-mode-map>M-x logview-next-timestamp-gap (logview-next-timestamp-gap) and similar commands.

This must be a non-negative number of seconds. Can be changed temporarily for a single buffer with \<logview-mode-map>M-x logview-change-target-gap-length (logview-change-target-gap-length).
