Variable: indent-bars-display-on-blank-lines

indent-bars-display-on-blank-lines is a customizable variable defined in indent-bars.el.

Value

t

Documentation

Whether to display bars on blank lines.

Bars are shown only on blank lines contiguously adjacent to lines already showing bars, by default the deepest adjacent non-blank line, or, if set to least the least deep such line.

(defcustom indent-bars-display-on-blank-lines t
  "Whether to display bars on blank lines.
Bars are shown only on blank lines contiguously adjacent to lines
already showing bars, by default the deepest adjacent non-blank
line, or, if set to `least' the least deep such line."
  :type '(choice
	  (const :tag "Disabled" nil)
	  (const :tag "Deepest adjacent" t)
	  (const :tag "Least deep adjacent" least))
  :set #'indent-bars--custom-set
  :initialize #'custom-initialize-default
  :group 'indent-bars)
