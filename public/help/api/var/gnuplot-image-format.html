Variable: gnuplot-image-format

gnuplot-image-format is a customizable variable defined in gnuplot.el.

Value

"png"

Documentation

Image format to use for displaying images within Emacs.

This will be sent directly to Gnuplot as a command of the form
"set terminal <FORMAT>". Common values are "png" and
"svg".

This only has an effect when gnuplot-inline-image-mode is non-nil.
