Variable: tuareg-default-indent

tuareg-default-indent is a customizable variable defined in tuareg.el.

Value

2

Documentation

Default indentation.

Global indentation variable (large values may lead to indentation overflows). When no governing keyword is found, this value is used to indent the line if it has to.
