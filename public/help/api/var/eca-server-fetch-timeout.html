Variable: eca-server-fetch-timeout

eca-server-fetch-timeout is a customizable variable defined in eca-process.el.

Value

20

Documentation

Seconds before a GitHub fetch is considered stuck.

Used as cURL --max-time when fetching the releases list and as cURL --connect-timeout when downloading the server binary, so an unreachable GitHub (e.g. an outage) cannot block Emacs for long.
