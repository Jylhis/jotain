Variable: majutsu-diff-sections-hook

majutsu-diff-sections-hook is a customizable variable defined in majutsu-diff.el.

Value

(majutsu-insert-diff)

Documentation

Hook run to insert sections into a majutsu-diff-mode buffer.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-diff.el
;;; Options
;;;; Diff Mode

(defcustom majutsu-diff-sections-hook
  (list #'majutsu-insert-diff
        ;; #'majutsu-insert-xref-buttons
        )
  "Hook run to insert sections into a `majutsu-diff-mode' buffer."
  :group 'majutsu-diff
  :type 'hook)
