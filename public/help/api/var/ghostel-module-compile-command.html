Variable: ghostel-module-compile-command

ghostel-module-compile-command is a customizable variable defined in ghostel-module-install.el.

Value

"zig build --prefix %s -Doptimize=ReleaseFast -Dcpu=baseline"

Documentation

Shell command used by ghostel-module-compile.

The command is formatted with one argument: the shell-quoted temporary Zig install prefix.
