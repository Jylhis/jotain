Variable: sqlind-minor-mode-hook

sqlind-minor-mode-hook is a customizable variable defined in sql-indent.el.

Value

nil

Documentation

Hook run after entering or leaving sqlind-minor-mode(var)/sqlind-minor-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
