Variable: combobulate-key-prefix

combobulate-key-prefix is a customizable variable defined in combobulate-settings.el.

Value

"C-c o"

Documentation

Prefix key for Combobulate commands. Leave blank to disable.

This is the prefix key for all Combobulate commands. It is recommended that you set this to something that is easy to type and remember, but that does not conflict with any other key.

When you change this key prefix you must restart Emacs for the change to take effect.

Note this must be a string readable by the kbd macro, and not a vector or an escaped string.
