Variable: eca-chat-save-image-filename-format

eca-chat-save-image-filename-format is a customizable variable defined in eca-chat-image.el.

Value

"eca-image-%s.%s"

Documentation

Format string for default filenames in eca-chat-save-image-at-point.

Receives two %s arguments via format: a timestamp string built from format-time-string with %Y%m%d-%H%M%S, and the file extension derived from the image media type (e.g. png, jpg).
