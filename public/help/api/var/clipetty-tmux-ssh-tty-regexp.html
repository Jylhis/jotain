Variable: clipetty-tmux-ssh-tty-regexp

clipetty-tmux-ssh-tty-regexp is a customizable variable defined in clipetty.el.

Value

"^SSH_TTY=\\([^\n]+\\)"

Documentation

This regexp is used to capture the SSH_TTY from output of tmux.

Unless you're inventing a new method for determining the SSH_TTY, after a detach / re-attach it's unlikely you'll need to change this.
