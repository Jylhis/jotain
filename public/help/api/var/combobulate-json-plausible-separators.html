Variable: combobulate-json-plausible-separators

combobulate-json-plausible-separators is a variable defined in combobulate-json.el.

Value

(",")

Documentation

List of strings of plausible separators found in this language.

This is a fairly blunt way of instructing Combobulate of the type of separators to expect in a language. It's used to help with editing. The default value is usually good enough for most languages.
