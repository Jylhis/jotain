Variable: tuareg-prettify-symbols-full

tuareg-prettify-symbols-full is a customizable variable defined in tuareg.el.

Value

nil

Documentation

If non-nil, add fun and -> and such to be prettified with symbols.

This may sound like a neat trick, but note that it can change the alignment and can thus lead to surprises. By default, only symbols that do not perturb in essential ways the alignment are used. See tuareg-prettify-symbols-basic-alist and tuareg-prettify-symbols-extra-alist.
