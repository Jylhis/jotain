Variable: magit-stash-mode-hook

magit-stash-mode-hook is a variable defined in magit-stash.el.

Value

nil

Documentation

Hook run after entering magit-stash-mode.

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
