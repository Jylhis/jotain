Variable: dired-async--modeline-mode-hook

dired-async--modeline-mode-hook is a customizable variable defined in dired-async.el.

Value

nil

Documentation

Hook run after entering or leaving dired-async--modeline-mode(var)/dired-async--modeline-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
