Variable: global-kkp-mode-hook

global-kkp-mode-hook is a customizable variable defined in kkp.el.

Value

nil

Documentation

Hook run after entering or leaving global-kkp-mode(var)/global-kkp-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
