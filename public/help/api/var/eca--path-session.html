Variable: eca--path-session

eca--path-session is a variable defined in eca-util.el.

Value

nil

Documentation

Session used to derive TRAMP path mappings.

Bound dynamically while handling server messages so path translation uses the session owning the message instead of resolving one from the current buffer.
