Variable: trashed-sort-key

trashed-sort-key is a customizable variable defined in trashed.el.

Value

("Date deleted" . t)

Documentation

Default sort key.

If nil, no additional sorting is performed. Otherwise, this should be a cons cell (COLUMN . FLIP). COLUMN is a string matching one of the column names. FLIP, if non-nil, means to invert the resulting sort.
