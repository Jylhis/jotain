Variable: eca-chat-image-scale-step

eca-chat-image-scale-step is a customizable variable defined in eca-chat-image.el.

Value

1.2

Documentation

Multiplicative step for the per-chat image zoom commands.

Applied to the buffer-local eca-chat-image-scale on each call to eca-chat-image-zoom-in (multiply) or eca-chat-image-zoom-out
(divide). A value of 1.0 disables zooming.
