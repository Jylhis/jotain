Variable: pdf-info-log

pdf-info-log is a customizable variable defined in pdf-info.el.

Value

nil

Documentation

Whether to log the communication with the server.

If this is non-nil, all communication with the epdfinfo program will be logged to the buffer "*pdf-info-log*".
