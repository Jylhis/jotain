Variable: denote-link-mouse-map

denote-link-mouse-map is an alias for denote-fontify-links-map, defined in denote.el.

This variable is obsolete since 4.2.0; use denote-fontify-links-map instead.

Value

<mouse-1>  denote-link-open-at-mouse
<mouse-2>  denote-link-open-at-mouse
<mouse-3>  denote-link-open-at-mouse
C-c C-o    denote-link-open-at-point
RET        denote-link-open-at-point

Documentation

Keymap for mouse actions over fontified Denote links.

Aliases

denote-fontify-links-map
