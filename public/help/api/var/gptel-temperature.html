Variable: gptel-temperature

gptel-temperature is a customizable variable defined in gptel-request.el.

Value

nil

Documentation

"Temperature" of the LLM response.

This is a number between 0.0 and 2.0 that controls the randomness of the response, with 2.0 being the most random. It can also be nil for the LLM API's default value.

To set the temperature for a chat session interactively call gptel-send with a prefix argument.
