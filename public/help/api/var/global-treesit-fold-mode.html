Variable: global-treesit-fold-mode

global-treesit-fold-mode is a customizable variable defined in treesit-fold.el.

Value

nil

Documentation

Non-nil if Global Treesit-Fold mode is enabled.

See the global-treesit-fold-mode(var)/global-treesit-fold-mode(fun) command for a description of this minor mode. Setting this variable directly does not take effect; either customize it (see the info node (emacs)Easy Customization) or call the function global-treesit-fold-mode(var)/global-treesit-fold-mode(fun).

Key Bindings

This command is not in any keymaps.
