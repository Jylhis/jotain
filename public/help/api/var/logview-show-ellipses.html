Variable: logview-show-ellipses

logview-show-ellipses is a customizable variable defined in logview.el.

Value

t

Documentation

Whether to show ellipses to indicate hidden log entries.

To temporarily change this on per-buffer basis type \<logview-mode-map>M-x logview-toggle-show-ellipses (logview-toggle-show-ellipses).
