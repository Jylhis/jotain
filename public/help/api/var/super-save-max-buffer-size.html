Variable: super-save-max-buffer-size

super-save-max-buffer-size is a customizable variable defined in super-save.el.

Value

nil

Documentation

Maximal size of buffer (in characters), for which super-save works.

Exists mostly because saving constantly huge buffers can be slow in some cases. Set to 0 or nil to disable.

This variable was added, or its default value changed, in super-save version 0.4.0.
