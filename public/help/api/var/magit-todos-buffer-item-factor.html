Variable: magit-todos-buffer-item-factor

magit-todos-buffer-item-factor is a customizable variable defined in magit-todos.el.

Value

10

Documentation

Adjustment to item grouping in dedicated magit-todos buffers.

Multiplies magit-todos-auto-group-items and magit-todos-max-items by this factor.
