Variable: verb-last

verb-last is a variable defined in verb.el.

Value

nil

Documentation

Stores the last received HTTP response (verb-response(var)/verb-response(fun) object).

This variable is shared across any buffers using Verb mode. Consider using this variable inside code tags if you wish to use results from previous requests on new requests.
