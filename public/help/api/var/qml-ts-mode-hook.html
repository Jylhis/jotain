Variable: qml-ts-mode-hook

qml-ts-mode-hook is a variable defined in qml-ts-mode.el.

Value

nil

Documentation

Hook run after entering qml-ts-mode.

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
