Variable: eca-chat-inline-max-lines

eca-chat-inline-max-lines is a customizable variable defined in eca-chat-inline.el.

Value

20

Documentation

Max answer lines the inline overlay viewport shows at once.

Longer answers are scrollable (\n / \p on the overlay, or
\C-M-v / \C-M-S-v from anywhere in the buffer); by default
the viewport follows the tail while streaming and jumps to the head when finished. nil means no limit.
