Variable: eca-chat-hide-markdown-markup

eca-chat-hide-markdown-markup is a customizable variable defined in eca-chat.el.

Value

t

Documentation

Whether ECA chat renders markdown-markup as invisible.

When non-nil, preserve the historical hidden-markup look. When nil, keep markup visible while leaving markdown-hide-markup enabled. This is recommended if fenced code blocks jump while typing or streaming.
