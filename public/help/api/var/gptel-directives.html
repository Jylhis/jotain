Variable: gptel-directives

gptel-directives is a customizable variable defined in gptel-request.el.

Documentation

System prompts or directives for the LLM.

Each entry in this alist maps a symbol naming the prompt/directive to the directive itself. By default, gptel uses the directive with the key
\+default.

To set the system prompt for a chat session from this list interactively, call gptel-send with a prefix argument, or call gptel-menu.

A "directive" is typically the system prompt (also called system message or system instruction) sent at the beginning of each request to the LLM. It is used to set general instructions, expectations and the overall tone.

A directive in gptel-directives can be a string (included as-is), a list of strings (system prompt + conversation template) or a function returning a string or list of strings. See gptel-system-prompt for details.
