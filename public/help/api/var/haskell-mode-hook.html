Variable: haskell-mode-hook

haskell-mode-hook is a customizable variable defined in haskell-mode.el.

Value

(haskell-indentation-mode(var)/haskell-indentation-mode(fun)
 interactive-haskell-mode)

Documentation

List of functions to run after haskell-mode is enabled.

Use to enable minor modes coming with haskell-mode or run an arbitrary function.

Note that haskell-indentation-mode(var)/haskell-indentation-mode(fun) and haskell-indent-mode should not be
run at the same time.
