Variable: tuareg-opam-mode-hook

tuareg-opam-mode-hook is a variable defined in tuareg-opam.el.

Value

nil

Documentation

Hook run after entering tuareg-opam-mode.

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
