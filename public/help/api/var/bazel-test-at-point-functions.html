Variable: bazel-test-at-point-functions

bazel-test-at-point-functions is a customizable variable defined in bazel.el.

Value

(which-function)

Documentation

Abnormal hook to find a test case at point.

Each function in this hook should check whether it recognizes the area around point as a test case, and return a string that can be used as value for Bazel’s --test_filter option if so. The default value of this option includes ‘which-function’ at low priority.
