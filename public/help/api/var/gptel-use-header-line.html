Variable: gptel-use-header-line

gptel-use-header-line is a customizable variable defined in gptel.el.

Value

t

Documentation

Whether gptel-mode(var)/gptel-mode(fun) should use header-line for status information.

When set to nil, use the mode line for (minimal) status information and the echo area for messages.
