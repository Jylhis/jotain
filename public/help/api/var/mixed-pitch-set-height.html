Variable: mixed-pitch-set-height

mixed-pitch-set-height is a customizable variable defined in mixed-pitch.el.

Value

nil

Documentation

If non-nil, set the height of the face.

When nil, only set the family.

This variable was added, or its default value changed, in mixed-pitch version 1.1.0.
