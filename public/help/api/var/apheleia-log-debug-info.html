Variable: apheleia-log-debug-info

apheleia-log-debug-info is a customizable variable defined in apheleia-log.el.

Value

nil

Documentation

Non-nil means to log debugging info to apheleia-debug-info-buffer.

This may be useful in understanding what commands Apheleia is running, in what order, and at what times, or for filing a bug report.
