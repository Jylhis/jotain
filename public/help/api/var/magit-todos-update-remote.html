Variable: magit-todos-update-remote

magit-todos-update-remote is a customizable variable defined in magit-todos.el.

Value

nil

Documentation

Automatically scan in remote repositories.

If nil, remote repos are only scanned when a manual scan is initiated (see command magit-todos-update(var)/magit-todos-update(fun)). Remote repos include ones accessed via TRAMP (i.e. any path for which file-remote-p returns non-nil).
