Variable: doom-modeline-excluded-modelines

doom-modeline-excluded-modelines is a customizable variable defined in doom-modeline-core.el.

Value

nil

Documentation

List of modeline names to exclude from doom-modeline-add-segment.

These modelines will not be modified when adding segments programmatically.
