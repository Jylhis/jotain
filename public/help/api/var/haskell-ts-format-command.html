Variable: haskell-ts-format-command

haskell-ts-format-command is a customizable variable defined in haskell-ts-mode.el.

Value

"ormolu --stdin-input-file %s"

Documentation

The command used to call the formatter. The input is given as the standard input. This string is passed to format, with the one argument being the buffer-file-name(var)/buffer-file-name(fun).
