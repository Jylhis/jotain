Variable: verb--inhibit-code-tags-evaluation

verb--inhibit-code-tags-evaluation is a variable defined in verb.el.

Value

nil

Documentation

When non-nil, do not evaluate code tags in requests specs.

This variable is used mostly to parse and then copy request specs to other buffers without actually expanding the embedded code tags.
