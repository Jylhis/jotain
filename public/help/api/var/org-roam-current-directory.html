Variable: org-roam-current-directory

org-roam-current-directory is an alias for org-roam-buffer-current-directory, defined in org-roam-compat.el.

This variable is obsolete since org-roam 2.0; use org-roam-buffer-current-directory instead.

Value

nil

Documentation

The org-roam-directory value of org-roam-buffer-current-node.

Set both, locally and globally in the same way as org-roam-buffer-current-node.

Aliases

org-roam-buffer-current-directory
