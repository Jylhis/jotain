Variable: claude-code-ide-use-side-window

claude-code-ide-use-side-window is a customizable variable defined in claude-code-ide.el.

Value

t

Documentation

Whether to display Claude Code in a side window.

When non-nil (default), Claude Code opens in a dedicated side window controlled by claude-code-ide-window-side and related settings. When nil, Claude Code opens in a regular buffer that follows standard display-buffer behavior.
