Variable: logview-font-lock-defaults

logview-font-lock-defaults is a variable defined in logview.el.

Value

(nil nil t nil
     (font-lock-fontify-region-function . logview--fontify-region))

Documentation

Value of font-lock-defaults in Logview buffers.

Derived modes shouldn't touch the value of this variable. Instead, in their initialization functions they can modify font-lock-defaults (already having a buffer-local value) as needed. They may also use font-lock-add-keywords and similar functions.

However, remember that Logview uses heavily optimized font-lock overrides. Some functionality you'd expect a major mode to support might not work. You can file a bug in the issue tracker if you have troubles writing a derived mode.
