Variable: pulsar-delay

pulsar-delay is a customizable variable defined in pulsar.el.

Value

0.05

Documentation

Delay between increments of a pulse.

Together with pulsar-iterations control the overall duration of a pulse. Only applies when pulsar-pulse is non-nil.

This variable was added, or its default value changed, in pulsar version 0.1.0.
