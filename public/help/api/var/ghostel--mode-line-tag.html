Variable: ghostel--mode-line-tag

ghostel--mode-line-tag is a buffer-local variable defined in ghostel.el.

Documentation

Current input-mode label rendered in mode-line-process.

String like ":Char" / ":Line" / ":Copy" / ":Emacs", or nil for semi-char. Composed with ghostel--mode-line-progress
(and the spinner construct, when active) by
ghostel--mode-line-refresh so OSC 9;4 progress updates do not clobber the input-mode label.
