Variable: git-commit-mode-hook

git-commit-mode-hook is an alias and customizable for git-commit-setup-hook, defined in git-commit.el.

Value

(git-commit-ensure-comment-gap
 git-commit-save-message
 git-commit-setup-capf
 git-commit-setup-changelog-support
 git-commit-setup-auto-fill
 git-commit-propertize-diff
 git-commit-collapse-diff
 bug-reference-mode)

Documentation

This variable is an alias for git-commit-setup-hook (which see).

Also note that git-commit-mode(var)/git-commit-mode(fun) (which see) is not a major-mode.
