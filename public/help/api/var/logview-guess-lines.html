Variable: logview-guess-lines

logview-guess-lines is a customizable variable defined in logview.el.

Value

500

Documentation

When guessing submodes, consider this many lines at the top.

If any line corresponds to a defined submode, all the others are not even looked at. If several lines look like log entry starts, but still cannot be matched against known submodes, the rest is skipped, see variable logview-max-promising-lines. However, setting this to a ridiculously large number can still be slow.
