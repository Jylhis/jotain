Variable: gptel-save-state-hook

gptel-save-state-hook is a customizable variable defined in gptel.el.

Value

nil

Documentation

Hook run before gptel saves model parameters to a file.

You can use this hook to store additional conversation state or model parameters to the chat buffer, or to modify the buffer in some other way.
