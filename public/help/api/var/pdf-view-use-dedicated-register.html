Variable: pdf-view-use-dedicated-register

pdf-view-use-dedicated-register is a customizable variable defined in pdf-view.el.

Value

t

Documentation

Whether to use dedicated register for PDF positions.

If this is non-nil, the commands pdf-view-position-to-register and pdf-view-jump-to-register use the buffer-local variable pdf-view-register-alist to store resp. retrieve marked positions. Otherwise the common variable register-alist is used.
