Variable: pulsar-pulse-on-window-change

pulsar-pulse-on-window-change is a customizable variable defined in pulsar.el.

Value

nil

Documentation

When non-nil, enable pulsing on every window change.

This covers all commands or functions that affect the current window. Users who prefer to trigger a pulse only after select functions (e.g. only after other-window) are advised to set this variable to nil and update the pulsar-pulse-functions accordingly.

This variable was added, or its default value changed, in pulsar version 1.2.0.
