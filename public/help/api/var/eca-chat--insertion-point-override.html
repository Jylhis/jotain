Variable: eca-chat--insertion-point-override

eca-chat--insertion-point-override is a variable defined in eca-chat.el.

Value

nil

Documentation

When non-nil, a marker overriding eca-chat--content-insertion-point.

Bound while prepending an older history page so the shared content renderer inserts above existing content instead of just above the prompt area.
