Variable: sops-extra-encrypt-args

sops-extra-encrypt-args is a customizable variable defined in sops.el.

Value

nil

Documentation

Additional arguments to sops on encrypt.

Inserted between --filename-override FILE and the trailing input-file path that sops--run appends. Example for age SSH:
'("-a" "<ssh-key>").
