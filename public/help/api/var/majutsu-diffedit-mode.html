Variable: majutsu-diffedit-mode

majutsu-diffedit-mode is a buffer-local variable defined in majutsu-edit.el.

Documentation

Non-nil if Majutsu-DiffEdit mode is enabled.

Use the command majutsu-diffedit-mode(var)/majutsu-diffedit-mode(fun) to change this variable.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-edit.el
(define-minor-mode majutsu-diffedit-mode
  "Minor mode for jj diffedit buffers."
  :lighter " DiffEdit"
  (if majutsu-diffedit-mode
      (progn
        (with-editor-mode 1)
        (when majutsu-edit-finish-on-save
          (add-hook 'after-save-hook #'majutsu-edit--finish-on-save nil t)))
    (remove-hook 'after-save-hook #'majutsu-edit--finish-on-save t)))
