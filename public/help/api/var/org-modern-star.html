Variable: org-modern-star

org-modern-star is a customizable variable defined in org-modern.el.

Value

fold

Documentation

Style heading stars.

Can be nil, fold or replace. See org-modern-fold-stars and org-modern-replace-stars for the respective configurations.

(defcustom org-modern-star 'fold
  "Style heading stars.
Can be nil, fold or replace.  See `org-modern-fold-stars' and
`org-modern-replace-stars' for the respective configurations."
  :type '(choice (const :tag "No styling" nil)
                 (const :tag "Folding indicators" fold)
                 (const :tag "Replace" replace)))
