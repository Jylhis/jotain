Variable: haskell-process-path-stack

haskell-process-path-stack is a customizable variable defined in haskell-customize.el.

Value

"stack"

Documentation

The path for starting stack.

This can either be a single string or a list of strings, where the first elements is a string and the remaining elements are arguments, which will be prepended to haskell-process-args-stack-ghci.
