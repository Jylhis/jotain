Variable: markdown-display-remote-images

markdown-display-remote-images is a customizable variable defined in markdown-mode.el.

Value

nil

Documentation

If non-nil, download and display remote images.

See also markdown-inline-image-overlays.

Only image URLs specified with a protocol listed in markdown-remote-image-protocols are displayed.
