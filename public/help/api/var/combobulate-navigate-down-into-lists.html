Variable: combobulate-navigate-down-into-lists

combobulate-navigate-down-into-lists is a customizable variable defined in combobulate-settings.el.

Value

t

Documentation

Whether to navigate into the first list-like structure ahead of point in the absence of other suitable nodes.
