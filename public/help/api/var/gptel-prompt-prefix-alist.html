Variable: gptel-prompt-prefix-alist

gptel-prompt-prefix-alist is a customizable variable defined in gptel-request.el.

Value

((markdown-mode . "### ") (org-mode . "*** ") (text-mode . "### "))

Documentation

String used as a prefix to the query being sent to the LLM.

This is meant for the user to distinguish between queries and responses, and is removed from the query before it is sent.

This is an alist mapping major modes to the prefix strings. This is only inserted in dedicated gptel buffers.
