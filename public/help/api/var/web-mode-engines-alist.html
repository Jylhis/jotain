Variable: web-mode-engines-alist

web-mode-engines-alist is a customizable variable defined in web-mode.el.

Value

nil

Documentation

A list of filename patterns and corresponding web-mode engine.

For example,
(setq web-mode-engines-alist
       '(("php" . "\\\\.phtml\\\\\\='")
         ("blade" . "\\\\.blade\\\\.")))
