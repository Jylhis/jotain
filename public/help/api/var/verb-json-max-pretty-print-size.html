Variable: verb-json-max-pretty-print-size

verb-json-max-pretty-print-size is a customizable variable defined in verb.el.

Value

1048576

Documentation

Max JSON file size (# of chars) to automatically prettify when received.

If nil, never prettify JSON files automatically. This variable only applies if verb-handler-json is being used to handle JSON responses.

(defcustom verb-json-max-pretty-print-size (* 1 1024 1024)
  "Max JSON file size (# of chars) to automatically prettify when received.
If nil, never prettify JSON files automatically.  This variable only applies
if `verb-handler-json' is being used to handle JSON responses."
  :type '(choice (integer :tag "Max bytes")
                 (const :tag "Off" nil)))
