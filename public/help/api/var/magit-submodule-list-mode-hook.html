Variable: magit-submodule-list-mode-hook

magit-submodule-list-mode-hook is a customizable variable defined in magit-submodule.el.

Value

(hl-line-mode)

Documentation

Hook run after entering Magit-Submodule-List mode.

This variable was added, or its default value changed, in magit version 2.9.0.

(defcustom magit-submodule-list-mode-hook (list #'hl-line-mode)

  :package-version '(magit . "2.9.0")

  :type 'hook
