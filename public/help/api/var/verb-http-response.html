Variable: verb-http-response

verb-http-response is a buffer-local variable defined in verb.el.

Documentation

HTTP response for this response buffer (verb-response(var)/verb-response(fun) object).

The decoded body contents of the response are included in the buffer itself.

In a response buffer, before the response has been received, this variable will be set to t.
