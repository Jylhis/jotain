Variable: gnuplot-basic-offset

gnuplot-basic-offset is a customizable variable defined in gnuplot.el.

Value

4

Documentation

Number of columns to indent lines inside a do- or if-else-block.

This applies only to new-style do- and if-statements using braces. Commands continued over a linebreak using a backslash are always indented to line up with the second word on the line beginning the continued command.
