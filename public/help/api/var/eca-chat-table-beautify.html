Variable: eca-chat-table-beautify

eca-chat-table-beautify is a customizable variable defined in eca-chat.el.

Value

t

Documentation

When non-nil, apply enhanced visual styling to markdown tables.

Adds header highlighting, dimmed separators, zebra-striped rows, and subtler pipe characters. Only affects visual presentation via overlays — the underlying buffer text is unchanged, so copy/paste works normally.
