Variable: combobulate-tsx-minor-mode-hook

combobulate-tsx-minor-mode-hook is a customizable variable defined in combobulate-js-ts.el.

Value

nil

Documentation

Hook run after entering or leaving combobulate-tsx-minor-mode(var)/combobulate-tsx-minor-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
