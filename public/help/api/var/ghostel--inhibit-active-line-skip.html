Variable: ghostel--inhibit-active-line-skip

ghostel--inhibit-active-line-skip is a variable defined in ghostel-links.el.

Value

nil

Documentation

When non-nil, ghostel--detect-urls scans the cursor's line too.

That line is normally left alone as the prompt being typed at. A terminal that has exited has no prompt, and its last row is ordinary output — often the one row a command that printed no trailing newline ended on.
