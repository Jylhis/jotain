Variable: hl-todo-mode-hook

hl-todo-mode-hook is a customizable variable defined in hl-todo.el.

Value

(hl-todo-mode--set-explicitly(var)/hl-todo-mode--set-explicitly(fun))

Documentation

Hook run after entering or leaving hl-todo-mode(var)/hl-todo-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
