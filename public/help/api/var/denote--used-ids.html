Variable: denote--used-ids

denote--used-ids is an alias for denote-used-identifiers, defined in denote.el.

This variable is obsolete since 4.1.0; use denote-used-identifiers instead.

Value

nil

Documentation

Hash table of used identifiers.

This variable should be set only for the duration of a command. It should stay nil otherwise.

Aliases

denote-used-identifiers
