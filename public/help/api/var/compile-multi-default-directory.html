Variable: compile-multi-default-directory

compile-multi-default-directory is a customizable variable defined in compile-multi.el.

Value

nil

Documentation

Assign default-directory of a compilation in compile-multi.

If set this function will be called prior to determining compilation triggers and actions and default-directory will be set to the result. If the result is nil then default-directory will not be changed.
