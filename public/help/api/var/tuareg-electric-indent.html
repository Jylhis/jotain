Variable: tuareg-electric-indent

tuareg-electric-indent is a customizable variable defined in tuareg.el.

Value

nil

Documentation

Whether to automatically indent the line after typing one of the words in tuareg-electric-indent-keywords. Lines starting with |, ), `]`, and } are always indented when the electric-indent-mode(var)/electric-indent-mode(fun) is turned on.
