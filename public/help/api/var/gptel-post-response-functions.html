Variable: gptel-post-response-functions

gptel-post-response-functions is a customizable variable defined in gptel.el.

Value

(pulse-momentary-highlight-region)

Documentation

Abnormal hook run after inserting the LLM response into the current buffer.

This hook is called in the buffer to which the LLM response is sent, and after the full response has been inserted. Each function is called with two arguments: the response beginning and end positions.

Note: this hook runs even if the request fails. In this case the response beginning and end positions are both the cursor position at the time of the request.

Aliases

gptel-post-response-hook (obsolete since 0.6.0)
