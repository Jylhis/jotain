Variable: forge-topic-wash-title-hook

forge-topic-wash-title-hook is a customizable variable defined in forge-topic.el.

Value

(magit-highlight-bracket-keywords)

Documentation

Functions used to highlight parts of each individual topic title.

These functions are called in order, in a buffer that containing the topic title. They should set text properties as they see fit, usually just font-lock-face. Before each function is called, point is at the beginning of the buffer.

This variable was added, or its default value changed, in forge version 0.4.7.
