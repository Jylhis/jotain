Variable: eca-process--releases-cache

eca-process--releases-cache is a variable defined in eca-process.el.

Value

nil

Documentation

Cached parsed releases list from GitHub API.

When non-nil, a cons cell of (FETCH-TIME . RELEASES) where FETCH-TIME is the value of float-time when RELEASES was last fetched. Honored together with eca-server-releases-cache-ttl by eca-process--fetch-releases.
