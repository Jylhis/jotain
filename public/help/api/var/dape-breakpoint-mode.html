Variable: dape-breakpoint-mode

dape-breakpoint-mode is a buffer-local variable defined in dape.el.

Documentation

Non-nil if Dape-Breakpoint mode is enabled.

Use the command dape-breakpoint-mode(var)/dape-breakpoint-mode(fun) to change this variable.

Key Bindings

This command is not in any keymaps.
