Variable: verb-tag

verb-tag is a customizable variable defined in verb.el.

Value

"verb"

Documentation

Tag used to mark headings that contain HTTP request specs.

Headings that do not contain this tag will be ignored when building requests from heading hierarchies.

If set to t, consider all headings to contain HTTP request specs.

You can set this variable file-locally to use different tags on different files, like so:

# -*- verb-tag: "foo" -*-

Note that if a heading has a tag, then all its subheadings inherit that tag as well. This can be changed via the org-use-tag-inheritance variable.
