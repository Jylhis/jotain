Variable: ghostel-ignore-cursor-change

ghostel-ignore-cursor-change is a customizable variable defined in ghostel.el.

Value

nil

Documentation

When non-nil, ignore terminal requests to change cursor shape or visibility.

Useful when editor-owned cursor behavior should take precedence over terminal-driven cursor changes. Copy mode restores cursor-type to its default value.
