Variable: gptel-max-tokens

gptel-max-tokens is a customizable variable defined in gptel-request.el.

Value

nil

Documentation

Max tokens per response.

This is roughly the number of words in the response. 100-300 is a reasonable range for short answers, 400 or more for longer responses.

To set the target token count for a chat session interactively call gptel-send with a prefix argument.
