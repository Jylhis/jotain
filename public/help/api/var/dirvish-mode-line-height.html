Variable: dirvish-mode-line-height

dirvish-mode-line-height is a customizable variable defined in dirvish.el.

Value

21

Documentation

Height of Dirvish's mode line.

The value should be a cons cell (H-WIN . H-FRAME), where H-WIN and H-FRAME represent the height of mode line in single window state and fullframe state respectively. If this value is a integer INT, it is seen as a shorthand for (INT . INT).
