Variable: doom-modeline-mode-hook

doom-modeline-mode-hook is a customizable variable defined in doom-modeline.el.

Value

(doom-modeline-override-time
 doom-modeline-override-battery
 doom-modeline-override-rcirc
 doom-modeline-override-mu4e-modeline
 doom-modeline-override-mu4e-alert
 doom-modeline-override-eglot
 doom-modeline-override-window-number)

Documentation

Hook run after entering or leaving doom-modeline-mode(var)/doom-modeline-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
