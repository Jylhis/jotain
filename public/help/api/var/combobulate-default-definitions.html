Documentation

Default definitions that each language minor mode can set.

This is a list of defvar forms that are used to define the default values for each language minor mode.

It is unlikely that a regular user would want to configure these, as they are used to set up the language minor modes used by Combobulate.

The primary use for these is through define-combobulate-language.
