Variable: combobulate-cursor-substitute-match

combobulate-cursor-substitute-match is a variable defined in combobulate-cursor.el.

Value

"\\(\\\\\\([0-9]+\\)\\)"

Documentation

Regexp that matches the backslash and number in a regexp group.

Altering this is possible, but not recommended as other parts of the code base make assumptions based on this.
