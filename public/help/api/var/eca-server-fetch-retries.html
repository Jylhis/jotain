Variable: eca-server-fetch-retries

eca-server-fetch-retries is a customizable variable defined in eca-process.el.

Value

2

Documentation

How many times curl retries transient GitHub failures.

Applied via cURL --retry to the releases list fetch and to server binary downloads when eca-server-download-method is curl. When all attempts fail, eca falls back to the already installed server binary if available.
