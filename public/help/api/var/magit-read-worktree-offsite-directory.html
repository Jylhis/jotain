Variable: magit-read-worktree-offsite-directory

magit-read-worktree-offsite-directory is a customizable variable defined in magit-worktree.el.

Value

"/build/tmp.DOvEMeeTIC/.local/share/wtrees/"

Documentation

Base directory used by magit-read-worktree-directory-offsite.

That function is suitable as magit-read-worktree-directory-function, but is not used by default.

This variable was added, or its default value changed, in magit version 4.4.0.
