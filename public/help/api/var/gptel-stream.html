Variable: gptel-stream

gptel-stream is a customizable variable defined in gptel-request.el.

Value

t

Documentation

Stream responses from the LLM as they are received.

This option is ignored unless
- the LLM backend supports streaming, and
- Curl is in use (see gptel-use-curl)

When set to nil, Emacs waits for the full response and inserts it all at once. This wait is asynchronous.

='tis a bit silly.
