Variable: bazel-display-coverage

bazel-display-coverage is a customizable variable defined in bazel.el.

Value

nil

Documentation

Specifies whether to parse compilation buffers for coverage information.

If nil, don’t attempt to find coverage information in compilation buffers. If t, always search for coverage information, and display the coverage status in buffers that visit covered files. If ‘local’, only do so for local files.
