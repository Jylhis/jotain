Variable: ghostel-detect-password-prompts

ghostel-detect-password-prompts is a customizable variable defined in ghostel.el.

Value

t

Documentation

Whether ghostel watches for password prompts and pops read-passwd.

When non-nil (the default), the libghostty heuristic and cursor-row regex run after each redraw and read-passwd is invoked on a rising edge. See ghostel--detect-password-prompt.
