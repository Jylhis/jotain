Variable: ghostel--term-rows

ghostel--term-rows is a buffer-local variable defined in ghostel.el.

Documentation

Committed row count of the native terminal.

Used for viewport/scrollback arithmetic. Updated by the native renderer when the terminal is created or a resize is committed.
