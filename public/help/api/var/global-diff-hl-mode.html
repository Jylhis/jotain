Variable: global-diff-hl-mode

global-diff-hl-mode is a customizable variable defined in diff-hl.el.

Value

nil

Documentation

Non-nil if Global Diff-Hl mode is enabled.

See the global-diff-hl-mode(var)/global-diff-hl-mode(fun) command for a description of this minor mode. Setting this variable directly does not take effect; either customize it (see the info node (emacs)Easy Customization) or call the function global-diff-hl-mode(var)/global-diff-hl-mode(fun).

Key Bindings

This command is not in any keymaps.
