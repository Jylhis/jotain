Variable: denote-menu-bar-mode

denote-menu-bar-mode is a customizable variable defined in denote.el.

Value

t

Documentation

Non-nil if Denote-Menu-Bar mode is enabled.

See the denote-menu-bar-mode(var)/denote-menu-bar-mode(fun) command for a description of this minor mode. Setting this variable directly does not take effect; either customize it (see the info node (emacs)Easy Customization) or call the function denote-menu-bar-mode(var)/denote-menu-bar-mode(fun).

Key Bindings

This command is not in any keymaps.

;;;###autoload
(define-minor-mode denote-menu-bar-mode "Show Denote menu bar."
  :global t
  :init-value t
  (if denote-menu-bar-mode
      (denote--menu-bar-enable)
    (define-key global-map [menu-bar denote] nil)))
