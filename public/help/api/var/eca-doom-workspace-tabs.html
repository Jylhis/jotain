Variable: eca-doom-workspace-tabs

eca-doom-workspace-tabs is a customizable variable defined in eca-doom.el.

Value

t

Documentation

Whether to decorate the Doom workspace tabline with ECA status.

When non-nil, workspaces related to an ECA session that is running or waiting for user approval are colored in the tabline shown by
+workspace/display and after workspace switches. Only used in
Doom Emacs with the :ui workspaces module enabled.
