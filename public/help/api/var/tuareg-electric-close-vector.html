Variable: tuareg-electric-close-vector

tuareg-electric-close-vector is a customizable variable defined in tuareg.el.

Value

t

Documentation

Non-nil means electrically insert | before a vector-closing ] or
> before an object-closing }.

Many people find electric keys irritating, so you can disable them by setting this variable to nil. You should probably have this on, though, if you also have tuareg-electric-indent on.
