Variable: dape-read-memory-default-count

dape-read-memory-default-count is an alias and customizable for dape-memory-page-size, defined in dape.el.

This variable is obsolete since 0.8.0; use dape-memory-page-size instead.

Value

1024

Documentation

The bytes read with dape-memory.

Aliases

dape-memory-page-size
