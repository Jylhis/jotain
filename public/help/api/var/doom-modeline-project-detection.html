Variable: doom-modeline-project-detection

doom-modeline-project-detection is a customizable variable defined in doom-modeline-core.el.

Value

auto

Documentation

How to detect the project root.

nil means to use default-directory.

The project management packages have some issues on detecting project root. E.g., projectile doesn't handle symlink folders well, while project is unable to handle sub-projects. Specify another one if you encounter the issue.

(defcustom doom-modeline-project-detection 'auto
  "How to detect the project root.

nil means to use `default-directory'.

The project management packages have some issues on detecting project root.
E.g., `projectile' doesn't handle symlink folders well, while `project' is
unable to handle sub-projects.
Specify another one if you encounter the issue."
  :type '(choice (const :tag "Auto-detect" auto)
                 (const :tag "Find File in Project" ffip)
                 (const :tag "Projectile" projectile)
                 (const :tag "Built-in Project" project)
                 (const :tag "Disable" nil))
  :group 'doom-modeline)
