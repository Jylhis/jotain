Variable: doom-modeline-irc-priority-only

doom-modeline-irc-priority-only is a customizable variable defined in doom-modeline-core.el.

Value

nil

Documentation

Only show IRC notifications for buffers matching a filter.

This lets you filter out general channel activity and only show what matters to you. Requires circe and tracking-faces-priorities or rcirc and rcirc-keywords to be configured.
