Variable: global-sops-mode

global-sops-mode is a customizable variable defined in sops.el.

Value

nil

Documentation

Non-nil if Global Sops mode is enabled.

See the global-sops-mode(var)/global-sops-mode(fun) command for a description of this minor mode. Setting this variable directly does not take effect; either customize it (see the info node (emacs)Easy Customization) or call the function global-sops-mode(var)/global-sops-mode(fun).

Key Bindings

This command is not in any keymaps.

;;;###autoload
(define-globalized-minor-mode global-sops-mode
  sops-mode
  (lambda () nil)  ; sops-mode itself is enabled inside sops--find-file-hook, not here
  :group 'sops
  (if global-sops-mode
      (progn
        (sops--check-v0.1.X-config)
        (add-hook 'find-file-hook #'sops--find-file-hook))
    (remove-hook 'find-file-hook #'sops--find-file-hook)))
