Variable: denote-sort-keywords-comparison-function

denote-sort-keywords-comparison-function is a customizable variable defined in denote.el.

Value

string-collate-lessp

Documentation

Function to sort the KEYWORDS component in file names.

The function accepts two arguments and must return a non-nil value if the first argument is smaller than the second one.

This variable was added, or its default value changed, in denote version 3.1.0.
