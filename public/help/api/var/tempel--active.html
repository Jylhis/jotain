Variable: tempel--active

tempel--active is a buffer-local variable defined in tempel.el.

Documentation

List of active templates.

Each template state is a pair, where the car is a list of overlays and the cdr is an alist of variable bindings. The template state is attached to each overlay as the property tempel--field. Furthermore overlays may be named with tempel--name or carry an evaluatable Lisp expression tempel--form.
