Variable: haskell-process-type

haskell-process-type is a customizable variable defined in haskell-customize.el.

Value

auto

Documentation

The inferior Haskell process type to use.

Customize this variable to see the supported symbol values.

When set to 'auto (the default), the directory contents and available programs will be used to make a best guess at the process type and the project directory.

Emacs looks in the current directory and then in its parents for a file "cabal.sandbox.config" or "cabal.project". its location is the project directory, and "cabal" will be used.

Otherwise if a file "stack.yaml" is found, its location is the project directory, and stack will be used Otherwise if a file "*.cabal" is found, its location is the project directory, and cabal will be used. If none of the above apply, ghc will be used.

(The value cabal-new-repl is obsolete, equivalent to cabal-repl).
