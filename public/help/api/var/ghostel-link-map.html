Variable: ghostel-link-map

ghostel-link-map is a variable defined in ghostel-links.el.

Value

<mouse-1>  ghostel-open-link-at-click
<mouse-2>  ghostel-open-link-at-click

Documentation

Keymap for clickable hyperlinks in ghostel buffers.

Mouse clicks on a linkified cell open the link in any input mode.

RET not bound here so a misdetected link inside a typed command in semi-char/char mode never hijacks the key away from the PTY.
