Variable: hl-todo-include-modes

hl-todo-include-modes is a customizable variable defined in hl-todo.el.

Value

(prog-mode text-mode conf-mode)

Documentation

Major-modes in which hl-todo-mode(var)/hl-todo-mode(fun) is activated.

This is used by global-hl-todo-mode(var)/global-hl-todo-mode(fun), which activates the local hl-todo-mode(var)/hl-todo-mode(fun) in all buffers whose major-mode derive from one of the modes listed here, but not from one of the modes listed in hl-todo-exclude-modes.

This variable was added, or its default value changed, in hl-todo version 3.7.0.
