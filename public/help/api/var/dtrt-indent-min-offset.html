Variable: dtrt-indent-min-offset

dtrt-indent-min-offset is a customizable variable defined in dtrt-indent.el.

Value

2

Documentation

*Minimum indentation offset that can be guessed.

You usually don't want to tinker with this - setting it to a higher value than 2 means that the rather common offset of 2 will no longer be guessed. Setting it to 1 will likely screw up dtrt-indent algorithms because every line in every source code matches that indentation level.
