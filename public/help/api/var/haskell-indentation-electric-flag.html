Variable: haskell-indentation-electric-flag

haskell-indentation-electric-flag is a customizable and buffer-local variable defined in haskell-indentation.el.

Documentation

Non-nil means insertion of some characters may auto reindent the line.

If the variable electric-indent-mode(var)/electric-indent-mode(fun) is non-nil then this variable is overridden.
