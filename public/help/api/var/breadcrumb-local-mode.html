Variable: breadcrumb-local-mode

breadcrumb-local-mode is a buffer-local variable defined in breadcrumb.el.

Documentation

Non-nil if Breadcrumb-Local mode is enabled.

Use the command breadcrumb-local-mode(var)/breadcrumb-local-mode(fun) to change this variable.

Key Bindings

This command is not in any keymaps.

(define-minor-mode breadcrumb-local-mode
  "Header lines with breadcrumbs."
  :init-value nil
  (if bc-local-mode (add-to-list 'header-line-format '(:eval (bc--header-line)))
    (setq header-line-format (delete '(:eval (bc--header-line)) header-line-format))))
