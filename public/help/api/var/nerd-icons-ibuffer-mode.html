Variable: nerd-icons-ibuffer-mode

nerd-icons-ibuffer-mode is a buffer-local variable defined in nerd-icons-ibuffer.el.

Documentation

Non-nil if Nerd-Icons-Ibuffer mode is enabled.

Use the command nerd-icons-ibuffer-mode(var)/nerd-icons-ibuffer-mode(fun) to change this variable.

Key Bindings

This command is not in any keymaps.

(define-minor-mode nerd-icons-ibuffer-mode
  "Display icons for all buffers in ibuffer."
  :lighter nil
  (when (derived-mode-p 'ibuffer-mode)
    (setq-local ibuffer-formats (if nerd-icons-ibuffer-mode
                                    nerd-icons-ibuffer-formats
                                  nerd-icons-ibuffer-old-formats))
    (ibuffer-update nil t)))
