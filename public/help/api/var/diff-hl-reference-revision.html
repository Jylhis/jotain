Variable: diff-hl-reference-revision

diff-hl-reference-revision is a variable defined in diff-hl.el.

Value

nil

Documentation

Revision to diff against. nil means the most recent one.

It can be a relative expression as well, such as "HEAD^" with Git, or
"-2" with Mercurial.
