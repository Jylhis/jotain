Variable: apheleia-log-only-errors

apheleia-log-only-errors is a customizable variable defined in apheleia-log.el.

Value

t

Documentation

Non-nil means Apheleia will only log when an error occurs.

Otherwise, Apheleia will log every time a formatter is run, even if it is successful.
