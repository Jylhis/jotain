Variable: zig-ts-mode-hook

zig-ts-mode-hook is a variable defined in zig-ts-mode.el.

Value

nil

Documentation

Hook run after entering zig-ts-mode.

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
