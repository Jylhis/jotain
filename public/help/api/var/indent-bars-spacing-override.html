Variable: indent-bars-spacing-override

indent-bars-spacing-override is a customizable and buffer-local variable defined in indent-bars.el.

Documentation

Override for default, major-mode based indentation spacing.

Set only if the default guessed spacing is incorrect. Becomes buffer-local automatically.

;; Defined in /nix/store/kmdsnipwffgk5c0fs4785bhqa9fl17c5-emacs-packages-deps/share/emacs/site-lisp/elpa/indent-bars-1.0.1/indent-bars.el
(defcustom indent-bars-spacing-override nil
  "Override for default, major-mode based indentation spacing.
Set only if the default guessed spacing is incorrect.  Becomes
buffer-local automatically."
  :local t
  :type '(choice integer (const :tag "Discover automatically" :value nil))
  :set #'indent-bars--custom-set
  :initialize #'custom-initialize-default
  :group 'indent-bars)
