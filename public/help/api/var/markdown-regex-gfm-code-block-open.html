Value

Documentation

Regular expression matching opening of GFM code blocks.

Group 1 matches the opening three or more backquotes. Group 2 matches the opening brace (optional) and surrounding whitespace. Group 3 matches the language identifier (optional). Group 4 matches the info string (optional). Group 5 matches the closing brace (optional), whitespace, and newline. Groups need to agree with markdown-regex-tilde-fence-begin.
