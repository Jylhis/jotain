Variable: consult-eglot-embark-mode-hook

consult-eglot-embark-mode-hook is a customizable variable defined in consult-eglot-embark.el.

Value

nil

Documentation

Hook run after entering or leaving consult-eglot-embark-mode(var)/consult-eglot-embark-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
