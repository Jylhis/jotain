Variable: apheleia-inhibit-functions

apheleia-inhibit-functions is a customizable variable defined in apheleia.el.

Value

nil

Documentation

List of functions that prevent Apheleia from turning on automatically.

If one of these returns non-nil then apheleia-mode(var)/apheleia-mode(fun) is not enabled in a buffer, even if apheleia-global-mode(var)/apheleia-global-mode(fun) is on. You can still manually enable apheleia-mode(var)/apheleia-mode(fun) in such a buffer.

See also apheleia-inhibit for another way to accomplish a similar task. See also apheleia-skip-functions for functions that prevent Apheleia from running even when the mode is enabled.
