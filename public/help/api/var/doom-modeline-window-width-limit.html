Variable: doom-modeline-window-width-limit

doom-modeline-window-width-limit is a customizable variable defined in doom-modeline-core.el.

Value

85

Documentation

The limit of the window width.

If window-width is smaller than the limit, some information won't be displayed. It can be an integer or a float number. nil means no limit.
