Variable: verb-code-tag-delimiters

verb-code-tag-delimiters is a customizable variable defined in verb.el.

Value

("{{" . "}}")

Documentation

Lisp code tag delimiters for HTTP request specifications.

The delimiters (left and right) are used to specify, evaluate and then substitute Lisp code tags inside HTTP request specifications. If different parts of your HTTP request specifications need to include literal values identical to one or both of the delimiters, it is recommended you change them to something else through this setting.
