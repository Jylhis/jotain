Variable: wgrep-results-parser

wgrep-results-parser is a variable defined in wgrep.el.

Value

wgrep-parse-command-results

Documentation

This function parse line oriented command output and set following properties.

wgrep-line-filename, wgrep-line-number, wgrep-ignore and wgrep-construct-filename-property function construct the property name with wgrep-line-filename and the value is same. This property is used for searching
 correct point of filename.
Not like wgrep-header&footer-parser should not set read-only property.
