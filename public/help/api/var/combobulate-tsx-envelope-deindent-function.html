Variable: combobulate-tsx-envelope-deindent-function

combobulate-tsx-envelope-deindent-function is a variable defined in combobulate-js-ts.el.

Value

nil

Documentation

Function to call to calculate the previous indentation level of point.

The function must determine, from its current position in the buffer, the *preceding* indentation level.

This is little use to anything except whitespace-sensitive languages like YAML and Python.
