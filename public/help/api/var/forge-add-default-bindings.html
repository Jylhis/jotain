Variable: forge-add-default-bindings

forge-add-default-bindings is a variable defined in forge.el.

Value

t

Documentation

Whether to add Forge's bindings to various Magit keymaps.

If you want to disable this, then you must set this to nil before magit is loaded. If you do it before forge but after magit is loaded, then magit-mode-map ends up being modified anyway.
