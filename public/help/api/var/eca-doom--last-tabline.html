Variable: eca-doom--last-tabline

eca-doom--last-tabline is a variable defined in eca-doom.el.

Value

nil

Documentation

The last tabline string produced by eca-doom--tabline-advice.

Used to detect whether the workspace tabline is the message currently shown, so eca-doom--do-refresh only redraws an already-visible tabline.
