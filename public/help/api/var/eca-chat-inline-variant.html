Variable: eca-chat-inline-variant

eca-chat-inline-variant is a customizable variable defined in eca-chat-inline.el.

Value

nil

Documentation

Model variant for inline chats, or nil to let the server decide.

When nil the server falls back to its chatInline.variant config, then the forked chat's variant.
