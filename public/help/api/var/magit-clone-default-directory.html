Variable: magit-clone-default-directory

magit-clone-default-directory is a customizable variable defined in magit-clone.el.

Value

nil

Documentation

Default directory to use when magit-clone reads destination.

If nil (the default), then use the value of default-directory. If a directory, then use that. If a function, then call that with the remote url as only argument and use the returned value.

This variable was added, or its default value changed, in magit version 2.90.0.
