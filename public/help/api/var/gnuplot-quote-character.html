Variable: gnuplot-quote-character

gnuplot-quote-character is a customizable variable defined in gnuplot.el.

Value

"'"

Documentation

Quotation character used for inserting quoted strings.

Gnuplot can use single or double quotes. If you prefer to have the filename insertion function never insert quotes for you, set this to the empty string.

(defcustom gnuplot-quote-character "\'"
  "Quotation character used for inserting quoted strings.
Gnuplot can use single or double quotes.  If you prefer to have the
filename insertion function never insert quotes for you, set this
to the empty string."
  :type '(radio (const :tag "double quote"  "\"")
                (const :tag "single quote"  "\'")
                (const :tag "none"          ""  )))
