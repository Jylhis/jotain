Variable: gnuplot-after-plot-hook

gnuplot-after-plot-hook is a customizable variable defined in gnuplot.el.

Value

(gnuplot-trim-comint-buffer)

Documentation

Hook run after gnuplot plots something.

This is the last thing done by the functions for plotting a line, a region, a buffer, or a file.
