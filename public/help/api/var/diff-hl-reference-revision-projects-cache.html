Variable: diff-hl-reference-revision-projects-cache

diff-hl-reference-revision-projects-cache is a variable defined in diff-hl.el.

Value

nil

Documentation

Alist of cached directory roots for per-project reference revisions.

Each element in this list has the form (DIR . REV). DIR is the expanded name of the directory. REV is the current reference revision.
