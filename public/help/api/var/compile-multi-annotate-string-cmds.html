Variable: compile-multi-annotate-string-cmds

compile-multi-annotate-string-cmds is a customizable variable defined in compile-multi.el.

Value

t

Documentation

Auto annotate string based commands in compile-multi-config.

When true if a command in compile-multi-config is a string or produces a string then generate an annotation for it automatically. This option only has significance when compile-multi-annotate-cmds is true.
