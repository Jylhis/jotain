Variable: magit-blame-goto-chunk-hook

magit-blame-goto-chunk-hook is a customizable variable defined in magit-blame.el.

Value

(magit-blame-maybe-update-revision-buffer
 magit-blame-maybe-show-message)

Documentation

Hook run after point entered another chunk.

This variable was added, or its default value changed, in magit version 2.13.0.
