Variable: super-save-exclude

super-save-exclude is a customizable variable defined in super-save.el.

Value

nil

Documentation

A list of regexps for buffer-file-name(var)/buffer-file-name(fun) excluded from super-save.

When a buffer-file-name(var)/buffer-file-name(fun) matches any of the regexps it is ignored.

This variable was added, or its default value changed, in super-save version 0.4.0.

When a `buffer-file-name' matches any of the regexps it is ignored."
  :group 'super-save
  :type '(repeat (choice regexp))
