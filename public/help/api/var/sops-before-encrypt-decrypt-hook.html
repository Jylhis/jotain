Variable: sops-before-encrypt-decrypt-hook

sops-before-encrypt-decrypt-hook is a variable defined in sops.el.

Value

nil

Documentation

Removed in v0.2. Was a single hook fired before both decrypt and encrypt.

Use sops-before-decrypt-hook and sops-before-encrypt-hook instead. Kept only as a special variable so v0.1.X configs can be detected at global-sops-mode(var)/global-sops-mode(fun) activation; see sops--check-v0.1.X-config.
