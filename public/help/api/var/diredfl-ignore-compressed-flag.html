Variable: diredfl-ignore-compressed-flag

diredfl-ignore-compressed-flag is a customizable variable defined in diredfl.el.

Value

t

Documentation

*Non-nil means to font-lock names of compressed files as ignored files.

This applies to filenames whose extensions are in diredfl-compressed-extensions. If nil they are highlighted using face diredfl-compressed-file-name.
