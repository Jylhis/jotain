Variable: eca-chat-image-window-fit-cap

eca-chat-image-window-fit-cap is a customizable variable defined in eca-chat-image.el.

Value

800

Documentation

Hard pixel cap applied when eca-chat-image-max-width is fit-window.

Prevents inline images from becoming oversized on very wide chat windows. Has no effect for other values of eca-chat-image-max-width.
