Variable: tuareg-match-clause-indent

tuareg-match-clause-indent is a customizable variable defined in tuareg.el.

Value

1

Documentation

How many spaces to indent a clause of match after a pattern | ... -> or ... -> (pattern without preceding | in the first clause of a matching). To respect <https://ocaml.org/docs/guidelines> the default is 1.
