Variable: markdown-enable-prefix-prompts

markdown-enable-prefix-prompts is a customizable variable defined in markdown-mode.el.

Value

t

Documentation

Display prompts for certain prefix commands.

Set to nil to disable these prompts.

This variable was added, or its default value changed, in markdown-mode version 2.3.
