Variable: diff-hl-show-staged-changes

diff-hl-show-staged-changes is a customizable variable defined in diff-hl.el.

Value

t

Documentation

Whether to include staged changes in the indicators.

Only affects Git, it's the only backend that has staging area.

When diff-hl-highlight-reference-function is non-nil, instead of being hidden, the staged changes become part of the "reference" indicators.
