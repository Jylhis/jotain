Variable: pretty-sha-path-special-modes

pretty-sha-path-special-modes is a variable defined in pretty-sha-path.el.

Value

(guix-info-mode ibuffer-mode)

Documentation

List of special modes that support font-locking.

By default, M-x global-pretty-sha-path-mode (global-pretty-sha-path-mode) enables prettifying in all buffers except the ones where font-lock-defaults is nil (see Info node (elisp) Font Lock Basics), because it may break the existing highlighting.

Modes from this list and all derived modes are exceptions
(global-pretty-sha-path-mode(var)/global-pretty-sha-path-mode(fun) enables prettifying there).
