Variable: combobulate-navigable-nodes

combobulate-navigable-nodes is a variable defined in combobulate-settings.el.

Value

nil

Documentation

List of node types used for general navigation and as a placeholder.

The macro with-navigation-nodes binds all activation nodes to this variable, so that Combobulate can act on those node types without requiring that they are lisetd explicitly.
