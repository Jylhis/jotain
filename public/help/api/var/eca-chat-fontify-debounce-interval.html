Variable: eca-chat-fontify-debounce-interval

eca-chat-fontify-debounce-interval is a customizable variable defined in eca-chat.el.

Value

0.15

Documentation

Idle delay in seconds before a deferred fontify runs during streaming.

Instead of calling font-lock-ensure on every streamed chunk, eca-chat--render-content schedules it via an idle timer with this delay. A single guaranteed font-lock-ensure always runs when the response finishes, before table alignment.

When nil, no intermediate fontify is scheduled and the buffer is only fontified at end-of-stream (jit-lock still handles visible-area updates during streaming).
