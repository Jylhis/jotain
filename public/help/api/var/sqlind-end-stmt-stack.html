Variable: sqlind-end-stmt-stack

sqlind-end-stmt-stack is a variable defined in sql-indent.el.

Value

nil

Documentation

Stack of end-of-statement positions.

This is used by the sqlind-maybe-* functions to skip over SQL programming blocks. This variable is dynamically bound.
