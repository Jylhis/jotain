Variable: breadcrumb-mode

breadcrumb-mode is a customizable variable defined in breadcrumb.el.

Value

nil

Documentation

Non-nil if Breadcrumb mode is enabled.

See the breadcrumb-mode(var)/breadcrumb-mode(fun) command for a description of this minor mode. Setting this variable directly does not take effect; either customize it (see the info node (emacs)Easy Customization) or call the function breadcrumb-mode(var)/breadcrumb-mode(fun).

Key Bindings

This command is not in any keymaps.
