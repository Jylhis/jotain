Variable: eca-completion-overlay-dim-ratio

eca-completion-overlay-dim-ratio is a customizable variable defined in eca-completion.el.

Value

0.5

Documentation

How far to blend each fontified span toward the default background.

A float in [0.0, 1.0]: 1.0 keeps the original syntax color, 0.0 collapses it to the background, and intermediate values produce a dimmed "ghost" look similar to Cursor or Copilot. Set to nil to disable dimming and show fully saturated syntax colors. Effective only when eca-completion-syntax-highlight is non-nil.
