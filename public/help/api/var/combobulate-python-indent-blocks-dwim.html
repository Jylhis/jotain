Variable: combobulate-python-indent-blocks-dwim

combobulate-python-indent-blocks-dwim is a customizable variable defined in combobulate-python.el.

Value

t

Documentation

Indent a whole block if point is on it instead of the line.

With point at the beginning of a block -- such as a for statement
-- Combobulate will instead indent the block instead of just the
line when you press M-x combobulate-python-indent-for-tab-command (combobulate-python-indent-for-tab-command).
