Variable: tuareg-match-patterns-aligned

tuareg-match-patterns-aligned is a customizable variable defined in tuareg.el.

Value

nil

Documentation

Non-nil means that the pipes for multiple patterns of a single case are aligned instead of being slightly shifted to spot the multiple patterns better.
         function v.s. function
         | A | A
           | B -> ... | B -> ...
         | C -> ... | C -> ...
