Variable: markdown-fontify-code-block-default-mode

markdown-fontify-code-block-default-mode is a customizable variable defined in markdown-mode.el.

Value

nil

Documentation

Default mode to use to fontify code blocks.

This mode is used when automatic detection fails, such as for GFM code blocks with no language specified.

This variable was added, or its default value changed, in markdown-mode version 2.4.
