Variable: global-hl-todo-mode

global-hl-todo-mode is a customizable variable defined in hl-todo.el.

Value

nil

Documentation

Non-nil if Global Hl-Todo mode is enabled.

See the global-hl-todo-mode(var)/global-hl-todo-mode(fun) command for a description of this minor mode. Setting this variable directly does not take effect; either customize it (see the info node (emacs)Easy Customization) or call the function global-hl-todo-mode(var)/global-hl-todo-mode(fun).

Key Bindings

This command is not in any keymaps.
