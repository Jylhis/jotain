Variable: pdf-view-use-unicode-ligther

pdf-view-use-unicode-ligther is a customizable variable defined in pdf-view.el.

Value

t

Documentation

Decide whether to use unicode symbols in the mode-line.

On some systems finding a font which supports those symbols can take some time. If you don't want to spend that time waiting and don't care for a nicer looking mode-line, set this variable to nil.

Note, that this option has only an effect when this library is loaded.
