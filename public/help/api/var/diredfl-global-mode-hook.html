Variable: diredfl-global-mode-hook

diredfl-global-mode-hook is a customizable variable defined in diredfl.el.

Value

nil

Documentation

Hook run after entering or leaving diredfl-global-mode(var)/diredfl-global-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
