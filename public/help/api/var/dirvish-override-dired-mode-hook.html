Variable: dirvish-override-dired-mode-hook

dirvish-override-dired-mode-hook is a customizable variable defined in dirvish.el.

Value

nil

Documentation

Hook run after entering or leaving dirvish-override-dired-mode(var)/dirvish-override-dired-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
