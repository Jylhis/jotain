Variable: markdown-gfm-downcase-languages

markdown-gfm-downcase-languages is a customizable variable defined in markdown-mode.el.

Value

t

Documentation

If non-nil, downcase suggested languages.

This applies to insertions done with markdown-electric-backquote.
