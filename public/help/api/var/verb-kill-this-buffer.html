Variable: verb-kill-this-buffer

verb-kill-this-buffer is a buffer-local variable defined in verb.el.

Documentation

If non-nil, kill this buffer after readings its contents.

When Verb evaluates Lisp code tags, a tag may produce a buffer as a result. If the buffer-local value of this variable is non-nil for that buffer, Verb will kill it after it has finished reading its contents.
