Variable: mc/max-cursors

mc/max-cursors is a customizable variable defined in multiple-cursors-core.el.

Value

nil

Documentation

Safety ceiling for the number of active cursors.

If your emacs slows down or freezes when using too many cursors, customize this value appropriately.

Cursors will be added until this value is reached, at which point you can either temporarily override the value or abort the operation entirely.

If this value is nil, there is no ceiling.
