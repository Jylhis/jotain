Variable: logview-preview-filter-changes

logview-preview-filter-changes is a customizable variable defined in logview.el.

Value

t

Documentation

Whether to preview filters as they are being edited.

This preview is activated whenever you change the filters in the buffer popped up by \<logview-mode-map>M-x logview-edit-filters (logview-edit-filters) or \<logview-mode-map>M-x logview-edit-thread-narrowing-filters (logview-edit-thread-narrowing-filters).

To temporarily change this on per-buffer basis type \<logview-mode-map>M-x logview-toggle-filter-preview (logview-toggle-filter-preview).
