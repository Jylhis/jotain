Variable: global-corfu-mode-hook

global-corfu-mode-hook is a customizable variable defined in corfu.el.

Value

nil

Documentation

Hook run after entering or leaving global-corfu-mode(var)/global-corfu-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
