Variable: pdf-view--have-rectangle-region

pdf-view--have-rectangle-region is a buffer-local variable defined in pdf-view.el.

Documentation

Non-nil if the region is currently rendered as a rectangle.

This variable is set in pdf-view-mouse-set-region and used in pdf-view-mouse-extend-region to determine the right choice regarding display of the region in the later function.
