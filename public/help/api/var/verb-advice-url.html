Variable: verb-advice-url

verb-advice-url is a customizable variable defined in verb.el.

Value

t

Documentation

Whether to advice url.el functions or not.

If non-nil, the following url.el functions will be advised in order to make Verb more flexible and user-friendly:
- url-http-user-agent-string: Advised to allow the user to set their
  own "User-Agent" headers.
- url-http-handle-authentication: Advised to disable annoying user
  prompt on 401 responses.
Note that the functions will be advised only during the duration of the HTTP requests made.
