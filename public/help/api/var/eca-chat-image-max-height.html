Variable: eca-chat-image-max-height

eca-chat-image-max-height is a customizable variable defined in eca-chat-image.el.

Value

nil

Documentation

Maximum height in pixels for inline images rendered in chat.

Applied via the :max-height property of create-image. When nil, no height constraint is applied; usually eca-chat-image-max-width is enough since chat images are typically wider than tall.
