Variable: ghostel--file-detection-tail

ghostel--file-detection-tail is a variable defined in ghostel-links.el.

Value

"\\(?::[0-9]+\\(?::[0-9]+\\)?\\)?"

Documentation

Fixed optional :LINE[:COL] tail.

When absent, the match is linkified as a bare file/directory reference opened at its start.
