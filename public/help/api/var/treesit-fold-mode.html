Variable: treesit-fold-mode

treesit-fold-mode is a buffer-local variable defined in treesit-fold.el.

Documentation

Non-nil if Treesit-Fold mode is enabled.

Use the command treesit-fold-mode(var)/treesit-fold-mode(fun) to change this variable.

Key Bindings

This command is not in any keymaps.

;; Defined in /nix/store/8bsxam5z769p2v85807qya1p1fb50bqx-emacs-packages-deps/share/emacs/site-lisp/elpa/treesit-fold-0.2.1/treesit-fold.el
;;;###autoload
(define-minor-mode treesit-fold-mode
  "Folding code using tree sitter."
  :group 'treesit-fold
  :init-value nil
  :lighter " Treesit-Fold"
  :keymap treesit-fold-mode-map
  (cond
   ((not (and (treesit-available-p)
              (treesit-parser-list)
              (treesit-fold-usable-mode-p)))
    (when treesit-fold-mode
      (treesit-fold-mode -1)))
   (treesit-fold-mode
    (treesit-fold--enable) t)
   (t
    (treesit-fold--disable))))
