Variable: combobulate-highlight-context

combobulate-highlight-context is a customizable variable defined in combobulate-settings.el.

Value

t

Documentation

Highlight contextual nodes that belong to the same sequence.

This is similar to show-paren-mode(var)/show-paren-mode(fun) but for Combobulate's notion of what a "pair" is.
