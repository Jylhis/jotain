Variable: verb-auto-show-headers-buffer

verb-auto-show-headers-buffer is a customizable variable defined in verb.el.

Value

nil

Documentation

Automatically show headers buffer after receiving an HTTP response.

Value nil means never show the headers buffer. Value when-empty means automatically show the headers buffer only when the response's body size is 0. Any other value means always show the headers buffer.
