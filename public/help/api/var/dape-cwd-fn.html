Variable: dape-cwd-fn

dape-cwd-fn is an alias and customizable for dape-cwd-function, defined in dape.el.

This variable is obsolete since 0.21.0; use dape-cwd-function instead.

Value

dape--default-cwd

Documentation

Function to get current working directory.

The function should return a string representing the absolute file path of the current working directory, usually the current project's root. See dape--default-cwd.

Aliases

dape-cwd-function
