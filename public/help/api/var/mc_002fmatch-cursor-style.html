Variable: mc/match-cursor-style

mc/match-cursor-style is a customizable variable defined in multiple-cursors-core.el.

Value

t

Documentation

If non-nil, attempt to match the cursor style that the user has selected. Namely, use vertical bars the user has configured Emacs to use that cursor.

If nil, just use standard rectangle cursors for all fake cursors.

In some modes/themes, the bar fake cursors are either not rendered or shift text.
