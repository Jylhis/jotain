Variable: dtrt-indent-ignore-single-chars-flag

dtrt-indent-ignore-single-chars-flag is a customizable variable defined in dtrt-indent.el.

Value

nil

Documentation

*Non-nil means ignore lines containing only a single character.

Whether to treat lines that contain only a single non-whitespace character as irrelevant for the analysis. Set this to t in to prevent hanging braces etc. from skewing the results. Set it to nil if you are dealing with source files whose indentation level isn't reliably guessed without those lines.
