Variable: ansible

ansible is an alias and buffer-local for ansible-mode(var)/ansible-mode(fun), defined in ansible.el.

This variable is obsolete since 2024-11-28; use ansible-mode(var)/ansible-mode(fun) instead.

Documentation

Non-nil if Ansible mode is enabled.

Use the command ansible-mode(var)/ansible-mode(fun) to change this variable.

Key Bindings

This command is not in any keymaps.

Aliases
