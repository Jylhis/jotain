Variable: markdown-regex-list

markdown-regex-list is a variable defined in markdown-mode.el.

Value

"^\\([[:blank:]]*\\)\\([#0-9]+\\.\\|[*+:-]\\)\\([[:blank:]]+\\)\\(\\[[ Xx]][[:blank:]]*\\)?"

Documentation

;; Defined in /nix/store/s4bvm9kdxw2hixpjqbqj3gi5xi7kr8wh-emacs-packages-deps/share/emacs/site-lisp/elpa/markdown-mode-20260827.909/markdown-mode.el
(defconst markdown-regex-list
  (markdown-rx line-start
               ;; 1. Leading whitespace
               (group (* blank))
               ;; 2. List marker: a numeral, bullet, or colon
               (group list-marker)
               ;; 3. Trailing whitespace
               (group (+ blank))
               ;; 4. Optional checkbox for GFM task list items
               (opt (group (and checkbox (* blank)))))
  "Regular expression for matching list items.")
