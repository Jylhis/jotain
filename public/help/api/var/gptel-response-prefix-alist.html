Variable: gptel-response-prefix-alist

gptel-response-prefix-alist is a customizable variable defined in gptel-request.el.

Value

((markdown-mode . "") (org-mode . "") (text-mode . ""))

Documentation

String inserted before the response from the LLM.

This is meant for the user to distinguish between queries and responses.

This is an alist mapping major modes to the reply prefix strings. This is only inserted in dedicated gptel buffers before the AI's response.
