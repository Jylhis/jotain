Variable: tuareg-highlight-all-operators

tuareg-highlight-all-operators is a customizable variable defined in tuareg.el.

Value

nil

Documentation

If t, highlight all operators (as opposed to unusual ones).

This is not turned on by default because this makes font-lock much less efficient.
