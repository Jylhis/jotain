Variable: dired-narrow-mode

dired-narrow-mode is a buffer-local variable defined in dired-narrow.el.

Documentation

Non-nil if dired-narrow mode is enabled.

Use the command dired-narrow-mode(var)/dired-narrow-mode(fun) to change this variable.

Key Bindings

This command is not in any keymaps.
