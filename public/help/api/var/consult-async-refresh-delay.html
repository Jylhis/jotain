Variable: consult-async-refresh-delay

consult-async-refresh-delay is a customizable variable defined in consult.el.

Value

0.2

Documentation

Refreshing delay of the completion UI for asynchronous commands.

The completion UI is only updated every consult-async-refresh-delay seconds. This applies to asynchronous commands like for example consult-grep.
