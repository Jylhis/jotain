Variable: eca-table-open-map

eca-table-open-map is a variable defined in eca-table.el.

Value

o  eca-table-open

Documentation

Keymap put on every markdown table so o opens it.

It is attached as an overlay (char-property) keymap, which takes precedence over evil state maps, so o opens the table when point is on it while leaving o untouched everywhere else.
