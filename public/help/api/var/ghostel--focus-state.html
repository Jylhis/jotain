Variable: ghostel--focus-state

ghostel--focus-state is a buffer-local variable defined in ghostel.el.

Documentation

Last focus state actually reported to the terminal for this buffer.

Non-nil means a focus-in event was delivered. Only updated when ghostel--focus-event actually emits (mode 1004 enabled), so that enabling 1004 after a focus change still lets the next event fire.
