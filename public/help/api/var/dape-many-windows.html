Variable: dape-many-windows

dape-many-windows is a customizable variable defined in dape.el.

Value

t

Documentation

Non-nil if Dape-Many-Windows mode is enabled.

See the dape-many-windows(var)/dape-many-windows(fun) command for a description of this minor mode. Setting this variable directly does not take effect; either customize it (see the info node (emacs)Easy Customization) or call the function dape-many-windows(var)/dape-many-windows(fun).

Key Bindings

This command is not in any keymaps.

;; Defined in /nix/store/l2knzmz5nqc323cf0hwsi3pa45p8w61v-emacs-packages-deps/share/emacs/site-lisp/elpa/dape-0.27.1/dape.el
(define-minor-mode dape-many-windows
  "Toggle many-buffer debug layout and simple layout.
The mode modifies `dape-start-hook' to remove or add the complex
layout for future debugging sessions."
  :global t
  :init-value t
  (if dape-many-windows
      (add-hook 'dape-start-hook #'dape-info)
    (remove-hook 'dape-start-hook #'dape-info)
    (dolist (buffer (dape--info-buffer-list))
      (when-let* ((window (get-buffer-window buffer)))
        (quit-window t window))))
  (when dape-active-mode
    (when dape-many-windows
      (dape-info nil))
    (when-let* ((conn (dape--live-connection 'parent t))
                (buffer (dape--shell-buffer conn)))
      (dape--display-buffer buffer))
    (when-let* ((window (get-buffer-window "*dape-repl*")))
      (quit-window nil window))
    (dape-repl)))
