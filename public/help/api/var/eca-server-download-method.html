Variable: eca-server-download-method

eca-server-download-method is a customizable variable defined in eca-process.el.

Value

url-retrieve

Documentation

The method to use to download eca server binary.

Some Emacs versions / distributions have issues with curl blocking Emacs, but url-retrieve should be always async. Test different options if facing issues.
