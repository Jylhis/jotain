Variable: gptel--known-tools

gptel--known-tools is a variable defined in gptel-request.el.

Value

nil

Documentation

Alist of gptel tools arranged by category.

A "tool" is a function spec (definition and description) provided by gptel to an LLM. See gptel-tool. Each tool is assigned a category when it is created, with a category of
"misc" if none is specified.

This is a two-level alist mapping categories and tool names to the tool itself. It is used as a global register of available tools and in gptel's UI, see variable gptel-tools.

In this example structure, cat-tool and the rest are cl-structs of type gptel-tool:

   CATEGORY TOOL NAME TOOL
 (("filesystem" . (("read_file" . cat-tool)
                   ("list_directory" . ls-tool)))
  ("emacs" . (("read_buffer" . buffer-substring-tool)
                   ("send_message" . message-tool))))

This variable is for internal use only, to define a tool use gptel-make-tool.
