Variable: ghostel--line-input-end

ghostel--line-input-end is a buffer-local variable defined in ghostel-line-mode.el.

Documentation

Marker pointing right after the last character of the in-progress input.

Has insertion-type t so a self-insert at this position causes the marker to advance with the new character. Bounding the input by an explicit marker (rather than point-max) keeps content past the prompt — e.g. a status bar drawn below the prompt row — out of the snapshot read and out of the renderer's clobber path.
