Variable: global-org-modern-mode

global-org-modern-mode is a customizable variable defined in org-modern.el.

Value

nil

Documentation

Non-nil if Global Org-Modern mode is enabled.

See the global-org-modern-mode(var)/global-org-modern-mode(fun) command for a description of this minor mode. Setting this variable directly does not take effect; either customize it (see the info node (emacs)Easy Customization) or call the function global-org-modern-mode(var)/global-org-modern-mode(fun).

Key Bindings

This command is not in any keymaps.

  :group 'org-modern
  (if global-org-modern-mode
