Variable: gptel-track-media

gptel-track-media is a customizable variable defined in gptel-request.el.

Value

nil

Documentation

Whether links to supported media types should be followed.

When this is non-nil, gptel will send text, images or other media from links in Org and Markdown buffers to the LLM.

Sending images or other binary media from links requires the active gptel-model to support it. See gptel-make-openai, gptel-make-anthropic, gptel-make-ollama or gptel-make-gemini for details on how to specify media support for models.

To include media (including binary formats like images) more generally, you can also use gptel-add or gptel-add-file instead.
