Variable: verb-trim-body-end

verb-trim-body-end is a customizable variable defined in verb.el.

Value

nil

Documentation

When set to a regexp, use it to trim request body endings.

If set to nil, read request bodies as they appear on the buffer. In that case, if any whitespace is present between the body end and the next heading (or buffer end), it will be included in the body.

  "When set to a regexp, use it to trim request body endings.
If set to nil, read request bodies as they appear on the buffer.  In
that case, if any whitespace is present between the body end and the
next heading (or buffer end), it will be included in the body."
