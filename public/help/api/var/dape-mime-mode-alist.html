Variable: dape-mime-mode-alist

dape-mime-mode-alist is a customizable variable defined in dape.el.

Value

(("text/x-lldb.disassembly" . asm-mode) ("text/javascript" . js-mode))

Documentation

Alist of MIME types vs corresponding major mode functions.

Each element should look like (MIME-TYPE . MODE) where MIME-TYPE is a string and MODE is the major mode function to use for buffers of this MIME type.
