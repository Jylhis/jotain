Variable: majutsu-log--required-columns

majutsu-log--required-columns is a variable defined in majutsu-log.el.

Value

(id commit-id parent-ids)

Documentation

Fields that must exist in majutsu-log-commit-columns.

These fields are transported even when users omit them from visible layout, so log semantics such as stable identity, commit-hash copying, and relation navigation remain available.
