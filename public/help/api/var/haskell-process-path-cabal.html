Variable: haskell-process-path-cabal

haskell-process-path-cabal is a customizable variable defined in haskell-customize.el.

Value

"cabal"

Documentation

Path to the cabal executable.

This can either be a single string or a list of strings, where the first elements is a string and the remaining elements are arguments, which will be prepended to haskell-process-args-cabal-repl.
