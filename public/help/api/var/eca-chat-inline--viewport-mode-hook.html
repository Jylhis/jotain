Variable: eca-chat-inline--viewport-mode-hook

eca-chat-inline--viewport-mode-hook is a customizable variable defined in eca-chat-inline.el.

Value

nil

Documentation

Hook run after entering or leaving eca-chat-inline--viewport-mode(var)/eca-chat-inline--viewport-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
