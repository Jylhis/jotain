Variable: global-corfu-minibuffer

global-corfu-minibuffer is a customizable variable defined in corfu.el.

Value

t

Documentation

Corfu should be enabled in the minibuffer by global-corfu-mode(var)/global-corfu-mode(fun).

The variable can either be t, nil or a custom predicate function. If the variable is set to t, Corfu is only enabled if the minibuffer has local completion-at-point-functions.
