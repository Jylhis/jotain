Variable: terraform-format-on-save-mode-hook

terraform-format-on-save-mode-hook is a customizable variable defined in terraform-mode.el.

Value

nil

Documentation

Hook run after entering or leaving terraform-format-on-save-mode(var)/terraform-format-on-save-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
