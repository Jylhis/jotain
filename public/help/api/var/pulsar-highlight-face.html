Variable: pulsar-highlight-face

pulsar-highlight-face is a customizable variable defined in pulsar.el.

Value

pulsar-generic

Documentation

Face used by temporary or permanent static highlights.

These are done by commands such as pulsar-highlight-temporarily and pulsar-highlight-permanently.

This variable was added, or its default value changed, in pulsar version 1.3.0.
