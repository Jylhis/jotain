Variable: async-quiet-switch

async-quiet-switch is a variable defined in async.el.

Value

"-Q"

Documentation

The Emacs parameter to use to call emacs without config.

Can be one of "-Q" or "-q". Default is "-Q" but it is sometimes useful to use "-q" to have a enhanced config or some more variables loaded.
