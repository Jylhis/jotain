Variable: dape-default-config-functions

dape-default-config-functions is a customizable variable defined in dape.el.

Value

(dape-config-autoport
 dape-config-tramp)

Documentation

Functions applied on config before starting debugging session.

Each function is called with one argument CONFIG and should return an PLIST of the format specified in dape-configs.

Functions are evaluated after functions defined in fn symbol in dape-configs. See fn in dape-configs function signature.
