Variable: tempel-template-sources

tempel-template-sources is a customizable variable defined in tempel.el.

Value

(tempel-path-templates)

Documentation

List of template sources.

A source can either be a function or a variable symbol. The functions must return a list of templates which apply to the buffer or context.
