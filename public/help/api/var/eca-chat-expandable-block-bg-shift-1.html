Variable: eca-chat-expandable-block-bg-shift-1

eca-chat-expandable-block-bg-shift-1 is a customizable variable defined in eca-chat-expandable.el.

Value

5

Documentation

Percentage to shift background for level-1 blocks.

Higher values make the block background more distinct from the surrounding buffer. The shift direction is automatic: lightens for dark themes and darkens for light themes.
