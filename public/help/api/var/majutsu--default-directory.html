Variable: majutsu--default-directory

majutsu--default-directory is a buffer-local variable defined in majutsu-mode.el.

Documentation

Value of default-directory when the buffer was generated.

This exists to prevent a let-bound default-directory from tricking buffer reuse logic into thinking a buffer belongs to a repository that it doesn't.
