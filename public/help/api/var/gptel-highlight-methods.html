Variable: gptel-highlight-methods

gptel-highlight-methods is a customizable variable defined in gptel.el.

Value

(margin)

Documentation

Types of LLM response highlighting used by gptel-highlight-mode(var)/gptel-highlight-mode(fun).

This must be a list of symbols denoting types of highlighting for LLM responses:
- face: highlight LLM responses using face gptel-response-highlight.
- fringe: highlight using a (left) fringe marker.
- margin: highlight in the (left) display margin.

margin and fringe markings are mutually exclusive, and use the gptel-response-fringe-highlight face.
