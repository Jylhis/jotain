Variable: logview-cache-filename

logview-cache-filename is a customizable variable defined in logview.el.

Value

"~/.emacs.d/logview-cache.extmap"

Documentation

Internal non-human-readable cache.

Customizable in case you want to put it somewhere else. This file can be safely deleted, but will be recreated by Logview next time you use the mode. Used to make startup faster.
