Variable: doom-modeline-spc-face-overrides

doom-modeline-spc-face-overrides is a customizable variable defined in doom-modeline-core.el.

Value

nil

Documentation

Property list of face attributes for whitespace in the modeline.

These face attributes override any attributes for spacing produced by doom-modeline-spc, doom-modeline-wspc, and doom-modeline-vspc.

See defface for possible attributes and values in this property list.
