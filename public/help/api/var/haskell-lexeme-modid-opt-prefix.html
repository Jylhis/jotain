Variable: haskell-lexeme-modid-opt-prefix

haskell-lexeme-modid-opt-prefix is a variable defined in haskell-lexeme.el.

Value

"\\(?:[[:upper:]][[:alnum:]'_]*\\.\\)*"

Documentation

Regexp matching a valid Haskell module prefix, potentially empty.

Module path prefix is separated by dots and finishes with a dot. For path component syntax see haskell-lexeme-modid.
