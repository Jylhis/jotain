Variable: vc-jj-region-history-mode-hook

vc-jj-region-history-mode-hook is a variable defined in vc-jj.el.

Value

nil

Documentation

Hook run after entering vc-jj-region-history-mode.

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
