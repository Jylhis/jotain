Variable: haskell-indentation-mode-hook

haskell-indentation-mode-hook is a customizable variable defined in haskell-indentation.el.

Value

nil

Documentation

Hook run after entering or leaving haskell-indentation-mode(var)/haskell-indentation-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
