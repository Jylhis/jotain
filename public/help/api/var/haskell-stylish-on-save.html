Variable: haskell-stylish-on-save

haskell-stylish-on-save is a customizable variable defined in haskell-customize.el.

Value

nil

Documentation

Whether to run stylish-haskell on the buffer before saving.

If this is true, haskell-add-import will not sort or align the imports.
