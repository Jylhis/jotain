Variable: gnuplot--info-keywords

gnuplot--info-keywords is a variable defined in gnuplot.el.

Value

pending

Documentation

A list of keywords used in GNUPLOT.

These are set by gnuplot--set-keywords-list from the values in info-lookup-cache.
