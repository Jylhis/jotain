Variable: markdown-enable-wiki-links

markdown-enable-wiki-links is a customizable variable defined in markdown-mode.el.

Value

nil

Documentation

Syntax highlighting for wiki links.

Set this to a non-nil value to turn on wiki link support by default. Support can be toggled later using the markdown-toggle-wiki-links function or M-x markdown-toggle-wiki-links (markdown-toggle-wiki-links).

This variable was added, or its default value changed, in markdown-mode version 2.2.
