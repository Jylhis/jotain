Variable: combobulate-proffer-allow-numeric-selection

combobulate-proffer-allow-numeric-selection is a customizable variable defined in combobulate-settings.el.

Value

t

Documentation

Allow numeric selection in proffer prompts that support numeric selection.

If non-nil, you can type a number to select a choice in a proffer prompt. This is useful if you have a lot of choices and want to quickly select one without having to type the whole thing out.

If nil, then numeric selection is disabled.
