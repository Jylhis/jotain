Variable: breadcrumb-local-mode-hook

breadcrumb-local-mode-hook is a customizable variable defined in breadcrumb.el.

Value

(breadcrumb-local-mode--set-explicitly(var)/breadcrumb-local-mode--set-explicitly(fun))

Documentation

Hook run after entering or leaving breadcrumb-local-mode(var)/breadcrumb-local-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
