Variable: combobulate-typescript-default-nodes

combobulate-typescript-default-nodes is a variable defined in combobulate-js-ts.el.

Value

nil

Documentation

List of active node types used for node discovery.

This variable is almost always auto-populated by Combobulate when a set of procedures are activated, and should only be let-bound or set with with-navigation-nodes.
