Variable: markdown-view-mode-hook

markdown-view-mode-hook is a variable defined in markdown-mode.el.

Value

nil

Documentation

Hook run after entering markdown-view-mode.

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
