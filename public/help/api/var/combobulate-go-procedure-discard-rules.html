Variable: combobulate-go-procedure-discard-rules

combobulate-go-procedure-discard-rules is a variable defined in combobulate-go.el.

Value

("comment")

Documentation

List of discard rules to apply to procedure matches.

This is a generic filter to apply across all procedures. Any rule specified in this list will be applied to all procedures, regardless of the procedure's activation rules.
