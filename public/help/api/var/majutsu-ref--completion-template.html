Variable: majutsu-ref--completion-template

Value

"concat(join(\"\\x1F\", self.name(), if(self.remote(), self.remote(), \"\"), if(self.conflict(), \"t\", \"\"), if(self.present(), \"t\", \"\"), if(self.tracked(), \"t\", \"\"), if(self.synced(), \"t\", \"\")), \"\\n\")"

Documentation

Template used to collect structured CommitRef completion metadata.

This uses join rather than separate because empty fields are meaningful in the machine transport format.

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-ref.el
(defconst majutsu-ref--completion-template
  (majutsu-template-compile
   `[:concat
     [:join ,majutsu-ref--completion-field-separator
            [:name]
            [:if [:remote] [:remote] ""]
            [:if [:conflict] "t" ""]
            [:if [:present] "t" ""]
            [:if [:tracked] "t" ""]
            [:if [:synced] "t" ""]]
     "\n"]
   'CommitRef)

This uses `join' rather than `separate' because empty fields are meaningful
in the machine transport format.")
