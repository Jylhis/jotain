Variable: majutsu-jjdescription-regexp

majutsu-jjdescription-regexp is a variable defined in majutsu-jjdescription.el.

Value

"\\(?:\\`\\|.*[/\\]\\)editor-[0-9A-Za-z]+\\.jjdescription\\'"

Documentation

Regexp matching temporary jj description files created for editing.

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-jjdescription.el
(defconst majutsu-jjdescription-regexp
  (rx (seq (or string-start
               (seq (* (not (any ?\n)))
                    (any ?/ ?\\)))
           "editor-" (+ (in "0-9A-Za-z"))
           ".jjdescription" string-end))
