Variable: dape-buffer-window-arrangement

dape-buffer-window-arrangement is a customizable variable defined in dape.el.

Value

left

Documentation

How to generally display buffers.

For additional configuration of which mode buffers are placed in which windows, see dape-info-buffer-window-groups.

If further customization is needed, use display-buffer-alist. Note that each buffer is displayed with display-buffer action ALIST entry category as dape-info- + group index, which can be used with display-buffer-alist for group-based actions.

See dape--display-buffer for additional details.

Aliases

dape-buffer-window-arrangment (obsolete since 0.3.0)
