Variable: csv-align-max-width

csv-align-max-width is a customizable variable defined in csv-mode.el.

Value

40

Documentation

Maximum width of a column in csv-align-mode(var)/csv-align-mode(fun).

This does not apply to the last column (for which the usual truncate-lines setting works better).
