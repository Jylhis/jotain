Variable: pdf-info-epdfinfo-error-filename

pdf-info-epdfinfo-error-filename is a customizable variable defined in pdf-info.el.

Value

nil

Documentation

Filename for error output of the epdfinfo executable.

If nil, discard any error messages. Useful for debugging.

;; Defined in /nix/store/wm0vc3dfi6c7pwjhcfpsnhyg4hd0b5yc-emacs-packages-deps/share/emacs/site-lisp/elpa/pdf-tools-20260102.1101/pdf-info.el
(defcustom pdf-info-epdfinfo-error-filename nil
  "Filename for error output of the epdfinfo executable.

If nil, discard any error messages.  Useful for debugging."
  :type `(choice (const :tag "None" nil)
                 ,@(when (file-directory-p "/tmp/")
                     '((const "/tmp/epdfinfo.log")))
                 (file)))
