Variable: vundo-window-side

vundo-window-side is a customizable variable defined in vundo.el.

Value

bottom

Documentation

The vundo window pops up on this side.

Source Code

;; Defined in /nix/store/7c2696v2qdrdv2vf2im8alazibi7qq0z-emacs-packages-deps/share/emacs/site-lisp/elpa/vundo-2.4.0/vundo.el
(defcustom vundo-window-side 'bottom
  "The vundo window pops up on this side."
  :type '(choice (const :tag "Bottom" bottom)
                 (const :tag "Top"    top)))
