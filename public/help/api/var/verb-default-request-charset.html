Variable: verb-default-request-charset

verb-default-request-charset is a customizable variable defined in verb.el.

Value

"utf-8"

Documentation

Charset to add to "Content-Type" headers in HTTP requests.

This variable is only used when the charset isn't specified in the header value ("charset=utf-8").
