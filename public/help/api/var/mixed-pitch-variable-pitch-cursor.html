Variable: mixed-pitch-variable-pitch-cursor

mixed-pitch-variable-pitch-cursor is a customizable variable defined in mixed-pitch.el.

Value

bar

Documentation

If non-nil, function mixed-pitch-mode(var)/mixed-pitch-mode(fun) changes the cursor.

When disabled, switch back to what it was before.

See cursor-type for a list of acceptable types.
