Variable: super-save-hook-triggers

super-save-hook-triggers is a customizable variable defined in super-save.el.

Value

nil

Documentation

A list of hooks which would trigger super-save-command.

With super-save-when-buffer-switched and super-save-when-focus-lost enabled (the defaults), this list defaults to nil as those options cover the common triggers.

This variable was added, or its default value changed, in super-save version 0.3.0.
