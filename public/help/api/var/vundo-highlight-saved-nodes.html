Variable: vundo-highlight-saved-nodes

vundo-highlight-saved-nodes is a customizable variable defined in vundo.el.

Value

t

Documentation

If non-nil, vundo will highlight nodes which have been saved and then modified.

The face vundo-saved is used for saved nodes, except for the most recent such node, which receives the face vundo-last-saved.
