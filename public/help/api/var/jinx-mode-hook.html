Variable: jinx-mode-hook

jinx-mode-hook is a customizable variable defined in jinx.el.

Value

(jinx-mode--set-explicitly(var)/jinx-mode--set-explicitly(fun))

Documentation

Hook run after entering or leaving jinx-mode(var)/jinx-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
