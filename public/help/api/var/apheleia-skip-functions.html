Variable: apheleia-skip-functions

apheleia-skip-functions is a customizable variable defined in apheleia.el.

Value

nil

Documentation

List of functions that prevent Apheleia from running when enabled.

These are invoked every time Apheleia wants to format a buffer, and the formatting operation is skipped if any of them return non-nil. See also apheleia-inhibit-functions for functions that prevent apheleia-mode(var)/apheleia-mode(fun) from being turned on in the first place.
