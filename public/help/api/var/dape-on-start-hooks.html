Variable: dape-on-start-hooks

dape-on-start-hooks is an alias and customizable for dape-start-hook, defined in dape.el.

This variable is obsolete since 0.13.0; use dape-start-hook instead.

Value

(dape-repl dape-info)

Documentation

Called when session starts.

Aliases

dape-start-hook
