Variable: eca-chat-inline-model

eca-chat-inline-model is a customizable variable defined in eca-chat-inline.el.

Value

nil

Documentation

Model for inline chats, or nil to let the server decide.

When nil the server falls back to its chatInline.model config, then the forked chat's model, then the default chat model.
