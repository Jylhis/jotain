Variable: compile-multi-embark-mode

compile-multi-embark-mode is a customizable variable defined in compile-multi-embark.el.

Value

nil

Documentation

Non-nil if Compile-Multi-Embark mode is enabled.

See the compile-multi-embark-mode(var)/compile-multi-embark-mode(fun) command for a description of this minor mode. Setting this variable directly does not take effect; either customize it (see the info node (emacs)Easy Customization) or call the function compile-multi-embark-mode(var)/compile-multi-embark-mode(fun).

Key Bindings

This command is not in any keymaps.

;;;###autoload
(define-minor-mode compile-multi-embark-mode
  "Minor mode enabling `embark' actions for `compile-multi' minibuffer sessions."
  :global t :group 'compile-multi-embark
  (if compile-multi-embark-mode
      (progn
        (push '(compile-multi compile-multi-embark-command-map) embark-keymap-alist)
        (push `(compile-multi . ,#'compile-multi-embark-transformer)
              embark-transformer-alist))
    (setq embark-keymap-alist (assq-delete-all 'compile-multi embark-keymap-alist)
          embark-transformer-alist (assq-delete-all 'compile-multi embark-transformer-alist))))
