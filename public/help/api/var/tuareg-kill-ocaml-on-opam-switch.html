Variable: tuareg-kill-ocaml-on-opam-switch

tuareg-kill-ocaml-on-opam-switch is a customizable variable defined in tuareg.el.

Value

t

Documentation

If t, kill Tuareg subprocesses when the OPAM switch changes.

If the user changes the OPAM switch using opam-switch-mode, this option asks to kill the subprocesses that are using the old switch.

See https://github.com/ProofGeneral/opam-switch-mode

Note: opam-switch-mode triggers automatic changes for exec-path(var)/exec-path(fun) and process-environment, which are useful to find the "ocaml" binary and that of its subprocesses, in the ambient opam switch.

opam-switch-mode is compatible with tuareg-mode whatever is the value of tuareg-opam-insinuate.
