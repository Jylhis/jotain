Variable: tuareg-smie--backward-and-cache

tuareg-smie--backward-and-cache is a buffer-local variable defined in tuareg.el.

Documentation

Alist memoising results from (smie-backward-sexp "and").

Each element is (POS-BEFORE POS-AFTER VALUE) where POS-BEFORE and POS-AFTER are the positions before and after the call respectivaly, and VALUE what the call returned.
