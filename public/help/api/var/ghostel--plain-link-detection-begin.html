Variable: ghostel--plain-link-detection-begin

ghostel--plain-link-detection-begin is a buffer-local variable defined in ghostel-links.el.

Documentation

Queued start bound for redraw-triggered plain-text link detection.

A marker: scrollback eviction deletes from the buffer start between the queue and the scan, which would leave a plain position pointing at unrelated text.
