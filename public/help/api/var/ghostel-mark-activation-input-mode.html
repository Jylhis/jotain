Variable: ghostel-mark-activation-input-mode

ghostel-mark-activation-input-mode is a customizable variable defined in ghostel.el.

Value

default

Documentation

Input mode to switch to when the mark becomes active in semi-char mode.

Triggered by any command that activates the region, e.g. set-mark-command, expand-region variants, mark-whole-buffer, exchange-point-and-mark. default follows ghostel-readonly-default-mode; nil disables the switch.

Mouse selection is governed separately by ghostel-mouse-drag-input-mode.
