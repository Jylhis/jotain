Variable: exec-path-from-shell-arguments

exec-path-from-shell-arguments is a customizable variable defined in exec-path-from-shell.el.

Value

("-l" "-i")

Documentation

Additional arguments to pass to the shell.

The default value denotes an interactive login shell.

Source Code

;; Defined in /nix/store/lzrv36jn1gafnd9x3mmwlizw57dr87rp-emacs-packages-deps/share/emacs/site-lisp/elpa/exec-path-from-shell-20260423.1833/exec-path-from-shell.el
(defcustom exec-path-from-shell-arguments
  (let ((shell (exec-path-from-shell--shell)))
    (if (string-match-p "t?csh$" shell)
        (list "-d")
      (if (string-match-p "fish" shell)
          (list "-l")
        (list "-l" "-i"))))
  "Additional arguments to pass to the shell.

The default value denotes an interactive login shell."
  :type '(repeat (string :tag "Shell argument"))
  :group 'exec-path-from-shell)
