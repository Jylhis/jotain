Variable: ghostel-password-prompt-debounce

ghostel-password-prompt-debounce is a customizable variable defined in ghostel.el.

Value

0.2

Documentation

Seconds to wait after a rising edge before opening read-passwd.

When the canonical+!echo heuristic first fires, ghostel waits this long and re-checks before invoking ghostel-password-prompt-functions. Sub-debounce flips (e.g. shell quirks that flap echo briefly) never reach the user - matching ghostty's natural 200 ms termios polling cadence. Set to 0 to open the prompt immediately.
