Variable: majutsu-annotate-disable-modes

majutsu-annotate-disable-modes is a customizable variable defined in majutsu-annotate.el.

Value

(fci-mode yascroll-bar-mode)

Documentation

List of modes not compatible with Majutsu-Annotate mode.

These modes are turned off when Majutsu-Annotate mode is turned on, and then turned on again when turning off the latter.

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-annotate.el
(defcustom majutsu-annotate-disable-modes '(fci-mode yascroll-bar-mode)
  "List of modes not compatible with Majutsu-Annotate mode.
These modes are turned off when Majutsu-Annotate mode is turned on,
and then turned on again when turning off the latter."
  :type '(repeat (symbol :tag "Mode"))
  :group 'majutsu-annotate)
