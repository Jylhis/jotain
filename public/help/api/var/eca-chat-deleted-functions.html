Variable: eca-chat-deleted-functions

eca-chat-deleted-functions is a variable defined in eca-chat.el.

Value

(eca-chat-inline--chat-deleted)

Documentation

Abnormal hook run after a chat deletion is processed.

Each function is called with SESSION and CHAT-ID after the chat is removed from the session registry and its buffer killed, when it was known; the hook runs even for chat ids unknown to the client.
