Variable: pulsar-global-mode

pulsar-global-mode is a customizable variable defined in pulsar.el.

Value

nil

Documentation

Non-nil if Pulsar-Global mode is enabled.

See the pulsar-global-mode(var)/pulsar-global-mode(fun) command for a description of this minor mode. Setting this variable directly does not take effect; either customize it (see the info node (emacs)Easy Customization) or call the function pulsar-global-mode(var)/pulsar-global-mode(fun).

Key Bindings

This command is not in any keymaps.
