Variable: combobulate-tsx-default-procedures

combobulate-tsx-default-procedures is a variable defined in combobulate-js-ts.el.

Value

nil

Documentation

List of active procedures used by Combobulate's procedure system.

This variable is almost always auto-populated by Combobulate from one of the other procedure variables, and should only be let-bound or set with with-navigation-nodes.
