Variable: gnuplot-insertions-polar-plots

gnuplot-insertions-polar-plots is a customizable variable defined in gnuplot.el.

("polar plots" ["polar" (gnuplot-insert "set polar") t]
 ["angles" (gnuplot-insert "set angles ") t]
