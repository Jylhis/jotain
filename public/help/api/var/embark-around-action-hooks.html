Documentation

Alist associating commands with post-action hooks.

The hooks are run instead of the embarked upon action. The hook can decide whether or not to run the action or it can run it in some special environment, like inside a let-binding or inside save-excursion. Each hook is called with keyword argument :run providing a function encapsulating the following around hooks and the action; the hook additionally receives the keyword arguments used for other types of action hooks, for more details see embark-target-injection-hooks.
