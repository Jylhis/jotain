Variable: majutsu-log--this-error

majutsu-log--this-error is a buffer-local variable defined in majutsu-log.el.

Documentation

Last jj side-effect error summary for this log buffer.

This is set by process runners (see majutsu-process-buffer) and rendered by majutsu-log-insert-error-header on the next refresh.
