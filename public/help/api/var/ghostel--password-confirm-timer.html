Variable: ghostel--password-confirm-timer

ghostel--password-confirm-timer is a buffer-local variable defined in ghostel.el.

Documentation

Pending debounce timer for ghostel-password-prompt-debounce.

Scheduled by ghostel--detect-password-prompt on the rising edge; cancelled on the falling edge or before re-scheduling. The timer body (ghostel--confirm-and-prompt) re-runs the heuristic before calling ghostel--prompt-password so short-lived flips never reach the user.
