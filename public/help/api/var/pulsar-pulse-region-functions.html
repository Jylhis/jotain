Documentation

Functions that highlight the affected region after invocation.

When the value is nil, no pulsing is in effect. Otherwise, the value is a list of functions that operate on the region.

This only takes effect when pulsar-mode(var)/pulsar-mode(fun) (buffer-local) or pulsar-global-mode(var)/pulsar-global-mode(fun) is enabled.

This variable was added, or its default value changed, in pulsar version 1.2.0.
