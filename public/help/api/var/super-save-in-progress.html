Variable: super-save-in-progress

super-save-in-progress is a variable defined in super-save.el.

Value

nil

Documentation

Non-nil when a super-save operation is in progress.

Save hook functions can check this variable to skip expensive processing during automatic saves. For example:

  (add-hook 'before-save-hook
            (lambda ()
              (unless super-save-in-progress
                (my-expensive-formatting-function))))
