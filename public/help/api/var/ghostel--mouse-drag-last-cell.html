Variable: ghostel--mouse-drag-last-cell

ghostel--mouse-drag-last-cell is a buffer-local variable defined in ghostel.el.

Documentation

Last (ROW . COL) forwarded as a motion event during a drag.

Used by ghostel--mouse-drag-motion to suppress duplicate motion events for the same cell: libghostty is not given a last_cell to deduplicate against, so without this every mouse-movement event
(many per cell) would re-encode and spam the PTY.
