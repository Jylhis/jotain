Variable: super-save-when-buffer-switched

super-save-when-buffer-switched is a customizable variable defined in super-save.el.

Value

t

Documentation

Save buffers when the selected window's buffer changes.

Uses window-buffer-change-functions and window-selection-change-functions to detect buffer switches. This catches all buffer switches regardless of how they happen, unlike super-save-triggers which only catches specific commands.

This variable was added, or its default value changed, in super-save version 0.5.0.
