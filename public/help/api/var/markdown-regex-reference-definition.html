Variable: markdown-regex-reference-definition

markdown-regex-reference-definition is a variable defined in markdown-mode.el.

Value

"^ \\{0,3\\}\\(?1:\\[\\)\\(?2:[^]\n]+?\\)\\(?3:\\]\\)\\(?4::\\)\\s *\\(?5:.*?\\)\\s *\\(?6: \"[^\"]*\"$\\|$\\)"

Documentation

Regular expression for a reference definition.

Group 1 matches the opening square bracket. Group 2 matches the reference label. Group 3 matches the closing square bracket. Group 4 matches the colon. Group 5 matches the URL. Group 6 matches the title attribute (optional).
