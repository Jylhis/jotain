Variable: kkp-control-modifier

kkp-control-modifier is a customizable variable defined in kkp.el.

Value

control

Documentation

This variable describes the behavior of the ctrl key.

It is one of the symbols shift, alt, control, super, hyper, meta, caps-lock or num-lock.
