Variable: ghostel-plain-link-detection-delay

ghostel-plain-link-detection-delay is a customizable variable defined in ghostel-links.el.

Value

0.1

Documentation

Delay in seconds before redraw-triggered plain-text link detection runs.

Redraws queue URL/file detection through ghostel--schedule-link-detection so multiple updates can be coalesced into a single scan. Set to 0 to scan immediately after each redraw. Native OSC-8 hyperlinks remain applied during redraw.
