Variable: pdf-view-printer-minor-mode-hook

pdf-view-printer-minor-mode-hook is a customizable variable defined in pdf-view.el.

Value

nil

Documentation

Hook run after entering or leaving pdf-view-printer-minor-mode(var)/pdf-view-printer-minor-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
