Variable: majutsu-jjdescription-mode-hook

majutsu-jjdescription-mode-hook is a customizable variable defined in majutsu-jjdescription.el.

Value

nil

Documentation

Hook run after entering or leaving majutsu-jjdescription-mode(var)/majutsu-jjdescription-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
