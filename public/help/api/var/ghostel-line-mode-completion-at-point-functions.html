Variable: ghostel-line-mode-completion-at-point-functions

ghostel-line-mode-completion-at-point-functions is a customizable variable defined in ghostel-line-mode.el.

Value

(comint-completion-at-point)

Documentation

Capfs activated for `TAB' in ghostel-line-mode.

Each function is called inside a save-restriction narrowed to the editable input region, so it sees only the user's typed text — not the prompt or the surrounding scrollback.

The default comint-completion-at-point dispatches through comint-dynamic-complete-functions (set up via shell-completion-vars), which gives filename completion, env-var completion, command completion from `PATH', pcomplete integration, and history expansion.
