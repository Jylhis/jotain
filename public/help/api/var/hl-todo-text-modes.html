Variable: hl-todo-text-modes

hl-todo-text-modes is a customizable variable defined in hl-todo.el.

Value

(text-mode)

Documentation

Major-modes that are considered text-modes.

In buffers whose major-mode derives from one of the modes listed here TODO keywords are always highlighted even if they are not located inside a string.

This variable was added, or its default value changed, in hl-todo version 2.1.0.
