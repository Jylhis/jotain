Variable: pdf-cache-prefetch-pages-function

pdf-cache-prefetch-pages-function is a customizable variable defined in pdf-cache.el.

Value

pdf-cache-prefetch-pages-function-default

Documentation

A function returning a list of pages to be prefetched.

It is called with no arguments in the PDF window and should return a list of page-numbers, determining the pages that should be prefetched and their order.
