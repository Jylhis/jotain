Variable: gitlab-ci-mode-hook

gitlab-ci-mode-hook is a variable defined in gitlab-ci-mode.el.

Value

nil

Documentation

Hook run after entering gitlab-ci-mode.

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
