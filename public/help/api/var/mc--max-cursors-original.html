Variable: mc--max-cursors-original

mc--max-cursors-original is a variable defined in multiple-cursors-core.el.

Value

nil

Documentation

This variable maintains the original maximum number of cursors.

When mc/create-fake-cursor-at-point is called and mc/max-cursors is overridden, this value serves as a backup so that mc/max-cursors can take on a new value. When mc/remove-fake-cursors is called, the values are reset.
