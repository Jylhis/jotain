Variable: magit-process-ensure-unix-line-ending

magit-process-ensure-unix-line-ending is a customizable variable defined in magit-process.el.

Value

t

Documentation

Whether Magit should ensure a unix coding system when talking to Git.

This variable was added, or its default value changed, in magit version 2.6.0.
