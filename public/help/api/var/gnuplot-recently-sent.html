Variable: gnuplot-recently-sent

gnuplot-recently-sent is a variable defined in gnuplot.el.

Value

nil

Documentation

This is a record of the most recent kind of text sent to gnuplot.

It takes as its value nil, line, region, buffer, or file. It is useful for functions included in gnuplot-after-plot-hook.
