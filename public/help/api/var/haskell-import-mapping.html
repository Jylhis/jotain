Variable: haskell-import-mapping

haskell-import-mapping is a customizable variable defined in haskell-customize.el.

Value

nil

Documentation

Support a mapping from module to import lines.

E.g. '(("Data.Map" . "import qualified Data.Map as M import Data.Map (Map)
"))

This will import

import qualified Data.Map as M import Data.Map (Map)

when Data.Map is the candidate.
