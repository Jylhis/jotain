Variable: forge-bug-reference-hooks

forge-bug-reference-hooks is a customizable variable defined in forge-topic.el.

Value

(find-file-hook forge-post-mode-hook git-commit-setup-hook
		magit-mode-hook)

Documentation

Hooks to which forge-bug-reference-setup is added.

This variable has to be customized before forge is loaded.

This variable was added, or its default value changed, in forge version 0.2.0.

(defcustom forge-bug-reference-hooks
  '(find-file-hook
    forge-post-mode-hook
    git-commit-setup-hook
    magit-mode-hook)
  "Hooks to which `forge-bug-reference-setup' is added.
This variable has to be customized before `forge' is loaded."

  :group 'forge
  :options '(find-file-hook
             forge-post-mode-hook
             git-commit-setup-hook
             magit-mode-hook)
