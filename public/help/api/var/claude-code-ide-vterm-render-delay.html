Variable: claude-code-ide-vterm-render-delay

claude-code-ide-vterm-render-delay is a customizable variable defined in claude-code-ide.el.

Value

0.005

Documentation

Rendering optimization delay for batched terminal updates.

This parameter defines the collection window for related terminal update sequences when anti-flicker mode is active. The timing balances visual smoothness with interaction responsiveness.

The 0.005 second (5ms) default delivers optimal rendering quality with imperceptible latency.
