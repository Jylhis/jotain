Variable: async-process-noquery-on-exit

async-process-noquery-on-exit is a variable defined in async.el.

Value

nil

Documentation

Used as the :noquery argument to make-process.

Intended to be let-bound around a call to async-start or async-start-process. If non-nil, the child Emacs process will be silently killed if the user exits the parent Emacs.
