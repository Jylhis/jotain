Variable: eca-chat--welcome-shown

eca-chat--welcome-shown is a buffer-local variable defined in eca-chat.el.

Documentation

Non-nil when this buffer still displays the welcome banner.

Set when the welcome message and resume link are inserted in eca-chat-mode; cleared by eca-chat--clear. Used to decide whether the first user prompt should erase the banner first.
