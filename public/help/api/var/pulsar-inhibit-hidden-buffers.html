Variable: pulsar-inhibit-hidden-buffers

pulsar-inhibit-hidden-buffers is a customizable variable defined in pulsar.el.

Value

t

Documentation

When non-nil, pulsar-mode(var)/pulsar-mode(fun) will not be enabled in hidden buffers.

Hidden buffers are those whose name starts with a space character. They are not meant to be touched by the user, so pulsing in them is not necessary. This option is provided in case there is some scenario where pulsing makes sense.

This variable was added, or its default value changed, in pulsar version 1.2.0.
