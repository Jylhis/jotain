Variable: auto-dark-polling-interval-seconds

auto-dark-polling-interval-seconds is a customizable variable defined in auto-dark.el.

Value

5

Documentation

The number of seconds between which to poll for dark mode state.

Emacs must be restarted for this value to take effect.
