Variable: async-library

async-library is a variable defined in async.el.

Value

nil

Documentation

Cache async library path.

It is useful only when you run multiple async processes in a loop, to avoid calling many times locate-library which is costly. This variable should be let bound around an async-start call and not used globally. Should be found with locate-library.
