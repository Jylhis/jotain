Variable: gnuplot-delay

gnuplot-delay is a customizable variable defined in gnuplot.el.

Value

0.02

Documentation

Amount of time to delay before sending a new line to gnuplot.

This is needed so that the the line is not written in the gnuplot buffer in advance of its prompt. Increase this number if the prompts and lines are displayed out of order.
