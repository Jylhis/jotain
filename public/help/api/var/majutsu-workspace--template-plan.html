Variable: majutsu-workspace--template-plan

majutsu-workspace--template-plan is a variable defined in majutsu-workspace.el.

Value

(:fields (current name change-id commit-id desc root) :specs

		     majutsu-workspace--parse-current)
	  (:template [:name] :parse identity)
