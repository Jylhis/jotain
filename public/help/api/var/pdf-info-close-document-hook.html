Variable: pdf-info-close-document-hook

pdf-info-close-document-hook is a customizable variable defined in pdf-info.el.

Value

nil

Documentation

A hook ran after a document was closed in the server.

The hook is run in the documents buffer, if it exists. Otherwise in a with-temp-buffer form.
