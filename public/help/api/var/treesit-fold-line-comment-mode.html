Variable: treesit-fold-line-comment-mode

treesit-fold-line-comment-mode is a buffer-local variable defined in treesit-fold.el.

Documentation

Non-nil if Treesit-Fold-Line-Comment mode is enabled.

Use the command treesit-fold-line-comment-mode(var)/treesit-fold-line-comment-mode(fun) to change this variable.

Key Bindings

This command is not in any keymaps.

(define-minor-mode treesit-fold-line-comment-mode
  "Enable line comment folding."
  :group 'treesit-fold
  :init-value nil
  (when (bound-and-true-p treesit-fold-indicators-mode)
    (treesit-fold-indicators-refresh)))
