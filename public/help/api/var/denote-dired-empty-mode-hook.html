Variable: denote-dired-empty-mode-hook

denote-dired-empty-mode-hook is a variable defined in denote.el.

Value

nil

Documentation

Hook run after entering denote-dired-empty-mode.

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
