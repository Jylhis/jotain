Variable: haskell-interactive-prompt-cont

haskell-interactive-prompt-cont is a customizable variable defined in haskell-customize.el.

Value

"λ| "

Documentation

The multi-line prompt to use.

The default is haskell-interactive-prompt with the last > replaced with |.

Aliases

haskell-interactive-prompt2 (obsolete since 17.1)
