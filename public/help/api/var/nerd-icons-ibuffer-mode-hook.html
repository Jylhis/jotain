Variable: nerd-icons-ibuffer-mode-hook

nerd-icons-ibuffer-mode-hook is a customizable variable defined in nerd-icons-ibuffer.el.

Value

nil

Documentation

Hook run after entering or leaving nerd-icons-ibuffer-mode(var)/nerd-icons-ibuffer-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
