Documentation

Alist of tree-sitter languages and major modes supported by Combobulate.

Each entry must be of the form

   (LANGUAGE MAJOR-MODES MINOR-MODE-FN)

Where LANGUAGE is the tree-sitter language symbol; MAJOR-MODES is a list of supported major modes; and MINOR-MODE-FN is a minor mode function that Combobulate must use for that language and those major modes.
