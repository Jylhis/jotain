Variable: org-appear-mode-hook

org-appear-mode-hook is a customizable variable defined in org-appear.el.

Value

nil

Documentation

Hook run after entering or leaving org-appear-mode(var)/org-appear-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
