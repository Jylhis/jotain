Variable: vundo-compact-display

vundo-compact-display is a customizable variable defined in vundo.el.

Value

nil

Documentation

Show a more compact tree display if non-nil.

Basically we display

    ○─○─○ instead of ○──○──○
    │ └─● │ └──●
    ├─○ ├──○
    └─○ └──○
