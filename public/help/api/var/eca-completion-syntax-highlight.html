Variable: eca-completion-syntax-highlight

eca-completion-syntax-highlight is a customizable variable defined in eca-completion.el.

Value

t

Documentation

Whether to syntax-highlight the inline completion overlay.

When non-nil, the suggestion is fontified using the buffer's major-mode before being displayed as ghost text, and eca-completion-overlay-face is composed on top of those font-lock faces (rather than overriding them) so syntax colors remain visible.
