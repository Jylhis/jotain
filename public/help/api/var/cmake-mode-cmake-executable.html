Variable: cmake-mode-cmake-executable

cmake-mode-cmake-executable is a customizable variable defined in cmake-mode.el.

Value

"cmake"

Documentation

*The name of the cmake executable.

This can be either absolute or looked up in $PATH. You can also set the path with these commands:
 (setenv "PATH" (concat (getenv "PATH") ";C:\\\\Program Files\\\\CMake 2.8\\\\bin"))
 (setenv "PATH" (concat (getenv "PATH") ":/usr/local/cmake/bin"))
