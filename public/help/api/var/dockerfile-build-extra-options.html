Variable: dockerfile-build-extra-options

dockerfile-build-extra-options is a customizable variable defined in dockerfile-mode.el.

Value

nil

Documentation

Extra command-line options to send to docker build.

Use this variable to add custom command-line switches not covered by existing dockerfile-build-* variables.

Example:
(setq-default dockerfile-build-extra-options "--network host")
