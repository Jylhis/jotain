Variable: magit-commit-ask-to-stage

magit-commit-ask-to-stage is a customizable variable defined in magit-commit.el.

Value

verbose

Documentation

Whether to ask to stage everything when committing and nothing is staged.

This variable was added, or its default value changed, in magit version 2.3.0.

Source Code

;; Defined in /nix/store/k1kwf51rwhxc2r08pvslpgkhbnr4nxnr-emacs-packages-deps/share/emacs/site-lisp/elpa/magit-20260822.1158/magit-commit.el
;;; Options

(defcustom magit-commit-ask-to-stage 'verbose
  "Whether to ask to stage everything when committing and nothing is staged."
  :package-version '(magit . "2.3.0")
  :group 'magit-commands
  :type '(choice (const :tag "Ask" t)
                 (const :tag "Ask showing diff" verbose)
                 (const :tag "Stage without confirmation" stage)
                 (const :tag "Don't ask" nil)))
