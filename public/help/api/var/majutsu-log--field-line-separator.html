Variable: majutsu-log--field-line-separator

majutsu-log--field-line-separator is a variable defined in majutsu-log.el.

Value

""

Documentation

Encoded newline separator used inside template field payloads.

Log records are transported as single lines, then this separator is decoded back to literal newlines after field splitting.
