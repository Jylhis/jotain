Variable: dtrt-indent-max-offset

dtrt-indent-max-offset is a customizable variable defined in dtrt-indent.el.

Value

8

Documentation

*Maximum indentation offset that can be guessed.

You usually don't want to tinker with this - setting it to a lower value than 8 means that the (unfortunately) rather common indentation offset of 8 will no longer be guessed. Setting it to a higher value than 8 should not be harmful, but source files using more than 8 spaces per indentation level are very rare.
