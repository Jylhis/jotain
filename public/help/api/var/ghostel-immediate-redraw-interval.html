Variable: ghostel-immediate-redraw-interval

ghostel-immediate-redraw-interval is a customizable variable defined in ghostel.el.

Value

0.05

Documentation

Maximum seconds since last keystroke for immediate redraw.

Output arriving within this interval of a ghostel--send-string call is considered interactive echo and redrawn immediately.
