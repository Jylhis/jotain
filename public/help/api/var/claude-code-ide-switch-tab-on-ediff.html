Variable: claude-code-ide-switch-tab-on-ediff

claude-code-ide-switch-tab-on-ediff is a customizable variable defined in claude-code-ide.el.

Value

t

Documentation

Whether to switch back to Claude's original tab when opening ediff.

When non-nil (default), Claude Code will switch back to the tab where Claude Code was started when opening an ediff session. When nil, the current tab remains active when ediff is opened.
