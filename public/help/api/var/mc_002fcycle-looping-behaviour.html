Variable: mc/cycle-looping-behaviour

mc/cycle-looping-behaviour is a customizable variable defined in mc-cycle-cursors.el.

Value

continue

Documentation

What to do if asked to cycle beyond the last cursor or before the first cursor.

Source Code

;; Defined in /nix/store/bwmgnvnjv89idk13xc843r24h4ygwjwz-emacs-packages-deps/share/emacs/site-lisp/elpa/multiple-cursors-20260419.931/mc-cycle-cursors.el
(defcustom mc/cycle-looping-behaviour 'continue
  "What to do if asked to cycle beyond the last cursor or before the first cursor."
  :type '(radio (const :tag "Loop around to beginning/end of document." continue)
                (const :tag "Warn and then loop around." warn)
                (const :tag "Signal an error." error)
                (const :tag "Don't loop." stop))
  :group 'multiple-cursors)
