Documentation

Component separator character.

The character used for separating components in the input. The presence of this separator character will inhibit quitting at completion boundaries, so that any further characters can be entered. To enter the first separator character, call corfu-insert-separator (bound to M-SPC by default). Useful for multi-component completion styles such as Orderless.
