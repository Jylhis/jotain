Variable: eca-chat-inline--viewport-mode

eca-chat-inline--viewport-mode is a buffer-local variable defined in eca-chat-inline.el.

Documentation

Non-nil if Eca-Chat-Inline--Viewport mode is enabled.

Use the command eca-chat-inline--viewport-mode(var)/eca-chat-inline--viewport-mode(fun) to change this variable.

Key Bindings

This command is not in any keymaps.
