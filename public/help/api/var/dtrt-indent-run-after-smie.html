Variable: dtrt-indent-run-after-smie

dtrt-indent-run-after-smie is a customizable variable defined in dtrt-indent.el.

Value

nil

Documentation

*Non-nil means to run dtrt-indent even in modes using SMIE.

Normally, dtrt-indent will detect SMIE-based modes and delegate to smie-config-guess. However, dtrt-indent configures some variables that SMIE does not (e.g. the contents of dtrt-indent-hook-generic-mapping-list), so you may want to run dtrt-indent even in SMIE-based modes. You can do so by enabling this setting.
