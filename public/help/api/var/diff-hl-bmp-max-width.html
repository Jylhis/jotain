Variable: diff-hl-bmp-max-width

diff-hl-bmp-max-width is a customizable variable defined in diff-hl.el.

Value

16

Documentation

Maximum width of the fringe indicator bitmaps, in pixels.

The bitmap width is decided by comparing this value with the current width of the fringe. When the fringe is hidden, this value is also used.
