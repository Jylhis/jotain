Variable: ghostel-command-start-functions

ghostel-command-start-functions is a customizable variable defined in ghostel.el.

Value

nil

Documentation

Hook run when a shell command starts running (OSC 133 C marker).

Each function is called with one argument: the buffer.

Requires shell integration; this fires from the shell's preexec/DEBUG hook just before the user's command runs. Useful for distinguishing a real command's lifecycle from prompt redraws (which emit D markers without a preceding C).

Errors in hook functions are demoted to messages via with-demoted-errors (re-signalled when debug-on-error is non-nil so the debugger can fire).
