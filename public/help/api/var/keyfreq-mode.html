Variable: keyfreq-mode

keyfreq-mode is a customizable variable defined in keyfreq.el.

Value

nil

Documentation

Non-nil if Keyfreq mode is enabled.

See the keyfreq-mode(var)/keyfreq-mode(fun) command for a description of this minor mode. Setting this variable directly does not take effect; either customize it (see the info node (emacs)Easy Customization) or call the function keyfreq-mode(var)/keyfreq-mode(fun).

Key Bindings

This command is not in any keymaps.

;;;###autoload
(define-minor-mode keyfreq-mode
  "Keyfreq mode records number of times each command was
called making it possible to access usage statistics through
various keyfreq-* functions."
  :global t
  :init-value nil
  :lighter nil
  :keymap nil
  :group 'keyfreq

  (if keyfreq-mode
      (add-hook 'pre-command-hook 'keyfreq-pre-command-hook)
    (remove-hook 'pre-command-hook 'keyfreq-pre-command-hook)))
