Variable: magit-log-merged-commit-count

magit-log-merged-commit-count is a customizable variable defined in magit-log.el.

Value

20

Documentation

How many surrounding commits to show for magit-log-merged.

magit-log-merged will shows approximately half of this number commits before and half after.

This variable was added, or its default value changed, in magit version 3.3.0.
