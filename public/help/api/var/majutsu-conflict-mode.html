Variable: majutsu-conflict-mode

majutsu-conflict-mode is a buffer-local variable defined in majutsu-conflict.el.

Documentation

Non-nil if Majutsu-Conflict mode is enabled.

Use the command majutsu-conflict-mode(var)/majutsu-conflict-mode(fun) to change this variable.

Key Bindings

This command is not in any keymaps.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-conflict.el
;;;###autoload
(define-minor-mode majutsu-conflict-mode
  "Minor mode for jj conflict markers.
Provides highlighting and navigation for conflict regions."
  :lighter " Conflict"
  :keymap majutsu-conflict-mode-map
  (if majutsu-conflict-mode
      (majutsu-conflict--enable)
    (majutsu-conflict--disable)))
