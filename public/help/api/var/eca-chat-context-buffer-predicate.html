Variable: eca-chat-context-buffer-predicate

eca-chat-context-buffer-predicate is a customizable variable defined in eca-chat-context.el.

Value

eca-chat-context-buffer-include-p

Documentation

Predicate deciding if a buffer can be offered as text context.

Called with a buffer, should return non-nil to offer it in the
@ completion and DWIM context commands.
