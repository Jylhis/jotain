Variable: logview-copy-visible-text-only

logview-copy-visible-text-only is a customizable variable defined in logview.el.

Value

t

Documentation

Whether to copy, kill, etc. only visible selected text.

Standard Emacs behavior is to copy even invisible text, but that typically doesn't make much sense with filtering.

To temporarily change this on per-buffer basis type \<logview-mode-map>M-x logview-toggle-copy-visible-text-only (logview-toggle-copy-visible-text-only).
