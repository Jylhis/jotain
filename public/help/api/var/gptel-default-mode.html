Variable: gptel-default-mode

gptel-default-mode is a customizable variable defined in gptel.el.

Value

text-mode

Documentation

The default major mode for dedicated chat buffers.

If markdown-mode is available, it is used. Otherwise gptel defaults to text-mode.
