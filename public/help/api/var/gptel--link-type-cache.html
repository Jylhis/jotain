Variable: gptel--link-type-cache

gptel--link-type-cache is a variable defined in gptel-request.el.

Value

nil

Documentation

Cache of checks for binary files.

Each alist entry maps an absolute file path to a cons cell of the form (t . binaryp), where binaryp is non-nil if the file is binary-encoded.
