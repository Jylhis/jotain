Variable: magit-todos-list-mode-hook

magit-todos-list-mode-hook is a variable defined in magit-todos.el.

Value

nil

Documentation

Hook run after entering magit-todos-list-mode.

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
