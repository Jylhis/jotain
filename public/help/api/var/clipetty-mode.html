Variable: clipetty-mode

clipetty-mode is a buffer-local variable defined in clipetty.el.

Documentation

Non-nil if Clipetty mode is enabled.

Use the command clipetty-mode(var)/clipetty-mode(fun) to change this variable.

Key Bindings

This command is not in any keymaps.

;;;###autoload
(define-minor-mode clipetty-mode
  "Minor mode to send every kill from a TTY frame to the system clipboard."
  :lighter " Clp"
  :init-value nil
  :global nil
  (if clipetty-mode
      (add-function :around (local 'interprogram-cut-function) #'clipetty-cut)
    (remove-function (local 'interprogram-cut-function) #'clipetty-cut)))
