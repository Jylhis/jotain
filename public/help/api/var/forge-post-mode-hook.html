Variable: forge-post-mode-hook

forge-post-mode-hook is a customizable variable defined in forge-post.el.

Value

(visual-line-mode(var)/visual-line-mode(fun)
 turn-on-flyspell)

Documentation

Hook run after entering Forge-Post mode.

This hook is run early on while setting up a buffer to edit a post. If you want to make changes to the already populated buffer, instead use forge-edit-post-hook.

This variable was added, or its default value changed, in forge version 0.2.0.

(defcustom forge-post-mode-hook
  '(visual-line-mode
    turn-on-flyspell)
  "Hook run after entering Forge-Post mode.
This hook is run early on while setting up a buffer to edit a post.
If you want to make changes to the already populated buffer, instead
use `forge-edit-post-hook'."
  :package-version '(forge . "0.2.0")
  :group 'forge
  :type 'hook
  :options '(visual-line-mode
             turn-on-flyspell))
