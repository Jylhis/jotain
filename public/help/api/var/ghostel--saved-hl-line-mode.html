Variable: ghostel--saved-hl-line-mode

ghostel--saved-hl-line-mode is a buffer-local variable defined in ghostel.el.

Documentation

Non-nil if line highlighting was active when ghostel-mode suppressed it.

Covers both global-hl-line-mode(var)/global-hl-line-mode(fun) and buffer-local hl-line-mode.
