Variable: markdown-wiki-link-search-type

markdown-wiki-link-search-type is a customizable variable defined in markdown-mode.el.

Value

nil

Documentation

A list of options for searching for markdown wiki links.

sub-directories: search for wiki link targets in sub directories parent-directories: search for wiki link targets in parent directories project: search for wiki link targets under project root

This variable was added, or its default value changed, in markdown-mode version 2.5.

;; Defined in /nix/store/s4bvm9kdxw2hixpjqbqj3gi5xi7kr8wh-emacs-packages-deps/share/emacs/site-lisp/elpa/markdown-mode-20260827.909/markdown-mode.el
(defcustom markdown-wiki-link-search-type nil
  "A list of options for searching for markdown wiki links.

`sub-directories': search for wiki link targets in sub directories
`parent-directories': search for wiki link targets in parent directories
`project': search for wiki link targets under project root"
  :group 'markdown
  :type '(set
          (const :tag "search wiki link from subdirectories" sub-directories)
          (const :tag "search wiki link from parent directories" parent-directories)
          (const :tag "search wiki link under project root" project))
  :package-version '(markdown-mode . "2.5"))
