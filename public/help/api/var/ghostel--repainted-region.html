Variable: ghostel--repainted-region

ghostel--repainted-region is a buffer-local variable defined in ghostel.el.

Documentation

Buffer range the last redraw rewrote, as a (MIN . MAX) cons, or nil.

Published by the renderer, which inserts every character of terminal output. Every redraw that renders sets it: nil when it painted nothing, so the value never outlives the redraw that produced it.
