Variable: global-hl-todo-mode-hook

global-hl-todo-mode-hook is a customizable variable defined in hl-todo.el.

Value

nil

Documentation

Hook run after entering or leaving global-hl-todo-mode(var)/global-hl-todo-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
