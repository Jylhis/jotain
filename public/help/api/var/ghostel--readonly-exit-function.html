Variable: ghostel--readonly-exit-function

ghostel--readonly-exit-function is a buffer-local variable defined in ghostel.el.

Documentation

When non-nil, ghostel-readonly-exit calls this instead of the default restore.

The function is responsible for the full post-exit state (input mode, keymap, read-only flag, mode line, redraw). Set in compilation-style compile buffers, whose exit must restore the view keymap rather than a terminal input mode.
