Variable: org-roam-node-template-prefixes

org-roam-node-template-prefixes is a customizable variable defined in org-roam-node.el.

Value

(("tags" . "#") ("todo" . "t:"))

Documentation

Prefixes for each of the node's properties.

This is used in conjunction with org-roam-node-display-template: in minibuffer completions the node properties will be prefixed with strings in this variable, acting as a query language of sorts.

For example, if a node has tags ("foo" "bar") and the alist has the entry ("tags" . "#"), these will appear as
"#foo #bar".
