Variable: gptel-curl-extra-args

gptel-curl-extra-args is a customizable variable defined in gptel-request.el.

Value

nil

Documentation

Extra arguments to pass to Curl when sending queries.

This should be a list of strings, each one a Curl command line argument. Note that these should not conflict with the options in gptel-curl--common-args, which gptel requires for correct functioning.

If you want to specify extra arguments only when using a specific gptel backend, use the :curl-args slot of the backend instead. See gptel-backend.
