Variable: dape-update-ui-hooks

dape-update-ui-hooks is an alias and customizable for dape-update-ui-hook, defined in dape.el.

This variable is obsolete since 0.13.0; use dape-update-ui-hook instead.

Value

(dape-inlay-hints-update dape-info-update)

Documentation

Called when it's sensible to refresh UI.

Aliases

dape-update-ui-hook
