Variable: bazel-command-options

bazel-command-options is a customizable variable defined in bazel.el.

Value

nil

Documentation

Command-line options for all Bazel commands.

The commands ‘bazel-build’, ‘bazel-test’ etc. insert these options after the command (‘build’, ‘test’, etc.); see URL
‘https://bazel.build/docs/user-manual#build-options’. To add
startup options, use the option ‘bazel-command’ instead. Instead of specifying startup options here, it’s typically preferable to use a ‘.bazelrc’ file instead; see URL
‘https://bazel.build/run/bazelrc’. Use this option only for
Bazel options that are really Emacs-specific, such as
‘--tool_tag=emacs’.
