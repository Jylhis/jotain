Variable: gnuplot-insertions-show-help-flag

gnuplot-insertions-show-help-flag is a customizable variable defined in gnuplot.el.

Value

nil

Documentation

Non-nil means to display certain help messages automatically.

These messages are shown after menu insertion of gnuplot commands.
