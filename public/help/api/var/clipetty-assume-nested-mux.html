Variable: clipetty-assume-nested-mux

clipetty-assume-nested-mux is a customizable variable defined in clipetty.el.

Value

nil

Documentation

Non-nil means if we detect a remote multiplexer, we assume it's nested.

Nesting is the practice of running a terminal multiplexer inside a terminal multiplexer, which is what you'd be doing if you ran tmux both locally and on remote hosts you SSH into.
