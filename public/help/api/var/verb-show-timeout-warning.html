Variable: verb-show-timeout-warning

verb-show-timeout-warning is a customizable variable defined in verb.el.

Value

10.0

Documentation

Reasonable max duration (s) for an HTTP request.

Indicates the number of seconds to wait after an HTTP request is sent to warn the user about a possible network timeout. When set to nil, don't show any warnings.
