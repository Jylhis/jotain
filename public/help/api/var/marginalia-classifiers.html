Variable: marginalia-classifiers

marginalia-classifiers is a customizable variable defined in marginalia.el.

Value

(marginalia-classify-by-command-name
 marginalia-classify-original-category marginalia-classify-by-prompt
 marginalia-classify-symbol)

Documentation

List of functions to determine current completion category.

Each function should take no arguments and return a symbol indicating the category, or nil to indicate it could not determine it.
