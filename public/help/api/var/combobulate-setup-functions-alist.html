Documentation

Alist of setup functions to call when M-x combobulate-mode (combobulate-mode) is enabled.

Because tree-sitter-enabled modes are different from the ordinary ones, you may wish to customize major-mode-remap-alist to silently treat the older modes as their newer TS-enabled counterparts.
