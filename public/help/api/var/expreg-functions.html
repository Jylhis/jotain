Variable: expreg-functions

expreg-functions is a buffer-local variable defined in expreg.el.

Documentation

A list of expansion functions.

Each function is called with no arguments and should return a list of (BEG . END). The list don’t have to be sorted, and can have duplicates. It’s also fine to include invalid regions, such as ones where BEG equals END, etc, they’ll be filtered out by
‘expreg--filter-regions’.

The function could move point, but shouldn’t return any scan-error, like end-of-buffer, or unbalanced parentheses, etc.
