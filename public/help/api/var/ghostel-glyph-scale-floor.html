Variable: ghostel-glyph-scale-floor

ghostel-glyph-scale-floor is a customizable and buffer-local variable defined in ghostel.el.

Documentation

Minimum scale for glyphs whose font metrics don't fit the cell.

0.0 (default) preserves strict grid alignment. 1.0 disables
shrinking entirely so CJK and other fallback glyphs render at natural size, potentially making rows slightly taller and cells slightly wider.

shrinking entirely so CJK and other fallback glyphs render at

  :type '(float 0.0 1.0)
  :local t)
