Variable: dired-narrow-mode-hook

dired-narrow-mode-hook is a customizable variable defined in dired-narrow.el.

Value

nil

Documentation

Hook run after entering or leaving dired-narrow-mode(var)/dired-narrow-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
