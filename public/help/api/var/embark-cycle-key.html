Variable: embark-cycle-key

embark-cycle-key is a customizable variable defined in embark.el.

Value

nil

Documentation

Key used for embark-cycle.

If the key is set to nil it defaults to the global binding of embark-act. The key must be a string which is accepted by key-valid-p.
