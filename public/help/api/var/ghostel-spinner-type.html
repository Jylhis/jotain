Variable: ghostel-spinner-type

ghostel-spinner-type is a customizable variable defined in ghostel.el.

Value

progress-bar

Documentation

Spinner style used by ghostel-spinner-progress.

Passed to spinner-create as its first argument; see spinner-types in spinner.el for the full list (e.g. progress-bar, horizontal-moving, vertical-breathing). Only consulted when ghostel-progress-function is ghostel-spinner-progress.
