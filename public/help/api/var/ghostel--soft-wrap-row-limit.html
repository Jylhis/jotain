Variable: ghostel--soft-wrap-row-limit

ghostel--soft-wrap-row-limit is a variable defined in ghostel-links.el.

Value

50

Documentation

How many rows ghostel--detect-urls joins into one logical line.

Output like a minified JSON blob is a single line megabytes long; joining all of it would cost more than any link is worth, and would hand the patterns a match candidate long enough to overflow the regexp matcher. Past the limit a row break is kept and joining starts over, so a link straddling that break resolves to one side of it.
