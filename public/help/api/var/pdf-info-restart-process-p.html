Variable: pdf-info-restart-process-p

pdf-info-restart-process-p is a customizable variable defined in pdf-info.el.

Value

ask

Documentation

What to do when the epdfinfo server died.

This should be one of nil -- do nothing,
t -- automatically restart it or
ask -- ask whether to restart or not.

If it is ask, the server quits and you answer no, this variable is set to nil.

(defcustom pdf-info-restart-process-p 'ask
  "What to do when the epdfinfo server died.

This should be one of
nil -- do nothing,
t   -- automatically restart it or
ask -- ask whether to restart or not.

If it is `ask', the server quits and you answer no, this variable
is set to nil."
  :type '(choice (const :tag "Do nothing" nil)
                 (const :tag "Restart silently" t)
                 (const :tag "Always ask" ask)))
