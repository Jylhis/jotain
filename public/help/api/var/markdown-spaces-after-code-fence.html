Variable: markdown-spaces-after-code-fence

markdown-spaces-after-code-fence is a customizable variable defined in markdown-mode.el.

Value

1

Documentation

Number of space characters to insert after a code fence.

C-c C-s C (markdown-insert-gfm-code-block) inserts this many spaces between an opening code fence and an info string.

This variable was added, or its default value changed, in markdown-mode version 2.3.
