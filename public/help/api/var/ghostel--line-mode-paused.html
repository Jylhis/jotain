Variable: ghostel--line-mode-paused

ghostel--line-mode-paused is a buffer-local variable defined in ghostel-line-mode.el.

Documentation

Sentinel plist marking line mode as paused, awaiting alt-screen exit.

Nil when not paused. Set by ghostel--line-mode-pause (auto-pause when an alt-screen TUI starts) and by ghostel--line-mode-defer-entry
(when the user invokes ghostel-line-mode while a TUI is already
running); consumed by ghostel--line-mode-try-resume once alt-screen has gone off and a prompt is locatable. Cleared when the user manually switches input modes so a later alt-screen exit does not surprise them by force-resuming line mode.
