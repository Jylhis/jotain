Variable: eca-chat-content-received-functions

eca-chat-content-received-functions is a variable defined in eca-chat.el.

Value

(eca-chat-inline--content-received)

Documentation

Abnormal hook run for every chat/contentReceived notification.

Each function is called with SESSION and PARAMS (the raw notification plist carrying :chatId, :role and :content) before the content is rendered in the chat buffer. Errors in subscribers are demoted so they never break chat rendering. Used by integrations such as eca-chat-inline to mirror streamed content elsewhere.
