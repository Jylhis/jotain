Variable: magit-todos-update

magit-todos-update is a customizable variable defined in magit-todos.el.

Value

t

Documentation

When or how often to scan for to-dos.

When set to manual updates, the list can be updated with the command magit-todos-update(var)/magit-todos-update(fun). When caching is enabled, scan for items whenever the Magit status buffer is refreshed and at least N seconds have passed since the last scan; otherwise, use cached items.

Key Bindings

This command is not in any keymaps.
