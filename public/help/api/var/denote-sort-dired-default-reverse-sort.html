Variable: denote-sort-dired-default-reverse-sort

denote-sort-dired-default-reverse-sort is a customizable variable defined in denote.el.

Value

nil

Documentation

If non-nil, reverse the sorting order by default.

This is used only if denote-sort-dired-extra-prompts omits the minibuffer prompt that asks for a reverse sort or not.

This variable was added, or its default value changed, in denote version 3.1.0.
