Variable: dape-repl-mode-hook

dape-repl-mode-hook is a variable defined in dape.el.

Value

nil

Documentation

Hook run after entering dape-repl-mode.

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
