Variable: indent-bars-ppss-syntax-table

indent-bars-ppss-syntax-table is a buffer-local variable defined in indent-bars.el.

Documentation

A special syntax table for identifying strings and list contexts.

This is used only if indent-bars-no-descend-lists and/or indent-bars-no-descend-string is non-nil. A special syntax table can be configured to override the mode-local table, e.g. to add or remove open/close paren characters.
