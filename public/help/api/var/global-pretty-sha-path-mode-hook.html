Variable: global-pretty-sha-path-mode-hook

global-pretty-sha-path-mode-hook is a customizable variable defined in pretty-sha-path.el.

Value

nil

Documentation

Hook run after entering or leaving global-pretty-sha-path-mode(var)/global-pretty-sha-path-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
