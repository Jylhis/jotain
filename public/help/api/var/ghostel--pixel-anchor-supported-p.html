Variable: ghostel--pixel-anchor-supported-p

ghostel--pixel-anchor-supported-p is a variable defined in ghostel.el.

Value

t

Documentation

Non-nil when window-text-pixel-size accepts the cons FROM form.

Emacs 29 shipped the cons FROM that ghostel--pixel-anchor needs together with IGNORE-LINE-AT-END (arity 7), so the arity probes for it; fboundp would not, since the function predates the form. Emacs 28 falls back to line-count anchoring, exact for ghostel's uniform row heights.

Source Code

;; Defined in /nix/store/1jkgkg7y6y6hp0xia3dsmcl5zaj0bnhq-emacs-packages-deps/share/emacs/site-lisp/ghostel.el
(defconst ghostel--pixel-anchor-supported-p
  (let ((max-args (cdr (subr-arity (symbol-function 'window-text-pixel-size)))))
    (and (integerp max-args) (>= max-args 7)))
