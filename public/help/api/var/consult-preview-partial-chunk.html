Variable: consult-preview-partial-chunk

consult-preview-partial-chunk is a customizable variable defined in consult.el.

Value

10240

Documentation

Partial preview chunk size in bytes.

If a file is larger than consult-preview-partial-size only the chunk from the beginning of the file is previewed.
