Variable: consult-compile-multi-mode

consult-compile-multi-mode is a customizable variable defined in consult-compile-multi.el.

Value

nil

Documentation

Non-nil if Consult-Compile-Multi mode is enabled.

See the consult-compile-multi-mode(var)/consult-compile-multi-mode(fun) command for a description of this minor mode. Setting this variable directly does not take effect; either customize it (see the info node (emacs)Easy Customization) or call the function consult-compile-multi-mode(var)/consult-compile-multi-mode(fun).

Key Bindings

This command is not in any keymaps.

;;; Minor mode to enable consult.

;;;###autoload
(define-minor-mode consult-compile-multi-mode
  "Run `compile-multi' with `consult'."
  :global t :group 'consult-compile-multi
  (setq compile-multi-interface
        (if consult-compile-multi-mode
            'consult
          nil)))
