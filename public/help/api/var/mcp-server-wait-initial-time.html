Variable: mcp-server-wait-initial-time

mcp-server-wait-initial-time is a customizable variable defined in mcp.el.

Value

2

Documentation

Seconds to wait after server init before fetching MCP resources.

This delay is applied after server initialization completes, but before requesting tools, prompts and resources. Gives the server time to fully initialize all components before handling requests.
