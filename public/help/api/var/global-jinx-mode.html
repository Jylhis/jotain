Variable: global-jinx-mode

global-jinx-mode is a customizable variable defined in jinx.el.

Value

nil

Documentation

Non-nil if Global Jinx mode is enabled.

See the global-jinx-mode(var)/global-jinx-mode(fun) command for a description of this minor mode. Setting this variable directly does not take effect; either customize it (see the info node (emacs)Easy Customization) or call the function global-jinx-mode(var)/global-jinx-mode(fun).

Key Bindings

This command is not in any keymaps.
