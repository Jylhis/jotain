Variable: pulsar-resolve-pulse-function-aliases

pulsar-resolve-pulse-function-aliases is a customizable variable defined in pulsar.el.

Value

t

Documentation

When non-nil, resolve function aliases in pulsar function lists.

The affected lists are pulsar-pulse-functions and pulsar-pulse-region-functions. This allows pulsar to respect, e.g., tab-new "parent," tab-bar-new-tab, and vice-versa, enabling Pulsar to respect tab-bar-new-tab alias tab-new.

This variable was added, or its default value changed, in pulsar version 1.1.0.
