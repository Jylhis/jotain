Variable: gptel--request-alist

gptel--request-alist is a variable defined in gptel-request.el.

Value

nil

Documentation

Alist of active gptel requests.

Each entry has the form (PROCESS . (FSM ABORT-CLOSURE)) If the ABORT-CLOSURE is called, it must abort the PROCESS.
