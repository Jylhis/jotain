Variable: gptel-post-response-hook

gptel-post-response-hook is an alias and customizable for gptel-post-response-functions, defined in gptel.el.

This variable is obsolete since 0.6.0; use gptel-post-response-functions instead.

Value

(pulse-momentary-highlight-region)

Documentation

Post-response functions are now called with two arguments: the start and end buffer positions of the response.

Aliases

gptel-post-response-functions
