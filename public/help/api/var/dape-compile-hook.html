Variable: dape-compile-hook

dape-compile-hook is a customizable variable defined in dape.el.

Value

nil

Documentation

Called after dape compilation finishes.

The hook is run with one argument, the compilation buffer when compilation is successful.

Aliases

dape-compile-compile-hooks (obsolete since 0.13.0)
