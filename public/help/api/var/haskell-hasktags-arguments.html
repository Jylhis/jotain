Variable: haskell-hasktags-arguments

haskell-hasktags-arguments is a customizable variable defined in haskell-cabal.el.

Value

("-e" "-x")

Documentation

Additional arguments for hasktags executable.

By default these are:

-e - generate ETAGS file
-x - generate additional information in CTAGS file.
