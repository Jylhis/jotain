Variable: rectangular-region-mode-hook

rectangular-region-mode-hook is a customizable variable defined in rectangular-region-mode.el.

Value

nil

Documentation

Hook run after entering or leaving rectangular-region-mode(var)/rectangular-region-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
