Variable: ghostel--line-mode-on-alt-screen

ghostel--line-mode-on-alt-screen is a buffer-local variable defined in ghostel-line-mode.el.

Documentation

Non-nil when line mode was entered deliberately on the alt screen.

Set by ghostel--line-mode-enter; tells ghostel--line-mode-pre-redraw not to auto-pause line mode merely because the alt screen is up. Cleared by ghostel--line-mode-teardown.
