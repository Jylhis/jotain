Variable: diredfl-mode

diredfl-mode is a buffer-local variable defined in diredfl.el.

Documentation

Non-nil if Diredfl mode is enabled.

Use the command diredfl-mode(var)/diredfl-mode(fun) to change this variable.

Key Bindings

This command is not in any keymaps.

;;;###autoload
(define-minor-mode diredfl-mode
  "Enable additional font locking in `dired-mode'."
  :global nil
  (setq font-lock-defaults
        (if diredfl-mode
            '((dired-font-lock-keywords
               dired-font-lock-keywords
               diredfl-font-lock-keywords-1)
              t nil nil beginning-of-line)
          '(dired-font-lock-keywords t nil nil beginning-of-line)))
  (font-lock-refresh-defaults))
