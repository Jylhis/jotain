Variable: org-modern-todo-faces

org-modern-todo-faces is a customizable variable defined in org-modern.el.

Value

nil

Documentation

Faces for todo keywords.

This is an alist, with todo keywords in the car and faces in the cdr. Example:

  (setq org-modern-todo-faces
    (quote (("TODO" :background "red" :foreground "yellow"))))

(defcustom org-modern-todo-faces nil
  "Faces for todo keywords.
This is an alist, with todo keywords in the car and faces in the
cdr.  Example:

  (setq org-modern-todo-faces
    (quote ((\"TODO\" :background \"red\" :foreground \"yellow\"))))"
  :type '(repeat
          (cons (choice
                  (string :tag "Keyword")
                  (const :tag "Default" t))
                (sexp :tag "Face   "))))
