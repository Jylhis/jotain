Variable: diff-hl-async-inhibit-functions

diff-hl-async-inhibit-functions is a customizable variable defined in diff-hl.el.

Value

(diff-hl-with-editor-p
 file-remote-p)

Documentation

Functions to call to check whether asychronous method should be disabled.

When diff-hl-update-async is non-nil, these functions are called in turn and passed the value default-directory.

If any returns non-nil, diff-hl-update will run synchronously anyway.
