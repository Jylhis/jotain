Variable: denote-use-directory

denote-use-directory is a variable defined in denote.el.

Value

nil

Documentation

The directory to be used in a note creation command.

See the documentation of denote for acceptable values. This variable is ignored if nil.

Only ever let bind this, otherwise the directory will always be the same.
