Variable: gnuplot-buffer-max-size

gnuplot-buffer-max-size is a customizable variable defined in gnuplot.el.

Value

1000

Documentation

The maximum size in lines of the gnuplot process buffer.

Each time text is written in the gnuplot process buffer, lines are trimmed from the beginning of the buffer so that the buffer is this many lines long. The lines are deleted after the most recent lines were interpretted by gnuplot. Setting to 0 turns off this feature.
