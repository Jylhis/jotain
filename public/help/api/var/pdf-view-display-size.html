Variable: pdf-view-display-size

pdf-view-display-size is a customizable and buffer-local variable defined in pdf-view.el.

Documentation

The desired size of displayed pages.

This may be one of fit-height, fit-width, fit-page or a number as a scale factor applied to the document's size. Any other value behaves like fit-width.

(defcustom pdf-view-display-size 'fit-width
  "The desired size of displayed pages.

This may be one of `fit-height', `fit-width', `fit-page' or a
number as a scale factor applied to the document's size.  Any
other value behaves like `fit-width'."
  :group 'pdf-view
  :type '(choice number
                 (const fit-height)
                 (const fit-width)
                 (const fit-page)))
