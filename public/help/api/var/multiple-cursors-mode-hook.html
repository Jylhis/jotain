Variable: multiple-cursors-mode-hook

multiple-cursors-mode-hook is a customizable variable defined in multiple-cursors-core.el.

Value

nil

Documentation

Hook run after entering or leaving multiple-cursors-mode(var)/multiple-cursors-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
