Variable: verb-base-headers

verb-base-headers is a customizable variable defined in verb.el.

Value

nil

Documentation

Set of HTTP headers used as base when reading request specs.

These headers will be included by default in requests, but still may be overridden by re-specifying them somewhere in the headings hierarchy.
