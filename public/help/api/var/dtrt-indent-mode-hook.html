Variable: dtrt-indent-mode-hook

dtrt-indent-mode-hook is a customizable variable defined in dtrt-indent.el.

Value

(dtrt-indent-mode--set-explicitly(var)/dtrt-indent-mode--set-explicitly(fun))

Documentation

Hook run after entering or leaving dtrt-indent-mode(var)/dtrt-indent-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
