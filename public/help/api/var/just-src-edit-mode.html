Variable: just-src-edit-mode

just-src-edit-mode is a buffer-local variable defined in just-ts-mode.el.

Documentation

Non-nil if Just-Src-Edit mode is enabled.

Use the command just-src-edit-mode(var)/just-src-edit-mode(fun) to change this variable.

Key Bindings

This command is not in any keymaps.
