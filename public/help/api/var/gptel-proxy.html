Variable: gptel-proxy

gptel-proxy is a customizable variable defined in gptel-request.el.

Value

""

Documentation

Path to a proxy to use for gptel interactions.

Passed to curl via --proxy arg, for example "proxy.yourorg.com:80" Leave it empty if you don't use a proxy.
