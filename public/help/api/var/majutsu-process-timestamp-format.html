Variable: majutsu-process-timestamp-format

majutsu-process-timestamp-format is a customizable variable defined in majutsu-process.el.

Value

nil

Documentation

Format of timestamp for each process section in the process buffer.

When non-nil, pass this to format-time-string and insert the result in the heading of each process section.
