Variable: tuareg-indent-align-with-first-arg

tuareg-indent-align-with-first-arg is a customizable variable defined in tuareg.el.

Value

nil

Documentation

Non-nil if indentation should try to align arguments on the first one.

With a non-nil value you get

    let x = List.map (fun x -> 5)
                     my list

whereas with a nil value you get

    let x = List.map (fun x -> 5)
              my list
