Variable: haskell-language-extensions

haskell-language-extensions is a customizable variable defined in haskell-customize.el.

Value

nil

Documentation

Language extensions in use. Should be in format: -XFoo,
-XNoFoo etc. The idea is that various tools written with HSE (or
any haskell-mode code that needs to be aware of syntactical properties; such as an indentation mode) that don't know what extensions to use can use this variable. Examples: hlint, hindent, structured-haskell-mode, tool-de-jour, etc.

You can set this per-project with a .dir-locals.el file
