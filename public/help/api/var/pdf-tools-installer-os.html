Variable: pdf-tools-installer-os

pdf-tools-installer-os is a customizable variable defined in pdf-tools.el.

Value

nil

Documentation

Specifies which installer to use.

If nil, the installer is chosen automatically. This variable is useful if you have multiple installers present on your system (e.g. nix on arch linux)
