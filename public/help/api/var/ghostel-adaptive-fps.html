Variable: ghostel-adaptive-fps

ghostel-adaptive-fps is a customizable variable defined in ghostel.el.

Value

t

Documentation

Use adaptive frame rate for terminal redraw.

When non-nil, use a shorter initial delay for responsive interactive feedback and stop the timer entirely when idle. When nil, use the fixed ghostel-timer-delay unconditionally.
