Variable: tuareg-font-lock-symbols

tuareg-font-lock-symbols is a customizable variable defined in tuareg.el.

This variable is obsolete since Emacs-24.4; use prettify-symbols-mode(var)/prettify-symbols-mode(fun) instead.

Value

nil

Documentation

Display fun and -> and such using symbols in fonts.

This may sound like a neat trick, but note that it can change the alignment and can thus lead to surprises. On recent Emacs >= 24.4, use prettify-symbols-mode(var)/prettify-symbols-mode(fun).
