Variable: denote-dired-directories-include-subdirectories

denote-dired-directories-include-subdirectories is a customizable variable defined in denote.el.

Value

nil

Documentation

If non-nil denote-dired-directories also affects all subdirectories.

Otherwise denote-dired-directories works only with exact matches.

This variable was added, or its default value changed, in denote version 2.2.0.
