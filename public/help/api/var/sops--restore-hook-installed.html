Variable: sops--restore-hook-installed

sops--restore-hook-installed is a variable defined in sops.el.

Value

nil

Documentation

Non-nil once the major-mode-change restoration hook is installed.

Set on first sops-mode(var)/sops-mode(fun) enable so a bare (require \=sops)' adds no global hook; see sops--restore-after-major-mode-change.
