Variable: pretty-sha-path-flush-function

pretty-sha-path-flush-function is a variable defined in pretty-sha-path.el.

Value

font-lock-flush

Documentation

Function used to refontify buffer.

This function is called without arguments after enabling/disabling pretty-sha-path-mode(var)/pretty-sha-path-mode(fun). If nil, do nothing.
