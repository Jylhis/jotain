Documentation

Regex matched against the cursor row to detect a password prompt.

Used when the libghostty heuristic (canonical mode + echo off via ghostel--pty-password-input-p) can't decide on its own - that is, when the local pty's termios was unreadable, or when ghostel--remote-shell-p indicates a remote shell whose echo state isn't reflected on the local pty.
