Variable: apheleia-format-after-save-in-progress

apheleia-format-after-save-in-progress is a variable defined in apheleia.el.

Value

nil

Documentation

Prevent apheleia-format-after-save from being called recursively.

This will be locally bound to t while apheleia-format-after-save is operating, to prevent an infinite loop.
