Documentation

Alist mapping Haskell symbols to chars.

Each element has the form (STRING . COMPONENTS) or (STRING COMPONENTS PREDICATE).

STRING is the Haskell symbol. COMPONENTS is a representation specification suitable as an argument to compose-region. PREDICATE if present is a function of one argument (the start position of the symbol) which should return non-nil if this mapping should be disabled at that position.
