Variable: tempel-path

tempel-path is a customizable variable defined in tempel.el.

Value

"/build/tmp.MoMkjYBiRd/.emacs.d/templates"

Documentation

A file or a list of template files.

The file paths can contain wildcards, e.g.,
"~/.config/emacs/templates/*/*.eld", which matches all
lisp-data-mode files in the subdirectories of the templates directory.
