Variable: diredfl-global-mode

diredfl-global-mode is a customizable variable defined in diredfl.el.

Value

nil

Documentation

Non-nil if Diredfl-Global mode is enabled.

See the diredfl-global-mode(var)/diredfl-global-mode(fun) command for a description of this minor mode. Setting this variable directly does not take effect; either customize it (see the info node (emacs)Easy Customization) or call the function diredfl-global-mode(var)/diredfl-global-mode(fun).

Key Bindings

This command is not in any keymaps.
