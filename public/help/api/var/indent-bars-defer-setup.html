Variable: indent-bars-defer-setup

indent-bars-defer-setup is a customizable variable defined in indent-bars.el.

Value

nil

Documentation

Whether to defer indent-bars setup to after-change-major-mode-hook.

Setting up indent-bars correctly in a buffer requires correct information about the indentation spacing and tabs vs. spaces. If these are set after indent-bars is initialized, via another minor mode, or in file or directory-local variables, this can lead to incorrect behavior. In these cases, it can be useful to defer indent-bars setup to the after-change-major-mode-hook. Enable this only if you only experience problems, and enable indent-bars via major mode hooks (e.g. python-base-mode).
