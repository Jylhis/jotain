Variable: ghostel-tramp-default-method

ghostel-tramp-default-method is a customizable variable defined in ghostel.el.

Value

nil

Documentation

TRAMP method for constructing remote paths from OSC 7 directory reports.

When directory tracking (OSC 7) reports a hostname that does not match the local machine and default-directory has no existing remote prefix, this method is used to build the TRAMP path (e.g. "/ssh:host:/path"). When nil, falls back to tramp-default-method.
