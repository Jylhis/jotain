Variable: bazel--buildifier-type

bazel--buildifier-type is a buffer-local variable defined in bazel.el.

Documentation

Type of the file that the current buffer visits.

This must be a symbol and a valid value for the Buildifier -type flag. See URL
‘https://github.com/bazelbuild/buildtools/blob/v6.3.3/buildifier/config/validation.go#L27’.
If nil, don’t pass a -type flag to Buildifier.
