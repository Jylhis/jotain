Variable: combobulate-mode

combobulate-mode is a buffer-local variable defined in combobulate-setup.el.

Documentation

Non-nil if the language-specific minor mode is enabled in this buffer.

Note that combobulate-mode(var)/combobulate-mode(fun) is not a true minor mode: it is a helper command that calls the proper Combobulate minor mode suitable for the major mode of the current buffer.

Key Bindings

This command is not in any keymaps.
