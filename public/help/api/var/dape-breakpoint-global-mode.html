Variable: dape-breakpoint-global-mode

dape-breakpoint-global-mode is a customizable variable defined in dape.el.

Value

nil

Documentation

Non-nil if Dape-Breakpoint-Global mode is enabled.

See the dape-breakpoint-global-mode(var)/dape-breakpoint-global-mode(fun) command for a description of this minor mode. Setting this variable directly does not take effect; either customize it (see the info node (emacs)Easy Customization) or call the function dape-breakpoint-global-mode(var)/dape-breakpoint-global-mode(fun).

Key Bindings

This command is not in any keymaps.
