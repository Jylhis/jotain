Variable: dtrt-indent-global-mode

dtrt-indent-global-mode is a customizable variable defined in dtrt-indent.el.

Value

nil

Documentation

Non-nil if Dtrt-Indent-Global mode is enabled.

See the dtrt-indent-global-mode(var)/dtrt-indent-global-mode(fun) command for a description of this minor mode. Setting this variable directly does not take effect; either customize it (see the info node (emacs)Easy Customization) or call the function dtrt-indent-global-mode(var)/dtrt-indent-global-mode(fun).

Key Bindings

This command is not in any keymaps.
