Variable: global-majutsu-jjdescription-mode

global-majutsu-jjdescription-mode is a customizable variable defined in majutsu-jjdescription.el.

Value

t

Documentation

Non-nil if Global Majutsu-Jjdescription mode is enabled.

See the global-majutsu-jjdescription-mode(var)/global-majutsu-jjdescription-mode(fun) command for a description of this minor mode. Setting this variable directly does not take effect; either customize it (see the info node (emacs)Easy Customization) or call the function global-majutsu-jjdescription-mode(var)/global-majutsu-jjdescription-mode(fun).

Key Bindings

This command is not in any keymaps.

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-jjdescription.el
(define-minor-mode global-majutsu-jjdescription-mode
  "Edit JJ description buffers.

This global mode arranges for `majutsu-jjdescription-setup' to run
when a JJ description file is opened."
  :group 'majutsu
  :type 'boolean
  :global t
  :init-value t
  :initialize
  (lambda (symbol exp)
    (custom-initialize-default symbol exp)
    (majutsu-jjdescription--set-global-hooks (symbol-value symbol)))
  (majutsu-jjdescription--set-global-hooks global-majutsu-jjdescription-mode))
