Variable: keyfreq-autosave-timeout

keyfreq-autosave-timeout is a customizable variable defined in keyfreq.el.

Value

600

Documentation

How often in seconds keyfreq-table should be saved when keyfreq-autosave-mode(var)/keyfreq-autosave-mode(fun) is enabled. Setting this value will take effect only after (re)enabling keyfreq-autosave-mode(var)/keyfreq-autosave-mode(fun).
