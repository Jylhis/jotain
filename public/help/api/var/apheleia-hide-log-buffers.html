Variable: apheleia-hide-log-buffers

apheleia-hide-log-buffers is a customizable variable defined in apheleia-log.el.

Value

nil

Documentation

Non-nil means log buffers will be hidden.

Hidden buffers have names that begin with a space, and do not appear in switch-to-buffer unless you type in a space manually.
