Variable: ghostel--inhibit-insert-forwarding

ghostel--inhibit-insert-forwarding is a buffer-local variable defined in ghostel.el.

Documentation

Non-nil disables insert forwarding (e.g. compilation-style runs).

Also suppresses automatic input-mode switching (point-leave, mark-activation).
