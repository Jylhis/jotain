Variable: dape-many-windows-hook

dape-many-windows-hook is a customizable variable defined in dape.el.

Value

nil

Documentation

Hook run after entering or leaving dape-many-windows(var)/dape-many-windows(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
