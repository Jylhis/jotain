Variable: claude-code-ide-enable-mcp-server

claude-code-ide-enable-mcp-server is a customizable variable defined in claude-code-ide-mcp-server.el.

Value

nil

Documentation

Enable MCP tools server for exposing Emacs functions to Claude.

When enabled, a separate MCP server will be started to provide Claude with access to configured Emacs functions.
