Variable: go-test-compilation-error-regexp-alist

go-test-compilation-error-regexp-alist is a customizable variable defined in gotest.el.

Value

(go-test-testing go-test-testify go-test-gopanic go-test-compile
		 go-test-linkage)

Documentation

Alist that specifies how to match errors in go test output.

The default set of regexps should only match the output of the standard go tool, which includes compile, link, stacktrace (panic) and package testing. There is support for matching error output from other packages, such as testify.

Only file names ending in .go will be matched by default.

Instead of an alist element, you can use a symbol, which is looked up in go-testcompilation-error-regexp-alist-alist.

See also: compilation-error-regexp-alist.
