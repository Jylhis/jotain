Variable: ghostel--pre-readonly-mode

ghostel--pre-readonly-mode is a buffer-local variable defined in ghostel.el.

Documentation

Input mode to restore when exiting a read-only mode.

Set on every entry to copy or Emacs mode and cleared on exit. Tracks the mode the user was in immediately before the most recent read-only entry, so Emacs → copy → exit returns to Emacs mode and copy → Emacs → exit returns to copy.
