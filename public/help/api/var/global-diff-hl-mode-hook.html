Variable: global-diff-hl-mode-hook

global-diff-hl-mode-hook is a customizable variable defined in diff-hl.el.

Value

nil

Documentation

Hook run after entering or leaving global-diff-hl-mode(var)/global-diff-hl-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
