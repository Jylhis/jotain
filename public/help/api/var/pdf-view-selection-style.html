Variable: pdf-view-selection-style

pdf-view-selection-style is a customizable variable defined in pdf-view.el.

Value

word

Documentation

The current default selection style.

Must be one of glyph, word, or line.

(defcustom pdf-view-selection-style 'word
  "The current default selection style.

Must be one of `glyph', `word', or `line'."
  :group 'pdf-view
  :type '(choice (const glyph)
                 (const word)
                 (const line)))
