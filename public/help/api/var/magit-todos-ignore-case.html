Variable: magit-todos-ignore-case

magit-todos-ignore-case is a customizable variable defined in magit-todos.el.

Value

nil

Documentation

Upcase keywords found in files.

If nil, a keyword like "Todo:" will not be shown. upcase can be a relatively expensive function, so this can be disabled if necessary.
