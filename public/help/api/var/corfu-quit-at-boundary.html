Variable: corfu-quit-at-boundary

corfu-quit-at-boundary is a customizable variable defined in corfu.el.

Value

separator

Documentation

Automatically quit at completion boundary.

nil: Never quit at completion boundary. t: Always quit at completion boundary. separator: Quit at boundary if no corfu-separator has been inserted.
