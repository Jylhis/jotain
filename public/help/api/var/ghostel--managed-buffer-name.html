Variable: ghostel--managed-buffer-name

ghostel--managed-buffer-name is a buffer-local variable defined in ghostel.el.

Documentation

Last buffer name managed by Ghostel title tracking.

Nil means title tracking has not claimed the buffer yet. Clearing this variable re-enables automatic renaming for the next title update.
