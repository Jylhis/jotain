Variable: denote-id-format

denote-id-format is an alias for denote-date-identifier-format, defined in denote.el.

This variable is obsolete since 4.1.0; use denote-date-identifier-format instead.

Value

"%Y%m%dT%H%M%S"

Documentation

Format of ID prefix of a note's filename.

The note's ID is derived from the date and time of its creation.

Aliases

denote-date-identifier-format
