Variable: gptel-api-key

gptel-api-key is a customizable variable defined in gptel-request.el.

Value

gptel-api-key-from-auth-source

Documentation

An API key (string) for the default LLM backend.

OpenAI by default.

Can also be a function of no arguments that returns an API key (more secure) for the active backend.
