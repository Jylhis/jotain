Variable: async-prompt-for-password

async-prompt-for-password is a customizable variable defined in async.el.

Value

t

Documentation

Prompt for password in parent Emacs if needed when non nil.

When this is nil child Emacs will hang forever when a user interaction for password is required unless a password is stored in a ".authinfo" file.
