Variable: magit-auto-revert-tracked-only

magit-auto-revert-tracked-only is a customizable variable defined in magit-autorevert.el.

Value

t

Documentation

Whether magit-auto-revert-mode(var)/magit-auto-revert-mode(fun) only reverts tracked files.

This variable was added, or its default value changed, in magit version 2.4.0.

Source Code

;; Defined in /nix/store/k1kwf51rwhxc2r08pvslpgkhbnr4nxnr-emacs-packages-deps/share/emacs/site-lisp/elpa/magit-20260822.1158/magit-autorevert.el
(defcustom magit-auto-revert-tracked-only t
  "Whether `magit-auto-revert-mode' only reverts tracked files."
  :package-version '(magit . "2.4.0")
  :group 'magit-auto-revert
  :type 'boolean
  :set (lambda (var val)
         (set var val)
         (when (and (bound-and-true-p magit-auto-revert-mode)
                    (featurep 'magit-autorevert))
           (magit-auto-revert-mode -1)
           (magit-auto-revert-mode))))
