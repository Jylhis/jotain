Variable: majutsu-diff-refine-max-chars

majutsu-diff-refine-max-chars is a customizable variable defined in majutsu-diff.el.

Value

4000

Documentation

Skip word refinement when a hunk spans more than this many characters.

Set to nil to always refine.

Source Code

;; Defined in /nix/store/bz86lcx20lhz4l1xw4qxxfrpzz1ibl7c-emacs-packages-deps/share/emacs/site-lisp/majutsu-diff.el
(defcustom majutsu-diff-refine-max-chars 4000
  "Skip word refinement when a hunk spans more than this many characters.
Set to nil to always refine."
  :group 'majutsu
  :type '(choice (const :tag "No limit" nil)
          (integer :tag "Max characters")))
