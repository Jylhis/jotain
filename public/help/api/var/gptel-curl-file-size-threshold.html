Variable: gptel-curl-file-size-threshold

gptel-curl-file-size-threshold is a customizable variable defined in gptel-request.el.

This variable is obsolete since 0.9.9.6; gptel now sends request contents via stdin, no longer subject to command-line argument limits. gptel-curl-file-size-threshold and the related temporary-file mechanism are no longer needed.

Value

130000

Documentation

Size threshold for using file input with Curl.

Specifies the size threshold for when to use a temporary file to pass data to Curl in gptel queries. If the size of the data to be sent in bytes exceeds this threshold, the data is written to a temporary file and passed to Curl using the --data-binary option with a file reference. Otherwise, the data is passed directly as a command-line argument.

The default of #x8000 on Windows comes from Microsoft's documentation.
