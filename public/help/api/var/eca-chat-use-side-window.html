Variable: eca-chat-use-side-window

eca-chat-use-side-window is a customizable variable defined in eca-chat.el.

Value

t

Documentation

Whether to display ECA chat in a dedicated side window.

When non-nil (default), ECA chat opens in a dedicated side window. When nil, it opens in a regular directional window. This setting is ignored when eca-chat-window-side is nil, which displays the chat in the selected window.
