Variable: eca-chat-tab-line

eca-chat-tab-line is a customizable variable defined in eca-chat.el.

Value

t

Documentation

Whether to show a tab line with chat tabs at the top of each chat window.

When non-nil, enables tab-line-mode in chat buffers with tabs for every open chat in the session. Each tab shows the chat status
(pending approval, loading), title and elapsed time.
