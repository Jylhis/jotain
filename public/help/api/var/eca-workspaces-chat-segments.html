Variable: eca-workspaces-chat-segments

eca-workspaces-chat-segments is a customizable variable defined in eca-workspaces.el.

Value

((status . 3) (title . 36) (elapsed . 11) (cost . 9) (model . 24)
 (hint))

Documentation

Segments rendered for each chat row and their padded widths.

Each entry is (SEGMENT . WIDTH). SEGMENT is one of the built-in symbols status, title, elapsed, cost, model, hint, or a function called with the chat buffer that returns a string. WIDTH nil means render unpadded.
