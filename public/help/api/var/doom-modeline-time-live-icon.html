Variable: doom-modeline-time-live-icon

doom-modeline-time-live-icon is a customizable variable defined in doom-modeline-core.el.

Value

t

Documentation

Whether display the live icons of time.

It respects option doom-modeline-icon(var)/doom-modeline-icon(fun) and option doom-modeline-time-icon(var)/doom-modeline-time-icon(fun).
