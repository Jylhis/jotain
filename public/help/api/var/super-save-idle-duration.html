Variable: super-save-idle-duration

super-save-idle-duration is a customizable variable defined in super-save.el.

Value

5

Documentation

Delay in seconds for which Emacs has to be idle before auto-saving.

See super-save-auto-save-when-idle.

This variable was added, or its default value changed, in super-save version 0.2.0.
