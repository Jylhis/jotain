Variable: logview-filter-edit-mode-hook

logview-filter-edit-mode-hook is a variable defined in logview.el.

Value

nil

Documentation

Hook run after entering logview-filter-edit-mode.

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
