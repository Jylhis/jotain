Variable: combobulate-query-mode-hook

combobulate-query-mode-hook is a variable defined in combobulate-query.el.

Value

nil

Documentation

Hook run after entering combobulate-query-mode.

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
