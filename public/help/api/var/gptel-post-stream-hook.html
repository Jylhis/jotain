Variable: gptel-post-stream-hook

gptel-post-stream-hook is a customizable variable defined in gptel.el.

Value

nil

Documentation

Hook run after each insertion of the LLM's streaming response.

This hook is called in the buffer from which the prompt was sent to the LLM, and after a text insertion.
