Variable: gptel-pre-response-hook

gptel-pre-response-hook is a customizable variable defined in gptel.el.

Value

nil

Documentation

Hook run before inserting the LLM response into the current buffer.

This hook is called in the buffer where the LLM response will be inserted.

Note: this hook only runs if the request succeeds.
