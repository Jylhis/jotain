Variable: eca-chat-session-status-changed-functions

eca-chat-session-status-changed-functions is a variable defined in eca-chat.el.

Value

(eca-workspaces--schedule-refresh
 eca-chat-inline--session-status-changed)

Documentation

Abnormal hook run when a session aggregated status may have changed.

Each function is called with a single argument, the session. It is invoked on transitions that can change eca-chat-session-status (a chat starting or finishing, a tool call requesting or resolving an approval, a question being asked or answered). Subscribers should be idempotent: the hook may run even when the status is unchanged. Used by integrations such as the Doom workspaces tabline to refresh external indicators.
