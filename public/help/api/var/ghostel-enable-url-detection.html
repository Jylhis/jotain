Variable: ghostel-enable-url-detection

ghostel-enable-url-detection is a customizable variable defined in ghostel-links.el.

Value

t

Documentation

Automatically detect and linkify URLs in terminal output.

When non-nil, plain-text URLs (http:// and https://) are made clickable even if the program did not use OSC 8 hyperlink escapes.
