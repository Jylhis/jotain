Variable: verb-response-body-mode-hook

verb-response-body-mode-hook is a customizable variable defined in verb.el.

Value

nil

Documentation

Hook run after entering or leaving verb-response-body-mode(var)/verb-response-body-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
