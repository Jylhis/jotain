Variable: clipetty-screen-regexp

clipetty-screen-regexp is a customizable variable defined in clipetty.el.

Value

"^screen"

Documentation

This regexp is matched against TERM to test for the presence of GNU screen.

If you've configured GNU screen to use an unusual terminal type, you can change this regular expression so Clipetty will recognize when you're running in screen.
