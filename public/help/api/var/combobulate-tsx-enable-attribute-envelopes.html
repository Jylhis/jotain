Variable: combobulate-tsx-enable-attribute-envelopes

combobulate-tsx-enable-attribute-envelopes is a customizable variable defined in combobulate-js-ts.el.

Value

t

Documentation

Pick a sensible value for a JSX attribute when you type =.

This uses attribute-envelope-alist to determine the attribute and the corresponding envelope to insert.
