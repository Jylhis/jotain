Variable: eca-settings-tab-line

eca-settings-tab-line is a customizable variable defined in eca-settings.el.

Value

t

Documentation

Whether to show a tab line in settings buffers.

When non-nil, enables tab-line-mode in settings buffers with tabs for each registered settings panel.
