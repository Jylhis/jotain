Variable: denote-ignore-region-in-denote-command

denote-ignore-region-in-denote-command is a variable defined in denote.el.

Value

nil

Documentation

If non-nil, the region is ignored by the denote command.

The denote command uses the region as the default title when prompted for a title. When this variable is non-nil, the denote command ignores the region. This variable is useful in commands that have their own way of handling the region.
