Variable: majutsu-diff-whitespace-max-chars

majutsu-diff-whitespace-max-chars is a customizable variable defined in majutsu-diff.el.

Value

12000

Documentation

Skip whitespace painting for hunks larger than this many chars.

Set to nil to always paint whitespace inside hunks.

Source Code

;; Defined in /nix/store/i798c3janm00vmzb7j0mbswxzazy63fp-emacs-packages-deps/share/emacs/site-lisp/majutsu-diff.el
(defcustom majutsu-diff-whitespace-max-chars 12000
  "Skip whitespace painting for hunks larger than this many chars.
Set to nil to always paint whitespace inside hunks."
  :group 'majutsu
  :type '(choice (const :tag "No limit" nil)
          (integer :tag "Max characters")))
