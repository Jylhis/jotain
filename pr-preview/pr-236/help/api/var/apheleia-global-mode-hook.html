Variable: apheleia-global-mode-hook

apheleia-global-mode-hook is a customizable variable defined in apheleia.el.

Value

nil

Documentation

Hook run after entering or leaving apheleia-global-mode(var)/apheleia-global-mode(fun).

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
