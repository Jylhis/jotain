Variable: eca-chat--kill-guarded-commands

eca-chat--kill-guarded-commands is a variable defined in eca-chat.el.

Value

(kill-line kill-visual-line kill-whole-line kill-region kill-sentence
	   backward-kill-sentence kill-sexp backward-kill-sexp
	   kill-paragraph backward-kill-paragraph)

Documentation

Kill commands advised with eca-chat--key-pressed-kill.

Unlike the char/word deletions handled by eca-chat--key-pressed-deletion, these move by line, sentence, sexp or paragraph, so from inside the prompt field they could cross the prompt/context markup above it (see #305).
