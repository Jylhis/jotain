Variable: dockerfile-use-buildkit

dockerfile-use-buildkit is a customizable variable defined in dockerfile-mode.el.

Value

nil

Documentation

Use Docker buildkit for building images?

This is the new buildsystem for docker, and in time it will replace the old one but for now it has to be explicitly enabled to work. It is supported from docker 18.09
