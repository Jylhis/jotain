Variable: dockerfile-mode-hook

dockerfile-mode-hook is a variable defined in dockerfile-mode.el.

Value

nil

Documentation

Hook run after entering dockerfile-mode.

No problems result if this variable is not bound. add-hook automatically binds it. (This is true for all hook variables.)
