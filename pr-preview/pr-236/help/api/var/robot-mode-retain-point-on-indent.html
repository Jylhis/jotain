Variable: robot-mode-retain-point-on-indent

robot-mode-retain-point-on-indent is a customizable variable defined in robot-mode.el.

Value

nil

Documentation

If the point position is after the indentation, retain it when indenting a line. Otherwise move point always back-to-indentation.
