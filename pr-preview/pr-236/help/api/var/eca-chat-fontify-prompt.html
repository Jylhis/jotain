Variable: eca-chat-fontify-prompt

eca-chat-fontify-prompt is a customizable variable defined in eca-chat.el.

Value

t

Documentation

Whether ECA chat applies Markdown fontification to prompt text.

When non-nil, preserve the historical prompt rendering behavior. When nil, prompt edits skip Markdown block scans over chat history. Set this to nil if typing in large ECA chat buffers is slow.
