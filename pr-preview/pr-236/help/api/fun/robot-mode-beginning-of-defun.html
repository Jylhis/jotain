Function: robot-mode-beginning-of-defun

robot-mode-beginning-of-defun is a natively compiled function defined in robot-mode.el.

Signature

(robot-mode-beginning-of-defun)

Documentation

Move the point to the beginning of the current defun.

Defuns are the steps of a keyword, test or task. This is used as beginning-of-defun-function of the mode.
