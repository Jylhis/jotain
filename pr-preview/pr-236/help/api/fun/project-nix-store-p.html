Function: project-nix-store-p

project-nix-store-p is a natively compiled function defined in project-nix-store.el.

Signature

(project-nix-store-p PROJECT)

Documentation

Return t if PROJECT is a store project.

Source Code

;; Defined in /nix/store/m0ikdzd7gfw395413q6w4n716fs0xz2g-emacs-packages-deps/share/emacs/site-lisp/project-nix-store.el
;; `project-nix-store-p' is called by `project-remember-project' via `project-list-exclude'.
;; It is possible to call `project-nix-store-p' before the autoloaded `project-nix-store-try'.
;; So autoload it, too.
;;;###autoload
(defun project-nix-store-p (project)
  "Return t if PROJECT is a store project."
  (eq (car-safe project) 'nix-store))
