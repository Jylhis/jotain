Function: ghostel--rebuild-mode-syntax-table

ghostel--rebuild-mode-syntax-table is a natively compiled function defined in ghostel.el.

Signature

(ghostel--rebuild-mode-syntax-table)

Documentation

Realize ghostel-word-boundary-string into ghostel-mode-syntax-table.

Mutates the table in place, so live ghostel buffers keep their buffer-local syntax-table reference and see customization changes.
