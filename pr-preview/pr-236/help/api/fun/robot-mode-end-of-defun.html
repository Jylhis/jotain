Function: robot-mode-end-of-defun

robot-mode-end-of-defun is a natively compiled function defined in robot-mode.el.

Signature

(robot-mode-end-of-defun)

Documentation

Move the point to the end of the current defun.

Defuns are the steps of a keyword, test or task. This is used as end-of-defun-function of the mode.

(defun robot-mode-end-of-defun ()
  "Move the point to the end of the current defun.

Defuns are the steps of a keyword, test or task. This is used as
`end-of-defun-function' of the mode."
  (end-of-line)
  (if (re-search-forward "^[[:graph:]]" nil t)
      (beginning-of-line)
    (goto-char (point-max))))
